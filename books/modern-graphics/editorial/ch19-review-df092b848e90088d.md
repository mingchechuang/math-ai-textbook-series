# 審稿結果

## 一、必須修正的實質錯誤

### 1. 球面穩定求根公式不完整，且程式會回傳錯誤的最近交點

**原句／公式：**

> $$ t_{near} = \frac{-b - \text{sign}(b)\sqrt{\Delta}}{2a} $$

以及：

```python
if b > 0:
    t1 = (-b - sqrt_delta) / (2 * a)
else:
    t1 = (-b + sqrt_delta) / (2 * a)

if t1 > epsilon:
    return t1
```

**錯誤原因：**

這個穩定式算出的不是固定意義下的 `near`，而是刻意避免抵消的其中一根。另一根必須由根的乘積求出，最後再排序。

例如章中球體：

- $b=-10$
- $\sqrt{\Delta}=2$

程式走 `else`，得到

$$
t_1=\frac{10+2}{2}=6
$$

並立即回傳 6；但正確最近交點是 4。因此目前 `intersect_sphere` 與函式註解「返回最小的正 $t$」矛盾。

**修法：**

採用完整穩定求根：

```python
q = -0.5 * (b + np.copysign(sqrt_delta, b))
if q == 0.0:
    roots = [-b / (2.0 * a)]
else:
    roots = [q / a, c / q]

roots.sort()
for root in roots:
    if t_min < root < t_max:
        return root
return None
```

其中 `t_min`、`t_max` 應成為明確參數，不要以單一 `epsilon` 同時代表所有容差。

---

### 2. 抵消誤差的符號說明寫反

**原句：**

> 當 $b$ 為負時，使用 $\frac{-b-\sqrt{\Delta}}{2a}$ 可能導致抵消誤差。

這句可以成立；但後文又寫：

> 若 $b$ 為負且 $\sqrt{\Delta}\approx-b$，則 $-b+\sqrt{\Delta}$ 會發生抵消。

**錯誤原因：**

若 $b<0$，則 $-b>0$、$\sqrt{\Delta}>0$，所以 $-b+\sqrt{\Delta}$ 是同號相加，不是抵消。會抵消的是

$$
-b-\sqrt{\Delta}.
$$

**修法：**

統一改成：

> 當兩個大小接近、符號相反的數相加時會發生消去誤差。若 $b<0$ 且 $\sqrt{\Delta}\approx-b$，直接計算 $-b-\sqrt{\Delta}$ 會抵消；若 $b>0$，則 $-b+\sqrt{\Delta}$ 可能抵消。

---

### 3. 球面 epsilon 範例的手算與實際程式不一致

**原句：**

> $t_1=(-(-2)-2)/2=0$

> 預期 `t_with_eps` 應接近 2.0。

> 預期 `t_no_eps` 可能因浮點誤差返回一個極小值或 None。

**錯誤原因：**

對該程式，$b=-2$，會走：

```python
t1 = (-b + sqrt_delta) / (2*a)
```

因此直接得到

$$
t_1=\frac{2+2}{2}=2.
$$

所以按稿中程式，`epsilon=0.0` 與 `epsilon=1e-4` 都會回傳 2.0，不會得到 0、極小值或 `None`。稿件也不能聲稱這段示範了 epsilon 的效果。

**正確預期輸出：**

```text
Sphere intersection from surface:
  t (no eps): 2.0
  t (with eps): 2.0

Triangle self-intersection check:
  Hit t: None
```

以上是依程式手算的預期，並非實際執行結果。

**修法：**

若要展示自相交，應建立帶有微小誤差的起點，例如稍微落入表面內，並比較不同 `t_min`；同時說明這是刻意構造的數值測試。純粹從精確球面點向球內射出，本來就應命中另一側 $t=2$，不能把它排除。

---

### 4. 「移除 epsilon 就會命中」不符合目前三角形程式

**原句：**

> 若移除 $\epsilon$，自相交測試會錯誤地報告命中。

**錯誤原因：**

即使呼叫 `epsilon=0`，判斷仍是：

```python
if t_ray > epsilon:
```

而精確共面起點得到 $t_{\rm ray}=0$，條件 $0>0$ 為假，仍不會命中。

**修法：**

改用有意加入誤差的案例，例如起點位於平面下方 $10^{-8}$ m、射線朝 $+Z$，則交點 $t=10^{-8}$：

- `t_min=0` 時命中；
- `t_min=10^{-6}` 時忽略。

並明示 `t_min` 是射線有效區間，不要籠統稱「移除 epsilon」。

---

### 5. 三角形回傳的重心座標順序錯置／未定義清楚

**原句：**

```python
返回 (t, (u, v, w))
u, v, w 為重心座標。
```

```python
w = 1.0 - u - v
return t_ray, (u, v, w)
```

**錯誤原因：**

Möller–Trumbore 中：

$$
\mathbf p=(1-u-v)\mathbf v_0+u\mathbf v_1+v\mathbf v_2.
$$

因此依頂點順序 $(v_0,v_1,v_2)$ 的權重應為

$$
(w_0,w_1,w_2)=(1-u-v,u,v).
$$

目前回傳 `(u, v, w)` 容易被誤認為依頂點順序排列。

**修法：**

回傳：

```python
w0 = 1.0 - u - v
return t_ray, (w0, u, v)
```

或明確寫成具名欄位，避免索引歧義。

---

### 6. 同一個 epsilon 混用了不同維度的量

**可定位處：**

```python
if abs(det) < 1e-8:
```

```python
if u < -epsilon or v < -epsilon ...
```

```python
if t_ray > epsilon:
```

**錯誤原因：**

在方向正規化、頂點以公尺表示時：

- $t_{\rm ray}$ 單位為 m；
- $u,v$ 無因次；
- `det = e1 · (d × e2)` 的單位為 m²。

它們不能共用同一個有物理意義的 epsilon。固定 `1e-8` 的 determinant 判斷也會隨三角形尺度改變。

**修法：**

至少分開命名：

- `t_min`、`t_max`：m；
- `bary_tol`：無因次；
- `det_tol`：依邊長尺度設定，或先拒絕面積過小的三角形，再採相對容差。

平面測試亦須規定 $\mathbf n$ 已正規化，否則 `n·d` 的固定容差會受法線倍率影響。

---

### 7. 零長方向向量未處理

**原句：**

```python
self.direction = direction / np.linalg.norm(direction)
```

**錯誤原因：**

若方向為零向量，會除以零並產生 `NaN`，後續求交結果不可判讀。

**修法：**

```python
length = np.linalg.norm(direction)
if not np.isfinite(length) or length <= 0.0:
    raise ValueError("ray direction must be finite and non-zero")
self.direction = direction / length
```

也應檢查輸入座標是否有限。

---

### 8. 判別式缺乏近零容差，與章題「數值穩健性」不相稱

**原句：**

```python
if delta < 0:
    return None
```

**問題：**

理論相切時 $\Delta=0$，浮點運算可能得到極小負值。直接判無交可能漏掉相切。

**修法：**

使用與係數尺度相關的容差；在 $-\tau_\Delta\le\Delta<0$ 時夾成零，真正小於 $-\tau_\Delta$ 才判無交。不可只給無尺度依據的固定常數。

---

### 9. 法線偏移方向並非永遠是 $+\epsilon\mathbf n$

**原句：**

> $$\mathbf{o}_{new}=\mathbf p+\epsilon\mathbf n$$

**錯誤原因：**

若新射線要往幾何法線反面傳播，固定加 $+\mathbf n$ 可能把起點推到錯誤介質或錯誤表面一側。這在折射、內部出射時尤其明顯。

**修法：**

至少依新射線方向選側：

$$
\mathbf o_{\rm new}
=
\mathbf p+
\operatorname{sign}(\mathbf d_{\rm new}\cdot\mathbf n_g)
\epsilon\mathbf n_g,
$$

其中 $\mathbf n_g$ 是幾何法線。並說明固定 epsilon 是教學簡化，不是所有尺度與浮點位置下都可靠的完整方案。

---

### 10. 三角形繞序的說明錯把雙面求交與背面剔除混在一起

**原句：**

> Möller–Trumbore 依賴 $det$ 的符號。若三角形頂點順序錯誤……可能誤判前後。

**錯誤原因：**

目前程式使用 `abs(det) < ...`，其餘計算保留 `det` 的正負，因此是雙面求交；反轉繞序通常不會因此漏掉同一幾何交點。只有啟用背面剔除時，才會依 `det` 符號拒絕其中一面。

**修法：**

明確區分：

- 雙面：拒絕 `abs(det) <= tol`；
- 只接受正面：依本章繞序及射線定義選擇 `det` 的符號條件。

## 二、內容與驗收缺口

### 1. 未完成章綱要求的小型 ray caster

目前程式只有球與三角形求交示範，沒有：

- 相機／像素射線；
- 最近命中物件選擇；
- 法線或材質著色；
- PPM 輸出；
- 明確影像尺寸與像素索引；
- RGB 範圍或輸出預期。

因此「最小化 CPU Ray Caster」名不副實。應加入可獨立執行的小型影像生成器，並明示像素原點左上、中心採 $(u+0.5,v+0.5)$，相機朝 $-Z$。

### 2. 平面只有公式，沒有程式與測試

章綱要求球／平面／三角形求交，但程式未提供 `intersect_plane`。至少應測：

- 一般命中；
- 平行且不共面；
- 共面；
- 命中位於 `t_min` 外；
- 法線是否已正規化。

共面時不是單一交點，API 必須決定回傳「無唯一交點」或特殊狀態。

### 3. 測試覆蓋不足

指定實驗要求「相切、平行、內部出射與 epsilon」，目前：

- 相切只手算，沒有可靠程式測試；
- 平行沒有程式測試；
- 內部出射只有習題敘述；
- epsilon 示範與程式不一致。

應列出每筆輸入與預期值，並避免聲稱已執行。

### 4. 缺少統一的射線區間

建議所有求交函式統一接受：

```python
t_min: float
t_max: float
```

陰影射線可用：

$$
t_{\max}=\|\mathbf l-\mathbf p\|-\delta,
$$

以排除光源之後的物件。這也比各函式內硬編碼 epsilon 更清楚。

### 5. 陰影函式沒有真正處理表面起點

**原句：**

> 需確保 $p$ 不在任何物體表面，否則需額外 $\epsilon$ 處理。

實際陰影點通常正是在表面上，不能把它排除為前提。應讓函式接收幾何法線，先偏移起點，並使用有限 `t_max`。

## 三、重算關鍵例題

### 球面一般穿越

對 $\mathbf o=(0,0,-5)$、$\mathbf d=(0,0,1)$、$R=1$：

$$
a=1,\quad b=-10,\quad c=24,\quad \Delta=4.
$$

穩定算法：

$$
q=-\frac12\left(b+\operatorname{copysign}(2,b)\right)
=-\frac12(-10-2)=6.
$$

兩根：

$$
t_0=\frac qa=6,\qquad t_1=\frac cq=\frac{24}{6}=4.
$$

排序後為 $(4,6)$，最近有效命中是 $t=4$。這直接證明目前程式提前回傳 6 是錯誤。

### 球面內部出射

取 $\mathbf o=(0,0,0)$、$\mathbf d=(1,0,0)$、$R=1$：

$$
a=1,\quad b=0,\quad c=-1,\quad\Delta=4.
$$

根為：

$$
t=-1,\ 1.
$$

射線區間若為 $(10^{-4},\infty)$，應回傳 $t=1$，交點 $(1,0,0)$，法線 $(1,0,0)$。

### 三角形例題

稿中更正後的向量：

$$
\mathbf q=(0.2,0.2,-1)\times(1,0,0)=(0,-1,-0.2)
$$

是正確的。得到：

$$
u=0.2,\quad v=0.2,\quad t=1.
$$

依頂點順序的重心權重應寫成：

$$
(w_0,w_1,w_2)=(0.6,0.2,0.2).
$$

正文應刪除先算錯再說「等等」的過程，改成乾淨、可核對的推導。

- 習題 4 的基本距離上界概念正確，但缺少法線偏移、`t_min/t_max` API 與端點容差，需修正。

## 五、引用與聲明界線

1. 「Kahan 技巧」目前沒有相應來源，且公式寫法不完整。應補可追溯來源，或只稱「較穩定的二次方程求根寫法」。
2. G1 是變換章，無法直接支持本章球／三角形求交主體；G4 較相關。
3. 「PBRT 推薦」必須指向實際相關章節；現有來源清單不代表已獨立查證。
4. 「$10^{-4}$ 到 $10^{-6}$ 通常安全」過度概括。應改成教學起始值，必須依尺度、資料型別、座標量級及相鄰表面距離驗證。
5. 「安全邊界」容易被誤解為物理安全閾值，建議改稱「數值排除距離」或「射線下界」。

## 六、可選文風建議

- 將變數 `t`（暫存向量）改名為 `tvec`，避免與射線參數 $t$ 混淆。
- 中英文術語首次並列即可，後續統一用「消去誤差」「背面剔除」等名稱。
- `print(f"固定字串")` 不需要 `f` 前綴。
- 章幅明顯未達指定最低正文量，應以平面實作、影像 ray caster、測試表及誤差尺度分析補足，而不是以宣傳案例充字。
- 色彩部分若加入輸出，應明示幾何法線映射到 RGB 只是資料視覺化；若輸出顯示色彩，需區分線性 RGB 與 sRGB。

目前核心球面函式會漏掉最近交點，測試預期亦與程式矛盾，且實驗覆蓋與完整 ray caster 尚未達章綱要求，必須修訂後再審。
