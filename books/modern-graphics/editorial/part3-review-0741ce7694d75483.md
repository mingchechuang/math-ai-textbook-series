## 必須修正

### 1. 第 16 章 Jacobian 開頭仍保留錯誤的單因果敘述

**原句：**

> 分母 $4(N\cdot\omega_i)(N\cdot\omega_o)$ 常被當作「背下來」的公式，其實它是把單位半球上的微面立體角 $d\omega_h$ 轉到巨觀入射立體角 $d\omega_i$ 的 Jacobian。

此句仍把整個 Cook–Torrance 分母等同於單一 Jacobian，與後文正確的說法矛盾。半向量映射本身只有

$$
d\omega_h
=
\frac{d\omega_o}{4|\omega_o\cdot h|}.
$$

最終分母還包含微面與巨觀表面的投影因子。

**修法：**

改為：

> 分母 $4(N\cdot\omega_i)(N\cdot\omega_o)$ 來自半向量映射 Jacobian、微面投影面積與巨觀入射／出射投影餘弦的合併，不能視為單一立體角 Jacobian。

後面的：

> 驗證這個 Jacobian 的完整性

也應改成：

> 驗證這組幾何與變數轉換因子的完整性

---

### 2. 第 16 章白色爐敘述混淆「不超過」與「必須相等」

**原句：**

> 假設入射輻射亮度在各方向都等於 $L$，則理想表面反射的總亮度也應等於 $L$，因為它不可能超過入射能量。

能量守恆只能推出

$$
L_o(\omega_o)\le L
$$

或相應方向半球反射率不超過 1；只有完全不吸收且模型完整的白色反射材質才應等於 $L$。吸收性材質得到低於 $L$ 是正確結果。

同段另稱：

> 總反射率在 $m=0$ 時應接近 $\rho$。

這也不普遍成立，因為非金屬仍有 $F_0\approx0.04$ 的鏡面反射；稿中 $\rho$ 是漫反射基底色，不是包含鏡面後的總半球反射率。

**修法：**

改為：

> 白色爐下，任何被動材質的出射輻亮度不應穩定超過環境輻亮度。對設定為白色且無吸收的完整模型，結果才應接近相等；本章的單次散射近似可能因未補償多重散射而偏低。

並將「總反射率應接近 $\rho$」改成「漫反射與鏡面合計應不超過 1；其值不等同於漫反射基底色 $\rho$」。

此外，未實際積分或引用可核對條件時，不宜斷言：

> $r\to1$ 時只到 $0.7L$ 甚至更低

此值依 $F_0$、$\rho$、觀察方向、是否平均觀察方向及漫反射耦合方式而變。應刪除固定的 `0.7L`，或完整限定測試參數並標為預期數值。

第 16 章只寫：

第 17 章則產生貼圖擾動後的最終世界空間著色法線 $\mathbf n_w$。目前讀者無法判斷 Cook–Torrance 的 $N$ 應使用幾何法線、插值法線或法線貼圖結果。

**修法：**

這是第 16、17 章資料接口，不只是文風補充。

## 程式邊界問題

### 第 16 章 `normalize` 未拒絕 NaN／inf

**原程式：**

```python
def normalize(v):
    n = np.linalg.norm(v)
    if n < 1e-12:
        raise ValueError("zero-length vector")
    return v / n
```

若 `v` 含 NaN，`n < 1e-12` 為假，函式會回傳 NaN。應改成：

```python
def normalize(v):
    v = np.asarray(v, dtype=float)
    if not np.all(np.isfinite(v)):
        raise ValueError("vector must be finite")
    n = np.linalg.norm(v)
    if not np.isfinite(n) or n < 1e-12:
        raise ValueError("zero-length or non-finite vector")
    return v / n
```

並加入非法方向輸入測試。這也使其邊界策略與第 17 章一致。
