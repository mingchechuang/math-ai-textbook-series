# 第五章　透視投影、裁切與深度

## 學習目標與先備知識

本章將推導並實作右手相機的透視投影，說明剪裁空間、NDC、透視除法與深度緩衝的關係。完成後，你應能：

- 區分透視投影與正交投影，說明它們如何映射相機座標。
- 推導 OpenGL 式投影矩陣，並驗算近平面與遠平面的深度端點。
- 判斷點或線段是否落在視錐內，並計算近平面裁切交點。
- 解釋透視深度為何非線性，以及近平面選擇對深度精度的影響。

先備知識是向量、矩陣乘法與齊次座標。沿用全書約定：世界座標系為右手系，相機局部座標看向 $-Z$、$+Y$ 為上；向量以直向量表示。長度單位為公尺，角度以弧度計算。

本章主線採 OpenGL 式慣例：NDC 的 $z$ 範圍為 $[-1,1]$，深度緩衝值為 $(z_{\mathrm{ndc}}+1)/2$。部分圖形 API 使用不同深度範圍與投影慣例，不能只替換矩陣而沿用本章的深度映射。

## 問題與直覺

三維物件要顯示在有限大小的影像中，必須經過相機變換、投影、裁切與視窗映射。透視投影使遠處物體的投影尺寸較小；正交投影則讓大小不隨深度改變。

理解深度管線時，須分清幾個量：

- 相機座標中的深度 $z$：在本章相機前方為負值。
- 剪裁座標中的 $z_c,w_c$：由投影矩陣產生，尚未完成除法。
- NDC 深度 $z_{\mathrm{ndc}}=z_c/w_c$：落在 $[-1,1]$ 的可見深度範圍。
- 深度緩衝值 $d=(z_{\mathrm{ndc}}+1)/2$：本章映射到 $[0,1]$。

它們不能混稱為「距離」。透視深度尤其不是相機距離的線性表示。

## 數學與幾何推導

### 透視投影矩陣

相機座標中的點寫成

$$
p_{\mathrm{cam}}=(x,y,z,1)^T.
$$

相機前方的點滿足 $z<0$。近平面與遠平面距離分別為 $n$ 與 $f$，條件是 $0<n<f$；它們位於 $z=-n$ 與 $z=-f$。令垂直視野角為 $\theta$，影像寬高比為 $a=W/H$。近平面邊界為

$$
t=n\tan\frac{\theta}{2},\quad b=-t,\quad
r=at,\quad l=-r.
$$

由相似三角形，投影到近平面後的橫向座標與縱向座標分別為 $nx/(-z)$ 與 $ny/(-z)$。為以齊次矩陣表達除以 $-z$，令 $w_c=-z$。再把近平面座標映射到 NDC，可得：

$$
P=
\begin{bmatrix}
\frac{2n}{r-l}&0&\frac{r+l}{r-l}&0\\
0&\frac{2n}{t-b}&\frac{t+b}{t-b}&0\\
0&0&-\frac{f+n}{f-n}&-\frac{2fn}{f-n}\\
0&0&-1&0
\end{bmatrix}.
$$

對稱視錐滿足 $l=-r$、$b=-t$，因此簡化為

$$
P=
\begin{bmatrix}
\frac{1}{a\tan(\theta/2)}&0&0&0\\
0&\frac{1}{\tan(\theta/2)}&0&0\\
0&0&-\frac{f+n}{f-n}&-\frac{2fn}{f-n}\\
0&0&-1&0
\end{bmatrix}.
$$

剪裁座標為

$$
p_{\mathrm{clip}}=Pp_{\mathrm{cam}}=(x_c,y_c,z_c,w_c)^T.
$$

因 $w_c=-z$，相機前方的點有 $w_c>0$。透視除法後得到

$$
(x_{\mathrm{ndc}},y_{\mathrm{ndc}},z_{\mathrm{ndc}})
=\left(\frac{x_c}{w_c},\frac{y_c}{w_c},\frac{z_c}{w_c}\right).
$$

剪裁空間中的可見條件是

$$
-w_c\le x_c,y_c,z_c\le w_c.
$$

更精確地說，三個分量各自都須介於 $-w_c$ 與 $w_c$ 之間，且 $w_c>0$。此條件除以 $w_c$ 後等價於 NDC 三分量均在 $[-1,1]$。實務上應先裁切剪裁座標，再做透視除法；特別是靠近近平面或位於相機後方的點，不可直接當作一般 NDC 點處理。

把 $z=-n$ 代入矩陣可得 $z_{\mathrm{ndc}}=-1$；把 $z=-f$ 代入可得 $z_{\mathrm{ndc}}=1$。所以本章深度緩衝值為

$$
d=\frac{z_{\mathrm{ndc}}+1}{2},
$$

近平面對應 $d=0$，遠平面對應 $d=1$。

由矩陣可整理出深度與相機座標的關係：

$$
z_{\mathrm{ndc}}
=\frac{f+n}{f-n}+\frac{2fn}{(f-n)z}.
$$

由於式中含有 $1/z$，深度分布不是距離的線性分布，近處會取得較多精度。近平面設得過小、遠平面又設得過大時，遠處深度容易出現精度不足，造成遮擋次序不穩定。

### 正交投影

正交投影在不同深度不改變物體投影大小。對範圍 $[l,r]\times[b,t]$、深度區間 $[-f,-n]$，可使用

$$
P_{\mathrm{ortho}}=
\begin{bmatrix}
\frac{2}{r-l}&0&0&-\frac{r+l}{r-l}\\
0&\frac{2}{t-b}&0&-\frac{t+b}{t-b}\\
0&0&-\frac{2}{f-n}&-\frac{f+n}{f-n}\\
0&0&0&1
\end{bmatrix}.
$$

其 $w_c=1$，因此沒有依 $z$ 改變大小的透視除法。正交投影仍需裁切視錐，只是投影後不產生近大遠小。

### 視窗與像素座標

對寬 $W$、高 $H$ 的影像，本書像素原點在左上，影像 $v$ 軸向下。NDC 到連續影像座標的映射為

$$
u=\frac{x_{\mathrm{ndc}}+1}{2}W,\qquad
v=\frac{1-y_{\mathrm{ndc}}}{2}H.
$$

$y$ 方向的負號是因 NDC 的 $Y$ 向上，而影像座標的 $v$ 向下。像素索引 $(i,j)$ 的中心位置為 $(i+0.5,j+0.5)$；連續座標如何對應像素索引，須依光柵化的取樣規則決定。

## 逐步手算例題

### 例一：驗算近平面、遠平面與中間深度

取 $n=1$ 公尺、$f=10$ 公尺。深度矩陣係數為

$$
A=-\frac{f+n}{f-n}=-\frac{11}{9},\qquad
B=-\frac{2fn}{f-n}=-\frac{20}{9}.
$$

因此 $z_c=Az+B$，$w_c=-z$。

在近平面 $z=-1$：

$$
z_c=-\frac{11}{9}(-1)-\frac{20}{9}=-1,\quad w_c=1,
$$

所以 $z_{\mathrm{ndc}}=-1$、$d=0$。

在遠平面 $z=-10$：

$$
z_c=-\frac{11}{9}(-10)-\frac{20}{9}=10,\quad w_c=10,
$$

所以 $z_{\mathrm{ndc}}=1$、$d=1$。

在 $z=-2$：

$$
z_c=-\frac{11}{9}(-2)-\frac{20}{9}=\frac{2}{9},\quad w_c=2.
$$

因此 $z_{\mathrm{ndc}}=1/9$，深度緩衝值 $d=5/9$。它不是距離比例 $1/9$。

### 例二：計算像素位置與深度

取 $\theta=90^\circ$、$a=2$、$n=1$、$f=10$。因 $\tan(\theta/2)=1$，投影矩陣的 $x,y$ 縮放係數分別為 $1/2$ 與 $1$。

對點 $p_{\mathrm{cam}}=(1,0,-2,1)^T$，剪裁座標為

$$
(x_c,y_c,z_c,w_c)=\left(\frac12,0,\frac29,2\right).
$$

透視除法後

$$
(x_{\mathrm{ndc}},y_{\mathrm{ndc}},z_{\mathrm{ndc}})
=\left(\frac14,0,\frac19\right),
$$

故深度緩衝值為 $5/9$。若影像為 $800\times400$，則

$$
u=\frac{1+1/4}{2}(800)=500,\qquad
v=\frac{1-0}{2}(400)=200.
$$

$(500,200)$ 是連續影像座標，不等同於像素索引。

### 近平面線段裁切

設近平面距離 $n=1$，線段端點的相機深度為 $z_A=-0.5$、$z_B=-2$。以正的相機前方距離 $s=-z$ 計算，近平面交點的內插比例為

$$
\lambda=\frac{n-s_A}{s_B-s_A}
=\frac{1-0.5}{2-0.5}=\frac13.
$$

對三維端點向量 $A,B$，交點為

$$
C=A+\lambda(B-A).
$$

裁切三角形時也以邊與近平面的交點建立新頂點。若頂點帶有 UV、顏色等屬性，交點屬性須用相同內插比例計算。裁切後的多邊形若有四個頂點，可再三角化；不可先對近平面外的點做不受限制的透視除法。

## 實作與程式

以下程式使用 Python 標準庫，不讀檔、不依賴網路或 GPU。它建立對稱視錐投影矩陣、檢查近平面與遠平面深度端點、測試視錐外點，並裁切一條穿越近平面的線段。矩陣以數學上的列、欄方式儲存，向量採直向量。

```python
import math


def perspective_rh_opengl(fovy, aspect, near, far):
    """右手相機看向 -Z，NDC z 範圍為 [-1, 1]。"""
    if not (0.0 < fovy < math.pi):
        raise ValueError("fovy 必須介於 0 與 pi 之間")
    if aspect <= 0.0 or near <= 0.0 or far <= near:
        raise ValueError("aspect、near、far 不符合條件")

    q = 1.0 / math.tan(fovy / 2.0)
    return [
        [q / aspect, 0.0, 0.0, 0.0],
        [0.0, q, 0.0, 0.0],
        [0.0, 0.0, -(far + near) / (far - near),
         -(2.0 * far * near) / (far - near)],
        [0.0, 0.0, -1.0, 0.0],
    ]


def mat_vec(matrix, vector):
    return [
        sum(matrix[r][c] * vector[c] for c in range(4))
        for r in range(4)
    ]


def ndc_and_depth(matrix, point):
    clip = mat_vec(matrix, [point[0], point[1], point[2], 1.0])
    w = clip[3]
    if w <= 0.0:
        raise ValueError("點不在相機前方")
    ndc = tuple(clip[i] / w for i in range(3))
    depth = (ndc[2] + 1.0) / 2.0
    return clip, ndc, depth


def inside_clip(clip, eps=1e-12):
    x, y, z, w = clip
    return (
        w > 0.0
        and -w - eps <= x <= w + eps
        and -w - eps <= y <= w + eps
        and -w - eps <= z <= w + eps
    )


def clip_segment_near(a, b, near):
    """輸入兩端點的 (x, y, z)，只裁切近平面 z=-near。"""
    a_in = a[2] <= -near
    b_in = b[2] <= -near

    if not a_in and not b_in:
        return None
    if a_in and b_in:
        return a, b

    t = (-near - a[2]) / (b[2] - a[2])
    c = tuple(a[i] + t * (b[i] - a[i]) for i in range(3))
    return (a, c) if a_in else (c, b)


def main():
    near, far = 1.0, 10.0
    matrix = perspective_rh_opengl(math.pi / 2.0, 2.0, near, far)

    for z, expected_depth in [(-near, 0.0), (-far, 1.0)]:
        clip, ndc, depth = ndc_and_depth(matrix, (0.0, 0.0, z))
        assert inside_clip(clip)
        assert abs(ndc[2] - (2.0 * expected_depth - 1.0)) < 1e-12
        assert abs(depth - expected_depth) < 1e-12

    outside = mat_vec(matrix, [20.0, 0.0, -2.0, 1.0])
    assert not inside_clip(outside)

    clipped = clip_segment_near(
        (0.0, 0.0, -0.5), (1.5, 0.0, -2.0), near
    )
    assert clipped is not None
    assert abs(clipped[0][2] + near) < 1e-12
    assert clipped[1] == (1.5, 0.0, -2.0)

    assert clip_segment_near(
        (0.0, 0.0, -0.2), (1.0, 0.0, -0.7), near
    ) is None

    print("near/far, side clipping, and near-plane tests passed")


if __name__ == "__main__":
    main()
```

近平面線段函式只示範一個裁切平面，不是完整的三角形裁切器。完整渲染流程還須處理左、右、上、下與遠平面，並在新交點同步內插所有頂點屬性。測試容差 $10^{-12}$ 適用於此簡單單位案例；若場景尺度改變，應依尺度與浮點誤差調整，而不是把該值當作通用常數。

## 測試與預期結果

程式斷言檢查近平面深度為 $0$、遠平面深度為 $1$，視錐外點被拒絕，線段交點落在 $z=-n$，並且全在近平面外的線段裁切結果為空。

若讀者執行程式，預期最後一行會印出：

```text
near/far, side clipping, and near-plane tests passed
```

這是由程式與公式可推得的預期文字，不表示作者已執行或驗證程式。

## 除錯與常見陷阱

- **相機前方符號反了：** 本章相機看向 $-Z$，前方點的 $z<0$，且 $w_c=-z>0$。
- **忘記透視除法：** 剪裁座標不是 NDC。直接拿 $x_c,y_c$ 對應像素，會破壞投影比例。
- **混用深度慣例：** 本章 NDC 深度是 $[-1,1]$。其他 API 若使用不同範圍，投影矩陣、剪裁條件和深度映射須一併調整。
- **先除法再處理近平面：** 近平面外點可能有不適合除法的 $w_c$。應在剪裁空間裁切，再做透視除法。
- **把深度當距離：** 深度是非線性投影量。若需相機距離，必須依相同的 $n,f$ 與投影公式反算。
- **深度範圍設得過寬：** 近平面過近或遠平面過遠，會使深度精度分布更不利。
- **影像 $Y$ 軸方向忘了翻轉：** 本書 NDC 的 $Y$ 向上，像素座標 $v$ 向下，映射時須反號。

## 養殖數位分身案例

假設合成池景中的池體長 $8$ 公尺、寬 $4$ 公尺，魚群活動深度約為 $0.5$ 至 $3$ 公尺。將池體與魚群頂點轉到相機座標後，依相機位置選擇涵蓋可見區域的視野角與長寬比。近平面須小於最近要成像物體的距離，但不應無理由地接近零；遠平面則須涵蓋最遠的池體或背景構件。

三角形若跨過近平面，先算交點、裁切並內插 UV 與其他屬性，再進行投影與光柵化。深度緩衝值可供遮擋比較，但不是以公尺為單位的距離標籤。

若輸出合成深度標註，資料清單應記錄投影慣例、近平面、遠平面，以及數值是否已反算成相機距離。只有一張灰階深度圖而沒有這些資訊，無法確定灰階代表什麼尺度。投影結果只描述設定中的合成場景，不是對真實魚體位置或水下光學性質的驗證。

## 習題

### 1. 手算：深度映射

取 $n=0.5$ 公尺、$f=8$ 公尺。求 $z=-0.5$、$z=-8$ 與 $z=-2$ 時的 $z_{\mathrm{ndc}}$ 和深度緩衝值。

### 2. 程式測試：近平面裁切

修改實作程式，測試線段兩端都在 $z>-n$ 時裁切結果為空；再測試線段兩端都滿足 $z\le -n$ 時，函式回傳原端點。

### 3. 反例與除錯：先做透視除法

近平面為 $n=1$，某點位於相機座標 $z=-0.5$。程式先投影並除以 $w_c$，若除法後座標看似落在 NDC 範圍內，就判定可見。說明錯誤，並寫出最簡單的近平面判斷。

### 4. 整合應用：設定裁切距離

合成池景中最近魚距離相機約 $0.8$ 公尺，最遠池壁約 $12$ 公尺。提出一組合理的 $n,f$，說明選擇理由；再說明把 $n$ 降到 $0.001$ 公尺可能造成的問題。

## 習題解答

### 1. 手算：深度映射

使用

$$
z_{\mathrm{ndc}}
=\frac{f+n}{f-n}+\frac{2fn}{(f-n)z},
\qquad
d=\frac{z_{\mathrm{ndc}}+1}{2}.
$$

本題 $(f+n)/(f-n)=17/15$，$2fn/(f-n)=16/15$。

- $z=-0.5$：$z_{\mathrm{ndc}}=-1$，$d=0$。
- $z=-8$：$z_{\mathrm{ndc}}=1$，$d=1$。
- $z=-2$：$z_{\mathrm{ndc}}=17/15-8/15=3/5$，$d=4/5$。

### 2. 程式測試：近平面裁切

在 $n=1$ 時，兩端點若是 $(0,0,-0.2)$ 與 $(1,0,-0.7)$，皆滿足 $z>-1$，所以預期回傳 `None`。若改用 $(0,0,-1.2)$ 與 $(1,0,-2)$，兩端皆在近平面後方的可見側，預期回傳原端點。這些測試只檢查近平面，不代表其他裁切平面也已驗證。

### 3. 反例與除錯：先做透視除法

$z=-0.5>-1$，點位於近平面外。只看透視除法結果可能漏掉近平面條件，且近平面外的投影結果不應當成有效可見點。對相機空間中的單點，最簡單的近平面測試是

$$
z\le -n.
$$

本例不符合條件，應裁去；若是三角形，則須先裁切三角形，而不是只丟棄其中一個頂點。

### 4. 整合應用：設定裁切距離

例如取 $n=0.5$ 公尺、$f=12$ 公尺。最近魚仍在近平面後方，最遠池壁位於遠平面內；若場景或相機會移動，可依需求留出合理餘量。把 $n$ 降到 $0.001$ 公尺，會讓深度分布更不均勻，使遠處深度精度較容易不足，增加遮擋排序錯誤的風險。除非必須看見極近物體，不宜把近平面任意設得很小。

## 本章小結

透視投影透過 $w_c=-z$ 產生近大遠小；透視除法將剪裁座標轉為 NDC。依本章 OpenGL 式慣例，NDC 深度為 $[-1,1]$，深度緩衝值為 $(z_{\mathrm{ndc}}+1)/2$。裁切應在除法前進行，跨越近平面的幾何需計算交點並同步內插屬性。正交投影則不隨深度縮放。最後，透視深度不是距離的線性編碼，近平面與遠平面的選擇會影響深度精度。
