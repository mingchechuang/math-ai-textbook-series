## 一、數學與邏輯錯誤（真錯誤）

### 1. 習題 2 (c) 解答中的角度線性性驗證邏輯錯誤
*   **原句/公式**：
    > (c) ... $\theta_k=2\arccos(w_t)$（短弧調整後 $w_t\ge 0$）；$\theta_k$ 對 $k$ 線性...
*   **錯誤原因**：
    1.  公式 $\theta = 2\arccos(w)$ 僅當旋轉軸固定在 $Z$ 軸（或 $q$ 的虛部僅有 $z$ 分量）時，$w$ 才能唯一對應旋轉角度且與時間線性。
    2.  若 $q_0$ 與 $q_1$ 是任意兩個單位四元數，插值過程中的中點四元數 $q_t$ 的 $w$ 分量並不一定使得 $2\arccos(w_t)$ 與 $t$ 呈現線性關係。例如，若旋轉涉及多個軸，$w_t$ 的變化曲線雖然對稱，但角度 $\theta_t$ 的定義應基於 $q_0$ 與 $q_t$ 之間的相對旋轉角，或者對於繞固定軸的旋轉才適用 $2\arccos(w_t)$（假設 $q_0$ 為恆等）。
    3.  更嚴謹的說法是：對於繞**單一固定軸**的旋轉，若 $q_0$ 為恆等旋轉 $(1,0,0,0)$，則 $w_t = \cos(\frac{\theta_t}{2})$，因此 $\theta_t = 2\arccos(w_t)$ 是線性的。
    4.  但是，如果 $q_0$ 不是恆等旋轉，或者旋轉軸不固定，這個公式就不適用。
    5.  題目中要求「驗證 $\theta_t$ 對 $t$ 線性」，但沒有指定旋轉軸固定或 $q_0$ 為恆等。雖然習題 (c) 的上下文可能暗示簡單情況，但解答中直接斷言 $\theta_k = 2\arccos(w_t)$ 是線性的是不嚴謹的。
    6.  **更嚴重的問題**：在「測試與預期結果」的測試 5 中，明確說了「$q_0$ 與 $q_1$ 相差 $90^\circ$ 繞 $Z$」，這時候 $w_t$ 確實與角度線性相關。但在習題 2 (c) 的解答中，並未重複這個限制，而是泛泛而談。
    7.  **修正建議**：應限定條件，例如「若 $q_0$ 為恆等旋轉且旋轉繞固定軸，則...」或改為計算相鄰樣本的角度差是否恆定。

### 2. 習題 4 驗證 2 的描述與習題 4 解答中的修正矛盾
*   **習題 4 題目**：
    > ... 以逐步掃描 $t$ 檢查相鄰姿態的四元數內積絕對值接近 1（無翻滾突變）。
*   **習題 4 解答**：
    > **驗證 2（無翻滾突變，輔助檢查）**：... 需要強調：**密集取樣的相鄰內積無法可靠辨識長弧與短弧**。...
*   **錯誤原因**：
    1.  題目要求讀者設計一個驗證，並暗示「檢查相鄰內積接近 1」可以檢測「無翻滾突變」。
    2.  解答卻指出這個檢查「無法可靠辨識長弧與短弧」，這是一個重要的數學事實（因為長弧和短弧在相鄰取樣點上可能看起來都很平滑，除非取樣點跨過了 $180^\circ$ 的邊界或者取樣密度極低）。
    3.  雖然解答提供了「驗證 3」來補充，但題目本身的引導（檢查內積接近 1 以確保無翻滾）在數學上對於檢測「走錯路徑（長弧）」是不足的。如果走長弧，相鄰樣本的内積依然會接近 1（因為它也是一條平滑曲線，只是路徑較長）。只有當路徑發生**跳變**（Discontinuity）時，內積才會突然變小。
    4.  如果 SLERP 實作正確（無論短弧長弧），相鄰內積都會接近 1。如果實作錯誤導致跳變，內積才會小。
    5.  因此，「檢查相鄰內積接近 1」只能檢測**不連續性**（Bug 或 跳變），而不能檢測**是否走了最短路徑**（Shortest Arc）。
    6.  題目將此檢查與「無翻滾突變」聯繫起來是可以的（突變即不連續），但解題中提到的「無法可靠辨識長弧與短弧」暗示了這個檢查對於確保「最短弧」無效。
    7.  **矛盾點**：題目讓學生做這個檢查，暗示它是一個有效的「無問題」指標；解答卻說它不足以區分長短弧。雖然解答補充了驗證 3，但題目的引導性稍顯不足。
    8.  **判定**：這屬於「可選文風/教學清晰度」問題，而非嚴格數學錯誤，因為「突變」通常指不連續。但如果學生誤以為「內積接近 1」就保證了「最短弧」，那就錯了。解答中已經澄清了這一點。
    9.  **建議**：在題目中就明確說明此檢查僅為「連續性檢查」，並引導學生思考其局限性，或要求結合驗證 3。目前的寫法尚可接受，因為解答有詳細說明。

### 3. `q_slerp` 中 `d` 的截斷邏輯
*   **程式碼**：
    ```python
    if d > 1.0:
        d = 1.0
    ```
*   **錯誤原因**：
    1.  在短弧調整後，$d$ 應該是 $q_0 \cdot q_1'$，其中 $q_1'$ 是 $q_1$ 或 $-q_1$。
    2.  理論上 $d \in [-1, 1]$。短弧調整確保 $d \ge 0$。
    3.  如果 $q_0$ 和 $q_1$ 都是單位四元數，$d$ 不應超過 1。
    4.  但是，如果輸入**不是**單位四元數，`q_normalize` 會將它們正規化，所以 $d$ 仍然不應超過 1。
    5.  浮點誤差可能導致 $d$ 略大於 1（例如 1.00000000001）。
    6.  `math.acos(d)` 在 $d > 1$ 時會拋出 `ValueError`。
    7.  因此，`if d > 1.0: d = 1.0` 是必要的防禦性編程。
    8.  **但是**，代碼中**沒有**處理 $d < -1.0$ 的情況。
    9.  雖然短弧調整後 $d$ 應 $\ge 0$，但如果 $q_0$ 或 $q_1$ 的歸一化過程有極端浮點錯誤，或者短弧調整邏輯有 bug，$d$ 可能會是負數。
    10. 更關鍵的是：如果 $d$ 是負數（例如 $-1.0000000001$），`acos` 會報錯。
    11. 代碼中：
        ```python
        if d < 0.0:
            q1 = ...
            d = -d
        if d > 1.0:
            d = 1.0
        ```
    12. 如果原始 $d$ 是 $-1.0000000001$，取反後是 $1.0000000001$，然後被截斷為 1.0。這是安全的。
    13. 如果原始 $d$ 是 $0.9999$，不取反，不截斷。
    14. 如果原始 $d$ 是 $-0.5$，取反後 $0.5$。
    15. **潛在問題**：如果 $q_0$ 和 $q_1$ 幾乎反對稱（Anti-parallel），$d \approx -1$。取反後 $d \approx 1$。`acos(1)` 是 0。$\sin(0)$ 是 0。進入 nlerp。這是正確的。
    16. 所以邏輯是健全的。無誤。
