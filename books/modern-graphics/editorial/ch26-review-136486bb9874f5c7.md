## 一、數學與邏輯錯誤（真錯誤）

### 1. 習題 3 (c) 解答中的角度描述錯誤
*   **原句**：
    > 「(c) 反例：$q_0=(1,0,0,0)$，$q_1=(-\tfrac{\sqrt 2}{2},0,0,-\tfrac{\sqrt 2}{2})$。$d=-\tfrac{\sqrt 2}{2}<0$，函式 $\Omega=\arccos(-\tfrac{\sqrt 2}{2})=3\pi/4$；$t=0.5$ 得到中間值約在 $135^\\circ$ 附近，而正確短弧應在 $45^\\circ$。」
*   **錯誤原因**：
    1.  此處討論的是四元數空間 $S^3$ 上的弧長參數，而非直接對應的旋轉角度。
    2.  四元數 $q = (\cos \alpha, \sin \alpha \hat{n})$ 對應旋轉角度 $\theta = 2\alpha$。
    3.  $q_1 = (-\frac{\sqrt 2}{2}, 0, 0, -\frac{\sqrt 2}{2})$。注意 $w < 0$。
        其旋轉角度對應的 $\alpha_1$ 滿足 $\cos \alpha_1 = -\frac{\sqrt 2}{2}$，即 $\alpha_1 = \frac{3\pi}{4}$ ($135^\circ$)。
        對應的旋轉角度為 $2 \times 135^\circ = 270^\circ$（或等價的 $-90^\circ$）。
    4.  $q_0 = (1,0,0,0)$，$\alpha_0 = 0$。
    5.  **長弧情況**：從 $\alpha=0$ 到 $\alpha=3\pi/4$ 的直接路徑（未經短弧調整）长度为 $3\pi/4$。
        中點 $t=0.5$ 時，$\alpha_{mid} = \frac{1}{2} (0 + \frac{3\pi}{4}) = \frac{3\pi}{8} = 67.5^\circ$。
        對應的旋轉角度為 $2 \times 67.5^\circ = 135^\circ$。
    6.  **短弧情況**：$q_1$ 與 $-q_1 = (\frac{\sqrt 2}{2}, 0, 0, \frac{\sqrt 2}{2})$ 代表同一旋轉。
        $-q_1$ 的 $\alpha' = \frac{\pi}{4} = 45^\circ$。
        從 $\alpha=0$ 到 $\alpha=\frac{\pi}{4}$ 的短弧長度為 $\frac{\pi}{4}$。
        中點 $t=0.5$ 時，$\alpha'_{mid} = \frac{\pi}{8} = 22.5^\circ$。
        對應的旋轉角度為 $2 \times 22.5^\circ = 45^\circ$。
    7.  **結論**：解答中說「中間值約在 $135^\circ$ 附近」是正確的（指長弧路徑的旋轉角度），「正確短弧應在 $45^\circ$」也是正確的。
    8.  **但是**，原文前面提到「$t=0.5$ 得到中間值約在 $135^\circ$ 附近」。這裡需要確認 $bad\_slerp$ 的行為。
        $bad\_slerp$ 未做短弧調整，使用 $q_1$ 直接計算。
        $\Omega = \arccos(d) = \arccos(-\frac{\sqrt 2}{2}) = \frac{3\pi}{4}$。
        $t=0.5$。
        結果四元數 $q_{mid}$ 位於 $q_0$ 和 $q_1$ 之間的大圓弧上。
        由於 $q_0$ 和 $q_1$ 的夾角為 $135^\circ$ ($3\pi/4$)，中點的「半角參數」為 $67.5^\circ$。
        對應的旋轉角度為 $135^\circ$。
        所以描述是正確的。
        
        **等等，再仔細檢查 $bad\_slerp$ 的公式**。
        $bad\_slerp$ 計算的是 $S^3$ 上的插值。
        如果 $d < 0$，它沒有翻轉 $q_1$，因此它計算的是從 $q_0$ 到 $q_1$ 的「長弧」（如果視 $q_1$ 的 $w$ 分量為負，這通常被視為長弧，因為 $S^3$ 上兩點間的距離定義為 $\arccos(d)$，當 $d<0$ 時，距離 $> \pi/2$）。
        在 $S^3$ 中，$q$ 和 $-q$ 是對徑點。$q_1$ 和 $q_0$ 的距離是 $3\pi/4$。
        短弧距離應該是 $2\pi - 3\pi/4$? 不，$S^3$ 的測地線距離是 $\arccos(d) \in [0, \pi]$。
        $q_0 \cdot q_1 = -\frac{\sqrt 2}{2}$。距離 $\Omega = \frac{3\pi}{4}$。
        這是長弧嗎？
        對於旋轉而言，$q_1$ 和 $-q_1$ 是同一旋轉。
        $q_0 \cdot (-q_1) = \frac{\sqrt 2}{2}$。距離 $\Omega' = \frac{\pi}{4}$。
        $\frac{\pi}{4} < \frac{3\pi}{4}$。所以 $\frac{3\pi}{4}$ 確實是較長的路徑（在 $S^3$ 球面上）。
        因此，$bad\_slerp$ 會走 $\frac{3\pi}{4}$ 的路徑。
        中點的旋轉角度是 $2 \times \frac{1}{2} \frac{3\pi}{4} = \frac{3\pi}{4} = 135^\circ$。
        正確短弧的旋轉角度是 $2 \times \frac{1}{2} \frac{\pi}{4} = \frac{\pi}{4} = 45^\circ$。
        
        **結論**：解答描述正確。無誤。

### 2. 習題 4 程式碼 `pose_at` 的搜尋邏輯效率與正確性
*   **原句/代碼**：
    ```python
    i = 0
    while i + 2 < len(times) and times[i + 1] <= t:
        i += 1
    ```
*   **錯誤原因**：
    1.  這是一個線性搜尋，時間複雜度 $O(N)$。對於大量關鍵影格，效率低下。
    2.  雖然本章不要求高效能，但作為「整合應用」，建議使用二分搜尋 ($O(\log N)$) 或明確說明這是教學簡化版。
    3.  **邏輯檢查**：
        *   條件 `times[i + 1] <= t`。
        *   如果 `times = [0, 1, 2]`, `t = 1.5`。
        *   `i=0`: `times[1]=1 <= 1.5` -> `i=1`.
        *   `i=1`: `i+2=3` 不小於 `3` (len=3)? `3 < 3` 為 False。循環結束。
        *   `i` 保持為 1。
        *   `t0 = times[1] = 1`, `t1 = times[2] = 2`。
        *   `u = (1.5 - 1) / (2 - 1) = 0.5`。
        *   正確。
        *   如果 `t = 0.5`。
        *   `i=0`: `times[1]=1 <= 0.5` -> False。
        *   `i=0`。
        *   `t0=0, t1=1`。`u=0.5`。正確。
        *   如果 `t = 2.0` (最末端)。
        *   前面有 `if t >= times[-1]: return q_list[-1]`。所以不會進入循環。
        *   邏輯正確，但效率低。作為教材，可以接受，但建議加註「生產環境應使用二分搜尋」。

### 3. 測試 5 中關於 nlerp 誤差的描述
*   **原句**：
    > 「若改用 nlerp，同一組 $t$ 的 $\theta_t$ 值與 SLERP 的角度差會在中間最大（$90^\circ$ 旋轉時量級約 $10^{-2}$ 弧度）」
*   **錯誤原因**：
    1.  讓我們估算一下 nlerp 在 $90^\circ$ ($\pi/2$) 旋轉時的誤差。
    2.  $q_0 = (1, 0)$ (2D 簡化，w, v)。$q_1 = (c, s)$ 其中 $c=\cos(\pi/8), s=\sin(\pi/8)$? 不，$90^\circ$ 旋轉對應半角 $45^\circ$。
        $q_0 = (1, 0, 0, 0)$。$q_1 = (\frac{\sqrt 2}{2}, 0, 0, \frac{\sqrt 2}{2})$。
    3.  $t=0.5$。
    4.  SLERP: $\theta = 45^\circ = \pi/4$。
    5.  NLERP:
        $v_{lin} = 0.5 (1, 0) + 0.5 (\frac{\sqrt 2}{2}, \frac{\sqrt 2}{2}) = (0.5 + 0.3535, 0.3535) = (0.8535, 0.3535)$。
        正規化前長度平方：$0.8535^2 + 0.3535^2 \approx 0.7285 + 0.125 = 0.8535$。
        長度 $\approx \sqrt{0.8535} \approx 0.9239$。
        正規化後 $w = 0.8535 / 0.9239 \approx 0.9238$。
        $s_{half} = 0.3535 / 0.9239 \approx 0.3826$。
        $\tan(\alpha_{nlerp}) = 0.3826 / 0.9238 \approx 0.4142$。
        $\alpha_{nlerp} = \arctan(0.4142) \approx 22.5^\circ$。
        $\theta_{nlerp} = 2 \times 22.5^\circ = 45^\circ$。
        
        **等等，nlerp 在 $t=0.5$ 時對於 $90^\circ$ 旋轉是非常準確的？**
        讓我們檢查 $t=0.25$。
        SLERP: $\theta = 22.5^\circ$。
        NLERP:
        $v_{lin} = 0.75 (1, 0) + 0.25 (0.707, 0.707) = (0.75 + 0.1768, 0.1768) = (0.9268, 0.1768)$。
        $w_{norm} \propto 0.9268, v_{norm} \propto 0.1768$。
        $\tan(\alpha) = 0.1768 / 0.9268 \approx 0.1907$。
        $\alpha \approx 10.8^\circ$。
        $\theta_{nlerp} \approx 21.6^\circ$。
        SLERP $\theta = 22.5^\circ$。
        差異 $22.5 - 21.6 = 0.9^\circ \approx 0.0157$ rad。
        
        最大差異通常出現在中間。
        $90^\circ$ 時，$t=0.5$ 差異極小。
        $180^\circ$ 時差異才顯著。
        
        對於 $90^\circ$ ($\pi/2$) 旋轉：
        SLERP 角度 $\theta_s(t) = \frac{\pi}{2} t$。
        NLERP 角度 $\theta_n(t)$。
        在 $t=0.5$，兩者幾乎重合。
        最大誤差可能在小於 $10^{-2}$ 弧度（約 $0.57^\circ$）。
        $0.9^\circ \approx 0.015$ rad。這與 $10^{-2}$ 量級相符（$1.5 \times 10^{-2}$）。
        
        所以「量級約 $10^{-2}$ 弧度」是合理的估算。無誤。

**例 1 重算**：
$q = (c, 0, 0, c)$, $p = (0, 1, 0, 0)$.
$q p = (0, c, c, 0)$.
$q^* = (c, 0, 0, -c)$.
$r q^* = (0, c, c, 0) (c, 0, 0, -c)$.
$w' = 0 \cdot c - (c \cdot 0 + c \cdot 0 + 0 \cdot -c) = 0$.
$v'_x = 0 \cdot 0 + c \cdot c + c \cdot -c - 0 \cdot 0$? 
公式：$w_1 v_2 + w_2 v_1 + v_1 \times v_2$.
$w_1=0, v_1=(c,c,0)$. $w_2=c, v_2=(0,0,-c)$.
$w_1 v_2 = 0$.
$w_2 v_1 = (c^2, c^2, 0)$.
$v_1 \times v_2 = (c,c,0) \times (0,0,-c) = (c(-c)-0, 0- c(-c), 0-0) = (-c^2, c^2, 0)$.
Sum: $(c^2-c^2, c^2+c^2, 0) = (0, 2c^2, 0) = (0, 1, 0)$.
正確。
