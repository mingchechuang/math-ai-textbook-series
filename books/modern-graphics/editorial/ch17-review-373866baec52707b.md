## 必須修正

### 1. 行列式下溢可能使正尺度變換被判成鏡射

**定位：**`transform_frame`：

```python
det_a = np.linalg.det(A)
mirror_sign = 1.0 if det_a > 0.0 else -1.0
```

**原因：**前段以奇異值比例允許良態的小尺度矩陣，但行列式可能因浮點下溢變成 `0.0`。此時即使 $A$ 的行列式在數學上為正，程式也會把手性判為負。例如正的極小均勻縮放矩陣，若行列式下溢為零，就會錯誤翻轉 $h$。這與章節宣稱的尺度穩健性不一致。

**修法：**用具符號對數行列式取得符號，例如 `sign, logabsdet = np.linalg.slogdet(A)`，並以 `sign` 決定手性；也可補上非有限或零符號的錯誤處理。另需注意，極端尺度仍可能讓逆轉置計算溢位，應有適當拒絕或警告。

## 建議修正

### UV 退化判定仍使用固定絕對容差

**定位：**`triangle_tangent_frame`：

```python
if abs(det_uv) <= uv_eps:
    raise ValueError("退化 UV 三角形")
```

**原因：**UV 三角形的面積會隨 UV 尺度平方改變。小型但形狀良好的 UV 島也可能因面積小而被拒絕；反過來，面積不小但形狀極狹長的 UV 三角形仍可能數值不穩。這與「依尺度設定 epsilon」的原則不完全一致。

**修法：**以 UV 邊長尺度正規化行列式，或直接檢查 UV 差分矩陣的奇異值比例／條件數；並說明此判定衡量的是退化或病態，不只是絕對面積。
