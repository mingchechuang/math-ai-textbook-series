# 審稿結果

本版已達最低字數，主要公式、例題、連續性判定、習題 4重算及曲率／參速界線均正確。尚有一個會使新增弧長函式失敗的退化案例，以及分段樣條在「全域參數」下的 $C^1$ 條件未納入區段尺度，需修正後才能批准。

## 一、必須修正的實質問題

### 1. 弧長反查函式會在零長區間除以零

**原句：**

```python
alpha = (target_s - arc[lo]) / (arc[hi] - arc[lo])
```

**問題：**

若曲線為常數曲線，或取樣區間兩端得到同一點，則：

$$
L_{k+1}-L_k=0.
$$

此時程式會除以零。特別是所有控制點重合時，`total == 0`，即使合法輸入 `target_s=0` 也會失敗。末端存在零長取樣段時，`target_s=total` 也可能遇到相同問題。

此外，`m=0` 時：

```python
ts = [k / m for k in range(m + 1)]
```

會直接除以零。

**修法：**

```python
if not isinstance(m, int) or m < 1:
    raise ValueError("m 必須是正整數")

if total <= length_tol:
    if abs(target_s) <= length_tol:
        return 0.0
    raise ValueError("零長曲線只接受 target_s=0")
```

反查時應跳過重複弧長，或檢查分母：

```python
denom = arc[hi] - arc[lo]
if denom <= length_tol:
    return ts[lo]
```

`length_tol` 應按場景尺度設定。

---

### 2. `target_s` 的邊界測試不含浮點容差

**原句：**

```python
if target_s < 0.0 or target_s > total:
    raise ValueError(...)
```

**問題：**

由其他浮點運算得到的目標值可能僅因捨入而略大於 `total`，造成不必要的拒絕。

**修法：**

```python
if target_s < -length_tol or target_s > total + length_tol:
    raise ValueError(...)
target_s = min(max(target_s, 0.0), total)
```

---

### 3. 分段樣條的全域 $C^1$ 條件缺少參數尺度

**原句：**

> $C^1$：$m(P_m-P_{m-1})=n(Q_1-Q_0)$。

以及：

> 每段使用局部參數 $u\in[0,1]$。全域時間需映射至對應段。

**問題：**

上述 $C^1$ 等式只適用於直接比較兩段的局部參數導數，或兩段擁有相同的全域參數區間長度。若 A、B 的全域區間長度分別為

$$
\Delta s_A=s_1^{(A)}-s_0^{(A)},\qquad
\Delta s_B=s_1^{(B)}-s_0^{(B)},
$$

由鏈式法則：

$$
\frac{dA}{ds}
=\frac{1}{\Delta s_A}\frac{dA}{du},
\qquad
\frac{dB}{ds}
=\frac{1}{\Delta s_B}\frac{dB}{du}.
$$

所以相對於全域參數 $s$ 的 $C^1$ 條件應為：

$$
\frac{m(P_m-P_{m-1})}{\Delta s_A}
=
\frac{n(Q_1-Q_0)}{\Delta s_B}.
$$

**修法：**

將目前條件明確標為「兩段皆以局部 $u\in[0,1]$ 比較時」，並在「全域時間到局部參數」一節補上鏈式法則。否則讀者可能先調整控制邊達到局部 $C^1$，之後配置不同段時長，又在全域動畫中產生速度跳變。

---

### 4. `m=200` 的誤差保證沒有依據

**原句：**

> 以公尺級場景、曲率中等的曲線而言，`m=200` 通常足以讓弧長相對誤差落在千分之一以下。

**問題：**

弧長誤差取決於曲線控制點配置、尺度、曲率及折返程度，不能只由「公尺級」與「曲率中等」保證。稿件沒有推導誤差界，也未執行數值實驗；這違反未實測不得宣稱品質的要求。

**修法：**

改為：

> `m=200` 僅為示範初值，不構成誤差保證。可比較 $M$ 與 $2M$ 的弧長估計，直到兩者差異低於指定容差。

例如：

$$
\frac{|L_{2M}-L_M|}{\max(L_{2M},\epsilon_L)}<\tau.
$$

仍應說明這是收斂檢查，不是對真實弧長誤差的嚴格上界。

---

### 5. 弧長函式的使用說明無法直接取得總長

**原句：**

> 用法是先用 `de_casteljau` 計算曲線總弧長……

**問題：**

`de_casteljau` 只計算單一曲線點，不會回傳總弧長；`arc_length_reparameterize` 又只回傳 $t$，沒有向呼叫端提供其內部算出的 `total`。因此說明與 API 不一致。

**修法：**

拆成兩個函式：

```python
ts, arc = build_arc_length_table(pts, m)
t = parameter_at_length(ts, arc, target_s)
```

或讓建表函式回傳 `(ts, arc, total)`。如此等分總長時不必為每個目標弧長重建整張表，目前寫法會重複做相同的 $O(M)$ 求值。
