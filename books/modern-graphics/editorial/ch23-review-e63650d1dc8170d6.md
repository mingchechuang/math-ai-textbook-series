## 一、新增臨界角測試逐式核對

### 測試 1：恰在臨界角，應有沿界面的折射射線

構造：$d=(\sin\theta_c,\cos\theta_c,0)=(3/4,\sqrt7/4,0)$、$N=\text{down}=(0,-1,0)$、$(n_1,n_2)=(\text{water},\text{air})$。

- `face_normal`：$\mathbf d\cdot\mathbf N=-\sqrt7/4<0$ → 通過 ✓
- $c_i=-d\cdot N=\sqrt7/4$，$\eta=n_1/n_2=4/3$
- $k=1-\eta^2(1-c_i^2)=1-(16/9)(1-7/16)=1-(16/9)(9/16)=0$
- `k < -1e-14` 為 false → **不**進入全反射分支 ✓
- $c_t=\sqrt{\max(0,0)}=0$
- $\mathbf t=\eta\mathbf d+(\eta c_i-c_t)\mathbf N=(1,\sqrt7/3,0)+(0,-\sqrt7/3,0)=(1,0,0)$
- $|\mathbf t|=1$ ✓；$\mathbf t\cdot\mathbf N=0$，即沿界面 ✓

`assert critical_ray is not None` 通過 ✓

### 測試 2：「低於臨界角」應仍有折射

$d_y=\cos\theta_c+10^{-5}>\cos\theta_c$ ⇒ $\theta_i<\theta_c$ ⇒ 有折射。
- $c_i=d_y>\cos\theta_c$ ⇒ $1-c_i^2<9/16$ ⇒ $\sin\theta_i<3/4$ ⇒ $(4/3)\sin\theta_i<1$ ⇒ **有** 透射 ✓

`assert below_ray is not None` 通過 ✓

### 測試 3：「高於臨界角」應全反射

$d_y=\cos\theta_c-10^{-5}<\cos\theta_c$ ⇒ $\theta_i>\theta_c$ ⇒ 全反射。
- $k\approx 1-(16/9)(9/16+(8\sqrt7/18)\cdot10^{-5})\approx -2.35\times10^{-5}< -10^{-14}$ → 全反射分支 ✓
- 回傳 `(reflected, None, 1.0)`；`above_ray is None`、`above_f == 1.0` 通過 ✓

### 單位性與符號

三條測試構造的方向 $x^2+y^2=1$ 均為單位向量 ✓；`face_normal` 對其再取 `unit` 無害。`critical_sin=air/water=3/4` 正是 $n_2/n_1$，與臨界角公式 $\theta_c=\arcsin(n_2/n_1)$ 一致 ✓。

**小結**：新增三條斷言正確且設計良好，使程式同時覆蓋「恰在臨界」、「低於臨界」、「高於臨界」三個關鍵狀態。
