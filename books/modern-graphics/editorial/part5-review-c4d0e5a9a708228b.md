## 跨章審稿結果

第25～30章的直向量、右手正角、父矩陣左乘子矩陣，以及第27章的 inverse bind 空間方向整體一致。第29章明確將線性公尺深度與 OpenGL 深度緩衝值分開；第30章亦明示其二維示意圖**沒有**三維深度通道，未與第29章的輸出混稱。不過，下列實質問題仍須修訂。

1. **第26章混淆四元數球面上的對徑路徑與旋轉的最短路徑。**定位：SLERP 邊界段稱「$d=-1$……『最短路徑』其實不唯一」，又稱短弧調整後的 nlerp 是其中一個選擇。原始 $q_0$ 與 $-q_0$ 在 $S^3$ 上確有多條等長半圓弧；但它們表示**同一旋轉**。程式先翻轉 $q_1$，使兩端成為同一四元數，隨後 nlerp 給出的是**常值姿態、零長度路徑**，不是選了一條半圓弧。請分別說明球面原始端點與雙覆蓋後的旋轉路徑。

2. **第26章習題2(c)的驗收條件對任意姿態不成立。**定位：解答要求任取 $q_0,q_1$ 後，令 $\theta_k=2\arccos(w_k)$，「$\theta_k$ 對 $k$ 線性」。SLERP 保證的是**相對起點的旋轉距離**按參數線性變化，不保證每個結果相對恆等旋轉的角度線性。請限定 $q_0=(1,0,0,0)$、選定單軸短弧；或改測 $2\arccos\!\left(|q_0\cdot q_t|\right)$ 是否等於 $t$ 乘兩端的最短旋轉距離。

3. **第26章習題4將密集取樣測試說成能辨識長弧，與測試量不符。**定位：「若實作走長弧……相鄰樣本會出現 $|\operatorname{dot}|$ 突然變小。」平滑走完長弧並密集取樣時，**相鄰**姿態仍可非常接近，內積絕對值仍接近1；該斷言不能可靠區分長、短弧。請另以已知兩端姿態檢查中點或四分點的旋轉方向／相對角度，並保留相鄰樣本測試作為偵測突變的輔助檢查。

4. **第28章求解器的外部參數驗證不足。**定位：`solve_ik` 檢查 `damping <= 0` 等條件，卻未像陣列輸入一樣檢查這些純量是否有限。例如 `damping=float("nan")` 不會被該比較拒絕，後續可能產生非有限更新或線性代數錯誤。請驗證 `damping`、`tolerance`、`max_step`、`h` 的有限性，並為 `max_iter` 驗證整數及正值。這是一般介面的邊界問題；目前稿中給定的正常數值例題不受影響。

5. **第30章未遵守本卷指定的數學標記。**定位：正文多處使用 `\(k\)`、`\(+X\)` 等；共通規格要求行內數學採 `$...$`。請統一改為 `$k$`、`$+X$` 等，並檢查全章同類標記。

**手算與接口抽核：**第27章尾骨作用於 $(2,0,0)$ 得 $(1,1,0)$，以 $(0.25,0.75)$ 混合得 $(1.25,0.75,0)$；第28章例一的 $J=\begin{bmatrix}-1&-1\\1&0\end{bmatrix}$ 與 DLS 更新 $(0.6,0.2)^T$ 正確。第29章深度例取 $z=1,n=0.1,f=10$，得 $d=9/9.9\approx0.9091$；其影像陣列採 `[v,u]`，與共通像素慣例一致。第30章習題的 `round(12.5)=12` 符合其明示的 Python 取整規則。第27章法線近似已交代權重梯度限制；第30章的 sRGB 示意編碼值與整數 ID 也已區分。

**可選改進（不另作拒稿理由）：**第30章的唯讀查詢只核對部分 manifest／標註欄位，尚未核對設定摘要或影像、遮罩內容；可將「可稽核」的驗收措辭限定於已實作的檢查，或增加對應測試。第26章來源清單含多項與四元數論點關聯較弱的資料，可精簡並維持「非逐條查證」界線。
