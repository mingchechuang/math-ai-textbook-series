## 審查結論

第 21 章已修正輻射亮度與輻照度的單位區分，先前指出的問題已解決。另有一項實質問題：第 20 章三角形求交使用固定絕對容差，且未限制方向向量長度，會使同一幾何射線的判定隨方向縮放而改變。

## 必須修正

1. **第 20 章 `triangle_hit` 的 determinant 容差不具尺度一致性**  
   定位程式：

   ```python
   det = dot(e1, p)
   if abs(det) < 1e-12:
       return None
   ```

   本章允許方向向量未正規化，且已說明改變方向長度會改變 \(t\)。但此處的 `det` 也與方向長度成正比；同一條幾何射線若將方向乘上很小的常數，可能因 `abs(det) < 1e-12` 被判為無交點，儘管幾何相交並未改變。固定絕對容差也未隨三角形尺度調整。

   **修法：**統一先正規化射線方向，或令退化／近平行判定採相對尺度，例如比較
   \[
   |det| < \tau\,\|\mathbf d\|\,\|\mathbf e_1\|\,\|\mathbf e_2\|,
   \]
   並說明 \(\tau\) 是無因次容差。補測同一射線方向乘不同正比例常數後，命中與否應一致；若採正規化策略，則另檢查 \(t\) 與距離的換算契約。
