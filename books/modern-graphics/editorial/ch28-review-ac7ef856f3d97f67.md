## 二、真錯誤（無）

以下各點經逐項重算，確認正確，列出以資佐證。

### 1. 兩連桿 FK 公式（「數學與幾何推導」）

原式：
$$\mathbf f(\boldsymbol\theta)=\mathbf b+\begin{bmatrix}L_1\cos\theta_1+L_2\cos(\theta_1+\theta_2)\\L_1\sin\theta_1+L_2\sin(\theta_1+\theta_2)\end{bmatrix}$$

核對：由 $M_{\text{parent}}M_{\text{local}}$ 逐層展開，關節 2 世界位置為 $\mathbf b+R(\theta_1)(L_1,0)^T$，末端為關節 2 加 $R(\theta_1+\theta_2)(L_2,0)^T$，展開即上式。**正確。**

### 2. 可達範圍（「兩連桿 FK 與可達範圍」）

原句：「$|L_1-L_2|\le r\le L_1+L_2$」。

核對：標準三角不等式；在無角度界限時為充要條件，加上界限僅為必要條件——文中已明示。**正確。**

### 3. 位置 Jacobian（「位置 Jacobian」）

逐項求導：
- $J_{11}=-L_1\sin\theta_1-L_2\sin(\theta_1+\theta_2)$
- $J_{12}=-L_2\sin(\theta_1+\theta_2)$
- $J_{21}=\ L_1\cos\theta_1+L_2\cos(\theta_1+\theta_2)$
- $J_{22}=\ L_2\cos(\theta_1+\theta_2)$

與原式一致。**正確。**

### 4. 有限差分 Jacobian

中央差分 $J_{:,j}\approx \frac{\mathbf f(\boldsymbol\theta+h\mathbf e_j)-\mathbf f(\boldsymbol\theta-h\mathbf e_j)}{2h}$，$h>0$ 以弧度為單位，維度為「公尺／弧度」。**正確。**

### 5. DLS 更新（「阻尼最小平方與關節界限」）

原式：$\Delta\boldsymbol\theta=J^T(JJ^T+\lambda^2I)^{-1}\mathbf e$。

推導：對 $\|J\Delta\boldsymbol\theta-\mathbf e\|^2+\lambda^2\|\Delta\boldsymbol\theta\|^2$ 取梯度得 $(J^TJ+\lambda^2I)\Delta\boldsymbol\theta=J^T\mathbf e$。利用恆等式 $J^T(JJ^T+\lambda^2I)=(J^TJ+\lambda^2I)J^T$，可證兩種形式等價。**正確。**

### 6. 手算例一（FK、Jacobian、DLS）

- $\boldsymbol\theta=(0,\pi/2)$、$L_1=L_2=1$：$f_x=1\cdot1+1\cdot0=1$；$f_y=1\cdot0+1\cdot1=1$。$f=(1,1)^T$ ✓
- $J_{11}=0-1=-1$；$J_{12}=-1$；$J_{21}=1+0=1$；$J_{22}=0$。$J=[[-1,-1],[1,0]]$ ✓
- $\mathbf e=(0,2)-(1,1)=(-1,1)^T$ ✓
- $JJ^T+I=\begin{pmatrix}3&-1\\-1&2\end{pmatrix}$，$\det=5$，反矩陣乘 $\mathbf e$ 得 $(-0.2,0.4)^T$ ✓
- $\Delta\boldsymbol\theta=J^T(-0.2,0.4)^T=(0.6,0.2)^T$ ✓

**全項正確。**

### 7. 手算例二（距離可達≠受限可達）

- $L_1=1,L_2=0.5$，$r=1.2$：$0.5\le1.2\le1.5$ ✓
- 兩關節固定零角時末端 $(1.5,0)$，無法抵達 $(1.2,0)$ ✓
- 目標 $(2,0)$：$r=2>1.5$，最近未受限末端 $(1.5,0)$，殘差 $0.5$ ✓

**正確。**

### 8. 程式（`fk`、`jacobian_fd`、`solve_ik`）

逐行核對：
- `fk`：`a1=q[0]`、`a2=q[0]+q[1]`，正弦餘弦展開與公式一致。✓
- `jacobian_fd`：以 `step[j]=h` 生成擾動，對 $j$ 求中央差分。✓
- `solve_ik`：
  - 輸入驗證與形狀檢查完整；`np.clip(q, lo, hi)` 保證初始在界限內。
  - `outside_ring` 判準：`radius > L.sum()+tolerance` 或 `radius < abs(L[0]-L[1])-tolerance`，邏輯正確。
  - DLS：`J.T @ solve(J@J.T + damping**2 * I, error)`，與公式相符。
  - 步長裁剪、16 次回退搜尋、僅接受實際殘差下降，皆與描述一致。
  - 返回 `iteration + (iteration < max_iter)` 表示已執行迭代次數；`for...else` 的 `iteration=max_iter` 設定正確。

**程式數學無誤。**

### 9. 程式測試斷言（紙上驗證）

- `fk([0, π/2], [1,1])` 與手算 (1,1) 相符 ✓
- `jacobian_fd` 於同點給出 $J=[[-1,-1],[1,0]]$ ✓
- 目標 $(1,1)$ 從 $(0.3,0.8)$ 起始：起始殘差約 $0.45$ 公尺（$\mathbf f(0.3,0.8)\approx(1.4089,1.1867)$），max_step $0.25$ rad，200 次迭代足以收斂到 $10^{-5}$ 以下。**預期可通過。**
- 目標 $(3,0)$ 從 $(0,0)$ 起始：
  - 起點即為 $(2,0)$，$\mathbf e=(1,0)$。此時 $J=[[0,0],[2,1]]$ 奇異。

  - `delta_norm=0 < 1e-12`，狀態設為「更新太小」；`outside_ring=True`，前置「目標在未受限可達圓環外；」。最終 `far_residual=1`，且 status 含「圓環外」。**兩條斷言成立。**

## 三、可選文風／篇幅建議（不影響批准）

以下非真錯誤，僅供作者參考。

1. **篇幅低於目標。** 實測 `measured_characters=3222`，滿足 3000 下限，但低於每章約 4500 的目標。建議：
   - 在「數學與幾何推導」補一段「肘上／肘下雙解」的幾何構造，並把 FK 推導對應到餘弦定理，說明無角度界限時存在兩個 $\theta_2$ 解。
   - 在「逐步手算例題」加一個「角度界限導致目標不可達」的具體數值案例（僅加限制不改目標），與例二互補。
   - 程式可加一個 `solve_ik` 的小呼叫範例，展示「上下限設為零、目標 (1,1)」，可直接列入「測試與預期結果」。

2. **`iteration` 回傳語意**。`iteration + (iteration < max_iter)` 的寫法精巧但易誤讀。建議在程式碼旁加註「回傳：已執行迭代次數（含成功那次）」，或在返回前以變數命名為 `iterations_used`。

3. **`outside_ring` 與 `tolerance` 的耦合**。`radius > L.sum() + tolerance` 的語意是「超出容差才標記」，等於是拿位置容差當作可達性容差的參數。建議在「除錯」一節加一句：「若希望嚴格標記圓環外，可另設獨立的可達性容差」，避免沿用時造成誤解。

4. **範例空間交代。** 例一在 XY 平面，但「問題與直覺」對場景描述是「魚身與魚尾兩個旋轉關節的角度」——讀者可能誤解為 3D。建議在學習目標或問題段落明示「本章為 2D 平面示範，3D 旋轉由前章四元數處理」。

5. **來源清單**。G1 註明為「座標與變換慣例的延伸參考」尚可，但本章核心（Jacobian、DLS、受限最佳化）在列出的三個來源中無直接對應。可考慮：
   - 加註一段說明本章公式源自機器人學經典（例如 Buss 2004 的 IK 講義）而不列入已查核來源；
   - 或明示 G1 僅作為座標系／變換慣例的對照，不涵蓋 IK 主體。

6. **`solve_ik` 的 `else` 分支**。「for...else」寫法是正確的，但對非 Python 熟練讀者可能不易察覺 `iteration` 已在迴圈結束後被重設為 `max_iter`。可以用註解或改成在 `for` 之後顯式賦值，可讀性較佳。
