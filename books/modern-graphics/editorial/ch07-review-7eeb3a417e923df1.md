## 必須修正

1. **尺度容差在小模型下不具尺度相對性**

   原文稱「面積容差應與 \(L^2\) 成比例」；程式卻寫成：

   ```python
   scale = max(float(np.linalg.norm(extent)), 1.0)
   cross_tol = relative_tol * scale * scale
   ```

   當模型尺度小於 1 公尺時，`scale` 固定為 1，容差不再隨模型尺度平方縮放。這會使縮小模型後，原本相同形狀的三角形可能被判為近退化，與文字說明及尺度相對判定不符。

   **修法：**使用實際正尺度計算，例如 `scale = float(np.linalg.norm(extent))`，並另行處理 `scale == 0` 或非有限座標的情況。補充說明 `extent` 範數是此處採用的代表長度。

2. **故障注入沒有寫明新增面也會被判為退化**

   原文：「加入面 `[0, 0, 1]`，預期列入重複索引面與退化面。」這兩項預期與程式邏輯一致。不過前一句說「可再進行三種故障注入」，後文又另提非法索引例子；讀者容易不清楚非法索引是否是第四種注入。另有一處更直接的落差：對 `[0,0,1]`，程式會繼續建邊表與 vertex link，可能使附帶拓撲報告難以解讀。

   **修法：**明說重複索引面會列入退化面，但本檢查器不會因而停止；建議將此案例另作「錯誤輸入後應先清理、再解讀拓撲」的示範，或在發現重複索引時停止後續拓撲分析。
