## 2. 逐項核對

### 2.1 維度與座標系
- **狀態**：✅ 正確
- **核對**：
    - 世界系：$+X$ 右，$+Y$ 上，$+Z$ 向觀者。
    - 骨架 $c(t)=(t,0,0)$ 沿 $+X$。
    - 參考向量 $R=(0,1,0)$（$+Y$）。
    - $T=(1,0,0)$。
    - $B = T \times R = (1,0,0) \times (0,1,0) = (0,0,1)$（$+Z$）。
    - $N = B \times T = (0,0,1) \times (1,0,0) = (0,1,0)$（$+Y$）。
    - 基底 $(T, N, B)$ 即 $(+X, +Y, +Z)$，右手系，$\det=+1$。
    - 符合慣例「右手世界系」與「三角形前面按外向法線看為逆時針」。

### 2.2 局部框架與法線
- **狀態**：✅ 正確
- **核對**：
    - 程式碼 `frame_from_tangent` 計算 $B = \text{cross}(T, \text{ref})$，$N = \text{cross}(B, T)$。
    - 手算例 11.1 中，$N=(0,1,0)$，$B=(0,0,1)$。
    - 截面點生成公式 $p = c + r(\cos\theta N + \sin\theta B)$。
    - 當 $\theta=0$，點在 $N$ 方向（$+Y$）。
    - 當 $\theta=\pi/2$，點在 $B$ 方向（$+Z$）。
    - 從外向法線（例如 $+Y$ 方向的法線）看，$\theta$ 增加方向是 $+Y \to +Z$。在 $XZ$ 平面投影（從 $+Y$ 看），$+Z$ 是向左（因為 $X$ 右 $Z$ 出，從上方看 $Z$ 軸指向左/後）。
    - 讓我們確認繞序：
        - $a$ ($\theta=0, +Y$), $b$ ($\theta=\pi/2, +Z$), $c$ ($\theta=0, +Y$ next ring), $d$ ($\theta=\pi/2, +Z$ next ring).
        - 三角形 $(a, b, d)$。
        - $e_1 = b - a$。$e_2 = d - a$。
        - 在例 11.1 的說明中，驗證了 $e_1 \times e_2$ 指向外側（$+Y, +Z$ 分量大於0）。
        - 程式碼 `sweep_circle` 使用 `(a, b, d)` 和 `(a, d, c)`。
        - 測試 2 中明確檢查了法線分量，確保向內/向外邏輯正確。
    - 結論：繞序邏輯自洽且符合外向法線慣例。

### 2.3 自交與退化判準
- **狀態**：✅ 正確
- **核對**：
    - 自交判準 $s(t) \kappa(t) < 1$ 被正確描述為「必要條件」。
    - 例 11.2 手算：$R=0.3, \kappa \approx 3.33$。$r_0=0.2 \Rightarrow 0.2 \times 3.33 = 0.666 < 1$（無自交）。$r_0=0.4 \Rightarrow 0.4 \times 3.33 = 1.33 > 1$（可能自交）。計算正確。
    - 退化判準：使用外積長度，單位說明清晰（平方公尺）。
    - `check_curvature_radius` 函式邏輯合理，使用離散曲率估計。
