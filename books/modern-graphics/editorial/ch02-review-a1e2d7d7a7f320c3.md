## 必須修正

1. **斷言測試會吞掉自己產生的 `AssertionError`**  
   定位：`run_assertions()` 與「習題 2 解答」中採用以下結構的測試：

   ```python
   try:
       normalize([0, 0, 0])
       raise AssertionError("零向量測試應該失敗")
   except ValueError:
       pass
   ```

   原因：`AssertionError` 是 `ValueError` 的子類。若 `normalize` 未如預期拋出錯誤，接著產生的 `AssertionError` 也會被 `except ValueError` 接住，測試便錯誤通過。共線三角形測試及錯誤 shape 測試也有同樣問題。  
   修法：只將函式呼叫放在 `try` 區塊中，於 `else` 區塊發出 `AssertionError`；或以 `pytest.raises(ValueError)` 撰寫，但須提供對應測試框架。此處應優先用不依賴額外套件的前一種方式。

2. **近退化例題的比例值近似不正確**  
   定位：「例題三：形狀容差與絕對面積」：

   ```math
   \rho =
   \frac{1}{1000\sqrt{1000^2+0.001^2}}
   \approx 10^{-6}.
   ```

   原因：分母約為 \(10^6\)，故比例約為 \(10^{-6}\)，但較精確地說是略小於 \(10^{-6}\)，實際約為 \(9.999999999995\times10^{-7}\)。目前的近似符號若只表達有效位數，尚可理解；但推導可寫得更清楚，避免讀者誤以為分母精確等於 \(10^6\)。  
   修法：寫成「約 \(9.999999999995\times10^{-7}\)，因此量級約為 \(10^{-6}\)」，或明確標成「量級約為 \(10^{-6}\)」。
