### 1. 習題 4 要求數值結果，但解答仍未計算

**原句：**

> 透過程式計算 11 個點。

### 2. 曲率與等參數取樣的因果仍然錯誤

**原句：**

> 預期弦長在曲率較大或速度較快的區間……較大。

以及：

> 生成網格時，曲率大處頂點稀疏，無法精確捕捉形狀。

**問題：**

相同 $\Delta t$ 對應的弧長主要由參速

$$
\frac{ds}{dt}=\|B'(t)\|
$$

決定，曲率大不代表弦長必然較大。高曲率反而可能在短弧段內造成較大折線近似誤差。

弧長均勻與曲率自適應是兩種不同目標：

- 弧長重參數化：使空間取樣間距近似均勻。
- 曲率／平坦度自適應細分：控制曲線與折線間的幾何誤差。

**修法：**

改為：

> 等參數取樣的弦長差異來自 $\|B'(t)\|$ 的變化。即使改成等弧長取樣，高曲率區仍可能需要額外細分，才能限制折線近似誤差。

### 3. `de_casteljau` 對空控制點會索引失敗

**原句：**

```python
pts = [np.asarray(p, dtype=float) for p in pts]
current = pts
...
return current[0]
```

**問題：**

若 `pts=[]`，最後會發生 `IndexError`。單一控制點雖可回傳常數曲線，但應明示為允許情況。控制點維度不一致時，也會在較晚的運算中產生不易理解的 broadcasting 錯誤。

`bezier_tangent` 對空控制點同樣會在 `np.zeros_like(pts[0])` 失敗。

**修法：**

新增共用驗證：

```python
def prepare_points(pts):
    pts = [np.asarray(p, dtype=float) for p in pts]
    if not pts:
        raise ValueError("至少需要一個控制點")
    shape = pts[0].shape
    if len(shape) != 1 or any(p.shape != shape for p in pts):
        raise ValueError("所有控制點必須為相同維度的一維向量")
    return pts
```

並由兩個函式呼叫。

### 4. `check_g1_continuity` 實際上只支援 2D

**原句：**

```python
cross = v_a[0] * v_b[1] - v_a[1] * v_b[0]
```

**問題：**

此式是 2D 行列式，但函式名稱與輸入檢查沒有明示僅支援 2D。本章前文把 Bézier 曲線作一般向量曲線處理，養殖案例又提到脊柱路徑，容易讓讀者傳入 3D 點。

**修法：**

二選一：

- 將函式命名為 `check_g1_continuity_2d`，並驗證每點 shape 為 `(2,)`。
- 改用維度無關的平行判定，例如比較正規化向量：

```python
ua = v_a / np.linalg.norm(v_a)
ub = v_b / np.linalg.norm(v_b)
if np.linalg.norm(ua - ub) > tol:
    return False, "Tangents are not aligned"
```

這同時檢查同向，適用 2D 與 3D。

### 5. $C^0$ 測試未關閉相對容差

**原句：**

```python
np.allclose(p_end, q_start, atol=tol)
```

**問題：**

`np.allclose` 仍會使用預設 `rtol`。如此 `tol` 並非唯一控制條件；在大座標值下，可能接受遠大於 `tol` 的絕對差異。

**修法：**

```python
np.allclose(p_end, q_start, rtol=0.0, atol=tol)
```

並說明 `tol` 應按場景尺度設定，而不是固定的物理閾值。

### 6. 動畫段落誤把不同骨骼變換等同單一仿射不變性

**原句：**

> 由於變換不變性，對控制點施加骨骼變換後，曲線自動正確變形……

**問題：**

Bézier 的仿射不變性是指所有控制點施加同一個仿射變換 $T$：

$$
T\!\left(\sum_i w_iP_i\right)=\sum_iw_iT(P_i).
$$

若不同控制點受不同骨骼矩陣或不同蒙皮權重影響，就不是單一 $T$，不能直接用此性質證明「自動正確」。重新以變形後控制點求值當然會得到一條新曲線，但這不等於骨骼變形與原曲線求值可交換。

**修法：**

改為：

> 若整段曲線的所有控制點施加同一仿射變換，曲線求值與該變換可交換。若控制點分別受不同骨骼影響，則只是以變形後控制點重新定義曲線，需另行驗證拼接連續性與形狀品質。

### 凸包測試的界線

**原句：**

> 凸包測試（Bernstein 權重非負性和為一）

這正確驗證了所實作 Bernstein 權重具備凸組合條件，但不是獨立的「點在幾何凸包內」演算法測試。建議改稱：

> 凸包性質的權重條件測試。

若學習目標堅持「凸包包含性測試」，可另加 2D 凸包與點包含測試；否則目前證明式測試可接受，但應精確命名。
