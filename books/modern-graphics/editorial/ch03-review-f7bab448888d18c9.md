## 二、公式核對（逐步重算）

1. **$T_2(a,b)$**：$3\times3$ 末欄 $(a,b,0)^T$、末橫列 $(0,0,1)$ → 作用於 $(x,y,1)$ 得 $(x+a,y+b,1)$ ✓
2. **$R_2(\theta)$ 第一縱行 $(\cos\theta,\sin\theta,0)$**：對 $e_x$ 作用確為 $(\cos\theta,\sin\theta)$；$\theta=\pi/2$ 得 $(0,1)$，與「$(1,0)$ 應轉到 $(0,1)$」自洽 ✓
3. **$R_z,R_x,R_y$ 符號**：$R_x$ 第二、三橫列 $(0,c,-s)$／$(0,s,c)$；$R_y$ $(c,0,s)$／$(-s,0,c)$，皆為右手正角 ✓
4. **$M=TRS$ 作用次序**：「先沿局部軸縮放，再旋轉，最後沿世界軸平移」——與「右側矩陣先作用」一致 ✓
5. **$M^{-1}=(TRS)^{-1}=S^{-1}R^{T}T(-t)$**：逆序法則展開無誤，文字「先扣除平移，再反向旋轉，最後逐軸除以縮放係數」與 $S^{-1}R^{T}T(-t)$ 由右而左的作用序完全吻合 ✓
6. **$T(t)p_h=(p+t,1)^T$、$T(t)v_h=(v,0)^T$**：直接驗算無誤 ✓

## 三、手算例題與習題解答重算

**例一** $p=(1,1,0),s=(2,1,1),\theta=\pi/2,t=(3,4,0)$
- 縮放 $(2,1,0)$ → $R_z(\pi/2)$ 得 $(-1,2,0)$ → 平移 $(2,6,0)$ ✓
- 逆推：$(-1,2,0)$ → $R_z(-\pi/2)$ 得 $(2,1,0)$ → 除以 $(2,1,1)$ 得 $(1,1,0)$ ✓
- 方向 $(1,0,0,0)$：縮放 $(2,0,0)$ → 旋轉 $(0,2,0)$，平移不作用 ✓

**例二** $TRp=(2,1,0,1)^T$、$RTp=(0,3,0,1)^T$ 逐項驗算正確 ✓

**習題1** $(1,2,0)$ → 縮放 $(2,6,0)$ → 旋轉 $(-6,2,0)$ → 平移 $(-2,1,0)$ ✓；逆推亦正確還原 $(1,2,0)$ ✓

**習題3** `scaling(...) @ rotation_z(...)` 為 $SR$，對 $(1,0,0,0)$ 得 $(0,1,0,0)$；所述操作 $RS$ 得 $(0,2,0,0)$，改法 `rotation_z @ scaling` 正確 ✓

**習題4** $(1,0,0)$ → 縮放 $(2,0,0)$ → 旋轉 $(0,2,0)$ → 局部平移 $(0,4,0)$ → 父平移 $(10,4,0)$ ✓；方向 $(0,2,0)$ ✓；$(M_{\text{parent}}M_{\text{local}})^{-1}=M_{\text{local}}^{-1}M_{\text{parent}}^{-1}$ 與「先撤父、再撤子」一致，逆推亦得 $(1,0,0,1)^T$ ✓
