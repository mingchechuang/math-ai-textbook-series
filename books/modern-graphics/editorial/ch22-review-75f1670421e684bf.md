## 必須修正

1. **球面光源背面樣本的 PDF 被錯誤設為零**  
   定位：`light_pdf_solid_angle`：

   ```python
   cosine_light = max(0.0, float(np.dot(light_normal, -wi)))
   if cosine_light <= 0.0:
       return 0.0
   ```

   原因：程式是**均勻抽樣整個球面**，其面積 PDF 在整個球面上皆為 `1 / light.area`。對背面點，單面光源的發光貢獻確實為零，但這不代表該點的抽樣 PDF 為零。將 PDF 設為零混淆了「樣本不發光」與「樣本不可能生成」。特別是 BSDF 射線命中背面時，對應的光源策略仍可能生成該位置；此處回傳零，會錯誤改變 MIS 權重。  
   修法：讓 PDF 函式回傳取樣分布的密度，不用發光餘弦將其歸零。另在發光貢獻計算中，依單面光源朝向判斷是否有能量；背面發光值為零，而不是抽樣 PDF 為零。若要只抽光源可見球冠，則須另外定義並實作該球冠的取樣分布及其 PDF，不能沿用整球均勻取樣的密度。

2. **需釐清面積取樣映射至方向時的 PDF／事件定義**  
   定位：「顯式光源取樣」的

   $$p_\omega=p_A\frac{r^2}{\cos\theta_L}$$

   以及「多光源的完整 PDF」對混合方向 PDF 的說明。  
   原因：面積取樣到立體角的轉換需使用光源端面積元素對方向的 Jacobian；若光源表面到方向的映射不是一對一，方向 PDF 應加總同方向所有可生成分支的密度。稿件後文已局部提及多個光源的混合 PDF，卻未明確說明球面整體取樣時同一方向可能對應球面上的多個點，因而與程式的 `light_pdf_solid_angle` 定義互相牽連。  
   修法：明確界定 MIS 比較的是「光源表面點事件」還是「方向事件」，並在 NEE 與 BSDF 命中光源兩側採用一致的事件與 PDF。若採方向 PDF，對所有可生成該方向且有關聯的光源點分支計算總密度；若採表面點事件，則需說明 BSDF 命中事件如何對應到同一事件空間。至少補一個球面光源的前後表面案例，避免讀者把單一交點的 Jacobian 誤當成方向總 PDF。
