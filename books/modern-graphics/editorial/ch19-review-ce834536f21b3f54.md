# 審稿結果

本版多數核心公式與容差維度已改善，也加入可重現測試；但仍有手算錯誤、函式型別不符、渲染場景與預期影像矛盾，以及習題引用不存在程式等問題。

## 一、必須修正的實質錯誤

### 1. 三角形手算仍保留錯誤外積

**原句：**

> $\mathbf q=(0,0,0.2)$  
> $v=-0.2$。  
> 等等，這裡 $v$ 為負？讓我們重新檢查外積。

**錯誤原因：**

正式推導中仍先給出錯誤結果。正確外積為：

$$
(0.2,0.2,-1)\times(1,0,0)
=(0,-1,-0.2).
$$

**修法：**

刪除錯誤段落，直接寫：

$$
\mathbf q=(0,-1,-0.2),
$$

$$
v=(0,0,1)\cdot(0,-1,-0.2)\times(-1)=0.2.
$$

若要展示常見錯誤，須另設明確標題，不能混入主解答。

---

### 2. `intersect_triangle` 型別標註與實際回傳值不符

**原句：**

```python
def intersect_triangle(...) -> Optional[
    Tuple[float, np.ndarray, Tuple[float, float, float]]
]:
```

實際回傳：

```python
return t, point, (w0, w1, w2), n
```

**錯誤原因：**

型別標註宣告三個元素，實際是四個元素。

**修法：**

```python
def intersect_triangle(
    ray: Ray, tri: Triangle
) -> Optional[
    Tuple[
        float,
        np.ndarray,
        Tuple[float, float, float],
        np.ndarray
    ]
]:
```

或使用 `NamedTuple`／dataclass 定義命中紀錄，避免索引意義不清。

---

### 3. 渲染測試場景與聲稱的預期影像矛盾

**原句：**

```python
s = Sphere(np.array([0.0, 0.0, 0.0]), 1.0)
p = Plane(np.array([0.0, 1.0, 0.0]), 0.0)
tri = Triangle(
    np.array([0.0, 0.0, 0.0]),
    np.array([1.0, 0.0, 0.0]),
    np.array([0.0, 1.0, 0.0])
)
img = render(
    16, 16, [s, p, tri],
    np.array([0.0, 1.0, 0.0]),
    np.array([0.0, 0.0, -1.0])
)
```

預期描述：

> 畫面中央有紅色球體。下方有綠色平面。後方有藍色三角形。

**錯誤原因：**

- 相機 $(0,1,0)$ 正好位於單位球表面。
- 三角形位於 $z=0$ 平面，相機也在 $z=0$，其交點主要是 $t=0$，會被 `t_min` 排除。
- 三角形不在「後方」，也不應預期正常顯示。
- 球體、平面與三角形共用測試物件，幾何配置不適合作為聲稱的展示場景。

**修法：**

將單元測試物件與渲染場景分開，例如：

```python
scene_sphere = Sphere(
    np.array([0.0, 0.0, -2.0]), 0.5,
    np.array([1.0, 0.0, 0.0])
)
scene_plane = Plane(
    np.array([0.0, 1.0, 0.0]), 0.0,
    np.array([0.0, 1.0, 0.0])
)
scene_tri = Triangle(
    np.array([-1.0, 0.1, -3.0]),
    np.array([1.0, 0.1, -3.0]),
    np.array([0.0, 1.5, -3.0]),
    np.array([0.0, 0.0, 1.0])
)
```

相機可維持 $(0,1,0)$ 朝 $-Z$。仍應以像素命中數或指定像素顏色作驗收，不能只靠視覺描述。

### 4. 平面名稱寫錯

**原句：**

> 射線平行於 XY 平面，預期 `None`。

但測試平面是：

```python
Plane(np.array([0.0, 1.0, 0.0]), 0.0)
```

**錯誤原因：**

其方程為 $y=0$，是 XZ 平面，不是 XY 平面。XY 平面的法線應為 $(0,0,1)$。

**修法：**

將敘述改為「射線平行於 XZ 平面」，或改測試平面法線。

---

### 5. `q == 0` 不等同一般相切

**原句：**

> 若 $q=0$（相切），$t_0=-b/(2a)$。

**錯誤原因：**

一般相切只代表 $\Delta=0$。例如 $(t-5)^2=0$ 中 $b=-10$，穩定公式得到 $q=5$，不是零。

在本章 $a=1$ 的情況下，`q == 0` 只出現在更特殊的 $b=0,\Delta=0$ 情形，也就是 $t=0$ 的雙根。

**修法：**

改為：

> 若 $q=0$，不可計算 $c/q$；此時直接使用雙根 $-b/(2a)$。一般相切應由經容差修正後的 $\Delta=0$ 判定，並不必然使 $q=0$。

---

### 6. 相切與消去誤差的敘述混淆

**原句：**

> 當射線與球面或平面僅有一個交點時，二次方程的判別式趨近於零，此時標準公式……可能因兩數相減而丟失有效位元。

**錯誤原因：**

- 平面求交不是二次方程，也沒有判別式。
- 判別式接近零的主要問題是誤差可能改變其正負，導致相切被誤判。
- 二次公式的嚴重消去通常發生在其中一根很小，即 $|b|\approx\sqrt{\Delta}$，不等同於 $\Delta\approx0$。

**修法：**

拆成兩點：

1. 球面相切：處理判別式接近零的符號誤差。
2. 大小懸殊的兩根：使用穩定求根避免消去誤差。
3. 平面平行：處理分母 $\mathbf n\cdot\mathbf d$ 接近零。

---

### 7. 習題解答引用不存在的程式

**原句：**

> 參見程式 `shadow_test` 邏輯。

**錯誤原因：**

本章程式沒有定義 `shadow_test`。這違反「若需新函式，當章提供完整定義」的要求，也不是完整習題解答。

**修法：**

提供完整函式，包含：

- 正規化幾何法線；
- 內積為零時的偏移側規則；
- 偏移後重新計算指向光源的方向與距離；
- `t_min` 與 `t_max`；
- 三種物件的求交分派。

習題敘述中的「使用 $t_{min}$ 偏移」也應改成「使用起點偏移與 `t_min` 射線下界」。

## 二、程式邊界與測試缺口

### 1. Ray 區間沒有驗證

**原句：**

```python
self.t_min = t_min
self.t_max = t_max
```

應拒絕非有限的 `t_min`、`NaN` 的 `t_max`，以及 `t_max < t_min`。允許 `t_max=inf` 可特別處理。

### 2. 相機尺寸未驗證

```python
aspect = width / height
```

若 `height == 0` 會除以零。應要求 `width`、`height` 為正整數。

### 3. 相機輸入有限性不足

目前只檢查：

```python
if d_norm < 1e-8:
```

若 `cam_dir` 含 `NaN`，比較結果為假，之後整張影像可能失效。應加入 `np.isfinite(d_norm)`，也應檢查 `cam_pos`。

### 4. PPM 輸入形狀沒有驗證

`write_ppm` 假設影像必為 `uint8` 的 `(H,W,3)`。作為完整獨立程式，宜檢查維度、通道數與 dtype，否則標頭可能與位元組內容不一致。

### 5. epsilon 測試只測精確表面，未測浮點擾動

目前表面向外案例能驗證 `t=0` 被排除，但未展示真正的近零誤差。建議再加入：

```python
r_near = Ray(
    np.array([0.0, 0.0, 1.0 - 1e-8]),
    np.array([0.0, 0.0, 1.0]),
    t_min=1e-6
)
assert intersect_sphere(r_near, s) is None
```

另建立 `t_min=0` 的射線，預期得到約 $10^{-8}$，才足以比較射線下界的作用。

### 6. 缺少球面最近根回歸測試

前版的核心錯誤正是回傳遠根。應保留明確回歸測試：

```python
r = Ray(
    np.array([0.0, 0.0, -5.0]),
    np.array([0.0, 0.0, 1.0])
)
assert np.isclose(intersect_sphere(r, s), 4.0)
```

### 7. 缺少三角形重心與外部未命中測試

目前只檢查 $t=1$。還應檢查：

```python
assert np.allclose(res[2], (0.6, 0.2, 0.2))
```

以及一條落在三角形外的射線預期 `None`。

## 三、維度、座標、法線、色彩與索引核對

### 已正確部分

- 射線方向經正規化後，$t$ 單位為公尺。
- $\Delta$、$b$、$c$ 的單位分析基本正確。
- 平面正規化時同步縮放 $d$，正確。
- 三角形 determinant 容差具有面積尺度。
- 像素使用 `img[j, i]`，符合左上原點及 row-major 影像索引。
- 相機朝 $-Z$，`right = cross(cam_dir, up)` 在指定配置下得到 $+X$。
- aspect ratio 已納入水平座標。
- RGB 被裁切到 $[0,1]$ 後量化為 `uint8`，輸出範圍正確。
- 色彩已改稱顯示 RGB，沒有再錯稱為線性轉 sRGB。
- 三角形法線由 `cross(e1,e2)` 取得，並朝向射線反面；應補充這是 face-forward 後的法線，不再保留原始外向方向。

### 仍需修字

> 不进行複雜的光學色彩空間轉換。

「进行」應改為繁體「進行」。

> 安全區域

依全書約定，建議改為「數值排除區間」，避免被理解為物理安全閾值。
