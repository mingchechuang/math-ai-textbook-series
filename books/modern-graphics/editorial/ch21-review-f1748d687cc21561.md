1.  **關於 IEEE 754 與 Python 行為**：
    在習題 2 解答中，作者明確指出 Python `float` 除以零會拋出 `ZeroDivisionError`，而 NumPy 陣列可能回傳 `inf/nan`。這是非常好的澄清，建議保留。
