## 仍須修正的兩處程式／敘述不一致

1. **出界旗標可能漏報。** 數學段寫「記錄原始世界位置和是否出界」，欄名為 `outside_image_before_clamp`，但程式在 `map_to_pixel()` 中先 `round`，才以 `0 <= raw_u < WIDTH` 判斷。略微超過世界範圍的座標，仍可能取整為邊界內索引，得到 `False`。**修法：**若旗標意指「世界位置超出設定範圍」，應在映射與取整前以 `xmin <= x <= xmax`、`ymin <= y <= ymax` 判斷；另保留像素夾取。若原意僅是「取整後索引是否越界」，則須改欄名及全文說明，不可稱物件是否出界。

2. **唯讀查詢未履行逐物件來源驗證。** 習題解答與驗收文字要求「物件來源標記為 `simulated`」，但 `validate_frame_record()` 只檢查 manifest 的 `data_status`，隨後直接回傳 `annotation["objects"]`。即使其中一筆物件標為其他來源，也會被當作合成物件回答。**修法：**逐筆驗證 `objects` 為預期清單、每筆 `source == "simulated"`，並確認所需 ID 與位置欄位存在；缺漏或來源不符時拒絕回答。加入一筆來源被竄改的反例測試。
