### 2. 曲率與取樣密度仍被錯誤連結

**原句：**

> 預期弦長在曲率較大或速度較快的區間……較大。

以及：

> 生成網格時，曲率大處頂點稀疏……

**問題：**

等 $\Delta t$ 的弧長主要由參速 $\|B'(t)\|$ 決定，曲率大不表示弦長必然較大，也不表示頂點必然稀疏。等弧長取樣與高曲率處自適應細分是兩個不同問題。

**修法：**

改為：

> 等參數取樣的空間間距差異主要來自 $\|B'(t)\|$ 的變化。弧長重參數化可使間距較均勻；但為控制折線近似誤差，高曲率區仍可能需要依平坦度或曲率額外細分。

小結中的「重參數化以優化網格品質」也應限定：它改善間距均勻性，不單獨保證幾何近似誤差。

### 3. `check_g1_continuity` 未檢查兩段點的維度一致

**原句：**

```python
pts_a = prepare_points(pts_a)
pts_b = prepare_points(pts_b)
```

**問題：**

`prepare_points` 只驗證各列表內部維度一致，沒有驗證 A 與 B 的維度相同。若一段為 2D、另一段為 3D，後續 `np.allclose` 或向量運算可能產生 broadcasting 錯誤，而不是清楚的輸入錯誤。

**修法：**

```python
if pts_a[0].shape != pts_b[0].shape:
    raise ValueError("兩段曲線的控制點維度必須相同")
```

### 4. 同一個 `tol` 混合了有單位與無單位容差

**原句：**

```python
if norm_a < tol or norm_b < tol:
```

以及：

```python
if np.linalg.norm(ua - ub) > tol:
```

**問題：**

前者是控制點座標單位下的長度容差，後者是正規化方向的無因次容差。使用同一個固定值不符合「epsilon 按場景尺度設定」的約定。

**修法：**

分成例如：

```python
def check_g1_continuity(pts_a, pts_b, position_tol=1e-9,
                        tangent_tol=1e-12, direction_tol=1e-9):
```

其中 `position_tol`、`tangent_tol` 應由場景尺度決定，`direction_tol` 才是無因次方向差容差。

### 5. 導數長度敘述需更精確

**原句：**

> 切線方向由 $B'(t)$ 決定，長度代表參速 $\frac{ds}{dt}$。

**問題：**

應明確是導數向量的範數，而非模糊的「長度」：

$$
\frac{ds}{dt}=\|B'(t)\|.
$$

若 $B'(t)=0$，切線方向未定義；此退化情況應在數學段或除錯段補充。
