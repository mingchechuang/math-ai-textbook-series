# 第05章 透視投影、裁切與深度

## 學習目標與先備知識

讀完本章後，你應能：

- 說明透視投影與正交投影如何把相機座標中的點映射到剪裁座標。
- 推導右手相機、視線沿 $-Z$、OpenGL 式 NDC 深度範圍 $[-1,1]$ 的透視投影矩陣。
- 區分剪裁座標、NDC、視窗座標與深度緩衝值，並解釋透視除法。
- 以近平面條件裁切三角形，並辨識深度精度如何受近平面與遠平面影響。

先備知識是向量、矩陣乘法與齊次座標。本文沿用全書約定：數學向量為直向量，世界座標系為右手系；相機位於原點時看向 $-Z$，相機上方為 $+Y$。長度以公尺表示，角度計算使用弧度。

本章主線採 OpenGL 式剪裁與 NDC 慣例。其他圖形 API 可能使用不同的深度範圍或矩陣慣例；不能把它們的投影矩陣與本章的裁切、深度映射規則混用。

## 問題與直覺

養殖池的三維場景必須顯示在有限大小的影像上。相機投影首先把場景位置轉成剪裁座標，再依剪裁體積移除不可見部分，最後將可見點映射到 NDC 與像素範圍。

透視投影符合近大遠小的觀察：距離相機兩倍遠的物體，其投影尺寸約為原來的一半。正交投影則不隨深度縮放，適合工程圖或量測視圖。兩者都必須經過裁切與視窗映射；差異主要在投影如何處理深度。

一個容易混淆之處是：相機空間的 $z$、剪裁座標的 $z_c$、除以 $w_c$ 後的 $z_{\mathrm{ndc}}$，以及深度緩衝值，並不是同一個量。它們的範圍與幾何意義各不相同。

## 數學與幾何推導

### 從視錐到透視投影

令相機座標中的點為

$$
p_{\mathrm{cam}}=(x,y,z,1)^T,
$$

其中可見物體位於相機前方，因此 $z<0$。令近平面距離為 $n>0$，遠平面距離為 $f>n$。兩平面分別位於 $z=-n$ 與 $z=-f$。

設垂直視野角為 $\theta$，影像長寬比為 $a=W/H$。近平面上、下界為

$$
t=n\tan\frac{\theta}{2},\qquad b=-t,
$$

左右界為

$$
r=at,\qquad l=-r.
$$

從相似三角形可得，點投影至近平面時，橫向位置依 $n/(-z)$ 縮放：

$$
x_{\mathrm{near}}=n\frac{x}{-z},\qquad
y_{\mathrm{near}}=n\frac{y}{-z}.
$$

因此，深度越遠，投影橫向與縱向座標的絕對值越小。為用矩陣表達這種除以 $-z$ 的效果，令剪裁座標的齊次分量為 $w_c=-z$。再將近平面上的左右、上下界線性映射到 NDC 的 $[-1,1]$，可得矩陣：

$$
P=
\begin{bmatrix}
\frac{2n}{r-l}&0&\frac{r+l}{r-l}&0\\
0&\frac{2n}{t-b}&\frac{t+b}{t-b}&0\\
0&0&-\frac{f+n}{f-n}&-\frac{2fn}{f-n}\\
0&0&-1&0
\end{bmatrix}.
$$

對稱視錐有 $l=-r$、$b=-t$，故簡化為

$$
P=
\begin{bmatrix}
\frac{1}{a\tan(\theta/2)}&0&0&0\\
0&\frac{1}{\tan(\theta/2)}&0&0\\
0&0&-\frac{f+n}{f-n}&-\frac{2fn}{f-n}\\
0&0&-1&0
\end{bmatrix}.
$$

矩陣右乘相機座標後得到剪裁座標：

$$
p_{\mathrm{clip}}=Pp_{\mathrm{cam}}=(x_c,y_c,z_c,w_c)^T.
$$

當 $z<0$ 時，$w_c=-z>0$。透視除法將剪裁座標轉成 NDC：

$$
x_{\mathrm{ndc}}=\frac{x_c}{w_c},\qquad
y_{\mathrm{ndc}}=\frac{y_c}{w_c},\qquad
z_{\mathrm{ndc}}=\frac{z_c}{w_c}.
$$

視錐內的點須滿足剪裁不等式

$$
-w_c\le x_c\le w_c,\qquad
-w_c\le y_c\le w_c,\qquad
-w_c\le z_c\le w_c.
$$

除以正的 $w_c$ 後，等價於三個 NDC 分量皆落在 $[-1,1]$。這些條件在除法前可用剪裁座標直接檢查；但靠近平面以外的點不能只因其 NDC 看似合理就保留。

將 $z=-n$ 代入矩陣可得 $z_{\mathrm{ndc}}=-1$；將 $z=-f$ 代入則得 $z_{\mathrm{ndc}}=1$。深度緩衝值定義為

$$
d=\frac{z_{\mathrm{ndc}}+1}{2},
$$

故近平面映到 $d=0$、遠平面映到 $d=1$。在一般透視投影中，深度不是相機距離的線性函數。由矩陣可整理為

$$
z_{\mathrm{ndc}}=\frac{f+n}{f-n}+\frac{2fn}{(f-n)z}.
$$

因此，深度精度大多集中在近平面附近。把 $n$ 設得遠小於實際需要的距離，會讓有效精度更不均勻；遠平面設得過大也會加重深度緩衝的量化與遮擋問題。

### 正交投影

正交投影保留等尺寸物體在不同深度時的投影大小。令視錐範圍為 $[l,r]\times[b,t]$，深度仍從 $z=-n$ 到 $z=-f$，則可用以下矩陣映射到本章的 NDC 範圍：

$$
P_{\mathrm{ortho}}=
\begin{bmatrix}
\frac{2}{r-l}&0&0&-\frac{r+l}{r-l}\\
0&\frac{2}{t-b}&0&-\frac{t+b}{t-b}\\
0&0&-\frac{2}{f-n}&-\frac{f+n}{f-n}\\
0&0&0&1
\end{bmatrix}.
$$

其 $w_c=1$，不需要因深度而縮放。正交投影同樣需要裁切，但不會出現透視除法造成的近大遠小。

### 視窗與像素座標

NDC 的 $x,y$ 範圍是 $[-1,1]$。對寬 $W$、高 $H$ 的影像，且像素原點位於左上角，可將 NDC 對應至連續影像座標：

$$
u=\frac{x_{\mathrm{ndc}}+1}{2}W,\qquad
v=\frac{1-y_{\mathrm{ndc}}}{2}H.
$$

負號反映影像座標的 $v$ 向下，而世界與相機座標的 $Y$ 向上。像素索引為整數 $(i,j)$，其中心位於 $(i+0.5,j+0.5)$。連續位置需透過光柵化規則落到像素；不能把整數索引直接當作像素中心。

## 逐步手算例題

### 例一：近平面與遠平面的深度映射

取 $n=1$ 公尺、$f=10$ 公尺。對稱投影的深度係數為

$$
A=-\frac{f+n}{f-n}=-\frac{11}{9},\qquad
B=-\frac{2fn}{f-n}=-\frac{20}{9}.
$$

矩陣第三列給出 $z_c=Az+B$，第四列給出 $w_c=-z$。

在近平面 $z=-1$：

$$
z_c=-\frac{11}{9}(-1)-\frac{20}{9}=-1,\qquad w_c=1.
$$

所以 $z_{\mathrm{ndc}}=-1$，深度 $d=0$。

在遠平面 $z=-10$：

$$
z_c=-\frac{11}{9}(-10)-\frac{20}{9}=10,\qquad w_c=10.
$$

所以 $z_{\mathrm{ndc}}=1$，深度 $d=1$。

再看中間距離 $z=-2$：

$$
z_c=-\frac{11}{9}(-2)-\frac{20}{9}=\frac{2}{9},\qquad
w_c=2.
$$

因此 $z_{\mathrm{ndc}}=1/9$，深度為 $5/9$，並非線性距離比例 $1/9$。

### 例二：從相機座標到像素位置

令 $n=1$、$f=10$、垂直視野角 $\theta=90^\circ$、長寬比 $a=2$。此時 $\tan(\theta/2)=1$，投影矩陣第一、二列的縮放係數分別為 $1/2$ 與 $1$。

取點 $p_{\mathrm{cam}}=(1,0,-2,1)^T$。計算得

$$
x_c=\frac12,\qquad y_c=0,\qquad
z_c=\frac29,\qquad w_c=2.
$$

透視除法後：

$$
(x_{\mathrm{ndc}},y_{\mathrm{ndc}},z_{\mathrm{ndc}})
=\left(\frac14,0,\frac19\right).
$$

其深度緩衝值為 $5/9$。若影像尺寸為 $800\times400$，則連續影像位置為

$$
u=\frac{1+1/4}{2}(800)=500,\qquad
v=\frac{1-0}{2}(400)=200.
$$

這是影像座標位置；像素索引與像素中心的取整方式由光柵化規則決定。

### 近平面裁切

若線段兩端點分別在相機深度 $z_A=-0.5$、$z_B=-2$，近平面為 $n=1$，則 $A$ 在近平面之外，$B$ 在可見側。以相機深度距離 $s=-z$ 表示，交點內插比例為

$$
\lambda=\frac{n-s_A}{s_B-s_A}
=\frac{1-0.5}{2-0.5}=\frac13.
$$

若端點位置是三維向量 $A,B$，裁切交點為

$$
C=A+\lambda(B-A).
$$

三角形裁切時，逐邊套用近平面半空間測試。三角形與平面相交後，結果可能是三角形、四邊形或空集合；四邊形可分成兩個三角形。若頂點還帶有顏色、UV 或其他屬性，交點也必須用相同的幾何內插比例計算屬性。裁切通常在剪裁空間或等價的相機空間中完成，不應先對近平面外點做不受限制的透視除法。

## 實作與程式

以下程式只用 Python 標準庫，建立對稱視錐的右手透視矩陣，檢查深度端點與剪裁範圍，並以線性插值示範近平面線段裁切。矩陣以直向量慣例表示，程式用列的巢狀串列儲存；`mat_vec` 直接實作數學上的矩陣乘直向量。

```python
import math


def perspective_rh_opengl(fovy, aspect, near, far):
    """右手相機看向 -Z；NDC z 範圍為 [-1, 1]。"""
    if not (0.0 < fovy < math.pi):
        raise ValueError("fovy 必須介於 0 與 pi 之間")
    if aspect <= 0.0 or near <= 0.0 or far <= near:
        raise ValueError("aspect、near、far 不符合條件")

    q = 1.0 / math.tan(fovy / 2.0)
    return [
        [q / aspect, 0.0, 0.0, 0.0],
        [0.0, q, 0.0, 0.0],
        [0.0, 0.0, -(far + near) / (far - near),
         -(2.0 * far * near) / (far - near)],
        [0.0, 0.0, -1.0, 0.0],
    ]


def mat_vec(matrix, vector):
    return [
        sum(matrix[row][col] * vector[col] for col in range(4))
        for row in range(4)
    ]


def ndc_and_depth(matrix, point):
    clip = mat_vec(matrix, [point[0], point[1], point[2], 1.0])
    w = clip[3]
    if w <= 0.0:
        raise ValueError("點不在相機前方，不能做本例透視除法")
    ndc = tuple(clip[i] / w for i in range(3))
    depth = (ndc[2] + 1.0) / 2.0
    return clip, ndc, depth


def inside_clip(clip, eps=1e-12):
    x, y, z, w = clip
    return (w > 0.0 and
            -w - eps <= x <= w + eps and
            -w - eps <= y <= w + eps and
            -w - eps <= z <= w + eps)


def clip_segment_near(a, b, near):
    """輸入兩端點的 (x, y, z)；保留相機前方 z <= -near 的線段部分。"""
    za, zb = a[2], b[2]
    a_in = za <= -near
    b_in = zb <= -near
    if not a_in and not b_in:
        return None
    if a_in and b_in:
        return a, b

    # 求 z=-near 的交點：a + t(b-a)
    t = (-near - za) / (zb - za)
    c = tuple(a[i] + t * (b[i] - a[i]) for i in range(3))
    return (a, c) if a_in else (c, b)


def main():
    n, f = 1.0, 10.0
    matrix = perspective_rh_opengl(math.pi / 2.0, 2.0, n, f)

    for z, expected_depth in [(-n, 0.0), (-f, 1.0)]:
        clip, ndc, depth = ndc_and_depth(matrix, (0.0, 0.0, z))
        assert inside_clip(clip)
        assert abs(depth - expected_depth) < 1e-12
        assert abs(ndc[2] - (2.0 * expected_depth - 1.0)) < 1e-12

    # 視野外點應被水平剪裁條件拒絕。
    outside = mat_vec(matrix, [20.0, 0.0, -2.0, 1.0])
    assert not inside_clip(outside)

    # 近面交點應落在 z=-near。
    clipped = clip_segment_near((0.0, 0.0, -0.5), (1.5, 0.0, -2.0), n)
    assert clipped is not None
    assert abs(clipped[0][2] + n) < 1e-12
    assert clipped[1] == (1.5, 0.0, -2.0)

    print("near/far depth, side clipping, and near-plane segment checks passed")


if __name__ == "__main__":
    main()
```

此程式使用絕對容差 $10^{-12}$，只適合這組單位與簡單案例的數值測試。若場景尺度改變，容差也應依座標尺度與浮點誤差重新選擇。實際渲染器通常會在齊次剪裁空間裁切三角形，並處理所有剪裁平面；上述函式只展示近平面與基本視錐內測試。

## 測試與預期結果

程式中的斷言可分別檢查：

- 近平面映到 NDC $z=-1$、深度 $0$。
- 遠平面映到 NDC $z=1$、深度 $1$。
- 橫向超出視錐的點不在剪裁範圍內。
- 一端在近平面外、一端在近平面內的線段，其新端點落在 $z=-n$。

若自行執行，預期最後一行會列出三類檢查通過。這只是根據程式與公式可推得的預期結果，不代表本章作者已執行程式或驗證特定硬體環境。另可增加測試：輸入兩端都在近平面外的線段，結果應為 `None`；兩端都在內的線段則應原樣返回。

## 除錯與常見陷阱

- **相機前方符號用錯。** 本章相機看向 $-Z$，可見點的 $z$ 為負。若測試點在 $z>0$，卻直接以 $w_c=-z$ 做透視除法，便會得到負的 $w_c$。
- **使用不同的 NDC 深度慣例。** 本章使用 $z_{\mathrm{ndc}}\in[-1,1]$，深度映射為 $(z_{\mathrm{ndc}}+1)/2$。若移植到採用 $[0,1]$ 深度範圍的 API，必須改用符合該 API 的投影矩陣與映射，不能只把深度值硬塞進另一套流程。
- **忘記透視除法。** 剪裁座標尚未成為 NDC。用 $x_c,y_c,z_c$ 直接映射像素，會使物體尺寸與深度關係錯誤。
- **在除法前做錯裁切。** NDC 不等式要先得到有限且正確的 $w_c$。近平面外點可能有極小或非正的 $w_c$，不能視為普通可見點。
- **近平面設得太近或遠平面設得太遠。** 除了增加不必要的裁切範圍，這也會惡化深度緩衝的可用精度。應以場景實際尺度設定近、遠距離。
- **把深度當成距離。** 深度值是投影後的非線性量，不宜不經反轉換就當成公尺。若需要從深度還原相機距離，必須使用同一組 $n,f$ 與投影慣例。
- **影像座標上下顛倒。** NDC 的 $Y$ 向上，但本書影像座標的 $v$ 向下；視窗映射必須反轉 $Y$。

## 養殖數位分身案例

假設池體長 $8$ 公尺、寬 $4$ 公尺，魚群活動範圍深度約 $0.5$ 至 $3$ 公尺。相機設於池邊，並將池體與魚群轉換至相機座標後，選擇涵蓋所需可見區域的視野角。近平面不應小到接近零；它必須小於最近需要成像的物體距離，但仍應盡可能合理地遠離零。遠平面則需覆蓋最遠的池體構件或背景物件，不必無限制地延伸。

投影後，每個頂點先得到剪裁座標。三角形若穿越近平面，要先切出可見部分，再進行透視除法與光柵化。魚體位於池底前方時，其深度緩衝值通常較大；位於相機附近的魚則通常較小。這些值可用於可見性比較，但深度值本身不是魚與相機的公尺距離。

若要產生合成深度標註，應明確記錄深度採用的慣例、近平面、遠平面及是否已反向轉換。僅保存一張灰階深度圖而不記錄這些設定，無法保證其數值可被解讀為相機距離。合成場景的投影與裁切結果只描述所建模型及所選相機設定，不能據此推論真實魚體位置或池中水下光學現象。

## 習題

### 1. 手算：深度映射

採本章右手 OpenGL 式投影，$n=0.5$ 公尺、$f=8$ 公尺。求相機座標 $z=-0.5$、$z=-8$、$z=-2$ 時的 NDC 深度與深度緩衝值。

### 2. 程式測試：擴充端點檢查

在實作程式中新增測試：$z=-n$ 與 $z=-f$ 的點都應通過剪裁範圍檢查；深度各映到 $0$、$1$。再新增近平面外的線段測試，確認兩端都在 $z>-n$ 時裁切結果為空。

### 3. 反例／除錯：錯誤裁切

某程式將相機座標 $z=-0.5$ 的點（$n=1$）先投影並做透視除法，若其 $x_{\mathrm{ndc}},y_{\mathrm{ndc}},z_{\mathrm{ndc}}$ 恰在 $[-1,1]$，就判定點可見。指出這種做法的錯誤，並給出最簡單的正確判斷方式。

### 4. 整合應用：選擇近平面

一個合成池景中，離相機最近的魚可能在 $0.8$ 公尺處，池壁最遠點在 $12$ 公尺處。選擇一組合理的 $n,f$，說明設定原則，並指出若把 $n$ 改成 $0.001$ 公尺、其他條件不變，主要會造成什麼問題。

## 習題解答

### 1. 手算：深度映射

使用

$$
z_{\mathrm{ndc}}=\frac{f+n}{f-n}+\frac{2fn}{(f-n)z},
\qquad
d=\frac{z_{\mathrm{ndc}}+1}{2}.
$$

此題 $(f+n)/(f-n)=8.5/7.5=17/15$，$2fn/(f-n)=8/7.5=16/15$。

- $z=-0.5$：$z_{\mathrm{ndc}}=17/15-32/15=-1$，所以 $d=0$。
- $z=-8$：$z_{\mathrm{ndc}}=17/15-2/15=1$，所以 $d=1$。
- $z=-2$：$z_{\mathrm{ndc}}=17/15-8/15=3/5$，所以 $d=4/5$。

### 2. 程式測試：擴充端點檢查

端點測試可沿用 `ndc_and_depth` 與 `inside_clip`：

```python
for z, expected in [(-n, 0.0), (-f, 1.0)]:
    clip, _, depth = ndc_and_depth(matrix, (0.0, 0.0, z))
    assert inside_clip(clip)
    assert abs(depth - expected) < 1e-12

assert clip_segment_near((0.0, 0.0, -0.2),
                         (1.0, 0.0, -0.7), n) is None
```

這裡的線段兩端都在近平面 $z=-n$ 的相機側前方之外，符合 $z>-n$，所以沒有可保留的區段。測試只檢查近平面；若要驗證完整視錐，還需涵蓋其餘剪裁平面。

### 3. 反例／除錯：錯誤裁切

該點位於 $z=-0.5>-1$，也就是近平面 $z=-1$ 的外側。只檢查除法後的座標可能漏掉近平面條件，還可能遇到不穩定的 $w_c$，因此不能據此宣告可見。正確作法是在透視除法前先檢查剪裁座標的不等式；對相機空間中的本例，最簡單的近平面測試是

$$
z\le -n.
$$

本例不符合此條件，應裁去或作三角形／線段裁切，而不是保留該點。

### 4. 整合應用：選擇近平面

例如取 $n=0.5$ 公尺、$f=12$ 公尺。最近魚的位置仍在近平面之後，池壁最遠點落在遠平面上。實際選值應留足場景與相機運動的餘裕，但不宜讓近平面過分靠近零。若把 $n$ 改成 $0.001$ 公尺，投影深度的非線性分布會更不均勻，深度緩衝在遠處更容易出現精度不足與遮擋次序錯誤；這不是改善可見範圍所必需的設定。

## 本章小結

- 透視投影以齊次座標的 $w_c=-z$ 表示距離縮放；除以 $w_c$ 後得到 NDC。
- 本章採用 OpenGL 式右手投影：相機看向 $-Z$，NDC 深度為 $[-1,1]$，深度緩衝值為 $(z_{\mathrm{ndc}}+1)/2$。
- 剪裁應在透視除法前按剪裁不等式進行；三角形與近平面相交時，需產生新的交點並同步內插屬性。
- 正交投影的 $w_c=1$，物體投影大小不隨深度變化。
- 透視深度並非距離的線性編碼。近平面與遠平面的選擇會影響深度精度；影像座標映射還須處理 $Y$ 軸方向差異。
