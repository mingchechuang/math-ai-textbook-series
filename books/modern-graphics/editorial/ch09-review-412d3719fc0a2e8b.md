# 審稿結果

稿件已涵蓋 Bernstein 基底、de Casteljau、導數與分段連續性，但存在程式與 NumPy 2.2.6 不相容、連續性條件不完整、習題資料矛盾、測試未真正驗證凸包，以及引用不匹配等實質問題。正文量亦低於最低要求，需修訂。

## 一、必須修正的實質問題

### 1. `np.math.factorial` 不符合指定的 NumPy 2.2.6 相容要求

**可定位原句：**

```python
coeff = np.math.factorial(n) / (np.math.factorial(i) * np.math.factorial(n-i))
```

以及：

```python
coeff = np.math.factorial(n-1) / (np.math.factorial(i) * np.math.factorial((n-1)-i))
```

**問題：**

`math` 是 Python 標準庫模組，不應透過 `np.math` 存取；在指定的 NumPy 2.x 環境中不能依賴此別名。這會使核心程式可能在呼叫 Bernstein 基底時直接失敗。稿件要求 Python 3.10+ 與 NumPy 2.2.6 相容，因此是阻斷性錯誤。

此外，使用 `/` 計算二項式係數會先得到浮點數，沒有必要。

**修法：**

```python
from math import comb

def bernstein_basis(n, i, t):
    if n < 0 or i < 0 or i > n:
        raise ValueError("需要 n >= 0 且 0 <= i <= n")
    return comb(n, i) * (t ** i) * ((1.0 - t) ** (n - i))
```

導數函式也應直接重用此函式，而不是重寫階乘：

```python
def bezier_tangent(pts, t):
    pts = [np.asarray(p, dtype=float) for p in pts]
    n = len(pts) - 1
    if n < 1:
        return np.zeros_like(pts[0])

    diff_pts = [pts[i + 1] - pts[i] for i in range(n)]
    tangent = np.zeros_like(pts[0])
    for i, dp in enumerate(diff_pts):
        tangent += dp * bernstein_basis(n - 1, i, t)
    return n * tangent
```

### 2. $G^1$ 條件不能只寫「共線」

**可定位原句：**

> **$G^1$ 連續（几何連續）：** 兩曲線在接點處的切線方向相同（共線），但長度（參速）不必相等。對於 Bézier，需滿足 $P_{end,0}, P_{last-1,0}, P_{0,1}, P_{1,1}$ 共線。

以及程式：

```python
assert abs(cross_2d) < 1e-6, "Not G1 continuous"
```

**問題：**

外積為零只表示平行或反平行。若兩個非零導數反向，接點可能形成折返或尖點，不能稱為具有相同有向切線的正則 $G^1$ 拼接。若任一導數為零，方向甚至沒有定義。

對兩段曲線 $A$、$B$，正則 $G^1$ 應要求：

$$
A(1)=B(0),\qquad B'(0)=\lambda A'(1),\quad \lambda>0,
$$

且兩端導數均非零。

**修法：**

除了外積，還要檢查長度與內積：

```python
eps = 1e-12
len_a = np.linalg.norm(v_A)
len_b = np.linalg.norm(v_B)
assert len_a > eps and len_b > eps, "接點切線不可為零向量"
assert abs(cross_2d) <= 1e-9 * len_a * len_b
assert np.dot(v_A, v_B) > 0.0, "切線反向，不是同向 G1 拼接"
```

### 3. $C^1$ 的控制點距離條件只適用於同次數曲線

**可定位原句：**

> 對於 Bézier，需滿足 $P_{last-1,0}$ 與 $P_{0,1}$ 到接點的距離相等且方向相反。

**問題：**

這只有在兩段 Bézier 次數相同時才成立。若第一段次數為 $m$、第二段次數為 $n$，則：

$$
A'(1)=m(A_m-A_{m-1}),
$$

$$
B'(0)=n(B_1-B_0).
$$

因此 $C^1$ 條件為：

$$
m(A_m-A_{m-1})=n(B_1-B_0).
$$

控制邊長不一定相等。

這一點也直接影響程式案例：第一段 `ctrl_pts` 有五點，是四次曲線；第二段 `Q0..Q3` 是三次曲線。雖然兩個控制邊向量相等，但端點導數分別為

$$
A'(1)=4(1,-1)=(4,-4),
$$

$$
B'(0)=3(1,-1)=(3,-3).
$$

所以它是 $G^1$，但不是 $C^1$。

**修法：**

將文字改為：

> 若兩段次數分別為 $m,n$，則 $C^1$ 要求  
> $m(A_m-A_{m-1})=n(B_1-B_0)$。只有在 $m=n$ 時，才可簡化為兩側控制邊向量相等。

### 4. 「凸包性質」的直覺敘述方向顛倒

**可定位原句：**

> 這種特性稱為凸包性質：曲線完全包圍在控制點形成的多邊形（凸包）內。

**問題：**

「曲線完全包圍在……內」語意是曲線包圍凸包，與實際關係相反。

**修法：**

> 曲線完全位於控制點所張成的凸包內。

另外，「控制點形成的多邊形」不一定就是凸包；控制多邊形與凸包是不同概念。

### 5. 程式沒有完成章目要求的「凸包測試」

**可定位原句：**

```python
# 簡單檢查：曲線點是否在控制點最小圍盒內
```

以及預期結果：

> **凸包測試：** 應無 `Warning` 輸出。

**問題：**

程式只測軸對齊邊界盒，不是凸包。落在 bounding box 內的點仍可能在控制點凸包外，因此不能稱為「凸包測試」。程式遇到錯誤也只有 `print` 與 `pass`，測試不會失敗。

**修法：**

二選一：

1. 將名稱明確改成「邊界盒必要條件粗檢」，不得宣稱驗證凸包。
2. 實作 2D 凸包及點在凸多邊形內測試，並以 `assert` 失敗。

至少還可直接驗證 Bernstein 權重：

```python
weights = np.array([bernstein_basis(n, i, t) for i in range(n + 1)])
assert np.all(weights >= -1e-12)
assert abs(np.sum(weights) - 1.0) < 1e-12
```

這從非負權重與權重和為一直接對應凸組合性，但若要測幾何實作錯誤，仍宜加入真正的凸包包含測試。

### 6. 一致性測試的文字與實際容差不一致

**可定位原句：**

> `Direct` 和 `deCasteljau` 的結果應完全相同（誤差小於 $10^{-6}$）。

程式則為：

```python
assert err < 1e-5
```

**問題：**

「完全相同」不適合浮點計算，而且文件寫 $10^{-6}$、程式卻使用 $10^{-5}$。

**修法：**

統一為例如：

```python
assert np.allclose(p1, p2, rtol=1e-12, atol=1e-12)
```

文字改成：

> 在本例尺度下，兩種求值結果預期於指定浮點容差內一致；不要求逐位元相同。

### 7. 習題 3 出現不存在的控制點，且題目與解答互相抵觸

**可定位原句：**

> 且保持 $Q_2, Q_3$ 不變，應如何調整 $Q_1$？

但曲線 B 定義為二次曲線：

> B: $Q_0(2,0), Q_1(3,-1), Q_2(4,0)$

**問題：**

二次曲線沒有 $Q_3$。此外，原始資料已滿足：

$$
P_2-P_1=(1,-1),\qquad Q_1-Q_0=(1,-1),
$$

所以不僅 $G^1$，還因兩段同為二次且導數相等而滿足 $C^1$。題目第三問「若希望……」沒有需要調整的內容。解答中大量猜測「題目原意」，不可留在正式教材。

**修法：**

將原始 $Q_1$ 改為 $(3,0)$，並將問題寫成：

> 保持 $Q_0,Q_2$ 不變，如何調整 $Q_1$ 使其至少達到 $G^1$？若還要求 $C^1$，$Q_1$ 應為何值？

答案：

- $G^1$：$Q_1=Q_0+k(1,-1)$，其中 $k>0$。
- $C^1$：因兩段皆為二次，取 $k=1$，故 $Q_1=(3,-1)$。

### 8. 習題 4 缺少控制點，無法得到要求的數值答案

**可定位原句：**

> 為一個由 5 個控制點定義的魚尾輪廓生成 10 個等參數間隔的點……

**問題：**

沒有給出五個控制點，因此無法生成具體點、計算弦長或找出最大區間。解答也只重述程序，未提供可核對的結果，不符合「習題解答」及可重現要求。

**修法：**

明列五個控制點，並在答案中表列十個點、九段弦長及最大區間。還需說明目前的取樣從 $t=0.1$ 開始，因此漏掉由端點 $t=0$ 到 $t=0.1$ 的弦段；若要比較完整十個區間，應採 $t=0,0.1,\ldots,1$ 共十一點。

### 9. 曲率與等參數取樣密度的因果敘述不正確

**可定位原句：**

> 直接使用 $t$ 會導致頂點在曲率大處稀疏、曲率小處密集。

以及解答：

> 在曲率較大或參速較大的區間，弦長較長。

**問題：**

相同 $\Delta t$ 所對應的弧長主要由參速 $\|B'(t)\|$ 決定，不是由曲率直接決定。高曲率區即使弧長取樣均勻，也可能仍需更多細分才能限制幾何偏差；這是另一個自適應準則。

**修法：**

區分兩件事：

- 等弧長取樣：處理頂點沿曲線的空間間距。
- 曲率或平坦度自適應細分：處理折線近似誤差。

不應寫成「弧長重參數化必然能精確捕捉高曲率」。

### 10. 題名為「曲線與樣條」，但樣條內容不足

**可定位範圍：**

全章只有分段 Bézier 的 $C^0/G^1/C^1$，結尾才提及 B-spline。

**問題：**

若此章所稱「樣條」是分段 Bézier 樣條，需明確定義節點、每段局部參數與拼接條件。若題名意圖涵蓋 B-spline，正文完全沒有基底、節點向量或局部控制性的基本說明。

**修法：**

至少新增一節「分段 Bézier 樣條」，說明：

- 每段參數 $u\in[0,1]$ 與全域參數的映射；
- 不同段次數對 $C^1$ 條件的影響；
- $C^0,C^1,G^1$ 的精確條件；
- Bézier 單段的全域控制與分段樣條的局部影響範圍。

## 二、具體例題重算

### 程式魚背四次曲線

控制點為：

$$
(0,0),(1,0.5),(2,1),(3,1),(4,0).
$$

因控制點的 $x_i=i$，四次 Bernstein 組合給出：

$$
x(t)=4t.
$$

逐點計算的預期值為：

| $t$ | $B(t)$ |
|---:|---:|
| 0 | $(0,0)$ |
| 0.25 | $(1,0.46875)$ |
| 0.5 | $(2,0.75)$ |
| 0.75 | $(3,0.65625)$ |
| 1 | $(4,0)$ |

因此稿件不能把例 1 的二次曲線結果 $(2,1)$ 當成目前 `test_fish_outline` 的中點預期；稿件目前有註明「若使用相同控制點」，但測試章最好直接列出實際程式資料的數值。

端點導數為：

$$
B'(0)=4(P_1-P_0)=4(1,0.5)=(4,2),
$$

$$
B'(1)=4(P_4-P_3)=4(1,-1)=(4,-4).
$$

第二段三次曲線起始導數為：

$$
Q'(0)=3(Q_1-Q_0)=3(1,-1)=(3,-3).
$$

兩者同向，故是 $G^1$；但向量不相等，故不是 $C^1$。

## 三、其他應修正事項

### 維度與座標

- 2D 控制點、2D 行列式及 3D 曲線概念基本相容。
- 本章未混用世界座標、影像座標或齊次座標，沒有座標系實質錯誤。
- 「2D 外積」應持續稱為行列式或嵌入 $z=0$ 後的外積 $z$ 分量，避免讀者誤認其結果是 2D 向量。

### 法線與平滑性

**原句：**

> $C^1$ 則確保光照計算時法線過渡完全平滑。

此說法過強。對平面正則曲線，非零且連續的切線可導出連續法線方向；對曲面拼接，僅有邊界曲線 $C^1$ 並不足以保證曲面法線連續。建議限定為「本章的正則平面輪廓」，不要推廣到一般曲面光照。

### 退化與邊界

程式應處理：

- 空控制點；
- 單一控制點；
- 控制點維度不一致；
- $t$ 是否限制在 $[0,1]$，或明說允許外插；
- 零端點導數導致切線方向未定義。

### 色彩與索引

本章沒有色彩管線或網格索引內容，無相關錯誤；不必為湊篇幅加入。

### 字數與完整性

系統量測為 2705 字，低於最低 3000 字及目標 4500 字。宜用真正缺少的內容補足，例如分段 Bézier 樣條、不同次數的連續性、曲線分割與自適應細分，而不是增加宣傳性文字。

## 四、引用界線

1. **G1 PBRT Transformations**可支持仿射變換概念，但不能單獨作為 Bézier、Bernstein 或樣條理論的主要來源。
2. **G4 Ray Tracing in One Weekend**被標為「Bézier 曲面基礎」，稿件未提供具體章節或論點對應；來源清單本身不代表此內容已獨立查證，應刪除不確定的用途聲明或改引真正討論曲線的資料。
3. `The NURBS Book` 不在提供的候選來源清單內，且缺少版次、出版社與年份。若保留，應補完整書目並明示為延伸閱讀，不能暗示本輪已查核。
4. 「程式碼為原創示範」「未直接抄襲」不是可由稿件本身證明的技術論點，參考來源段落可刪除此自我聲明。
5. 本審查未執行程式，也未外部查閱上述來源；修訂後仍需人工及指定環境實測。
