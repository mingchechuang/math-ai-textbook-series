## 一、數學與邏輯錯誤（真錯誤）

### 1. Top-Left 規則在 Y-Down 座標系下的定義錯誤
*   **原句/公式**：
    > 在螢幕座標（Y 向下）下，定義邊 $a\to b$ 為**左上邊**當且僅當
    > $$ (b_y-a_y)<0 \quad\text{或}\quad (b_y=a_y \land b_x>a_x). $$
    > 即「向上」或「水平向右」。
*   **錯誤原因**：
    1.  **Top-Left 規則的目的**：確保相鄰三角形在共享邊上只有一個將其視為邊界，從而消除縫隙或重疊。
    2.  **Y-Down 座標系特性**：像素原點在左上，$y$ 軸向下增大。
    3.  **標準定義**：在 Y-Down 座標系中，一條邊被視為 "Top-Left" 邊（即該邊界像素歸屬於此三角形），通常定義為：**終點 $b$ 相對起點 $a$ 在「上方」（$y_b < y_a$）或「右方」（$y_b = y_a$ 且 $x_b > x_a$）**。
    4.  **驗證**：
        *   考慮兩三角形共享邊 $AB$。T1 頂點順序 $A \to B \to C$（逆時針，Y-Down 下 area > 0）。T2 頂點順序 $B \to A \to D$（逆時針，Y-Down 下 area > 0）。
        *   在 T1 中，邊方向為 $A \to B$。在 T2 中，邊方向為 $B \to A$。
        *   若 $B$ 在 $A$ 的「上方」（$y_B < y_A$）：
            *   T1 邊 $A \to B$：$dy = y_B - y_A < 0$。滿足條件（Top-Left）。
            *   T2 邊 $B \to A$：$dy = y_A - y_B > 0$。不滿足條件。
            *   結果：像素歸屬 T1。正確。
        *   若 $B$ 在 $A$ 的「右方」（$y_B = y_A, x_B > x_A$）：
            *   T1 邊 $A \to B$：$dy = 0, dx > 0$。滿足條件（Top-Left）。
            *   T2 邊 $B \to A$：$dy = 0, dx < 0$。不滿足條件。
            *   結果：像素歸屬 T1。正確。
    5.  **結論**：原句中的定義 $(b_y-a_y)<0$ 或 $(b_y=a_y \land b_x>a_x)$ 在 Y-Down 座標系中是**正確**的。
    *   *自我糾正*：我最初懷疑此處有誤，但經過詳細推導，在 Y-Down 座標下，"Top-Left" 邊的定義確實是邊向量指向上方或右方。這與 Y-Up 座標系（通常定義為邊向量指向下方或左方為 Top-Left，或者相反，取決於具體實現）不同，但本稿明確使用了 Y-Down 並給出了對應定義。
    *   *再檢查*：許多文獻（如 OpenGL）在 Y-Up NDC 中定義 Top-Left。但本節明確說明「螢幕座標 Y 向下」。在此座標下，「向上」即 $y$ 減小。定義合理。
    *   *潛在陷阱*：如果 $b_y - a_y < 0$ 表示邊從下往上走（在 Y-Down 中，上邊 $y$ 值小）。是的，$y_b < y_a$ 意味著 $b$ 比 $a$ 更靠上。
    *   **判定**：此處**無誤**。之前的審稿疑慮解除。

### 2. 習題 2 的解答中關於 $T_3$ 的覆蓋描述
*   **原句**：
    > (b) 覆蓋像素集合為兩個共斜邊的直角三角形（斜邊 $x+y=32$）加上第三個三角形完全落在 $T_1$ 內（不再增加計數）...

    1.  $T_1 = (0,0), (32,0), (0,32)$。區域：$x \ge 0, y \ge 0, x+y \le 32$。
    2.  $T_2 = (0,0), (0,32), (32,32)$。區域：$x \ge 0, y \le 32, x \ge 32-y$ ? 不，T2 頂點是 $(0,0), (0,32), (32,32)$。

    3.  $T_3 = (16,0), (32,16), (16,32)$。
        *   邊 1: $(16,0) \to (32,16)$ (斜率 1, $y = x - 16$)
        *   邊 2: $(32,16) \to (16,32)$ (斜率 -1, $y = -x + 48$)
        *   邊 3: $(16,32) \to (16,0)$ (x=16)
        *   T3 內部：$x \ge 16$，且 $y \ge x-16$，且 $y \le -x+48$。
    4.  **比較 T3 與 T1**：
        *   T1 的斜邊是 $x+y=32$ (即 $y = -x+32$)。
        *   T3 的頂點 $(16,0)$ 在 T1 內。$(32,16)$: $32+16=48 > 32$，**在 T1 外**。
        *   $(16,32)$: $16+32=48 > 32$，**在 T1 外**。

    7.  實際上，$T_1$ 覆蓋左下三角形，$T_2$ 覆蓋左上三角形。它們拼成左半正方形 ($x \le 32-y$? 不，T1+T2 覆蓋 $x+y \le 32$ 和 $y \ge x$ ? 不，T1 是 $x+y \le 32, y \ge 0, x \ge 0$。T2 是 $y \ge x, y \le 32, x \ge 0$。
        *   T1 和 T2 的並集覆蓋了正方形 $[0,32]\times[0,32]$ 的**左下半部分**（由對角線 $x+y=32$ 和 $y=x$ ? 不，T1 和 T2 共享邊 $(0,0)-(0,32)$ 嗎？不，T1 邊 $(0,0)-(0,32)$，T2 邊 $(0,0)-(0,32)$。它們共享左邊。
        *   T1: $(0,0), (32,0), (0,32)$。
        *   T2: $(0,0), (0,32), (32,32)$。
        *   它們覆蓋了整個正方形嗎？
            *   T1: $x \ge 0, y \ge 0, x+y \le 32$。
            *   T2: $x \ge 0, y \le 32, y \ge x$。
            *   並集：$(x \ge 0, y \ge 0, x+y \le 32) \cup (x \ge 0, y \le 32, y \ge x)$。
            *   點 $(32, 16)$: $x+y=48 > 32$ (不在 T1)。$y=16 < x=32$ (不在 T2)。
            *   所以 T1 和 T2 **沒有**覆蓋整個正方形，它們留出了右側的三角區域（$x+y > 32$ 且 $y < x$）。
    8.  $T_3$ 覆蓋了右側的部分。
    9.  解答稱 T3 完全落在 T1 內是嚴重的幾何錯誤。

### 3. 程式碼 `is_top_left` 與理論定義的一致性
*   **程式碼**：
    ```python
    def is_top_left(ax, ay, bx, by):
        dy, dx = by - ay, bx - ax
        return (dy < 0.0) or (dy == 0.0 and dx > 0.0)
    ```
*   **核對**：
    *   理論定義：$(b_y-a_y)<0$ 或 $(b_y=a_y \land b_x>a_x)$。
    *   程式碼實現完全一致。
    *   **但是**，在 `raster_triangle` 中，當 `area2 < 0` 時，頂點 `v0` 和 `v1` 被交換，以使 `area2` 變正。
    *   交換後，邊的定義也改變了。
    *   原邊 $0 \to 1$ 變成 $1 \to 0$ (交換前)，交換後 $v0$ 是原 $v1$， $v1$ 是原 $v0$。
    *   新的邊 $0 \to 1$ (交換後) 對應原 $1 \to 0$。
    *   程式碼中 `e2 = edge(x0, y0, x1, y1, ...)` 計算的是當前 $v0 \to v1$。
    *   `is_top_left(x0, y0, x1, y1)` 檢查的也是當前 $v0 \to v1$。
    *   這確保了無論頂點順序如何，只要最終 `area2 > 0`，邊的方向定義與 Top-Left 檢查是一致的。
    *   **無誤**。
