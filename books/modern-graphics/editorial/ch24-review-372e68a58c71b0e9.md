但沒有呼叫 `time.perf_counter()`，也沒有記錄或輸出任何時間。因此目前沒有完成章節核心與實驗要求中的「時間記錄」。

**修法：**

加入明確的計時範圍，例如：

```python
start = time.perf_counter()
test_img = render_simulated(spp=spp, seed=seed, bias=0.0)
```

但必須同時說明：`render_simulated` 只生成一個固定大小的高斯噪聲陣列，運算量幾乎不隨 `spp` 改變，所以這項計時不能驗證真實渲染時間與 spp 的關係。真正的效能實驗應呼叫第 22 章的路徑追蹤器，或另寫一個確實執行 $WH\cdot spp$ 次樣本工作的合成核心。

### 2. 程式沒有真正估計偏誤與變異數

**原文：**

> 此程式驗證……偏誤—變異數分離

但程式只計算每個 seed 對真值的 MSE，再對五個 MSE 取平均與標準差：

```python
mses.append(mse)
avg_mse = np.mean(mses)
std_mse = np.std(mses)
```

這沒有分別估計

$$
\|\mathbb E[\hat I]-I\|^2
$$

與

$$
\mathbb E[\|\hat I-\mathbb E[\hat I]\|^2].
$$

**修法：**

保存所有 seed 的影像：

```python
stack = np.stack(images, axis=0)
mean_img = np.mean(stack, axis=0)
bias2 = np.mean((mean_img - ref_true) ** 2)
variance = np.mean(np.var(stack, axis=0, ddof=1))
```

有限 $K$ 時，直接用樣本平均估出的 `bias2` 本身也含有限 seed 誤差；正文應說這是估計值，不是精確分解。若只保留目前程式，則把宣稱改成「觀察有偏與無偏案例的 MSE 趨勢」。

### 3. `±std_mse` 不是信賴區間

**原輸出：**

```python
print(f"... Avg MSE: {avg_mse:.6f} (±{std_mse:.6f})")
```

正文則說：

> 應以多 seed 平均值與信賴區間判斷。

`np.std(mses)` 預設 `ddof=0`，只是五個 MSE 的母體形式標準差，不是平均 MSE 的標準誤，更不是信賴區間。

**修法：**

至少把輸出標明為：

```python
sample_std = np.std(mses, ddof=1)
print(f"mean={avg_mse:.6f}, sample_std={sample_std:.6f}")
```

若要報平均值的標準誤：

```python
se = sample_std / np.sqrt(len(mses))
```

若要報正式信賴區間，還要明定分布假設與臨界值。只有五個 seed 時，不宜把 `mean ± std` 稱為信賴區間。

### 4. `box_blur` 不是一般所稱的 Box blur，且 `radius` 語意錯誤

**原程式：**

```python
offsets = [(-radius, 0), (radius, 0),
           (0, -radius), (0, radius), (0, 0)]
```

此程式只平均中心與上下左右五個位置，是十字形濾波器，不是 $(2r+1)\times(2r+1)$ 方形 Box filter。當 `radius=2` 時，它甚至不包含距離 1 的鄰居。

**修法：**

若名稱保留為 `box_blur`，應遍歷完整方形視窗：

```python
for dy in range(-radius, radius + 1):
    for dx in range(-radius, radius + 1):
        ...
```

或把函式改名為 `cross_blur`，並明說是五點平均器。

---

### 5. `np.roll` 造成影像環繞，邊界測試會得到錯誤鄰接

**原註解：**

> 為避免邊界填充複雜化，使用 NumPy roll

`np.roll` 會把最右側像素捲到最左側、最下側捲到最上側，相當於週期邊界。一般影像不是週期貼圖，因此會使不相鄰的邊界互相污染。這會破壞後續邊緣、亮點及假細節測試。

**修法：**

明確採用邊界策略，例如：

```python
padded = np.pad(img, ((radius, radius),
                      (radius, radius),
                      (0, 0)),
                mode="edge")
```

再擷取視窗平均。若刻意採週期邊界，函式名稱與教材必須明說，且不能拿它代表一般影像降噪。

### 6. `Blur reduces MSE? True` 不是有限隨機樣本的必然輸出

**原文：**

> *預期*：`Blur reduces MSE? True`

對常數真值及獨立零均值噪聲，鄰域平均在期望上降低方差；但對某個固定 seed 的有限隨機影像，不能僅靠理論保證每次實現的經驗 MSE 必然降低。尤其目前 `np.roll` 使樣本重用，邊界又採週期形式。

**修法：**

改為：

> 跨足夠多個獨立 seed 的平均 MSE 預期降低；單一 seed 可能因隨機波動不符合此趨勢。

測試應收集多個 seed，對 `mse_blur - mse_noisy` 報平均值與離散程度。

---

### 7. 降噪「假細節」與「過度平滑」混為一談

**原句：**

> 在邊緣可能產生光暈或模糊，稱為「假細節」或「過度平滑」。

模糊和過度平滑主要是**細節損失**；光暈是濾波偽影；「假細節」通常指降噪器生成輸入或真值中不存在的紋理或結構。簡單正權重 Box filter 通常不會憑空產生高頻細節，但會跨邊緣混色。

**修法：**

分開定義：

- 過度平滑：真實高頻細節被移除；
- 邊緣滲色／光暈：跨物體邊界混合；
- 假細節：輸出出現參考圖不存在的結構，較常見於資料驅動或非線性重建方法。

至少加入階梯邊緣、單像素亮點及純噪聲案例；目前只有常數圖，無法驗證任何邊緣損失或假細節。

---

### 8. 養殖案例的效能敘述使用了未定義的「有效樣本數」

**原句：**

> 需記錄有效樣本數以校正效能指標。

若每像素發射一條路徑，`Samples/sec` 應計算實際啟動的路徑樣本數。高消光係數可能縮短平均路徑，但不會自動改變啟動樣本數。要解釋每樣本成本，應另記錄：

- 總路徑數；
- 總射線數或總路徑節點數；
- 平均路徑長度；
- 相交測試數；
- 提前終止比例。

「有效樣本數」若沒有正式定義，不能用來校正效能。

---

### 9. 金屬黑斑不能只靠 1 spp 與 1000 spp 判定偏誤

**原解答：**

> 若 1000 spp 的圖像中，黑色斑塊仍然存在且位置固定，則為偏誤。  
> 若斑塊消失……則為噪聲。

固定位置的高方差區域也可能在有限 1000 spp 下仍偏暗，例如極低機率高貢獻路徑。反之，錯誤的有偏演算法也可能隨 spp 呈現較平滑結果。

**修法：**

應要求：

1. 建立高可信參考圖或可解析案例；
2. 對每個 spp 使用多個 seed；
3. 計算黑斑遮罩區域的跨 seed 平均與變異數；
4. 檢查平均誤差是否隨 spp 仍穩定非零；
5. 分別檢查 NaN、法線、PDF、BRDF/PDF 比值及路徑終止。

MSE 趨勢只能提供證據，不能單獨證明根因。

## 二、程式邊界與可重現性

### 1. `render_simulated` 缺少輸入檢查

`spp <= 0` 會造成除零或無效平方根，非整數 spp 也不符合本章定義。應檢查：

```python
if not isinstance(spp, (int, np.integer)) or spp <= 0:
    raise ValueError("spp must be a positive integer")
```

`sigma` 應為有限非負值，`bias` 應為有限值。

### 2. Gaussian 模擬可能產生負輻射值

```python
img = 0.5 + noise + bias
```

可能得到負值。作為零均值統計玩具模型可以接受，但應明說它不是物理路徑貢獻模型。不能直接裁切到零，因為裁切會引入額外偏誤。

### 3. `compare_renders` 缺少必要檢查

至少應檢查：

- `img1`、`img2`、`ref` shape 一致；
- shape 為 `(H,W,C)`；
- `time1,time2` 為有限正數；
- `spp1,spp2` 為正整數；
- 所有影像值有限。

目前 `H, W, C = img1.shape` 對灰階或錯誤維度只會產生不清楚的拆包錯誤。

### 4. 主程式沒有呼叫實驗

程式區塊結束於 `run_experiment` 定義，沒有：

```python
if __name__ == "__main__":
    run_experiment()
```

因此作為獨立程式執行時不會輸出任何結果，不符合「完整可獨立閱讀的小程式」。

## 三、公式與手算核對

### 正確項目

以下內容目前數學上正確：

- RGB MSE／MAE 對 $HWC$ 純量值平均的定義；
- 偏誤—變異數期望分解；
- 案例 1 的 $0.01$ 與 $1/12$；
- 案例 2 的
  $0.04/16=0.0025$、
  $0.04/64=0.000625$；
- 習題 1 的 MSE $0.025$、MAE $0.15$；
- 常數偏誤 $0.05$ 對應 MSE 底限 $0.0025$；
- 每秒樣本數使用 $WH\cdot spp/time$，不乘 RGB 通道數。

### 需補充的條件

含噪參考圖的方差相加公式要求測試圖與參考圖誤差獨立且無偏。若使用共同隨機數，則還有協方差項：

$$
\operatorname{Var}(T-R)
=
\operatorname{Var}(T)+\operatorname{Var}(R)
-2\operatorname{Cov}(T,R).
$$

應補上「獨立」條件，避免將公式誤用於配對 seed 實驗。
