# 第九章：Bézier 曲線與樣條

## 1. 學習目標與先備知識

本章探討如何使用 Bézier 曲線定義平滑的 2D 或 3D 路徑，並利用其數學性質進行幾何建模。讀者需掌握第一卷的向量加法、標量乘法、矩陣運算及 Python/NumPy 基礎。

**學習目標：**
1. 理解 Bézier 曲線的仿射組合定義與 Bernstein 基底。
2. 掌握 de Casteljau 演算法的幾何意義與遞迴實現。
3. 計算曲線導數以確定切線方向。
4. 理解 $C^0$（位置連續）與 $G^1$（切線連續）在樣條拼接中的角色。
5. 實作程式驗證曲線的端點性、凸包性質與切線連續性。

**先備知識橋接：**
*   **微積分：** 多項式求導則。若 $P(t) = \sum p_i B_i(t)$，則 $P'(t) = \sum p_i B_i'(t)$。
*   **線性代數：** 仿射組合（仿射變換保持直線與比例不變）。

## 2. 問題與直覺

在養殖場數位分身中，魚體輪廓並非剛體，而是具有流暢邊界的非剛體。使用多邊形網格近似會產生明顯的折線感，而貝茲曲線提供了一種由少量控制點定義平滑曲面的方式。

**直覺理解：**
想象一條皮筋，其兩端固定，中間受到若干「錨點」的牽引。當錨點移動時，皮筋（曲線）隨之變形，但曲線本身不一定經過中間的錨點（只有端點必經）。這種特性稱為**凸包性質**：曲線完全包圍在控制點形成的多邊形（凸包）內。

## 3. 數學與幾何推導

### 3.1 Bernstein 基底與 Bézier 定義

$n$ 次 Bézier 曲線由 $n+1$ 個控制點 $P_0, P_1, \dots, P_n$ 定義，參數 $t \in [0, 1]$。曲線方程為：

$$
B(t) = \sum_{i=0}^{n} P_i \binom{n}{i} t^i (1-t)^{n-i}
$$

其中 $\binom{n}{i} = \frac{n!}{i!(n-i)!}$ 為二項式係數。函式 $B_i(t) = \binom{n}{i} t^i (1-t)^{n-i}$ 稱為第 $i$ 個 **Bernstein 基底函數**。

**關鍵性質：**
1.  **歸一性 (Partition of Unity)：** $\sum_{i=0}^{n} B_i(t) = 1$。這保證了 $B(t)$ 是控制點的**仿射組合**（權重和為 1）。
2.  **端點插值：** $B(0) = P_0$ 且 $B(1) = P_n$。
3.  **凸包性：** 曲線位於控制點集的凸包內。
4.  **變換不變性：** 對控制點施加仿射變換 $T$，等於對曲線結果施加 $T$。即 $T(B(t)) = B_T(t)$。

### 3.2 導數與切線

曲線的切線方向由一階導數 $B'(t)$ 決定。對 $B(t)$ 求導：

$$
B'(t) = \sum_{i=0}^{n-1} (P_{i+1} - P_i) \binom{n-1}{i} (1-t)^{n-1-i} t^i \cdot n
$$

簡化後，可發現 $B'(t)$ 本身是一個 $n-1$ 次 Bézier 曲線，其控制點為差分向量 $\Delta P_i = P_{i+1} - P_i$ 的加權組合。

*   在 $t=0$ 處，切線方向平行於 $P_1 - P_0$。
*   在 $t=1$ 處，切線方向平行於 $P_n - P_{n-1}$。

### 3.3 de Casteljau 演算法

直接計算高次多項式在 $t$ 接近端點時數值不穩。de Casteljau 演算法提供幾何遞迴計算方式，具有數值穩定性且直觀。

**算法步驟（以 $n=3$ 為例）：**
1.  在每對相鄰控制點之間，計算線性插值點：
    $Q_i(t) = (1-t)P_i + t P_{i+1}$，其中 $i=0, \dots, n-1$。
2.  對 $Q$ 序列重複此步驟：
    $R_i(t) = (1-t)Q_i(t) + t Q_{i+1}(t)$，其中 $i=0, \dots, n-2$。
3.  重複直到剩餘 1 個點，該點即為 $B(t)$。

此過程可視化為控制多邊形的逐步「收縮」。

### 3.4 連續性：$C^k$ 與 $G^k$

當拼接兩段 Bézier 曲線 $B_0(t)$ 和 $B_1(t)$ 時：
*   **$C^0$ 連續：** $B_0(1) = B_1(0)$。位置連續。
*   **$G^1$ 連續（几何連續）：** 兩曲線在接點處的切線方向相同（共線），但長度（參速）不必相等。對於 Bézier，需滿足 $P_{end,0}, P_{last-1,0}, P_{0,1}, P_{1,1}$ 共線。
*   **$C^1$ 連續（參數連續）：** $G^1$ 且導數向量相等：$B_0'(1) = B_1'(0)$。對於 Bézier，需滿足 $P_{last-1,0}$ 與 $P_{0,1}$ 到接點的距離相等且方向相反。

在建模中，$G^1$ 通常足以實現視覺平滑，$C^1$ 則確保光照計算時法線過渡完全平滑。

## 4. 逐步手算例題

### 例 1：計算二次 Bézier 曲線中點切線

**已知：** 控制點 $P_0(0,0)$, $P_1(2,2)$, $P_2(4,0)$。求 $t=0.5$ 時的點與切線斜率。

**解：**
1.  **計算點 $B(0.5)$：**
    $B_i(0.5)$ 權重：
    $B_0(0.5) = \binom{2}{0}(0.5)^0(0.5)^2 = 0.25$
    $B_1(0.5) = \binom{2}{1}(0.5)^1(0.5)^1 = 0.5$
    $B_2(0.5) = \binom{2}{2}(0.5)^2(0.5)^0 = 0.25$

    $B(0.5) = 0.25 P_0 + 0.5 P_1 + 0.25 P_2$
    $x = 0.25(0) + 0.5(2) + 0.25(4) = 0 + 1 + 1 = 2$
    $y = 0.25(0) + 0.5(2) + 0.25(0) = 0 + 1 + 0 = 1$
    點為 $(2, 1)$。

2.  **計算導數 $B'(t)$：**
    公式：$B'(t) = 2[(1-t)(P_1-P_0) + t(P_2-P_1)]$ （對於 $n=2$，基底導數簡化為線性組合）
    更通用的 $n=2$ 導數形式：
    $B'(t) = 2(1-t)(P_1-P_0) + 2t(P_2-P_1)$
    
    在 $t=0.5$：
    $B'(0.5) = 2(0.5)(P_1-P_0) + 2(0.5)(P_2-P_1) = (P_1-P_0) + (P_2-P_1) = P_2 - P_0$
    
    $P_2 - P_0 = (4,0) - (0,0) = (4, 0)$。
    切線向量為 $(4,0)$，斜率為 $0/4 = 0$（水平）。
    *驗證幾何直覺：對稱拋物線頂點處切線應為水平。*

### 例 2：檢查 $G^1$ 連續性

**已知：** 曲線 A 末段控制點 $A_1(0,0), A_2(1,1), A_3(2,0)$。曲線 B 起始控制點 $B_0(2,0), B_1(3,1), B_2(4,0)$。
接點為 $A_3 = B_0 = (2,0)$。

**解：**
1.  **$C^0$ 檢查：** $A_3 = B_0$，成立。
2.  **$G^1$ 檢查：** 需 $A_2, A_3, B_0, B_1$ 共線。
    向量 $v_A = A_3 - A_2 = (2,0) - (1,1) = (1, -1)$。
    向量 $v_B = B_1 - B_0 = (3,1) - (2,0) = (1, 1)$。
    外積（2D 為行列式）：$1(1) - (-1)(1) = 2 \neq 0$。
    不共線，故**不滿足 $G^1$**，接點處會有明顯拐角。

## 5. 實作與程式

使用 Python 和 NumPy 實現 Bézier 曲線。

```python
import numpy as np

def bernstein_basis(n, i, t):
    """計算第 i 個 Bernstein 基底值，n 為次數"""
    # 使用對數或簡單乘法避免階乘溢出，n 通常不大
    coeff = np.math.factorial(n) / (np.math.factorial(i) * np.math.factorial(n-i))
    return coeff * (t ** i) * ((1 - t) ** (n - i))

def bezier_point(pts, t):
    """
    計算 Bézier 曲線上 t 處的點。
    pts: list of np.array (控制點)
    t: float
    """
    n = len(pts) - 1
    p = np.zeros(len(pts[0]))
    for i in range(n + 1):
        p += pts[i] * bernstein_basis(n, i, t)
    return p

def de_casteljau(pts, t):
    """
    de Casteljau 演算法遞迴計算點。
    pts: list of np.array
    t: float
    """
    current_pts = pts
    while len(current_pts) > 1:
        new_pts = []
        for i in range(len(current_pts) - 1):
            # 線性插值: (1-t)*P_i + t*P_{i+1}
            new_pt = (1 - t) * current_pts[i] + t * current_pts[i+1]
            new_pts.append(new_pt)
        current_pts = new_pts
    return current_pts[0]

def bezier_tangent(pts, t):
    """
    計算切線向量（未正規化）。
    """
    n = len(pts) - 1
    # 導數控制點為差分
    diff_pts = [pts[i+1] - pts[i] for i in range(n)]
    # 導數曲線的次數為 n-1
    # 導數公式: B'(t) = n * sum_{i=0}^{n-1} diff_pts[i] * B_{n-1,i}(t)
    tangent = np.zeros(len(pts[0]))
    for i in range(n):
        # 注意：導數的基底指數對應 n-1
        coeff = np.math.factorial(n-1) / (np.math.factorial(i) * np.math.factorial((n-1)-i))
        basis_val = coeff * (t ** i) * ((1 - t) ** ((n-1) - i))
        tangent += diff_pts[i] * basis_val
    return tangent * n # 乘以上次的 n

def test_fish_outline():
    """
    模擬魚體上部輪廓 (2D)
    """
    # 控制點定義魚背脊
    # P0: 頭部前端, P1: 頭部後, P2: 背鰭前, P3: 背鰭後, P4: 尾部前
    ctrl_pts = [
        np.array([0.0, 0.0]),   # 0
        np.array([1.0, 0.5]),   # 1
        np.array([2.0, 1.0]),   # 2
        np.array([3.0, 1.0]),   # 3
        np.array([4.0, 0.0])    # 4
    ]
    n = len(ctrl_pts) - 1
    
    print("Testing de Casteljau vs Direct Calculation")
    ts = [0.0, 0.25, 0.5, 0.75, 1.0]
    for t in ts:
        p1 = bezier_point(ctrl_pts, t)
        p2 = de_casteljau(ctrl_pts, t)
        err = np.linalg.norm(p1 - p2)
        print(f"t={t:.2f}: Direct={p1}, deCasteljau={p2}, Err={err:.6f}")
        assert err < 1e-5, "Mismatch in calculation methods"
        
    # 切線連續性測試 (人工拼接)
    # 將上述曲線視為第一段 A (P0..P4)
    # 建構第二段 B (P4..P7) 使其在 P4 處 G1 連續
    # A 末端切線方向: P4 - P3 = [1, -1]
    # B 起始切線方向: Q1 - Q0 必須平行於 [1, -1]
    P4 = ctrl_pts[4]
    Q0 = P4
    Q1 = P4 + np.array([1.0, -1.0]) # 確保方向
    Q2 = P4 + np.array([2.0, -1.0])
    Q3 = P4 + np.array([3.0, 0.0])
    
    # 檢查 G1: 向量 (P4-P3) 和 (Q1-Q0) 是否平行
    v_A = P4 - ctrl_pts[3]
    v_B = Q1 - Q0
    cross_2d = v_A[0]*v_B[1] - v_A[1]*v_B[0]
    print(f"G1 Check at junction: Cross Product = {cross_2d}")
    assert abs(cross_2d) < 1e-6, "Not G1 continuous"
    
    # 凸包性質測試
    # 簡單檢查：曲線點是否在控制點最小圍盒內（必要條件，非充分條件，但足夠檢測明顯錯誤）
    min_coord = np.min(np.array(ctrl_pts), axis=0)
    max_coord = np.max(np.array(ctrl_pts), axis=0)
    for t in np.linspace(0, 1, 50):
        pt = bezier_point(ctrl_pts, t)
        if not (np.all(pt >= min_coord - 1e-6) and np.all(pt <= max_coord + 1e-6)):
            print(f"Warning: Point {pt} at t={t} outside bounding box of control points")
            # 注意：Bézier 曲線必在凸包內，凸包必在 Bounding Box 內。
            # 若在 BBox 外絕對錯誤。若在凸包外才真正違反。這裡僅做 BBox 粗檢。
            pass 

if __name__ == "__main__":
    test_fish_outline()
```

## 7. 除錯與常見陷阱

1.  **權重未歸一化：**
    *   若手動實現 Bernstein 基底，忘記乘以二項式係數 $\binom{n}{i}$，曲線將不經過端點，且形狀嚴重失真。
    *   **解決：** 使用 `np.math.factorial` 或預計算係數表，並檢查 $\sum B_i(t) = 1$。

2.  **數值不穩定（高次曲線）：**
    *   直接計算 $t^i(1-t)^{n-i}$ 在 $n > 10$ 且 $t$ 極端時可能精丟失。
    *   **解決：** 始終使用 **de Casteljau 演算法**進行求值，它具有遞迴線性插值的數值穩定性。

3.  **混淆 $C^1$ 與 $G^1$：**
    *   在光柵化或法線計算中，若需要 $C^1$ 連續（導數向量相等），但僅保證了 $G^1$（方向平行），導致法線過渡出現「皺褶」或光照閃爍。
    *   **解決：** 明確需求。視覺平滑通常 $G^1$ 夠用；物理模擬或高精度法線插值需 $C^1$。檢查時不僅比對方向，還要比對長度（對於 $C^1$）。

4.  **參數化不均勻 (Parameterization Bias)：**
    *   參數 $t$ 線性遞增不代表弧長線性遞增。若需等距取樣（如生成網格頂點），直接使用 $t$ 會導致頂點在曲率大處稀疏、曲率小處密集。
    *   **解決：** 使用弧長參數化（Arc-length reparameterization）。先計算累積弧長表，再透過二分搜索將等距弧長映射回 $t$ 值。

5.  **控制點共線退化：**
    *   若所有控制點共線，曲線退化為直線。若某些控制點重合，曲線會在该區域停留時間較長（參速變慢）。
    *   **解決：** 檢查控制點距離，避免無意義的重複點，或在生成模型時施加最小距離約束。

## 8. 養殖數位分身案例

在養殖場數位分身中，魚體形狀變化（如擺尾）可建模為 Bézier 曲線控制點的動畫。

**應用場景：**
1.  **身體截面輪廓：** 將魚體沿脊柱切分，每個截面用 Bézier 曲線定義外輪廓。
2.  **脊椎路徑：** 魚的主體脊柱本身是一條 3D Bézier 曲線。
3.  **動畫綁定：**
    *   定義關鍵影格：靜止、擺尾左、擺尾右。
    *   控制點隨時間插值。由於 Bézier 曲線的變換不變性，對控制點施加骨骼矩陣變換後，曲線自動正確變形，無需重新計算高次多項式係數。
4.  **數據驗證：**
    *   利用凸包性質，檢查動畫過程中魚體輪廓是否超出預期體積範圍（防止模擬穿透或異常膨脹）。
    *   利用切線連續性，確保魚鰭與魚身連接處無斷裂，生成流暢的貼圖 UV。

**限制：**
Bézier 曲線局部控制性較差（移動一個控制點影響整條曲線）。對於極長的多節脊椎，可能需要分段使用樣條（如 B-Splines），但本章聚焦於 Bézier 基礎，分段拼接需嚴格管理 $G^1/C^1$ 連續性。

## 10. 習題解答

### 解答 1
1.  **$B(0.5)$：**
    $n=3$。
    $B_0(0.5) = \binom{3}{0}(0.5)^0(0.5)^3 = 0.125$
    $B_1(0.5) = \binom{3}{1}(0.5)^1(0.5)^2 = 0.375$
    $B_2(0.5) = \binom{3}{2}(0.5)^2(0.5)^1 = 0.375$
    $B_3(0.5) = \binom{3}{3}(0.5)^3(0.5)^0 = 0.125$
    
    $x = 0.125(0) + 0.375(1) + 0.375(2) + 0.125(3) = 0 + 0.375 + 0.75 + 0.375 = 1.5$
    $y = 0.125(0) + 0.375(1) + 0.375(1) + 0.125(0) = 0 + 0.375 + 0.375 + 0 = 0.75$
    點為 $(1.5, 0.75)$。

2.  **$B'(0)$：**
    公式 $B'(t) = 3 \sum_{i=0}^{2} (P_{i+1}-P_i) \binom{2}{i} (1-t)^{2-i} t^i$
    在 $t=0$，只有 $i=0$ 項非零（因為 $t^i$ 項）：
    $B'(0) = 3 (P_1-P_0) \binom{2}{0} (1)^2 (0)^0 = 3(P_1-P_0)$
    $P_1-P_0 = (1,1) - (0,0) = (1,1)$
    $B'(0) = (3, 3)$。
    切線方向為 $(1,1)$，斜率 1。

3.  **對稱性：**
    控制點 $y$ 座標：$0, 1, 1, 0$。關於 $x=1.5$ 對稱。
    $x$ 座標：$0, 1, 2, 3$。
    $B(1-t)$ 的 $x$ 座標應為 $3 - B(t)$ 的 $x$ 座標？
    由於控制點 $x$ 均勻分佈且 $y$ 對稱，曲線關於 $x=1.5$ 軸對稱。
    驗證：$B(0.5) = (1.5, 0.75)$ 在軸上。$B(0)$ 與 $B(1)$ 對稱。是的，對稱。

### 解答 2
控制點 $Q_0(0,0), Q_1(0,2), Q_2(2,2), Q_3(2,0)$。
$n=3$。
$B(0.5) = 0.125 Q_0 + 0.375 Q_1 + 0.375 Q_2 + 0.125 Q_3$
$x = 0.125(0) + 0.375(0) + 0.375(2) + 0.125(2) = 0 + 0 + 0.75 + 0.25 = 1.0$
$y = 0.125(0) + 0.375(2) + 0.375(2) + 0.125(0) = 0 + 0.75 + 0.75 + 0 = 1.5$
點為 $(1.0, 1.5)$。
**結論：** 預期的 $(1, 1.5)$ 是正確的。這顯示了對於特定對稱控制點，中點可能符合直覺，但不可假設。

### 解答 3
1.  **$C^0$：** $P_2(2,0) = Q_0(2,0)$。是。
2.  **$G^1$：**
    A 末端切線方向：$P_2 - P_1 = (2,0) - (1,1) = (1, -1)$。
    B 起始切線方向：$Q_1 - Q_0 = (3,-1) - (2,0) = (1, -1)$。
    向量平行且同向（外積為0）。
    **是** $G^1$ 連續。
    *(註：題目原意可能是給一個不平行的例子，但這裡給的數據恰好平行。若改為 $Q_1(3,0)$，則 $Q_1-Q_0=(1,0)$，與 $(1,-1)$ 不平行，則不連續。在此按給定數據回答：是連續的。若題目意在檢查不連續情況，請調整 $Q_1$ 為非共線點。)*
    **重新檢查題目意圖：** 通常此類習題會給不連續的例子。若 $Q_1(3,0)$，則方向 $(1,0)$ 與 $(1,-1)$ 不共線。
    假設題目數據 $Q_1(3,-1)$ 確實導致連續。
    
    若題目問「若希望...應如何調整」，暗示原數據可能不連續或需要優化。
    若原數據已連續，則無需調整。
    **修正理解：** 可能我計算錯誤？
    $P_2-P_1 = (1, -1)$。
    $Q_1-Q_0 = (1, -1)$。
    它們完全相同。所以不僅 $G^1$，甚至是 $C^1$（導數向量相等）。
    
    若題目給的是 $Q_1(3,0)$：
    $Q_1-Q_0 = (1,0)$。
    要使其與 $(1,-1)$ 平行，需 $Q_1 = Q_0 + k(1,-1)$。
    通常取 $k=1$ 以保持規模一致（$C^1$ 連續），則 $Q_1 = (2,0) + (1,-1) = (3,-1)$。
    所以，若原 $Q_1$ 是 $(3,0)$，調整為 $(3,-1)$ 即可。
    在此，我假設讀者需理解**方向向量需共線**這一核心。

3.  **調整方法：**
    需滿足 $(Q_1 - Q_0)$ 平行於 $(P_2 - P_1)$。
    $P_2 - P_1 = (1, -1)$。
    設 $Q_1 = (x, y)$。
    $Q_1 - Q_0 = (x-2, y-0) = (x-2, y)$。
    需 $(x-2, y) = k(1, -1)$。
    最簡單取 $k=1$（保持參數速度連續），則 $x-2=1 \Rightarrow x=3$, $y=-1$。
    故 $Q_1$ 應為 $(3, -1)$。

### 解答 4
1.  **生成點：** 使用 `de_casteljau` 對 $t=0.1, \dots, 1.0$ 計算點。
2.  **弦長：** 計算 $\|P_i - P_{i-1}\|$。
3.  **最大區間：** 在曲率較大或參速較大的區間，弦長較長。
4.  **討論：**
    *   **原因：** Bézier 曲線的參數 $t$ 與弧長 $s$ 非線性關係。$ds/dt = \|B'(t)\|$。若 $\|B'(t)\|$ 變化大，則相同 $\Delta t$ 對應的 $\Delta s$ 不同。
    *   **影響：** 若直接生成網格，三角形頂點在曲率大處會稀疏，導致網格無法精確捕捉形狀，出現視覺失真或法線計算錯誤。
    *   **解決：** 必須進行**弧長重參數化**。計算累積弧長表，確保生成的頂點在空間上均勻分佈，而非參數上均勻。

## 11. 本章小結

本章建立了 Bézier 曲線的數學基礎，從 Bernstein 基底到 de Casteljau 演算法，並探討了連續性條件。關鍵要點：
1.  Bézier 曲線是控制點的仿射組合，滿足凸包性質。
2.  de Casteljau 演算法是數值穩定且幾何直觀的求值方法。
3.  $G^1$ 連續性確保幾何平滑，需控制點共線。
4.  參數均勻不等於弧長均勻，應用中需進行重參數化。
這些概念是後續樣條曲線、曲面建模及物理模擬的基礎。
