# 第04章 線性方程、消去法與秩

## 學習目標與先備知識

本章處理「已知部分觀測，想反推背後未知量」的線性問題。讀者需已熟悉第02章的列向量、內積與第03章的矩陣乘法、轉置。全書採用列向量：若 $x\in\mathbb{R}^d$、$W\in\mathbb{R}^{m\times d}$，則 $y=Wx\in\mathbb{R}^m$。本章會先建立「線性方程組」的語言，再用高斯消去求出解，最後用秩（rank）判斷解是無解、唯一解，還是無窮多解。

本章目標：能用增廣矩陣與行運算手算小規模系統；能說明主元、秩、自由變數的意義；能判斷感測器數據是否「可識別」。本節不預設微積分或機率知識。

## 從池A提出問題

池A有兩支溫度感測器 $T_1,T_2$ 與一支溶氧感測器 $D$。為校正漂移，我們假設真實溫度 $\theta$（攝氏）與感測器原始讀數的關係是線性的。取兩組「已知真值」的校正點：

- 第一組：真值 $\theta=20$ 時，$T_1$ 讀數 $8$、$T_2$ 讀數 $14$；
- 第二組：真值 $\theta=25$ 時，$T_1$ 讀數 $12$、$T_2$ 讀數 $18$。

把每個感測器讀數寫成「斜率 $\times$ 真值 $+$ 截距」：$T_1=a_1\theta+b_1$、$T_2=a_2\theta+b_2$。未知數是斜率與截距 $a_1,b_1,a_2,b_2$。每個校正點對每個感測器給出一個方程，兩支感測器共四個未知數、四個方程。這是典型的線性方程組：已知係數與右端，求未知參數。

## 概念與推導

**線性方程組。** 形如 $Ax=b$ 的方程組中，$A\in\mathbb{R}^{m\times n}$ 是係數矩陣，$x\in\mathbb{R}^n$ 是未知向量，$b\in\mathbb{R}^m$ 是常數項。把 $A$ 與 $b$ 併成增廣矩陣 $\left[\,A\mid b\,\right]$（形狀 $m\times(n{+}1)$），可用「初等行運算」逐步化簡：交換兩行、某行乘非零常數、某行加上另一行的倍數。這些運算不改變解集合。

**高斯消去與主元。** 目標是化簡成階梯形（row echelon form）：每一非零行的第一個非零項（主元，pivot）比上一行更靠右，且主元下方全為零。若繼續讓主元上方也變零，即得簡化階梯形（reduced row echelon form）。主元所在的變數稱主元變數；沒有主元的變數稱自由變數（free variable），它們可任取，其餘變數由它們決定。

**秩與一致性。** 矩陣的秩是其階梯形中非零行的數目，也等於主元的個數。記 $r=\operatorname{rank}(A)$，$r'=\operatorname{rank}([A\mid b])$。判斷法則：
- 若 $r<r'$，系統不一致，無解（例如出現 $0=c\neq0$）。
- 若 $r=r'=n$（未知數個數），解唯一。
- 若 $r=r'<n$，系統一致但有 $n-r$ 個自由變數，解有無窮多個。

直覺上：每個獨立方程消去一個自由度；當獨立方程數不足以鎖定所有未知數，剩下的自由度就成了「不可識別」的部分。

## 手算例題

以校正感測器 $T_1$ 的方程組示範（$T_2$ 同型，略去）。未知數按 $(a_1,b_1)$ 排列：

$$
\begin{cases}
20a_1+b_1=8\\
25a_1+b_1=12
\end{cases}
\qquad
\left[\begin{array}{cc|c}
20 & 1 & 8\\
25 & 1 & 12
\end{array}\right]
$$

用第一行消去第二行的 $a_1$ 項。第二行 $-R_1+\left(\tfrac{5}{4}\right)R_1$ 較繁，改先交換並簡化：把第一行減第二行得 $-5a_1=-4$，即 $a_1=\tfrac{4}{5}=0.8$。代回 $20(0.8)+b_1=8$，得 $16+b_1=8$，故 $b_1=-8$。

核對第二組：$25(0.8)+(-8)=20-8=12$，成立。此 $2\times2$ 係數矩陣
$\begin{bmatrix}20&1\\25&1\end{bmatrix}$ 的行列式 $20-25=-5\neq0$，秩為 2，等於未知數個數，故唯一解。

**不可識別情形。** 假設 $T_2$ 的兩組讀數分別是 $14$ 與 $18$，但我們額外發現 $T_2$ 實際上等於 $T_1+6$（兩支量同一物理量，只差固定偏移）。此時 $a_2=a_1$、$b_2=b_1+6$，未知數被綁定，有效獨立方程少一個：系統中出現兩個可互相推出的行，增廣後有一行可被消成全零行，秩下降，自由度多出一个，即無法單獨確定 $T_2$ 的斜率與截距，只能確定「差值 $6$」。

## Python實驗

以下用 NumPy 解 $T_1$ 校正方程並檢查秩（請在隔離環境自行執行，本教材不在此宣告結果）：

```python
import numpy as np

# 已知真值 theta=20、25 對應 T1 讀數 8、12
A = np.array([[20.0, 1.0],
              [25.0, 1.0]])   # shape (2,2)
b = np.array([8.0, 12.0])     # shape (2,)

print("rank(A) =", np.linalg.matrix_rank(A))   # 預期 2
x = np.linalg.solve(A, b)                       # 解 (a1, b1)
print("a1, b1 =", x)                            # 預期 [0.8, -8.0]
print("residual =", A @ x - b)                  # 預期 [0, 0]
```

**不可識別示範：** 把第二支感測器設成與 $T_1$ 線性相依（$T_2=T_1+6$），即第二行等於第一行加一個常數項：

```python
B = np.array([[20.0, 1.0, 0.0],
              [20.0, 1.0, 0.0],
              [25.0, 1.0, 0.0]])   # 含相依行
c = np.array([8.0, 14.0, 12.0])
print("rank(B) =", np.linalg.matrix_rank(B))   # 預期 < 3
```

秩小於未知數個數時，`np.linalg.solve` 會報奇異或警告，需改用 `np.linalg.lstsq` 取最小範數解，並把多餘自由度交給自由變數。

## 連回生成式AI、多模態與Agent

線性可識別性在多模態與 agent 場景反覆出現。Embedding 層把詞彙映到向量時，若某些特徵線性相依（如同義詞在同一資料中永遠同步出現），對應參數無法被資料唯一決定，必須靠正則化或先驗打破退化，與本節自由變數同構。注意力層 $QK^\top$ 與後續線性投影也是求解/擬合 $Ax=b$ 的變體：當 $A$ 列秩不足，梯度方向落在零空間，參數更新不改變輸出，模型「看不見」這些自由度。

對 pool A 的 agent 而言，感測融合先問「這些感測器是否提供獨立資訊」。若 $D$ 與 $T$ 因設備佈置而高度線性相依，融合矩陣 $W$（形狀 $m\times d$，$d$ 為感測器數、$m$ 為觀測數）的秩低於 $d$，則「水質狀態向量」不可識別，agent 應標記為資料不足，轉請人工覆核，而不是輸出看似確定的建議。線性代數在這裡是骨架，但真實池受非線性、統計與因果因素影響，秩的判斷不能取代現場專業判斷。

## 常見錯誤與限制

1. **把秩當成行列式。** 只有方陣行列式非零才等价於滿秩；一般矩陣用非零行數判斷秩。
2. **混淆列與行。** 本節行運算作用在矩陣的「列（row）」上；中文「行」有時指 column，本節凡指運算對象皆稱列。
3. **用浮點直接判秩。** 浮點有誤差，$r'$ 判斷需設容差（NumPy `matrix_rank` 內含此機制），不可用 `==0`。
4. **解出唯一解就當真實。** 唯一解只表示在假設線性模型成立下可識別；模型本身是否成立，需非線性與因果分析，不能省略。
5. **忽略單位。** 真值與讀數皆須同一單位；混用攝氏與攝氏偏移會造成方程不一致假象。

## 習題

1. **基本計算：** 解方程組 $\begin{cases}2x+y=5\\ x-y=1\end{cases}$，寫出增廣矩陣、做高斯消去，並指出主元與秩。
2. **觀念：** 若 $A\in\mathbb{R}^{3\times2}$ 且 $\operatorname{rank}(A)=2$，則 $Ax=b$ 對任意 $b$ 是否一定有解？對任意 $b$ 解是否唯一？說明。
3. **養殖應用：** pool A 有兩支溶氧感測器，觀測發現它們讀數永遠相差 $0.3\,\mathrm{mg/L}$（固定偏移），即 $D_2=D_1+0.3$。請問：以這兩支感測器校正「單一真實溶氧值」時，係數矩陣的秩與未知數個數有何關係？agent 應如何處理？

## 習題解答

1. 增廣矩陣 $\left[\begin{smallmatrix}2&1&5\\1&-1&1\end{smallmatrix}\right]$。$R_1-R_2$ 得 $x+y$ 與 $x-y$ 可消去：$R_1+R_2$ 消 $y$：$3x=6\Rightarrow x=2$，代回 $y=1$。主元在 $x,y$ 兩列，秩 $=2$，等於未知數個數，唯一解。
2. 因 $A$ 是 $3\times2$，$\operatorname{rank}(A)=2=\operatorname{rank}([A\mid b])$ 當且僅當 $b$ 落在 $A$ 的列空間（column space）。對任意 $b\in\mathbb{R}^3$ 不保證在列空間內，故不一定有解；但若有解，因秩 $=2=$未知數個數，解唯一。
3. 兩感測器只差固定偏移，獨立方程只有一個有效，秩 $=1$ 小於未知數個數（真實溶氧 $+$ 可能的漂移參數），系統不可識別。agent 應標記為「感測器相依、不可識別」，拒絕自動校正或加藥，轉請現場人員處理。

## 本章小結

本章以池A感測器校正為引，建立線性方程組、高斯消去、主元、秩與自由變數的完整語言，並給出一致性判斷法則：$r<r'$ 無解、$r=r'=n$ 唯一解、$r=r'<n$ 無窮解。手算例題展示 $2\times2$ 解法與行列式判滿秩，再以「兩感測器固定偏移」說明秩不足造成不可識別。Python 段以 `matrix_rank` 與 `solve/lstsq` 演示。這些概念是後續正交投影、最小平方、條件數與 agent 資料有效性檢查的基礎：當線性骨架的秩不足時，任何下游模型都應先標記資料不足並交由人工覆核，而非輸出偽確定結論。
