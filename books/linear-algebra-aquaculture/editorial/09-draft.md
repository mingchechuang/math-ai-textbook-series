# 第09章 共變異數、PCA與資料洩漏

## 學習目標與先備知識

本章要學會三件事。第一，從中心化資料計算樣本共變異數，並理解它度量兩變數如何協同偏離平均。第二，用共變異數矩陣找出主成分，即資料變異最大的方向，並計算各主成分解釋的變異比例。第三，理解資料洩漏：若用測試日的平均或標準差去縮放訓練資料，等於把測試日的資訊提前帶入，評估就不再誠實。

你需要先懂向量、矩陣乘法、特徵值與對稱矩陣譜定理（第7章），以及奇異值分解（第8章）。本章假設讀者熟悉基本Python與NumPy，不需要微積分或機率理論。

## 從池A提出問題

池A連續記錄溫度、溶氧與pH。假設我們已有7天訓練資料與1天測試資料。若要把三維特徵壓到一維以便畫圖或檢索，該選哪個方向？直覺是選「波動最大」的方向。但要小心：如果我們把訓練加測試共8天的平均一起算，再用同一組統計量處理所有日子，測試日就偷偷參與了縮放器的決定，等於在考試前偷看考卷。

## 概念與推導

設批次 $X\in\mathbb{R}^{n\times d}$，每列一筆觀測。先求樣本平均

$$\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i\in\mathbb{R}^{d}$$

中心化 $Z=(x_i-\bar{x})_{i=1}^{n}$。樣本共變異數矩陣為

$$S=\frac{1}{n-1}Z^{T}Z\in\mathbb{R}^{d\times d}$$

分母 $n-1$ 是Bessel修正，使 $S$ 對母體共變異數不具系統性低估。$S$ 對稱半正定，可用譜定理對角化：

$$S=U\Lambda U^{T}$$

$U$ 的欄向量即特徵向量（主成分方向），$\Lambda=\mathrm{diag}(\lambda_1\ge\lambda_2\ge\cdots\ge\lambda_d)$。第 $k$ 個主成分解釋變異比例為 $\lambda_k/\sum_j\lambda_j$。

資料洩漏的核心規則：所有統計量（$\bar{x}$、$S$、$U$）只從訓練時段估計，測試日只套用 $z=(x-\bar{x}_{train})$ 與投影 $zU_k$。

## 手算例題

訓練集4筆、2維：$(1,2),(2,4),(3,3),(4,5)$。

平均 $\bar{x}=(2.5,3.5)$。中心化後 $Z$ 各列：$(-1.5,-1.5),(-0.5,0.5),(0.5,-0.5),(1.5,1.5)$。

$Z^{T}Z$ 的 $(1,1)$ 項：$2.25+0.25+0.25+2.25=5$；$(1,2)$ 項：$2.25-0.25-0.25+2.25=4$。故 $S=\frac{1}{3}\begin{pmatrix}5&4\\4&5\end{pmatrix}$。

特徵值：$\lambda_{1,2}=\frac{5\pm4}{3}=\frac{7}{3},\,\frac{1}{3}$。第一主成分方向 $\frac{1}{\sqrt2}(1,1)$。解釋變異 $=\frac{7/3}{8/3}=\frac78=87.5\%$。測試日新點 $(3,4)$ 套用訓練統計量：$z=(0.5,0.5)$，投影 $z\cdot\frac{1}{\sqrt2}(1,1)=\frac{1}{\sqrt2}\approx0.707$。若改用含測試日的8天平均，投影值會改變，這就是洩漏。

## Python實驗

```python
import numpy as np
np.random.seed(42)
train = np.random.randn(30, 3) * np.array([1.0, 2.0, 0.5])
test  = np.random.randn(5, 3)  * np.array([1.0, 2.0, 0.5])

mu_train = train.mean(axis=0)
Z = train - mu_train
S = Z.T @ Z / (len(train) - 1)
w, U = np.linalg.eigh(S)
idx = np.argsort(w)[::-1]
w, U = w[idx], U[:, idx]
expl = w / w.sum()
print("解釋變異:", np.round(expl, 3))          # 預期約 [0.66, 0.29, 0.05]
score = (test - mu_train) @ U[:, 0]
print("測試第一主成分前2個:", np.round(score[:2], 3))
```

輸入：上面固定的 $n=30$ 訓練與 $n=5$ 測試矩陣。預期輸出：`解釋變異` 約 `[0.66, 0.29, 0.05]`（seed=42 下可核對），`測試第一主成分前2個` 為兩支浮點數，量級約 $\pm1$。注意：seed只固定亂數，不保證統計可靠性。

## 連回生成式AI、多模態與Agent

池A的感測、水面影像與工作日誌各自有維度與變異尺度。PCA可用訓練時段把高維特徵壓到幾維潛在座標，供後續檢索（第18章）或對比學習（第16章）使用。對agent而言，若它在測試日才「決定」用哪組平均去縮放，就等於讓推理過程接觸答案。安全做法：縮放器與PCA在部署前凍結，agent只能呼叫，不能重估。這與第19章「缺值或過期資料先拒絕執行」的規則一致。

## 常見錯誤與限制

一是把 $n$ 當成分母，結果特徵值系統性偏小，解釋變異仍正確但與Bessel修正是兩套慣例，需一致。二是用全資料（含測試）做中心化，造成洩漏。三是把主成分解釋變異誤解為因果效應：$87.5\%$ 只表示線性投影後殘差平方和最小，不代表溫度「導致」溶氧。四是忽略PCA對線性相關敏感，非線性結構（如時間週期）未必被捕捉。五是seed固定後誤以為結果具統計保證；它只是可重現性，不是可靠性。

## 習題

1. **基本計算**：3筆2維訓練資料 $(0,0),(2,2),(4,0)$。計算 $\bar{x}$、$S$（分母 $n-1$），並給出第一主成分方向與解釋變異比例。
2. **觀念**：若你先用7天訓練資料算出 $\bar{x}$，再發現第8天（測試日）有筆誤，修正後重算 $\bar{x}$ 會造成什麼問題？為何正確做法是保留訓練統計量不變？
3. **養殖應用**：池A某週溫度標準差很小、溶氧標準差很大，二者相關係數接近0。請說明第一主成分大概會落在哪個方向，以及這是否代表溫度與溶氧「無關」，還是只是線性協變異小。

## 習題解答

1. $\bar{x}=(2,4/3)$。中心化 $Z$ 列：$(-2,-4/3),(0,2/3),(2,-4/3)$。$Z^{T}Z$ 的 $(1,1)=8$，$(1,2)=(-8/3+0-8/3)=-16/3$，$(2,2)=16/9+4/9+16/9=36/9=4$。$S=\frac12\begin{pmatrix}8&-16/3\\-16/3&4\end{pmatrix}=\begin{pmatrix}4&-8/3\\-8/3&2\end{pmatrix}$。特徵值 $\lambda=\frac{6\pm\sqrt{36-4\cdot16/9}}{2}=\frac{6\pm\sqrt{36-64/9}}{2}=\frac{6\pm\sqrt{260/9}}{2}=\frac{6\pm\frac{2\sqrt{65}}{3}}{2}$，即 $\lambda_1\approx3.86$、$\lambda_2\approx2.14$。解釋變異 $\approx\frac{3.86}{6}=64.3\%$。第一主成分方向為 $\lambda_1$ 對應特徵向量，比例約 $(1,-0.82)$ 歸一化後。
2. 修正測試日會改變「訓練統計量」，使訓練與測試共享被污染的平均，評估高估模型泛化能力。正確做法：訓練統計量在切分當下凍結；測試日筆誤只影響測試集本身，不回溯修改縮放器。
3. 第一主成分大致落在溶氧方向（因為其變異大且相關接近0，共變異數矩陣近似對角，較大特徵值對應溶氧軸）。這不代表溫度與溶氧無關，只表示在觀測時段內二者線性協變異小；非線性、時滯或條件關係仍可能存在，PCA無法排除。

## 本章小結

本章建立三條主軸：共變異數矩陣以 $n-1$ 分母與中心化資料度量協同變異；PCA透過對稱矩陣譜定理给出變異最大的方向與解釋變異比例；資料洩漏要求所有統計量只從訓練時段估計，測試日只套用。這些是後續檢索、融合與agent安全判斷的基礎，但PCA只捕捉線性結構，不能替代因果推論或現場專業判斷。
