# 全書編輯規格

繁體中文，高中數學與基本Python讀者；不預設已懂微積分、機率或深度學習。
全書主軸：生成式AI -> 多模態 -> agent -> 水產品養殖；前半部奠基，後半部連成同一虛構池A案例。
所有向量預設列向量(column vector)，x∈R^d、W∈R^(m×d)、y=Wx∈R^m；批次X∈R^(n×d)以每列一筆觀測，Y=XW^T。
術語裁決：「列向量(column vector)」為固定複合詞，明指d×1的直向向量；矩陣位置則用橫列(row)／縱行(column)。欄是column的位置同義詞，不另設「欄向量」或「行向量」作column vector的正式譯名。空間正式名稱為列空間(row space)與行空間(column space)，必要時優先附英文與維度。不得僅因「列向量」與「橫列」中單字相同而判定公式方向錯誤。
attention另明確約定Q,K∈R^(n×d_k)、V∈R^(n×d_v)，softmax逐列；文字須分清列(row)與行(column)，避免中文歧義。
樣本共變異數分母n-1；訓練集估計mean/std，驗證/測試集只套用。固定seed=42，但seed不是統計可靠性保證。
實體量：temperature_c(攝氏)、do_mg_l(溶氧mg/L)、ph(無量綱)。資料全為教學合成，不提供真實物種適用閾值。
同一故事：池A的感測器+水面影像+工作日誌->特徵->模型->檢索SOP->agent建議->資料有效性檢查->人工批准。
任何示範不連真實設備，不下投餌、加藥、增氧指令；安全操作须由現場專業人員制定，模型建議不能代替養殖專業。
線性代數只是生成式AI的骨架，非線性、統計、因果推論與控制不可被省略或假裝已證明。
引用只使用給定來源ID；不偽造論文頁碼、實驗成果、真實養殖收益或人體安全閾值。
