# 審稿結果

前輪的 PCG recurrence、SGS 名稱、量綱、網格位置及誤差範數問題均已實質修正。手算與非 SPD 反例亦一致。尚有少數程式邊界契約需修補。

## 必須修正

### 1. 允許零容差，卻使用嚴格小於，精確解可能被判成 breakdown

- **原句／程式**：
  ```python
  if norm_r_true < atol + rtol * norm_b:
  ```
  同一判定出現於初始與迭代停止處。
- **原因**：程式允許 `atol=0`、`rtol=0`。此時即使真殘差恰為零，`0 < 0` 仍為假，演算法會繼續，之後可能因零搜索方向被判成 `breakdown`。
- **最小修法**：兩處皆改成：
  ```python
  if norm_r_true <= atol + rtol * norm_b:
  ```
  並增加 `atol=rtol=0`、精確初始解的邊界測試。

### 2. `x0` 輸入檢查本身可能拋出未處理例外

- **原句／程式**：
  ```python
  if x0.shape != b.shape or not np.all(np.isfinite(x0)):
  ```
- **原因**：若 `x0` 是 list 或其他沒有 `.shape` 的物件，函式會直接產生 `AttributeError`，未依文件契約回傳 `invalid_x0`。
- **最小修法**：先檢查 `x0` 是一維實數 NumPy 陣列，或先安全轉換：
  ```python
  x0 = np.asarray(x0)
  if x0.ndim != 1 or x0.shape != b.shape ...
  ```
  並拒絕非有限及複數資料。

### 3. 求解器宣稱 SPD 實數系統，卻接受複數 `b`／`data`

- **原句／程式**：
  ```python
  np.issubdtype(b.dtype, np.number)
  ```
  `validate_csr` 也未限制 `data` 為實數一維陣列。
- **原因**：`np.number` 包含複數。`csr_matvec` 建立的是實數 `y=np.zeros(n)`，複數乘積寫入時可能遺失虛部；同時程式使用的是轉置內積 `np.dot`，不是 Hermitian 內積，並不構成複數 Hermitian positive definite CG。
- **最小修法**：本章既限定實數 SPD，應要求 `b`、`data`、`x0` 為一維實數浮點／整數陣列，明確拒絕複數。`validate_csr` 亦應檢查 `data.ndim == 1` 及實數 numeric dtype。

## 建議一併修正

### 4. 最大值原理不可由「場平滑」或殘差門檻直接保證

- **原句**：
  > 溫度場應平滑，無振盪。最大值／最小值應出現在邊界（極值原理）。
- **原因**：連續極值原理不自動等於近似迭代解的嚴格離散保證。標準五點離散的精確解具離散最大值原理，但有限求解容差下可能有小幅違反。
- **最小修法**：限定為「此五點 M-matrix 離散的精確離散解」；數值解則實際測試內部超界量，並按真殘差與容差解讀，不以平滑外觀批准。

### 5. 小結對 Jacobi 的敘述宜加條件

- **原句**：
  > Jacobi 預條件可通過改善條件數來加速收斂。
- **原因**：本章自己的常係數 1D 例中條件數恰好不變。
- **最小修法**：改成「對部分縮放不均或變係數系統可能改善條件數；本章常係數 1D 例不改善」。
