# 第26章 能量泛函與變分梯度流 審稿意見

## 1. 重算與核對

### 1.1 界面能量 (Interface Energy) 計算
*   **原句**：$\sigma = \frac{2\sqrt{2}}{3} \sqrt{\kappa}$。
*   **重算**：
    *   能量泛函 $F[\phi] = \int_{-\infty}^{\infty} \left[ W(\phi) + \frac{\kappa}{2}(\phi')^2 \right] dx$，其中 $W(\phi) = \frac{(\phi^2-1)^2}{4}$。
    *   歐拉-拉格朗日方程：$\mu = W'(\phi) - \kappa \phi'' = \phi^3 - \phi - \kappa \phi'' = 0$。
    *   乘以 $\phi'$ 並積分：$\frac{1}{4}(\phi^2-1)^2 - \frac{\kappa}{2}(\phi')^2 = C$。
    *   邊界條件 $\phi \to \pm 1$ 時 $\phi' \to 0$，故 $C=0$。
    *   $\frac{\kappa}{2}(\phi')^2 = \frac{(\phi^2-1)^2}{4} \implies \phi' = \frac{1-\phi^2}{\sqrt{2\kappa}}$ (取正支，$\phi$ 從 -1 到 1)。
    *   $dx = \frac{\sqrt{2\kappa}}{1-\phi^2} d\phi$。
    *   $\sigma = \int_{-1}^{1} \left[ W(\phi) + W(\phi) \right] \frac{dx}{d\phi} d\phi = \int_{-1}^{1} 2 \cdot \frac{(1-\phi^2)^2}{4} \cdot \frac{\sqrt{2\kappa}}{1-\phi^2} d\phi$。
    *   $\sigma = \frac{\sqrt{2\kappa}}{2} \int_{-1}^{1} (1-\phi^2) d\phi = \frac{\sqrt{2\kappa}}{2} \left[ \phi - \frac{\phi^3}{3} \right]_{-1}^{1} = \frac{\sqrt{2\kappa}}{2} \cdot \frac{4}{3} = \frac{2\sqrt{2}}{3} \sqrt{\kappa}$。
*   **結論**：原句計算正確。

### 1.2 習題 2 解析解驗證
*   **原句**：$\phi(t) = \frac{\phi_0 e^t}{\sqrt{1 - \phi_0^2 + \phi_0^2 e^{2t}}}$。
*   **重算**：
    *   ODE: $\phi_t = \phi - \phi^3 = \phi(1-\phi^2)$。
    *   $\int \frac{d\phi}{\phi(1-\phi^2)} = t + C$。
    *   部分分式：$\frac{1}{\phi(1-\phi^2)} = \frac{1}{\phi} + \frac{1}{2}\left(\frac{1}{1-\phi} - \frac{1}{1+\phi}\right)$。
    *   積分：$\ln|\phi| - \frac{1}{2}\ln|1-\phi| - \frac{1}{2}\ln|1+\phi| = t + C$。
    *   $\ln \left( \frac{\phi}{\sqrt{1-\phi^2}} \right) = t + C$。
    *   $\frac{\phi}{\sqrt{1-\phi^2}} = A e^t$，其中 $A = \frac{\phi_0}{\sqrt{1-\phi_0^2}}$。
    *   $\phi^2 = A^2 e^{2t} (1-\phi^2) \implies \phi^2 (1 + A^2 e^{2t}) = A^2 e^{2t}$。
    *   $\phi = \frac{A e^t}{\sqrt{1 + A^2 e^{2t}}}$。
    *   代入 $A$：
        $$ \phi = \frac{\frac{\phi_0}{\sqrt{1-\phi_0^2}} e^t}{\sqrt{1 + \frac{\phi_0^2 e^{2t}}{1-\phi_0^2}}} = \frac{\phi_0 e^t}{\sqrt{1-\phi_0^2 + \phi_0^2 e^{2t}}} $$
*   **結論**：解析解正確。

### 1.3 歐拉顯式手算驗證
*   **參數**：$\phi_0 = 0.5, \Delta t = 0.1$。
*   **第一步**：
    *   歐拉：$\phi^1 = 0.5 + 0.1(0.5 - 0.5^3) = 0.5 + 0.1(0.375) = 0.5375$。
    *   解析解 $t=0.1$：
        *   分母 $\sqrt{0.75 + 0.25 e^{0.2}} = \sqrt{0.75 + 0.25(1.2214)} = \sqrt{1.05535} \approx 1.0273$。
        *   分子 $0.5 e^{0.1} = 0.5(1.1052) = 0.5526$。
        *   $\phi(0.1) \approx 0.5526 / 1.0273 \approx 0.5379$。
    *   誤差：$|0.5379 - 0.5375| = 0.0004$。
*   **第二步**：
    *   歐拉：$\phi^2 = 0.5375 + 0.1(0.5375 - 0.5375^3) \approx 0.5375 + 0.1(0.3822) = 0.57572$。
    *   解析解 $t=0.2$：
        *   分母 $\sqrt{0.75 + 0.25 e^{0.4}} = \sqrt{0.75 + 0.25(1.4918)} = \sqrt{1.12295} \approx 1.0597$。
        *   分子 $0.5 e^{0.2} = 0.5(1.2214) = 0.6107$。
        *   $\phi(0.2) \approx 0.6107 / 1.0597 \approx 0.5763$。
    *   誤差：$|0.5763 - 0.57572| \approx 0.0006$。
*   **結論**：原句數值計算與誤差估計正確。

### 1.4 Hessian 特徵值估算
*   **原句**：$\lambda_{\max} \approx 18.4$。
*   **重算**：
    *   離散 Laplacian 在週期網格 $N=64$ 上的最大特徵值（Nyquist 模態）為 $\frac{4}{\Delta x^2}$。
    *   $\Delta x = 1/64 \implies \frac{4}{\Delta x^2} = 4 \times 64^2 = 16384$。
    *   梯度項貢獻：$\kappa \times 16384 = 10^{-3} \times 16384 = 16.384$。
    *   雙井項 $W''(\phi) = 3\phi^2 - 1$。在 $\phi=\pm 1$ 時，$W''=2$。
    *   總和 $\approx 16.384 + 2 = 18.384 \approx 18.4$。
*   **結論**：估算合理。

### 1.5 程式碼邏輯檢查
*   `chem_potential_1d`:
    *   `lap = (np.roll(phi, -1) - 2.0 * phi + np.roll(phi, 1)) / dx ** 2`。
    *   這是標準二階中心差分 Laplacian。
    *   `mu = (phi ** 3 - phi) - kappa * lap`。
    *   符合 $\mu = W'(\phi) - \kappa \Delta \phi$。
*   `free_energy_1d`:
    *   `grad = (np.roll(phi, -1) - phi) / dx`。
    *   這是前向差分 $(\phi_{i+1}-\phi_i)/dx$。
    *   在週期邊界下，$\sum (\phi_{i+1}-\phi_i)^2$ 與 $\sum (\nabla \phi)^2$ 在離散意義上是等價的能量項（僅差邊界項，週期下消失）。
    *   `return dx * np.sum(W + 0.5 * kappa * grad ** 2)`。
    *   符合 $F_h = \sum \Delta x [ W + \frac{\kappa}{2} |\nabla \phi|^2 ]$。
*   `gradient_check_demo`:
    *   比較 `grad_check` (數值方向導數) 與 `dx * np.sum(mu * v)` (解析梯度點積)。
    *   離散能量梯度 $\nabla F_h$ 的分量為 $\frac{\partial F_h}{\partial \phi_i}$。
    *   在歐氏空間中，能量下降方向是 $-\nabla F_h$。
    *   AC 方程 $\phi_t = -M \mu$。
    *   若 $F_h$ 定義為 $\sum \Delta x (...) $，則 $\frac{\partial F_h}{\partial \phi_i} = \Delta x \mu_i$。
    *   所以 $\nabla F_h \cdot \mathbf{v} = \sum \frac{\partial F_h}{\partial \phi_i} v_i = \sum \Delta x \mu_i v_i$。
    *   程式碼中 `rhs = dx * np.sum(mu * v)` 正確對應此理論。
*   **結論**：程式邏輯與數學定義一致。

## 2. 可定位原句、原因、最小修法

### 疑慮 1：邊界案例描述中的 $\lambda_{\max}$ 符號混用
*   **原句**：
    ```
    **邊界案例（$\kappa = 0$）**：... $\lambda_{\max} = \max_i |3\phi_i^2 - 1|$ ...
    ```
*   **原因**：
    在「數學與物理推導」小結中，明確指出 $\lambda_{\max}$ 是「非線性顯式映射之 Jacobian... 的譜上界」，且與 $F_h$ 的 Hessian 不同。
    但在「邊界案例（$\kappa=0$）」中，直接寫出 $\lambda_{\max} = \max_i |3\phi_i^2 - 1|$。
    當 $\kappa=0$ 時，離散映射為 $\phi_i^{n+1} = \phi_i^n - \Delta t (\phi_i^n)^3 + \Delta t \phi_i^n$。
    這是對角矩陣（對角線性化）。Jacobian 的特徵值即為各點的局部斜率 $1 - 3\Delta t \phi_i^2 + \Delta t$? 不，Jacobian 是映射的導數。
    映射 $G(\phi) = \phi - \Delta t (\phi^3 - \phi)$。
    $G'(\phi) = 1 - \Delta t (3\phi^2 - 1)$。
    穩定性條件要求 $|G'(\phi)| < 1$。
    最壞情況是 $3\phi^2 - 1$ 最大時，即 $\phi=\pm 1$，$3\phi^2-1=2$。
    此時 $|1 - 2\Delta t| < 1 \implies 0 < \Delta t < 1$。
    原句寫 $\lambda_{\max} = \max_i |3\phi_i^2 - 1|$，這看起來像是在計算 ODE 的局部 Lipschitz 常數，而非顯式格式的穩定性邊界。
    若 $\lambda_{\max}$ 定義為「Jacobian 譜上界」，對於對角顯式格式，穩定性取決於 $1 - \Delta t \lambda_{local}$ 是否在 $(-1, 1)$ 內。
    原句的寫法容易讓讀者誤以為穩定性條件直接是 $\Delta t < 2 / \max(3\phi^2-1)$。
    雖然結論（$\Delta t$ 需小）是對的，但符號定義與前文的「Jacobian 譜上界」略有出入（前文指的是映射的 Jacobian 特徵值，這裡指的是被函數項的導數）。
*   **最小修法**：
    將「$\lambda_{\max} = \max_i |3\phi_i^2 - 1|$」改為「局部線性化係數的上界為 $\max_i |3\phi_i^2 - 1|$，對應穩定性限制 $M\Delta t < 2/\max_i(3\phi_i^2 - 1)$（在 $\phi$ 接近 $\pm 1$ 時）」。或簡化為「此時穩定性受限於雙井勢項的最陡峭處，$\phi=\pm 1$」。

### 疑慮 2：習題 4 解答中 CH 格式符號
*   **原句**：
    ```
    演化式必須取 $+\Delta t\,\Delta_h\mu^{n+1}$；在本卷 $L \approx \Delta$ 為負半定 Laplacian 的約定下...
    ```
*   **原因**：
    Cahn-Hilliard 方程為 $\phi_t = \nabla \cdot (M \nabla \mu) = M \Delta \mu$ (若 M 常數)。
    後向歐拉離散：$\frac{\phi^{n+1} - \phi^n}{\Delta t} = M \Delta_h \mu^{n+1}$。
    所以 $\phi^{n+1} = \phi^n + \Delta t M \Delta_h \mu^{n+1}$。
    原句寫的是 $\phi^{n+1} = \phi^n + \Delta t \Delta_h \mu^{n+1}$。符號正確（正號）。
    解釋中提到「負號會反轉耗散方向」，這是正確的，因為如果是減號，就是 $\phi_t = -\Delta \mu$，能量會增加。
    此處無誤。

## 3. 總結
稿件在數學推導、手算驗證、程式邏輯上均正確。
唯一的微小瑕疵在於「邊界案例（$\kappa=0$）」中對 $\lambda_{\max}$ 的定義與前文「Jacobian 譜上界」的定義在細節上稍有不一致（一個是 ODE 項係數，一個是映射導數），但不影響結論。
