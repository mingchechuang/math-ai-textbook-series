# 第20章 交錯網格與壓力投影

## 學習目標與先備知識

本章以二維、定密度不可壓流體說明 MAC（Marker-And-Cell）交錯網格及壓力投影。讀完後，你應能說明速度與壓力的存放位置、推導離散散度與壓力 Poisson 方程、在週期小格網執行預測／校正，並分辨數值診斷與物理驗證。

先備知識包括向量微積分、有限體積通量及線性方程。座標採右手系，$X$ 向右、$Y$ 向上。cell 中心純量 $q[j,i]$ 的形狀為 $(N_y,N_x)$，$i$ 沿 $+X$、$j$ 沿 $+Y$，展平索引 $k=jN_x+i$。二維例以每單位厚度計；程式僅需 Python 3.10+ 與 NumPy。

## 問題與直覺

不可壓條件是

$$
\nabla\cdot\mathbf{u}=0.
$$

數值預測步驟可能得到有散度的暫定速度 $\mathbf{u}^{\ast}$。壓力梯度會修正這個速度，使它符合離散不可壓條件。MAC 配置如下：

- 壓力 $p[j,i]$ 存於 cell 中心。
- $u_x[j,i]$ 存於垂直面，形狀 $(N_y,N_x+1)$。
- $u_y[j,i]$ 存於水平面，形狀 $(N_y+1,N_x)$。

面速度直接表示穿過控制體各面的法向速度，因而能自然組成有限體積通量。交錯配置可減少某些同位網格的壓力—速度解耦問題，但不能取代正確的算子、邊界條件或物理模型。

本章採週期邊界，以隔離投影算法；週期池域只是合成測試，不代表實際池塘的邊界條件。遇到固壁、入口、出口或自由液面，必須另行推導壓力邊界閉合。

## 數學與物理推導

### 連續方程與投影

定密度流體的動量方程可寫成

$$
\frac{\partial\mathbf{u}}{\partial t}
+(\mathbf{u}\cdot\nabla)\mathbf{u}
=-\frac{1}{\rho}\nabla p+\nu\Delta\mathbf{u}+\mathbf{f},
\qquad
\nabla\cdot\mathbf{u}=0.
$$

速度單位為 $\mathrm{m/s}$，時間為 $\mathrm{s}$，密度為 $\mathrm{kg/m^3}$，壓力為 $\mathrm{Pa}$，運動黏度為 $\mathrm{m^2/s}$，加速度來源 $\mathbf{f}$ 為 $\mathrm{m/s^2}$。方程各項皆為加速度。雷諾數 $Re=UL/\nu$ 比較慣性與黏性尺度，卻不會自行指定邊界或保證數值穩定。

以不含壓力的步驟求得 $\mathbf{u}^{\ast}$，再校正：

$$
\mathbf{u}^{n+1}
=
\mathbf{u}^{\ast}-\frac{\Delta t}{\rho}\nabla p.
$$

取散度並令校正後散度為零，得到

$$
\Delta p=\frac{\rho}{\Delta t}\nabla\cdot\mathbf{u}^{\ast}.
$$

本文的 $\Delta=\nabla\cdot\nabla$ 是通常非正的 Laplacian。若改用 $A=-\Delta$，則等價方程為

$$
-\Delta p=-\frac{\rho}{\Delta t}\nabla\cdot\mathbf{u}^{\ast}.
$$

改變算子符號時必須同時改變右端符號。

### MAC 離散散度、梯度與零空間

令格距為 $h_x,h_y$。cell $(j,i)$ 的離散散度為

$$
(D\mathbf{u})_{j,i}
=
\frac{u_x[j,i+1]-u_x[j,i]}{h_x}
+
\frac{u_y[j+1,i]-u_y[j,i]}{h_y}.
$$

東、北面對外法向通量取正；西、南面取負。此式等於 cell 淨流出量除以面積。壓力在相鄰 cell 中心間差分到面上，形成梯度 $G$。週期索引跨越邊界時相接；例如水平面梯度使用相鄰兩個壓力中心的差除以 $h_x$。

在一致的面積／體積內積下，週期網格具有離散分部積分關係 $D=-G^\mathsf{T}$。因此 $DG$ 是負半定離散 Laplacian，常數壓力是零模態。離散校正為

$$
\mathbf{u}^{n+1}
=\mathbf{u}^{\ast}-\frac{\Delta t}{\rho}Gp,
\qquad
DGp=\frac{\rho}{\Delta t}D\mathbf{u}^{\ast}.
$$

週期 Poisson 方程右端須與常數零空間相容，也就是平均值為零。壓力只確定到一個常數，通常指定 $\operatorname{mean}(p)=0$。若右端不相容，任意加迭代次數或釘住任一壓力節點，都不能把原本不相容的方程變成正確週期解。

相容的離散梯度、散度與內積，能使理想投影成為正交投影：校正速度滿足離散無散度，且投影不增加相應動能。有限容差、錯誤算子或不匹配的差分可能破壞這些性質。小散度僅是離散檢查，不是對連續模型或現場流場的驗證。

離散內積的選擇直接決定投影的正交性。對 cell 中心的壓力與離散散度使用體積加權內積，對面上的速度使用面積加權內積，兩者配對後才能得到散布算子與梯度算子的伴隨關係。若把面速度誤用 cell 中心內積衡量，或把壓力誤用面內積衡量，伴隨性就不再成立，投影後的速度場可能殘留可觀散度，也可能讓動能出現非物理增長。初學者可先固定均勻格距與單位密度，逐面檢查每個內部面在離散散度與離散梯度中各出現一次且符號相反；此後再引入變格距時，仍須維持面積與體積的配對權重。週期接縫的首尾兩份面在同一物理面上，只計一次權重。壓力常數零模態與右端均值相容性、面積體積內積的正交性、以及校正後的離散散度，是三項彼此獨立的檢查；通過其一不蘊含其二，也不能由其中一項取代另一項。實務上應分別記錄：投影前散度、校正後散度、壓力均值、週期接縫差與動能變化，作為後續診斷的原始數據，而非只憑單一的散度範數下結論。

### 邊界條件

週期邊界沒有獨立的壓力邊界值，但須處理常數零模態。固壁通常要求校正前後的法向速度符合無穿透條件，因此壓力修正的法向梯度要配合暫定法向速度。不能只把週期程式中的接縫改成零，就宣稱已施加固壁邊界。壓力均值歸零是數學規範，不是量測到的絕對壓力。

## 逐步手算例題

### 例一：單一 cell 的面通量

取 $h_x=2\,\mathrm{m}$、$h_y=1\,\mathrm{m}$，令西、東、南、北面的速度分量分別為 $u_W=1$、$u_E=3$、$v_S=-2$、$v_N=0\,\mathrm{m/s}$。則

$$
D\mathbf{u}
=
\frac{u_E-u_W}{h_x}
+\frac{v_N-v_S}{h_y}
=
\frac{3-1}{2}+\frac{0-(-2)}{1}
=3\,\mathrm{s^{-1}}.
$$

逐面核對：東面流出 $3h_y=3\,\mathrm{m^2/s}$，西面流出 $-u_Wh_y=-1\,\mathrm{m^2/s}$，北面為零，南面流出 $-v_Sh_x=4\,\mathrm{m^2/s}$。淨流出 $6\,\mathrm{m^2/s}$，除以面積 $2\,\mathrm{m^2}$ 得 $3\,\mathrm{s^{-1}}$。

### 例二：三格週期模式投影

取一維三格週期模式，$h_x=1\,\mathrm{m}$、$\rho=1\,\mathrm{kg/m^3}$、$\Delta t=0.5\,\mathrm{s}$。此模式的離散 Laplacian 特徵值為 $-3\,\mathrm{m^{-2}}$。若暫定散度 $r=(3,0,-3)\,\mathrm{s^{-1}}$，壓力方程要求

$$
DGp=\frac{\rho}{\Delta t}r=(6,0,-6).
$$

由 $DGp=-3p$ 得 $p=(-2,0,2)$，平均值為零。校正後散度為

$$
D\mathbf{u}^{n+1}
=
r-\frac{\Delta t}{\rho}DGp
=
r-\frac{0.5}{1}(6,0,-6)
=0.
$$

此例只展示離散符號及時間係數；其他格距、波數與維度會改變特徵值。

## 實作與程式

以下程式使用均勻週期格網上的 FFT 解 Poisson 方程。預測步驟只加上合成面加速度，不含對流、黏性或實際池域邊界，因此不是完整 CFD。速度與梯度陣列採浮點型別：整數速度陣列會被明確拒絕，以免 `empty_like` 建立整數梯度、將非整數差分截斷，導致校正所用的 $G$ 與 Poisson 算子不一致。

```python
import numpy as np

def div_mac(ux, uy, dx, dy):
    """ux: (ny,nx+1), uy: (ny+1,nx); 回傳 cell 散度。"""
    return (ux[:, 1:] - ux[:, :-1]) / dx + \
           (uy[1:, :] - uy[:-1, :]) / dy

def project_periodic(ux, uy, dx, dy, dt, rho):
    """週期 MAC 投影；回傳新速度、零均值壓力、投影前散度。"""
    if not isinstance(ux, np.ndarray) or not isinstance(uy, np.ndarray):
        raise ValueError("ux、uy 必須是 NumPy 陣列")
    if ux.ndim != 2 or uy.ndim != 2:
        raise ValueError("ux、uy 必須是二維陣列")
    if not np.issubdtype(ux.dtype, np.floating) or \
       not np.issubdtype(uy.dtype, np.floating):
        raise ValueError("ux、uy 必須使用浮點 dtype")

    ny, nxp1 = ux.shape
    nx = nxp1 - 1
    if nx < 1 or ny < 1:
        raise ValueError("格網的 nx、ny 必須至少為 1")
    if uy.shape != (ny + 1, nx):
        raise ValueError("MAC 陣列形狀不一致")

    scales = np.asarray([dx, dy, dt, rho], dtype=float)
    if not np.isfinite(scales).all():
        raise ValueError("dx、dy、dt、rho 必須全部有限")
    if not np.all(scales > 0.0):
        raise ValueError("dx、dy、dt、rho 必須為正")
    if not np.isfinite(ux).all() or not np.isfinite(uy).all():
        raise ValueError("速度必須全部有限")
    if not np.allclose(ux[:, 0], ux[:, -1]):
        raise ValueError("ux 週期接縫不一致")
    if not np.allclose(uy[0, :], uy[-1, :]):
        raise ValueError("uy 週期接縫不一致")

    rhs_div = div_mac(ux, uy, dx, dy)
    if abs(rhs_div.mean()) > 1e-11:
        raise ValueError("週期 Poisson 右端不相容")

    kx = 2.0 * np.pi * np.fft.fftfreq(nx, d=dx)
    ky = 2.0 * np.pi * np.fft.fftfreq(ny, d=dy)
    lam_x = -4.0 * np.sin(0.5 * kx * dx)**2 / dx**2
    lam_y = -4.0 * np.sin(0.5 * ky * dy)**2 / dy**2
    lam = lam_y[:, None] + lam_x[None, :]

    rhs_hat = np.fft.fft2((rho / dt) * rhs_div)
    p_hat = np.zeros_like(rhs_hat, dtype=complex)
    nonzero = lam != 0.0
    p_hat[nonzero] = rhs_hat[nonzero] / lam[nonzero]
    p = np.fft.ifft2(p_hat).real
    p -= p.mean()

    # 明確建立浮點梯度陣列；不依賴輸入陣列的 dtype。
    gx = np.empty(ux.shape, dtype=np.result_type(ux.dtype, np.float64))
    gy = np.empty(uy.shape, dtype=np.result_type(uy.dtype, np.float64))
    gx[:, 1:nx] = (p[:, 1:] - p[:, :-1]) / dx
    gx[:, 0] = (p[:, 0] - p[:, -1]) / dx
    gx[:, -1] = gx[:, 0]
    gy[1:ny, :] = (p[1:, :] - p[:-1, :]) / dy
    gy[0, :] = (p[0, :] - p[-1, :]) / dy
    gy[-1, :] = gy[0, :]

    ux_new = ux.astype(gx.dtype) - (dt / rho) * gx
    uy_new = uy.astype(gy.dtype) - (dt / rho) * gy
    ux_new[:, -1] = ux_new[:, 0]
    uy_new[-1, :] = uy_new[0, :]
    return ux_new, uy_new, p, rhs_div

def face_kinetic_energy(ux, uy, dx, dy, rho):
    """每單位厚度的合成能量診斷；週期接縫不重複計權。"""
    uc = 0.5 * (ux[:, :-1] + ux[:, 1:])
    vc = 0.5 * (uy[:-1, :] + uy[1:, :])
    return 0.5 * rho * dx * dy * np.sum(uc**2 + vc**2)

def run_demo():
    nx = ny = 8
    dx = dy = 1.0
    dt, rho = 0.1, 1.0

    # 使用浮點陣列，週期首尾面同步。
    ux = np.zeros((ny, nx + 1), dtype=float)
    uy = np.zeros((ny + 1, nx), dtype=float)
    for j in range(ny):
        for i in range(nx):
            ux[j, i] = 0.1 * np.sin(2 * np.pi * i / nx)
            uy[j, i] = 0.1 * np.cos(2 * np.pi * j / ny)
    ux[:, -1] = ux[:, 0]
    uy[-1, :] = uy[0, :]

    # 合成面加速度；兩方向均保持週期接縫一致。
    ax = np.zeros_like(ux)
    ay = np.zeros_like(uy)
    for i in range(nx):
        ax[:, i] = 0.2 * np.cos(2 * np.pi * i / nx)
    ax[:, -1] = ax[:, 0]
    for j in range(ny):
        ay[j, :] = 0.2 * np.sin(2 * np.pi * j / ny)
    ay[-1, :] = ay[0, :]

    ux_star = ux + dt * ax
    uy_star = uy + dt * ay
    ux_new, uy_new, p, div_before = project_periodic(
        ux_star, uy_star, dx, dy, dt, rho
    )
    div_after = div_mac(ux_new, uy_new, dx, dy)

    print("pressure mean:", p.mean())
    print("max divergence before:", np.max(np.abs(div_before)))
    print("max divergence after:", np.max(np.abs(div_after)))
    print("kinetic energy before:",
          face_kinetic_energy(ux_star, uy_star, dx, dy, rho))
    print("kinetic energy after:",
          face_kinetic_energy(ux_new, uy_new, dx, dy, rho))

if __name__ == "__main__":
    run_demo()
```

此 FFT 特徵值是中心差分 Laplacian 在均勻週期格網上的特徵值，不是連續波數平方。程式中的 $10^{-11}$ 是合成小例的絕對相容門檻，並非通用容差。此程式未經執行；以下僅列預期測試行為，不宣稱取得實際輸出或收斂階。

## 測試與預期結果

### 正常測試：純梯度速度

令週期暫定速度為 $\mathbf{u}^{\ast}=Gq$。在算子相容、右端相容的條件下，預期投影消除其可表示為梯度的部分，散度接近浮點誤差。常數速度不會被消除，因為它本來無散度。應分別檢查散度和速度，不能由其中一項取代另一項。

### 邊界測試：週期接縫

建立有限的浮點面速度，確保 $u_x[:,0]=u_x[:,-1]$ 且 $u_y[0,:]=u_y[-1,:]$。預期投影後兩組接縫仍一致、壓力均值接近零。壓力加常數不改變面梯度，也不改變速度校正。

### 故障測試：接縫不一致及非有限輸入

只改動 $u_x[:,-1]$ 而不改 $u_x[:,0]$，預期函式以週期接縫錯誤拒絕輸入。速度含 `NaN` 或 `Inf`、尺度為 `NaN` 或 `Inf`，亦應拒絕。這些資料不能藉由自動平均或裁零來「修復」，否則會改變輸入並掩蓋錯誤。

### 故障測試：dtype 與形狀

把速度陣列改為整數 dtype，預期函式在建立梯度前拒絕。即使整數速度本身能表示某些值，壓力面差除以格距後可以是非整數；若把梯度存進整數陣列，便會截斷。例子可取整數速度、非整數壓力梯度，檢查拒絕訊息而非讓梯度被截斷。另將速度改為一維、空格網或不符合 MAC 對應形狀，預期應在 FFT 前明確拒絕。

### 分開判讀數值性質

- **穩定性：** 解一個 Poisson 方程不保證含平流、黏性的完整時間推進穩定。
- **守恆：** cell 面通量差使共享內部面的流入與流出抵消；週期接縫的副本不能重複計量。
- **能量：** 理想正交投影不增加其相容內積下的速度動能。程式的 `face_kinetic_energy` 以相鄰面速度平均形成診斷，並非精確的面質量矩陣範數。
- **非負與物理可信：** 速度、壓力不是濃度，非負性不適用。散度小也不代表真實池域已獲驗證。

## 除錯與常見陷阱

1. **Poisson 符號錯誤：** 若採 $A=-DG$，右端也須乘負號。
2. **漏掉物理尺度：** 壓力方程右端包含 $\rho/\Delta t$，不能把散度直接當壓力。
3. **忽略零空間：** 週期壓力只確定到常數；右端不相容時，任意固定一個壓力值不會修復原方程。
4. **週期面重複計量：** 首尾兩份表示同一物理面；同步存值不等於把它算成兩個面。
5. **算子不相容：** 若實際速度校正用的梯度與 Poisson 方程所用的 $DG$ 不一致，投影後散度不會如推導消失。
6. **整數 dtype 截斷：** 梯度與校正速度應以浮點資料計算；不應把非整數差分寫入整數陣列。
7. **把週期法套到固壁：** 固壁必須另定法向速度及相應壓力邊界。
8. **殘差等於真實誤差：** 小代數殘差不能證明算子、網格或物理模型正確。

## 養殖與相場案例

在矩形合成池域可用週期速度測試被動溶質輸運。令池域平面尺度 $L_x,L_y$ 以 m 計，厚度另行指定；濃度 $c$ 以 $\mathrm{kg/m^3}$ 計，擴散係數 $K$ 以 $\mathrm{m^2/s}$ 計。平流項與擴散項的單位皆為 $\mathrm{kg/(m^3\,s)}$；來源項也須採此單位。此練習能檢查速度散度與溶質通量收支，但不能推論現場溶氧閾值或管理結果。

mg/L 轉成 SI 濃度時，$1\,\mathrm{mg}=10^{-6}\,\mathrm{kg}$，$1\,\mathrm{L}=10^{-3}\,\mathrm{m^3}$，所以 $1\,\mathrm{mg/L}=10^{-3}\,\mathrm{kg/m^3}$。流場投影不會自動保證濃度方程守恆、穩定或非負；這些性質須由濃度方程本身的離散與邊界條件判斷。

相場序參量不是速度或溶氧濃度。若要與流場耦合，須另定耦合力、自由能及邊界交換，並檢查離散能量收支。溶氧跨管理閾值不是物理相變，本章投影也不是成核、相分離或固液相變模型。

## 習題

### 習題一：手算通量

一個 $2\,\mathrm{m}\times3\,\mathrm{m}$ 的 cell，西、東、南、北面速度分量為 $u_W=-1$、$u_E=2$、$v_S=0$、$v_N=3\,\mathrm{m/s}$；$u$ 沿 $+X$、$v$ 沿 $+Y$。求散度與淨流出量，說明西面通量符號。

### 習題二：符號反例

若以 $\mathbf{u}^{n+1}=\mathbf{u}^{\ast}-(\Delta t/\rho)Gp$ 校正，卻解 $DGp=-(\rho/\Delta t)D\mathbf{u}^{\ast}$，求校正後散度並說明結果。

### 習題三：程式與 dtype 故障

分別將 `ux_star` 改成整數陣列，以及執行 `ux_star[0, -1] += 0.1` 但不改首面。預期發生什麼？若取消整數 dtype 檢查而令梯度陣列由整數速度建立，可能造成何種錯誤？

### 習題四：整合模型

池域厚度為 $H$，cell 平均濃度 $c$ 單位為 $\mathrm{kg/m^3}$，給定投影後速度，擴散係數 $K$ 為常數。寫出無反應、無外源方程，說明總質量與邊界條件如何影響收支，並列出壓力投影不能保證的性質。

## 習題解答

### 解答一

$$
D\mathbf{u}
=
\frac{2-(-1)}{2}+\frac{3-0}{3}
=2.5\,\mathrm{s^{-1}}.
$$

cell 面積為 $6\,\mathrm{m^2}$，淨流出量是 $2.5\times6=15\,\mathrm{m^2/s}$。逐面計算：東面 $6$、西面外法向通量 $-u_W\times3=3$、北面 $6$、南面 $0$，合計 $15\,\mathrm{m^2/s}$。西面外法向指向 $-X$，故其外法向速度為 $-u_W$。

### 解答二

$$
D\mathbf{u}^{n+1}
=
D\mathbf{u}^{\ast}
-\frac{\Delta t}{\rho}DGp
=
D\mathbf{u}^{\ast}
+\frac{\Delta t}{\rho}\frac{\rho}{\Delta t}
D\mathbf{u}^{\ast}
=
2D\mathbf{u}^{\ast}.
$$

錯誤符號使原有散度加倍，而不是消除。

### 解答三

整數速度輸入應在函式入口被拒絕；若沒有 dtype 檢查，整數梯度陣列會截斷非整數差分，實際校正使用的梯度便與 Poisson 方程的 $G$ 不一致。只改動週期接縫的一端則應觸發接縫錯誤。不能自動平均，因為平均會改寫資料並掩蓋更新或索引錯誤。

### 解答四

$$
\frac{\partial c}{\partial t}
+\nabla\cdot(\mathbf{u}c)
=
\nabla\cdot(K\nabla c),
\qquad
\nabla\cdot\mathbf{u}=0.
$$

兩側單位為 $\mathrm{kg/(m^3\,s)}$。cell 平均資料的總質量為 $H\sum_{j,i}c_{j,i}\Delta x\Delta y$。週期或全域零淨通量邊界且無源時，理想守恆離散應保持此量；開放邊界則須計入流入與流出。壓力投影本身不能保證濃度正性、濃度方程穩定、參數正確或現場預測可信。

## 本章小結

MAC 網格將壓力放在 cell 中心、速度放在面上，使速度直接表示控制體面通量。壓力投影的核心是相容的散度、梯度與 Poisson 算子。週期問題須滿足右端相容條件並處理常數零模態；程式還須驗證陣列形狀、有限輸入與浮點 dtype。投影後應分別檢查散度、接縫、壓力均值與能量診斷。這些檢查不等於完整流體模擬的穩定性、濃度正性或物理驗證。
