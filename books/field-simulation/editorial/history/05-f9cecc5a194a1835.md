# 第05章 平流、特徵線與資訊傳播

## 學習目標與先備知識

本章建立平流方程的物理意義、特徵線解法與數值邊界條件，並以一維線性平流及上風法說明資訊如何傳播。完成本章後，讀者應能：

1. 從守恆式辨認平流速度、濃度與邊界通量的方向。
2. 用特徵線求解常速度線性平流，判斷何處需要給定邊界資料。
3. 解釋流入與流出邊界的差異，以及速度反向時邊界角色如何交換。
4. 實作週期平移及一階上風法，檢查質量、波形與時間步長限制。
5. 分辨 CFL 條件、穩定性、正性與物理解的可信度；它們不是同一件事。

先備知識是偏導數、控制體通量與基本 Python／NumPy。以下先以一維平流為主；二維方向判斷可直接用速度與邊界外法向的內積延伸。

## 問題與直覺

考慮濃度場 $c(x,t)$，由已知速度 $a$ 搬運。若沒有擴散、反應或來源，濃度值沿著流體運動而保持不變：

$$
c_t+a c_x=0.
$$

這是非守恆寫法。當速度為常數時，它等價於守恆式

$$
c_t+(ac)_x=0.
$$

若 $a=a(x,t)$，則 $(ac)_x=a c_x+a_xc$，一般不能把 $c_t+a c_x=0$ 與 $c_t+(ac)_x=0$ 混為一談。前者描述純粹隨流搬運的標量，後者是對密度或濃度作守恆記帳；速度有散度時，兩者代表不同物理假設。

直覺上，波形不變地向右移動是 $a>0$，向左移動是 $a<0$。因此，數值更新不能從「看起來自然」決定取左格或右格，而要依資訊傳播方向選取上游資料。對 $a>0$，左方是上游；對 $a<0$，右方是上游。

本章的有因次例子使用 $x$ 的單位 m、$t$ 的單位 s、速度 $a$ 的單位 m/s、濃度 $c$ 的單位 kg/m$^3$。因此 $c_t$ 與 $a c_x$ 的單位皆為 kg/(m$^3$ s)。沒有擴散係數；若加入擴散，其係數單位應為 m$^2$/s，且會形成不同的平流—擴散方程。

## 數學與物理推導

### 特徵線與特徵速度

設 $a$ 為常數，沿曲線 $x(t)$ 計算 $c$ 的全導數：

$$
\frac{d}{dt}c(x(t),t)=c_t+\frac{dx}{dt}c_x.
$$

若令特徵線速度 $\frac{dx}{dt}=a$，則由平流方程得到

$$
\frac{d}{dt}c(x(t),t)=0.
$$

所以特徵線是 $x(t)=x_0+at$，濃度沿每條特徵線保持常數。若初始資料為 $c(x,0)=c_0(x)$，則

$$
c(x,t)=c_0(x-at).
$$

這個解表明資訊以速度 $a$ 傳播：在時間 $t$ 後，位置 $x$ 的值來自初始位置 $x-at$。

若 $a=a(x,t)$，仍可沿著滿足 $\frac{dx}{dt}=a(x(t),t)$ 的曲線追蹤解；但特徵線通常不能再寫成直線，且若流場不夠光滑，解的正則性與唯一性需要額外條件。若速度是未知量並與 $c$ 耦合，本章的線性常速度公式便不再是完整模型。

### 流入與流出邊界

在區間 $0\leq x\leq L$，邊界外法向在左端為 $n=-1$，右端為 $n=+1$。邊界處若 $a n<0$，速度指向計算域內，該處為流入邊界，應給定進入域內的資料；若 $a n>0$，速度指向域外，該處為流出邊界，通常不應再任意指定一個獨立濃度值。

因此：

- $a>0$ 時左端流入、右端流出。
- $a<0$ 時右端流入、左端流出。
- $a=0$ 時沒有由該速度造成的平流流入或流出。

這是連續方程的資訊方向，不只是數值格式的慣例。將流出端也強行指定濃度，可能使問題過度指定；在離散計算中，如何落實邊界還須配合所選格式。

### 守恆與上風離散

一維有限體積格網將 $c_i$ 視為第 $i$ 格的平均濃度。若每格寬度為 $\Delta x$，一格每單位厚度的質量是 $c_i\Delta x$。對守恆式在控制體積積分，得到

$$
\frac{d c_i}{dt}
=-\frac{F_{i+1/2}-F_{i-1/2}}{\Delta x},
$$

其中 $F$ 是穿過格面、沿 $+x$ 方向計算的濃度通量。對常速度 $a$，上風通量為

$$
F_{i+1/2}=
\begin{cases}
a c_i,&a\geq 0,\\
a c_{i+1},&a<0.
\end{cases}
$$

這一選擇是使用格面上游側的濃度。對均勻網格，令 $C=a\Delta t/\Delta x$ 為帶正負號的 Courant 數，一階顯式上風更新可寫成

$$
c_i^{n+1}=
\begin{cases}
c_i^n-C(c_i^n-c_{i-1}^n),&a\geq0,\\
c_i^n-C(c_{i+1}^n-c_i^n),&a<0.
\end{cases}
$$

它可以改寫成舊值的加權平均。當 $a>0$ 時，$c_i^{n+1}=(1-C)c_i^n+C c_{i-1}^n$；當 $a<0$ 時，$c_i^{n+1}=(1-|C|)c_i^n+|C|c_{i+1}^n$。若 $|C|\leq1$，兩個權重皆非負且總和為一，故此格式在這些假設下保持非負資料的非負性，且不超出鄰近舊值的範圍。

上風格式的穩定條件與上述凸組合條件一致，要求 $|a|\Delta t/\Delta x\leq1$。這是此格式與問題設定下的重要條件，不是所有平流格式都自動具備相同穩定範圍的保證。CFL 條件表達離散時間步必須容納資訊穿越格網的速度；符合 CFL 並不單獨保證任意格式穩定，更不保證高階解不振盪、物理模型正確或誤差很小。

對週期邊界，最右格右側接回最左格，格面通量在週期接點兩側相同；將所有格的更新相加時，通量逐面抵消，因此 $\sum_i c_i\Delta x$ 在精確算術下守恆。對非週期域，總質量的改變則由流入與流出邊界通量決定。若格網存放的是濃度而不是質量，檢查總量時不可省略 $\Delta x$；二維時須乘以格面積，若表示實際總質量還要乘以明示的厚度。

## 逐步手算例題

### 例一：特徵線平移與邊界角色

取區間 $0\leq x\leq10$ m，速度 $a=2$ m/s，初始濃度為

$$
c_0(x)=1+0.1x\quad\text{kg/m}^3.
$$

在 $t=1$ s、$x=6$ m，特徵線倒推的初始位置為

$$
x_0=x-at=6-(2)(1)=4\text{ m}.
$$

因此 $c(6,1)=c_0(4)=1.4$ kg/m$^3$。特徵線在一秒內向右行進 2 m，而濃度值保持不變。因 $a>0$，左端是流入端；要在特徵線由左端進入域內之後求解，必須提供左端流入資料。右端是流出端，不應再以任意獨立濃度覆寫由域內特徵線帶出的值。

現在令速度反向為 $a=-2$ m/s。同一位置同一時間的倒推位置是 $x_0=6-(-2)(1)=8$ m，故在尚未受到邊界影響時，$c(6,1)=c_0(8)=1.8$ kg/m$^3$。此時右端是流入端，左端為流出端。速度改號不只改變答案，也改變必須提供邊界資料的一側。

### 例二：一個上風更新與質量帳

令 $\Delta x=1$ m、$a=2$ m/s、$\Delta t=0.25$ s，則 $C=0.5$。考慮週期三格，初值

$$
(c_0,c_1,c_2)=(1,3,2)\quad\text{kg/m}^3.
$$

速度向右時，每格取本格與左鄰格：

$$
c_0^{1}=(1-0.5)(1)+0.5(2)=1.5,
$$

$$
c_1^{1}=(1-0.5)(3)+0.5(1)=2,
$$

$$
c_2^{1}=(1-0.5)(2)+0.5(3)=2.5.
$$

更新後總和為 $1.5+2+2.5=6$，等於更新前的 $1+3+2=6$。由於 $\Delta x=1$ m，每單位厚度總質量亦為 $6$ kg/m$^2$。這是離散守恆檢查，不表示波形毫無數值誤差：上風格式會使波形變平滑，尤其是陡峭跳躍處。

若改為 $a=-2$ m/s，同樣 $|C|=0.5$，每格改取本格與右鄰格。可見穩定步長應依速度大小決定，資料方向則依速度正負決定。

## 實作與程式

以下程式只依賴 Python 3.10+ 與 NumPy，在 CPU 上執行；採 cell-centered 格網與週期邊界。變數 `c[j]` 在此是一維索引，不含二維慣例的上下方向。程式拒絕非有限資料、非正格寬、負時間步長及超出上風 CFL 範圍的輸入，並使用 `np.roll` 取得週期鄰格。`np.roll` 只代表週期接鄰，不適用於非週期流入邊界。

```python
import numpy as np


def upwind_periodic_step(c, a, dx, dt):
    """一維常速度平流的一階週期上風更新；c 是每格平均濃度。"""
    c = np.asarray(c, dtype=float)
    if c.ndim != 1 or c.size < 2:
        raise ValueError("c 必須是一維且至少含兩格")
    if not np.all(np.isfinite(c)):
        raise ValueError("c 必須全部為有限值")
    if not np.isfinite(a) or not np.isfinite(dx) or not np.isfinite(dt):
        raise ValueError("a、dx、dt 必須為有限值")
    if dx <= 0 or dt < 0:
        raise ValueError("dx 必須大於零，dt 不得小於零")

    courant = abs(a) * dt / dx
    if courant > 1.0:
        raise ValueError("違反一階上風格式的 CFL 條件 |a|*dt/dx <= 1")

    if a > 0:
        upstream = np.roll(c, 1)
        return c - (a * dt / dx) * (c - upstream)
    if a < 0:
        upstream = np.roll(c, -1)
        return c - (a * dt / dx) * (upstream - c)
    return c.copy()


def advect_periodic(c, a, dx, dt, steps):
    """以固定步長作多步週期上風平流。"""
    c = np.asarray(c, dtype=float)
    if not isinstance(steps, int) or steps < 0:
        raise ValueError("steps 必須是非負整數")
    for _ in range(steps):
        c = upwind_periodic_step(c, a, dx, dt)
    return c


if __name__ == "__main__":
    # 合成濃度，單位 kg/m^3；週期區間長度為 1 m。
    nx = 64
    dx = 1.0 / nx
    x = (np.arange(nx) + 0.5) * dx
    c0 = 1.0 + 0.4 * np.sin(2.0 * np.pi * x)

    a = 0.5       # m/s
    dt = 0.5 * dx / abs(a)  # CFL = 0.5
    c1 = advect_periodic(c0, a, dx, dt, steps=10)

    mass0 = np.sum(c0) * dx
    mass1 = np.sum(c1) * dx
    print("CFL =", abs(a) * dt / dx)
    print("初末每單位厚度質量 =", mass0, mass1)
    print("最小濃度 =", np.min(c1))
```

最後三行預期會顯示 CFL 為 $0.5$，初末質量在浮點捨入誤差範圍內一致，最小濃度保持非負。程式不以裁零處理負值；若發現負值，應先查核輸入、時間步長、格式與邊界，而不是掩蓋症狀。

## 測試與預期結果

以下是測試設計及依公式推得的預期，不是已執行程式的紀錄。

1. **正常：零速度。** 以任意有限初值、$a=0$ 更新，輸出應逐格等於輸入；總量不變。
2. **正常：週期質量。** 用前述三格資料及 $C=0.5$，更新結果預期為 $(1.5,2,2.5)$，加權總量維持 $6$ kg/m$^2$。
3. **正常：反向平移。** 令 $a<0$，在 CFL 範圍內更新；預期使用右鄰格為上游，而不是左鄰格。
4. **邊界：一格週期值。** 本程式刻意要求至少兩格；只含一格時預期明確拒絕，避免把退化格網誤當一般平移測試。
5. **故障：超限時間步。** 令 $|a|\Delta t/\Delta x>1$，函式預期丟出 `ValueError`，不應靜默截短時間步長。
6. **故障：非有限輸入。** 濃度含 `NaN`、速度為無窮大或格寬為 `NaN`，預期拒絕。
7. **物理邊界測試：非週期流入。** 若採 $a>0$ 的非週期域，必須在左端提供流入濃度，右端依出流處理。將週期函式套用於非週期資料，會把右端資料錯誤繞回左端；應另寫通量與邊界閉合，不能把這個結果視為正確解。

離散總量守恆只檢查內部格面通量抵消，不能證明平移速度、初始場或邊界資料符合實際物理。觀測收斂階也需以解析解或製造解、空間與時間分開細化及網格加權範數驗證；僅看一張平滑圖不足以判斷正確性。

## 除錯與常見陷阱

**把速度方向寫反。** 若 $a>0$ 卻用右鄰格作上游，資訊來自下游。以單一局部峰值或前述非對稱三格值測試，較容易辨識索引方向錯誤。

**把絕對值 CFL 當成更新公式。** CFL 使用速度大小，但更新的帶符號差分仍須依速度正負改變。若只把 $|a|$ 填入公式，負速度也會向右搬運。

**流入與流出邊界都硬塞資料。** 邊界條件的數量和位置應依特徵方向決定。流入端必須有資料；出流端通常不能任意再指定濃度。若模型還含擴散，擴散項會引入額外邊界條件需求，不能只沿用純平流的判斷。

**把 CFL 視為充分穩定性定理。** CFL 條件反映資訊傳播限制，具體穩定範圍仍由格式、方程及邊界處理決定。對本章的一階顯式上風法，$|C|\leq1$ 有凸組合推導；不能把它直接套到任意高階或不同時間積分格式。

**混淆守恆、非負與低耗散。** 週期上風更新可以守恆，且在指定 CFL 下保持非負，但仍會把陡峭波形抹平。守恆不表示波形正確，非負不表示沒有數值耗散，而 CFL 合格也不表示模型已通過物理驗證。

**濃度總和與總質量混用。** 應計算 $\sum_i c_i\Delta x$，有不同格寬時則乘各格體積；不能因未加權濃度總和看似固定，就宣稱實際質量守恆。

## 養殖與相場案例

以下是合成的一維池域例子，不代表任何現場速度、物性或管理閾值。令沿池長方向為 $x$，$c$ 表示合成溶質濃度，單位 kg/m$^3$；給定合成速度 $a=0.02$ m/s，初始濃度為

$$
c(x,0)=0.50+0.10\sin\left(\frac{2\pi x}{L}\right)\quad\text{kg/m}^3.
$$

若只研究週期平移，可採週期域並以 $c(x,t)=c(x-at,0)$ 作解析核對。週期假設表示池域首尾相接，是方便驗證的合成條件，不是對實際池體邊界的描述。若研究有入口與出口的水道，則速度向右時要提供入口流入濃度，出口依出流通量記帳；若方向改為向左，角色交換。

在更完整的溶質模型中，可以加入擴散、反應或外部來源，例如 $c_t+(ac)_x=(D c_x)_x+R(c)+S$。此時 $D$ 的單位是 m$^2$/s，若 $R$ 與 $S$ 表示濃度變化率，其單位皆為 kg/(m$^3$ s)。平流方向、擴散邊界條件與反應來源必須各自交代；不得僅因某個管理指標跨越指定數值，就把它解釋成熱力學相變。

相場的序參量若由流動搬運，常見形式可含平流項，例如 $\phi_t+\mathbf{u}\cdot\nabla\phi=-M\mu$。這不表示單純平流會造成相變：右側的化學勢演化才代表本模型選定的相場動力學。相場方程與本章的線性平流方程是不同機制，耦合時必須說明邊界、尺度與參數，不能把濃度管理閾值當作序參量或相界。

## 習題

### 題一：特徵線手算

在無限直線上，速度為 $a=-3$ m/s，初始資料為 $c_0(x)=2+0.5x$ kg/m$^3$。求 $t=2$ s、$x=1$ m 的濃度，並指出有限區間 $0\leq x\leq5$ m 的流入端。

### 題二：上風更新與守恆

一維週期四格，$\Delta x=0.5$ m，$a=1$ m/s，$\Delta t=0.25$ s。初值為 $(2,0,0,0)$ kg/m$^3$。計算一步一階上風結果，並驗算每單位厚度總質量。

### 題三：程式修改與故障測試

解釋本章 `upwind_periodic_step` 為何不適用於非週期入口資料。列出 $a>0$ 時一個合適的簡化邊界設定方式，並說明為何不能只把週期索引改成固定端點而不檢查格面通量。

### 題四：整合判斷

某人使用一階上風法，發現總質量守恆、濃度非負，且 Courant 數為 $0.8$。他據此宣稱波形正確、數值解穩定且模型符合實際池域。指出至少三項推論問題，並提出一套可稽核的驗證計畫。

## 習題解答

### 題一解答

沿特徵線倒推：

$$
x_0=x-at=1-(-3)(2)=7\text{ m}.
$$

因此無限直線上的解為 $c(1,2)=c_0(7)=2+0.5(7)=5.5$ kg/m$^3$。在有限區間中，$a<0$ 代表資訊向左移，右端 $x=5$ m 是流入端，左端是流出端。求有限域中的值時，還必須提供右端流入資料；若沒有該資料，只能在特徵尚未碰到邊界的區域使用初值決定解。

### 題二解答

Courant 數為 $C=a\Delta t/\Delta x=(1)(0.25)/(0.5)=0.5$。正速度取左鄰為上游。週期索引下：

- 第 0 格左鄰是第 3 格，故 $c_0^1=(1-0.5)2+0.5(0)=1$。
- 第 1 格左鄰是第 0 格，故 $c_1^1=(1-0.5)0+0.5(2)=1$。
- 第 2 格與第 3 格皆為零，更新仍為零。

更新結果為 $(1,1,0,0)$ kg/m$^3$。更新前每單位厚度質量為 $(2)(0.5)=1$ kg/m$^2$；更新後為 $(1+1)(0.5)=1$ kg/m$^2$。數值把原本集中於一格的脈衝分散到上游及本格，守恆並未消除數值擴散。

### 題三解答

`np.roll` 把陣列末格接到首格，是週期條件的明確實作；非週期入口不能把出口濃度繞回入口。對 $a>0$，可在左端設定給定流入濃度 $c_{\rm in}(t)$，並對內部格面使用左側上游值；右端流出則由域內資料形成出口通量。若以有限體積更新，須在最左格的左邊界面指定 $F_{1/2}=a c_{\rm in}$，右側內部面則依上風值計算。

只把端點索引改成自身，會改變邊界通量而不必然符合指定的流入值，也可能讓邊界格的質量更新與應有的進出量不符。正確作法是明列邊界面通量、控制體體積與資料所代表的量，再核對總質量變化是否等於入口減出口通量。

### 題四解答

第一，質量守恆在週期域主要反映共享格面通量抵消，不能證明平移速度、波形或實際邊界正確。第二，非負性只限制數值值域，不表示波形無擴散，也不表示解析誤差小。第三，$C=0.8$ 對本章的一階顯式上風格式符合 $|C|\leq1$，但不能推廣成所有格式的充分穩定性結論。第四，模型符合實際池域還須驗證幾何、速度、來源、邊界與資料假設；合成或離散性質不能替代現場驗證。

可稽核計畫是：先以常速度週期問題與平移解析解比較；使用格網加權範數記錄誤差；固定空間格網細化時間步長，再固定足夠小時間誤差細化空間格網；對正負速度分別核對平移方向；另以非週期入口問題測試流入資料與出口通量；逐步記錄質量收支、最小值、最大值、CFL、網格尺寸及邊界條件。若進一步比對實際資料，須另列校準資料與獨立驗證資料，不能以同一組資料同時調參又宣稱已驗證。

## 本章小結

線性平流沿特徵線搬運資訊，特徵速度是 $a$；流入與流出邊界由速度相對外法向的方向決定。上風法依速度正負選取上游值，對本章的一階顯式格式，$|a|\Delta t/\Delta x\leq1$ 使更新成為舊值的凸組合，並在相應假設下支持穩定性與非負性分析。週期有限體積通量可逐面抵消而守恆，但守恆、正性、波形精度、穩定性與物理可信度必須分開核對。非週期流入資料不可用週期繞接代替。
