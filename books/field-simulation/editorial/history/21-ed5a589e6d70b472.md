# 第21章 溫度與溶氧的合成傳輸模型

## 學習目標與先備知識

本章是第四部「流體、多物理場與不確定性」中的一章，處理養殖系統裡兩個最常被關心的純量場：水溫 $T(\mathbf{x},t)$ 與溶氧濃度 $c(\mathbf{x},t)$。讀完本章後期望能做到以下幾件事。第一，能把熱收支與溶質收支分別寫成平流—擴散—反應形式，並逐項標示 SI 單位。第二，能辨識兩種簡化反應模型（一階消耗與零階消耗、表面復氧與體積復氧）各自適用的情境與單位要求。第三，能以合成係數建立小型溫度與溶氧模型，並對收支、單位、非負性分別測試。第四，能分辨「不提供現場閾值」與「模型可用」之間的差異：本章給出的是合成係數下的數值行為，不是養殖操作建議。第五，能分辨參數可辨識與不可辨識的邊界，知道在什麼條件下一組合成實驗無法同時反推多個係數。

先備知識：第 01 章的場與 SI 單位、第 03 章散度定理與通量、第 04 章擴散與反應、第 05 章平流與資訊傳播、第 09 章有限體積守恆通量、第 10 章高解析平流。讀者應已熟悉 NumPy 二維陣列與 `q[j,i]` 索引約定。本章的所有資料均為合成，不連真實設備，不代表任何養殖場池的物性。

## 問題與直覺

養殖水體裡的溫度與溶氧並非空間均勻。白天表層受日照加熱，底層水溫可能低數度；夜間表層散熱，形成反向分層。溶氧則由水面復氧、藻類光合作用產生，同時被魚類呼吸、底泥耗氧與有機物分解消耗。如果忽略空間變化，只用一個「平均溶氧」描述整個池子，那麼在分層期間就會誤判魚類實際所處水層的溶氧狀態。因此需要在空間上求解。

在方程式層級，溫度和溶氧的演化都可以寫成同一類守恆律：一個純量隨給定流速被攜帶、因擴散而平滑、並因來源／匯項而增減。不同的是它們的係數與反應項形式。溫度通常用熱擴散率 $\alpha$（單位 m$^2$/s，約 $1.4\times 10^{-7}$ m$^2$/s 在 293 K 清水），溶氧的分子擴散係數 $D$ 約在 $10^{-9}$ 至 $2\times 10^{-9}$ m$^2$/s 之間；但實際水體中渦流混合遠大於分子擴散，因此模型中的 $D$ 往往是等效渦流擴散係數，可能達 $10^{-4}$ 至 $10^{-2}$ m$^2$/s。這是模型選擇，不是物理常數。

反應項需要特別處理單位。溶氧的一階消耗 $-k_d c$ 中，若 $c$ 的單位是 kg/m$^3$，則 $k_d$ 的單位必須是 1/s，才能讓 $k_d c$ 的單位與 $\partial_t c$ 一致。表面復氧項 $k_a(c_{\text{sat}}-c)$ 同樣需要 $k_a$ 以 1/s 計，並以 $c_{\text{sat}}$ 為該溫度與鹽度下的飽和濃度——本章中 $c_{\text{sat}}$ 僅為合成常數，不作為實際操作參考。溫度方程的來源 $Q/(\rho c_p)$ 中，$Q$ 是單位體積熱源（W/m$^3$），$\rho c_p$ 是體積熱容（J/(m$^3\cdot$K)），比值單位為 K/s，與 $\partial_t T$ 一致。

一個重要的直覺是時間尺度比較。若池深 $L=2$ m、$D=10^{-6}$ m$^2$/s，垂直擴散時間尺度 $L^2/D = 4\times 10^6$ s，約 46 天，也就是說單靠分子擴散幾乎沒有混合。若 $D=10^{-4}$ m$^2$/s，尺度約 $4\times 10^4$ s，約 11 小時，一個日循環內可以讓表層與底層有相當交換。復氧時間尺度 $1/k_a$ 若 $k_a=10^{-5}$ s$^{-1}$（約 0.036 h$^{-1}$），則尺度約 28 小時；$k_a=10^{-4}$ s$^{-1}$ 則尺度約 2.8 小時。這些比較驅動我們選擇時間步與網格，也決定模型是否需要顯示三維結構，或可以用一維垂直模型。

## 數學與物理推導

### 溫度方程

設給定流速 $\mathbf{u}(\mathbf{x},t)$（單位 m/s），水溫 $T$（單位 K 或明示攝氏溫差），熱擴散率 $\alpha>0$（m$^2$/s），體積熱源 $Q$（W/m$^3$），水密度 $\rho$（kg/m$^3$）與比熱 $c_p$（J/(kg·K)）。守恆律為
$$ \frac{\partial T}{\partial t} + \nabla\cdot(\mathbf{u}T) = \nabla\cdot(\alpha\nabla T) + \frac{Q}{\rho c_p}. $$
若流速無散度（不可壓流體），$\nabla\cdot\mathbf{u}=0$，則 $\nabla\cdot(\mathbf{u}T)=\mathbf{u}\cdot\nabla T$，化為平流形式：
$$ \frac{\partial T}{\partial t} + \mathbf{u}\cdot\nabla T = \nabla\cdot(\alpha\nabla T) + \frac{Q}{\rho c_p}. $$
來源項單位檢查：$[Q/(\rho c_p)] = \text{W/m}^3 \cdot \text{m}^3/(\text{kg}\cdot\text{J}/(\text{kg}\cdot\text{K}))$，即 $\text{W}/(\text{J}/\text{K}) = \text{K/s}$，與 $\partial_t T$ 一致。

若 $\alpha$ 為常數且流場為零，方程退化為熱傳方程 $\partial_t T = \alpha\nabla^2 T + Q/(\rho c_p)$。若再有穩態與無來源，則 $\nabla^2 T=0$，是 Laplace 方程，由邊界條件完全決定，這與第 13 章 Poisson 問題同構。

### 溶氧方程

溶氧由平流、擴散、消耗與復氧共同決定。寫成
$$ \frac{\partial c}{\partial t} + \nabla\cdot(\mathbf{u}c) = \nabla\cdot(D\nabla c) - R(c) + k_a(c_{\text{sat}} - c), $$
其中 $c$ 單位 kg/m$^3$；$D$ 為等效擴散係數（m$^2$/s）；$R(c)$ 為消耗率（kg/(m$^3\cdot$s)）；$k_a$ 為復氧速率（1/s）；$c_{\text{sat}}$ 為飽和濃度（kg/m$^3$，合成常數）。$R(c)$ 形式依情境：

第一，零階消耗 $R=R_0$，單位 kg/(m$^3\cdot$s)。常用於底泥耗氧或高濃度下呼吸不受濃度限制的情況。第二，一階消耗 $R=k_d c$，$k_d$ 單位 1/s，常用於稀釋情境或生物量固定的水體。第三，Michaelis–Menten $R=R_{\max}c/(c+K_m)$，$R_{\max}$ 單位 kg/(m$^3\cdot$s)，$K_m$ 單位 kg/m$^3$。本章主要在合成實驗中採用前兩種，第三種留給習題。

若 $\nabla\cdot\mathbf{u}=0$，$\nabla\cdot(\mathbf{u}c)=\mathbf{u}\cdot\nabla c$。若 $D$ 為常數，$\nabla\cdot(D\nabla c)=D\nabla^2 c$。此時加入一階消耗與復氧：
$$ \frac{\partial c}{\partial t} + \mathbf{u}\cdot\nabla c = D\nabla^2 c - k_d c + k_a(c_{\text{sat}} - c). $$
合併反應項：$-(k_d + k_a)c + k_a c_{\text{sat}}$。若無平流與擴散，則穩態為 $c_\infty = k_a c_{\text{sat}}/(k_d + k_a)$。這是一個重要的合成結果：在純反應系統中，穩態濃度由消耗與復氧的比值決定，不依賴初始條件。它也可以用來檢驗實作的零維極限：若把域做得極小且強制均勻，數值穩態應與解析穩態相符。

### 無因次化

取參考長度 $L$、參考速度 $U$、參考濃度 $C_0$、參考時間 $T_{\text{ref}} = L/U$。溫度方程中的熱 Peclet 數 $\mathrm{Pe}_T = UL/\alpha$ 比較平流與熱擴散。溶氧的 $\mathrm{Pe}_c = UL/D$ 比較平流與溶質擴散。Damköhler 數 $\mathrm{Da}_d = k_d L/U$ 比較反應與平流時間尺度；$\mathrm{Da}_a = k_a L/U$ 比較復氧與平流。無因次方程為
$$ \frac{\partial c^*}{\partial t^*} + \mathbf{u}^*\cdot\nabla^* c^* = \frac{1}{\mathrm{Pe}_c}\nabla^{*2}c^* - \mathrm{Da}_d\, c^* + \mathrm{Da}_a(c^*_{\text{sat}} - c^*). $$
這些組合是比較不同情境的關鍵，也決定數值方法是否會受限於平流、擴散或反應。

當流速趨於零（$U\to 0$）時，原參考時間 $T_{\text{ref}}=L/U$ 不再適用。此時應改以擴散尺度為主：取 $T_{\text{ref}}=L^2/D$，並以 $\mathbf{u}=U\mathbf{u}^*$ 定義無因次速度。因為平流項與擴散項的尺度比為 $UL/D=\mathrm{Pe}_c$，無因次方程變為
$$ \frac{\partial c^*}{\partial t^*} + \mathrm{Pe}_c\,\mathbf{u}^*\cdot\nabla^* c^* = \nabla^{*2} c^* - \mathrm{Da}_d^{(\text{diff})} c^* + \mathrm{Da}_a^{(\text{diff})}(c^*_{\text{sat}} - c^*). $$
其中 $\mathrm{Da}_d^{(\text{diff})}=k_dL^2/D$、$\mathrm{Da}_a^{(\text{diff})}=k_aL^2/D$ 是相對於擴散時間尺度的 Damköhler 數。若嚴格取 $U=0$，則平流項直接消失，不必再定義 $\mathbf{u}^*$；若 $U$ 只是很小但非零，則 $\mathrm{Pe}_c\ll1$ 表示平流相對擴散較弱。這個形式在弱平流的池底耗氧或實驗室擴散槽中更自然，也說明同一組物理係數在不同流況下需要用不同的無因次組合描述，否則比較會失真。

若 $\mathrm{Pe}\gg 1$ 而擴散主導的網格尺度小於平流，顯式方法的時間步會被擴散條件限制；若反應時間尺度 $\ll L/U$，則反應剛性需要隱式處理。這些在第 09 至 12 章已討論，本章沿用其判準。

### 邊界條件

溫度與溶氧的邊界條件依物理情境。令 $\partial_n$ 沿水域的單位外法向，向外通量取正。水面熱交換常用 Robin 條件：$-k_{\text{th}}\partial_n T=h_{\text{th}}(T-T_{\text{air}})$，其中 $k_{\text{th}}$ 為熱傳導率（W/(m·K)），$h_{\text{th}}$ 為熱交換係數（W/(m$^2\cdot$K)）；水比空氣熱時，右端為正，表示熱向外流。水面復氧可寫為 $-D\partial_n c=h_m(c-c_{\text{sat}})$，$h_m$ 單位 m/s；水中濃度較低時，外向溶質通量為負，表示氧進入水域。池底若為不透水且無通量則用 Neumann 零通量。固體壁面通常也是零通量。若採用 Dirichlet 條件（例如邊界處濃度固定），需檢查與來源項及穩態的相容性。純 Neumann 條件下，穩態須滿足來源體積積分與邊界通量的收支相容條件；若全部邊界通量為零而淨來源不為零，則不存在穩態。Robin 條件的離散需注意半格邊界位置：水面通常位於 cell 面而非 cell 中心，因此邊界通量是面通量，與 cell 體積的通量散度要正確對齊。

## 逐步手算例題

### 例題 1：零維純反應穩態與時間演化

忽略平流與擴散，考慮 $c(0)=C_0=8\times 10^{-3}$ kg/m$^3$（等同 8 mg/L，換算：$1\,\text{mg/L}=10^{-3}\,\text{kg/m}^3$），$k_d = 2\times 10^{-5}$ s$^{-1}$，$k_a = 3\times 10^{-5}$ s$^{-1}$，$c_{\text{sat}} = 9\times 10^{-3}$ kg/m$^3$。求穩態濃度與時間常數。

解：合併反應率係數 $k_{\text{tot}} = k_d + k_a = 5\times 10^{-5}$ s$^{-1}$，穩態 $c_\infty = k_a c_{\text{sat}}/k_{\text{tot}} = (3\times 10^{-5}\cdot 9\times 10^{-3})/(5\times 10^{-5}) = 0.6\cdot 9\times 10^{-3} = 5.4\times 10^{-3}$ kg/m$^3$（5.4 mg/L）。時間常數 $\tau = 1/k_{\text{tot}} = 2\times 10^4$ s，約 5.56 小時。初始與穩態差 $C_0 - c_\infty = 2.6\times 10^{-3}$ kg/m$^3$。解析解 $c(t) = c_\infty + (C_0 - c_\infty)e^{-t/\tau}$。在 $t = \tau$ 時，$c(\tau) = c_\infty + (C_0 - c_\infty)/e \approx 5.4\times 10^{-3} + 0.957\times 10^{-3} \approx 6.357\times 10^{-3}$ kg/m$^3$（約 6.36 mg/L），仍未低於穩態，符合單調趨近。

### 例題 2：一維穩態平流的溶氧剖面

考慮一維渠道，$x\in[0,L]$、$L=100$ m，均勻流速 $u=0.02$ m/s 沿正 $x$，$D=0$（忽略軸向擴散），$k_d = 2\times 10^{-5}$ s$^{-1}$，$k_a = 10^{-5}$ s$^{-1}$，$c_{\text{sat}} = 9\times 10^{-3}$ kg/m$^3$，入口 $c(0)=7\times 10^{-3}$ kg/m$^3$。求穩態 $c(x)$。

解：穩態下 $u\,dc/dx = -(k_d + k_a)c + k_a c_{\text{sat}}$。令 $\lambda = (k_d+k_a)/u = 3\times 10^{-5}/0.02 = 1.5\times 10^{-3}$ m$^{-1}$，$c_\infty = k_a c_{\text{sat}}/(k_d+k_a) = 0.333\cdot 9\times 10^{-3} = 3\times 10^{-3}$ kg/m$^3$。解為 $c(x) = c_\infty + (c(0)-c_\infty)e^{-\lambda x}$。當 $x=100$ m，$\lambda L = 0.15$，$e^{-0.15}\approx 0.861$，故 $c(100) = 3\times 10^{-3} + (7-3)\times 10^{-3}\cdot 0.861 \approx 6.44\times 10^{-3}$ kg/m$^3$。若要在 100 m 內顯著趨近穩態（例如剩餘偏差小於 10\% 初始偏差），需 $\lambda L \ge 2.3$，即 $L\ge 1.53$ km，遠超本例。這說明短渠道內軸向平流的資訊傳播對反應項的影響很小時，不能忽略下游濃度的變化。

### 例題 3：二維量綱檢查

若採二維垂直剖面模型，$x$ 水平、$y$ 垂直，池長 $L_x=4$ m、池深 $L_y=2$ m，$N_x=41$、$N_y=21$，$\Delta x=\Delta y\approx 0.1$ m。等效渦流擴散 $D=10^{-4}$ m$^2$/s，顯式 FTCS 二維穩定條件 $D\Delta t(1/\Delta x^2 + 1/\Delta y^2)\le 1/2$，代入得 $\Delta t \le 0.5/(10^{-4}\cdot 200) = 25$ s。這是必須遵守的穩定限制，與時間尺度無關。若要模擬一天（86400 s），需約 3456 步；若要模擬一週，需約 24200 步。若改用隱式時間格式則可放寬 $\Delta t$，但每個時間步要解線性系統。

## 實作與程式

以下程式建立合成溫度與溶氧模型的最小二維步進器，使用顯式 FTCS，並逐步檢查收支與非負性。此程式只依賴 NumPy 與標準庫；未執行前不宣稱結果，輸出均為依推導的預期。

```python
import numpy as np

def make_grid(Nx, Ny, Lx, Ly):
    if not isinstance(Nx, int) or not isinstance(Ny, int):
        raise ValueError("Nx, Ny 必須為整數")
    if Nx < 2 or Ny < 2:
        raise ValueError("Nx, Ny 至少為 2")
    if not (np.isfinite(Lx) and np.isfinite(Ly) and Lx > 0 and Ly > 0):
        raise ValueError("Lx, Ly 必須為正有限值")
    dx, dy = Lx / Nx, Ly / Ny
    # cell 中心：x = (i+1/2)dx, y = (j+1/2)dy
    xc = (np.arange(Nx) + 0.5) * dx
    yc = (np.arange(Ny) + 0.5) * dy
    return dx, dy, xc, yc

def laplacian_2d(q, dx, dy):
    # 零通量 Neumann：ghost 值等於邊界值，等效於以邊界值延伸
    qx = np.pad(q, 1, mode='edge')
    lap = (qx[1:-1, 2:] - 2.0*qx[1:-1, 1:-1] + qx[1:-1, :-2]) / dx**2
    lap += (qx[2:, 1:-1] - 2.0*qx[1:-1, 1:-1] + qx[:-2, 1:-1]) / dy**2
    return lap

def step_reaction_diffusion(T, c, dx, dy, alpha, D, dt,
                            Q_over_rhocp, kd, ka, c_sat):
    # 邊界條件：零通量 Neumann（以 edge padding 表示）
    lap_T = laplacian_2d(T, dx, dy)
    lap_c = laplacian_2d(c, dx, dy)
    T_new = T + dt * (alpha * lap_T + Q_over_rhocp)
    c_new = c + dt * (D * lap_c - kd * c + ka * (c_sat - c))
    return T_new, c_new

def stability_limit_2d(coef, dx, dy):
    # 顯式 FTCS 二維穩定條件：coef * dt * (1/dx^2 + 1/dy^2) <= 1/2
    return 0.5 / (coef * (1.0/dx**2 + 1.0/dy**2))

def total_mass_2d(c, dx, dy):
    # cell 平均乘體積；二維每單位厚度，故單位為 kg/m (per unit thickness)
    return float(np.sum(c) * dx * dy)

def check_nonnegative(c, tol=0.0):
    return bool(np.all(c >= -tol))
```

預期輸出（未執行）：以 $N_x=41$、$N_y=21$、$L_x=4$、$L_y=2$、$D=10^{-4}$、$k_d=2\times 10^{-5}$、$k_a=10^{-5}$、$c_{\text{sat}}=9\times 10^{-3}$、初始 $c=7\times 10^{-3}$、$\Delta t=10$ s 呼叫 `stability_limit_2d(D, dx, dy)` 應得約 25 s，故 $\Delta t=10$ s 穩定；執行 100 步後 `total_mass_2d` 應小於初始總量（因淨消耗 $k_d c - k_a(c_{\text{sat}}-c)$ 為淨匯），且 `check_nonnegative` 應回傳 `True`。

若要在其他章節重用此模組，請明確匯入；本章未使用 SciPy。

## 測試與預期結果

正常測試：(1) 以 `Nx=Ny=32`、`Lx=Ly=1.0` 建立網格，`xc[0]=0.5/32`、`xc[-1]=1.0-0.5/32`；(2) 對常數場 $T\equiv 293.15$ K，`laplacian_2d` 應回傳全零（至浮點）；(3) 對零維極限（$N_x=N_y=2$ 且無擴散），比較 100 步結果與解析 $c(t)=c_\infty+(c_0-c_\infty)e^{-k_{\text{tot}}t}$，誤差應隨 $\Delta t$ 縮小而下降；(4) 邊界零通量下 `total_mass_2d` 的變化應完全由反應項貢獻，數值上與 $\sum\Delta t\cdot(-k_d c + k_a(c_{\text{sat}}-c))dx\,dy$ 一致到二階時間誤差。

邊界測試：(1) $N_x=N_y=2$ 應被 `make_grid` 接受；程式的零通量邊界差分仍有定義，但格網過粗，不宜用來宣稱二階收斂；(2) `laplacian_2d` 對 `np.pad` 採 `'edge'`，驗證邊界 cells 的單側差分符號與零通量一致；(3) 初始 $c$ 為零，`check_nonnegative` 應通過，且復氧項應使 $c$ 隨時間單調增加至 $c_\infty$。

故障測試：(1) `make_grid` 傳入 `Nx=32.0` 應由型別檢查拒絕；(2) `Lx=-1` 應拒絕；(3) 若 $\Delta t$ 超過 `stability_limit_2d` 且使用 `step_reaction_diffusion`，預期會出現非物理負值或振盪，`check_nonnegative` 應回傳 `False`；這正是「事後裁零」不被允許的情境，必須改 $\Delta t$ 或改用隱式格式，而非 `np.maximum(c, 0)`；(4) `c_sat` 為負值時穩態為負，屬於模型設定錯誤，應在 `make_config` 層面拒絕。

穩定性、守恆、能量下降、非負與物理可信必須分開陳述。顯式 FTCS 在 $\Delta t$ 滿足條件時穩定，且有反應項的一階消耗—復氧使解非負（在充分小的 $\Delta t$ 下），但質量不守恆——這正是本章模型的一部分。能量下降屬於擴散算子的散逸性質，與能量泛函的嚴格定義不同；本章不宣稱能量泛函單調。物理可信需要獨立資料驗證，本章僅處理合成係數的模型內部自洽性。

## 除錯與常見陷阱

第一個陷阱是把 mg/L 與 kg/m$^3$ 混用。同一個模型的兩段程式若分別輸入 $c_{\text{sat}}=9$ 與 $c_{\text{sat}}=9\times 10^{-3}$，結果會相差一千倍，且不會有任何警告。務必在 `make_config` 中明示單位欄位。第二個陷阱是把分子擴散與渦流擴散混為一談。水的溶氧分子擴散為 $10^{-9}$ 量級，混入 $10^{-4}$ 等效值雖常用於工程近似，但若誤當分子擴散並宣稱「水體太厚無法在一日內均勻混合」就會誤導。第三個陷阱是把零階消耗與一階消耗混用。$R=R_0$ 在低濃度下會把 $c$ 推到負值；物理上應該改為一階或 Michaelis–Menten，或加正性修正，但修正須重新設計模型並記錄。第四個陷阱是忽略飽和濃度的溫度依賴。實際 $c_{\text{sat}}$ 隨水溫升高而降低，若在水溫一天變化 5 K 的模擬中把 $c_{\text{sat}}$ 固定，會引入模型誤差。第五個陷阱是把 $\Delta t$ 取到接近穩定上限且以為只要圖形平滑就正確。第六個陷阱是為了讓結果好看而用 `np.clip(c, 0, None)`，這在沒有記錄質量改變時屬於掩蓋不穩定。

第七個陷阱是 Damköhler 數與時間步的不匹配。若 $k_d\Delta t \gg 1$，顯式一階消耗會讓 $c$ 在一步內跳過穩態甚至變號。這與擴散穩定條件不同，需要對反應項也要求 $\max(k_{\text{tot}})\Delta t \lesssim 0.1$ 以求精確，或改用隱式／指數積分。第八個陷阱是誤以為 $\nabla\cdot\mathbf{u}=0$ 自動成立。若速度場來自離散投影或外部資料，離散散度可能不嚴格為零，這會引入 spurious source。必須在離散層檢查 $\sum_{\text{faces}}\mathbf{u}\cdot\mathbf{n}\,A$。

第九個陷阱是把熱擴散率當作常數而忽略溫度依賴。$\alpha$ 隨溫度在 273 K 至 313 K 之間變化約 30\%；若模擬跨越數十 K，把 $\alpha$ 固定是模型誤差而非離散誤差。第十個陷阱是忘記殘差與誤差的區別。在某些穩態求解中，殘差可以很小但解誤差仍大，因為系統的條件數很高；迭代停止必須以真殘差 $r=b-Ax$ 搭配明確的 atol/rtol，而不是以相鄰兩次迭代的差為唯一準則。

## 養殖與相場案例

本節所有數據均為合成，不提供現場操作閾值，也不連真實設備。考慮一個合成二維池剖面：$L_x=10$ m、$L_y=3$ m，$N_x=101$、$N_y=31$，$\Delta x=\Delta y\approx0.1$ m。給定一個合成環流場 $\mathbf{u}=(u_x,u_y)$，其離散散度檢查在小於 $10^{-12}$ 的容差內為零（由 MAC 投影得到，細節見第 20 章）。水溫合成初始 $T_0=298.15$ K；底面 $T_b=296.15$ K，水面熱交換係數合成 $h_{\text{th}}=5$ W/(m$^2\cdot$K)，氣溫合成 $T_{\text{air}}=294.15$ K。溶氧合成初始 $c_0=6\times 10^{-3}$ kg/m$^3$（6 mg/L），底泥耗氧以等效體積一階 $k_d=5\times 10^{-6}$ s$^{-1}$ 近似，水面復氧合成 $k_a=2\times 10^{-5}$ s$^{-1}$，$c_{\text{sat}}=9\times 10^{-3}$ kg/m$^3$。

在這組合成係數下，$1/k_a=5\times 10^4$ s ≈ 13.9 小時，意味著表層復氧時間尺度約半天；$1/k_d=2\times 10^5$ s ≈ 55 小時，底層消耗時間尺度約兩天。二者的競爭會使穩態在 $k_a c_{\text{sat}}/(k_d+k_a) \approx 7.2\times 10^{-3}$ kg/m$^3$ 附近，但這個數字只是合成係數下的穩態，絕不能作為真實池子的操作或預警閾值。若把 $k_a$ 減小十倍，穩態降至 $k_a c_{\text{sat}}/(k_d+k_a)$ 給出的 $\approx 2.5\times 10^{-3}$ kg/m$^3$，說明模型對 $k_a$ 高度敏感。

進一步做敏感度分析。零維穩態 $c_\infty = k_a c_{\text{sat}}/(k_d+k_a)$ 對 $k_a$ 的相對敏感度為
$$ \frac{\partial \ln c_\infty}{\partial \ln k_a} = \frac{k_d}{k_d+k_a}, $$
對 $k_d$ 的相對敏感度為
$$ \frac{\partial \ln c_\infty}{\partial \ln k_d} = -\frac{k_d}{k_d+k_a}. $$
兩個相對敏感度大小相同、符號相反；絕對值總和為 $2k_d/(k_d+k_a)$，並非恆等於一。本案例 $k_d=5\times10^{-6}$、$k_a=2\times10^{-5}\,\mathrm{s^{-1}}$，兩者分別為 $0.2$ 與 $-0.2$，絕對值總和為 $0.4$。當 $k_d\ll k_a$ 時，$c_\infty$ 接近 $c_{\text{sat}}$，對兩個速率的相對敏感度都趨近零；當 $k_d\gg k_a$ 時，兩者的相對敏感度分別趨近 $1$ 與 $-1$。這也提示參數可辨識性：若合成實驗只量測穩態，不可能同時可靠地反推 $k_a$ 與 $k_d$，因為觀測到的穩態只給出比值 $k_a/(k_d+k_a)$ 的一個函數。要打破這個退化，須取得能提供速率尺度的額外資訊，例如已知 $c_{\text{sat}}$ 時，擾動後回到穩態的時間常數；單純改變已知的 $c_{\text{sat}}$ 並再量穩態，仍只給出同一速率比值。

同樣討論也適用於擴散係數。若觀測只有穩態，且邊界條件與來源給定，則 $D$ 只影響空間分布的形狀尺度，與反應項一起決定一組無因次的 Damköhler 數 $k_d L^2/D$ 與 $k_a L^2/D$，單一穩態剖面無法同時分離這兩個。這引出可辨識性問題：需多點或多時刻資料，或加入獨立約束。合成實驗時，真值僅作為測試用途，用來檢查反推方法是否在理想條件下能達到預期精度，不能宣稱「校準成功即驗證通過」；校準屬於 verification/validation 中的前者，需要獨立資料才能宣稱物理可信。

相場角度看，溶氧跨管理閾值不是相變。水溫若接近冰點或密度極大值附近雖有「異常」行為，但那屬於水的狀態方程，不是相場雙井結構。若引入冰—水相變，須另列 Stefan 條件與潛熱，第 29 章處理。本章不涉及相場動力學。

## 習題

**習題 1（手算）**：合成零維系統 $C_0=7\times 10^{-3}$ kg/m$^3$，$k_d=1.5\times 10^{-5}$ s$^{-1}$，$k_a=2.5\times 10^{-5}$ s$^{-1}$，$c_{\text{sat}}=8.5\times 10^{-3}$ kg/m$^3$。求穩態與時間常數，並算 $t=3\tau$ 時的 $c(t)$ 至三位有效數字。

**習題 2（程式）**：修改 `step_reaction_diffusion`，使反應項使用隱式後向 Euler 而擴散仍用顯式。寫出更新後的 $c^{n+1} = (c^n + \Delta t\,k_a c_{\text{sat}} + \Delta t\,D\nabla^2 c^n)/(1+\Delta t(k_d+k_a))$，並驗證在 $k_d\Delta t\gg 1$ 時解仍非負且有界。

**習題 3（反例）**：某合成模型將 $k_d$ 設為零、$D=0$、零通量 Neumann，且初始 $c=0$、$c_{\text{sat}}=9\times 10^{-3}$ kg/m$^3$。說明此設定下長期解的物理意義，並指出「穩態是 $c=c_{\text{sat}}$」這句話在什麼條件下成立；若把 $k_d$ 改為一階正消耗，穩態有何變化。

**習題 4（整合）**：在二維零通量域 $L_x=1$ m、$L_y=1$ m、$N_x=N_y=21$、$D=10^{-4}$ m$^2$/s、$k_d=10^{-5}$ s$^{-1}$、$k_a=2\times10^{-5}$ s$^{-1}$、$c_{\text{sat}}=9\times10^{-3}$ kg/m$^3$、$c_0=5\times 10^{-3}$ kg/m$^3$ 均勻，$u=0$ 下，計算顯式 FTCS 的 $\Delta t$ 上限，並估算到 $t=1000$ s 需要多少步；同時論證質量在此設定下不守恆，並給出質量隨時間的預期增減方向。另求穩態對 $k_a$ 的相對敏感度與對 $k_d$ 的相對敏感度。

## 習題解答

**解答 1**：$k_{\text{tot}}=k_d+k_a=4\times 10^{-5}$ s$^{-1}$，$\tau=2.5\times 10^4$ s。$c_\infty = k_a c_{\text{sat}}/k_{\text{tot}} = (2.5\times 10^{-5}\cdot 8.5\times 10^{-3})/(4\times 10^{-5})=0.625\cdot 8.5\times 10^{-3}=5.3125\times 10^{-3}$ kg/m$^3$（約 5.31 mg/L）。在 $t=3\tau$，$e^{-3}\approx 0.0498$，$c(3\tau)=5.3125\times 10^{-3}+(7-5.3125)\times 10^{-3}\cdot 0.0498\approx 5.3125\times 10^{-3}+0.0841\times 10^{-3}\approx 5.397\times 10^{-3}$ kg/m$^3$。

**解答 2**：更新式
```python
def step_imex(T, c, dx, dy, alpha, D, dt, Q_over_rhocp, kd, ka, c_sat):
    lap_T = laplacian_2d(T, dx, dy)
    lap_c = laplacian_2d(c, dx, dy)
    T_new = T + dt * (alpha * lap_T + Q_over_rhocp)
    rhs = c + dt * (D * lap_c + ka * c_sat)
    c_new = rhs / (1.0 + dt * (kd + ka))
    return T_new, c_new
```
由於 $1+\Delta t(k_d+k_a)>0$，更新對 $c^n\ge 0$ 且 $D\nabla^2 c^n$ 未把 $c^n$ 拉得太大時保持非負；在擴散顯式的情況下仍需對擴散單獨套用 FTCS 穩定判準。當 $k_d\Delta t \gg 1$ 時，$c^{n+1}\approx (D\nabla^2 c^n + k_a c_{\text{sat}})/(k_d+k_a)$，穩態反應部分由比值控制，與零維穩態一致。

**解答 3**：當 $k_d=0$、$D=0$、零通量 Neumann、$c_0=0$，方程退化為 $\partial_t c = k_a(c_{\text{sat}}-c)$。解為 $c(t)=c_{\text{sat}}(1-e^{-k_a t})$。長期趨近 $c_{\text{sat}}$，且「穩態是 $c_{\text{sat}}$」僅在沒有淨消耗且初始條件無其他約束時成立。若 $k_d>0$，穩態變為 $c_\infty=k_a c_{\text{sat}}/(k_d+k_a)<c_{\text{sat}}$，嚴格小於 $c_{\text{sat}}$（當 $k_d>0$），比對應的飽和值更低。

**解答 4**：$\Delta x=\Delta y=1/21\approx 0.04762$ m。顯式 FTCS 二維穩定條件 $\Delta t \le 0.5/(D(1/\Delta x^2+1/\Delta y^2)) = 0.5/(10^{-4}\cdot(2\cdot 441.0))\approx 0.5/(0.0882)\approx 5.67$ s。取 $\Delta t=5$ s 則穩定。$t=1000$ s 需 200 步。反應項淨率 $-k_d c + k_a(c_{\text{sat}}-c) = -(k_d+k_a)c + k_a c_{\text{sat}}$；當 $c<c_\infty=k_a c_{\text{sat}}/(k_d+k_a)=6\times 10^{-3}$ kg/m$^3$，淨率為正，故總質量隨時間增加，直到趨近 $c_\infty\cdot|\Omega|$。初始 $c_0=5\times 10^{-3}<c_\infty$，故質量單調增加，且因零通量 Neumann 下擴散不改變總質量，質量演化完全由反應項貢獻。相對敏感度：$\partial\ln c_\infty/\partial\ln k_a = k_d/(k_d+k_a) = 10^{-5}/(3\times 10^{-5}) = 1/3$；$\partial\ln c_\infty/\partial\ln k_d = -k_d/(k_d+k_a) = -1/3$。兩者絕對值相加為 $2/3$，而非一；此設定下兩個相對敏感度大小相同、符號相反。

## 本章小結

本章把養殖系統中的水溫與溶氧寫成兩條獨立的守恆律，並在給定流速下採平流—擴散—反應形式。我們強調單位紀律（mg/L 到 kg/m$^3$、來源項與 $\partial_t c$ 同單位、$k_d$ 與 $k_a$ 均為 1/s）、三種消耗形式與兩種復氧形式、無因次組合（$\mathrm{Pe}$、$\mathrm{Da}$，含 $U\to 0$ 時的擴散尺度選擇）、以及邊界條件的選擇。三個手算例子分別處理零維穩態、一維穩態平流與二維時間步估算，都是合成係數下的預期結果。實作以小格網顯式步進器為基礎，並將質量、非負性與穩定條件分開檢查，同時修正 `make_grid` 對整數型別的檢查以符合故障測試。養殖案例中加入了敏感度與可辨識性分析，說明單一穩態觀測無法同時分離 $k_a$ 與 $k_d$，需要多情境資料。本章不提供現場閾值，也不涉及相場動力學；溶氧跨管理閾值不是相變。若後續章節要進行參數反推，必須先在本章層級確認合成實驗的資訊量足以辨識 $k_d$、$k_a$、$D$ 等係數，並記錄哪些參數在當前設定下不可辨識。
