# 第15章 預條件、GMRES與求解診斷

## 學習目標與先備知識

本章討論非對稱線性系統的 Krylov 求解法、預條件與求解診斷。完成本章後，應能說明 GMRES 如何在 Krylov 子空間中尋找近似解，分辨左、右預條件所使用的殘差，並以原系統真殘差判斷是否達標。亦應能辨識尺度不平衡、重啟停滯及病態矩陣，並將代數求解誤差、離散誤差與模型誤差分開。

先備知識為矩陣向量乘法、線性方程組與向量範數。以下實作使用 Python 3.10+ 與 NumPy，限於 CPU 小型稠密矩陣；不需 SciPy。程式未執行，文中只描述依推導的預期結果，不代表測試或效能實測。

## 問題與直覺

考慮離散系統

$$
Ax=b,
$$

其中 $A\in\mathbb{R}^{n\times n}$，而 $x,b\in\mathbb{R}^n$。若 $A$ 對稱正定，共軛梯度法（CG）具有相應的收斂理論。平流離散常含方向性耦合，導致矩陣不對稱；這時 CG 的適用條件不成立，不能只因某次迭代結果看似合理就認定方法有效。

GMRES（generalized minimal residual method，廣義最小殘差法）在由初始殘差所生成的 Krylov 子空間中，選擇使殘差二範數最小的近似解。未重啟 GMRES 在理想算術下，最多經過 $n$ 個有效方向可求得精確解；但需儲存逐步增加的基底，且正交化成本會上升。重啟 GMRES 每累積 $m$ 個方向便重新開始，降低記憶體使用，卻可能因捨棄先前方向而停滯。

預條件器 $P$ 旨在改善迭代系統的數值性質。實務上通常不形成 $P^{-1}$，而是提供近似解方程 $Pz=v$ 的程序。預條件建構與套用的成本、穩定性及結構適配度，都應和迭代次數一併評估。

## 數學與物理推導

給定初值 $x_0$，原系統真殘差為

$$
r_k=b-Ax_k.
$$

當 $\|b\|_2>0$ 時，相對殘差可定義為

$$
\eta_k=\frac{\|r_k\|_2}{\|b\|_2}.
$$

常用的停止條件為

$$
\|b-Ax_k\|_2\le \mathrm{atol}+\mathrm{rtol}\,\|b\|_2,
$$

其中絕對容差 $\mathrm{atol}$、相對容差 $\mathrm{rtol}$ 及所採範數都必須明示。若 $b=0$，相對殘差無法按上述定義計算，應使用絕對殘差判準或明確指定其他尺度。

殘差小只表示方程未平衡量小，不保證解誤差小。若 $A$ 可逆且 $x_*$ 是精確解，則

$$
\|x_k-x_*\|_2\le \|A^{-1}\|_2\|r_k\|_2.
$$

矩陣條件數影響右端擾動與殘差對解的放大程度。因此，真殘差、解誤差、離散誤差與物理模型誤差應分開檢查。

### Krylov 子空間與最小殘差

令 $r_0=b-Ax_0$，第 $m$ 階 Krylov 子空間為

$$
\mathcal{K}_m(A,r_0)
=\operatorname{span}\{r_0,Ar_0,\ldots,A^{m-1}r_0\}.
$$

GMRES 在 $x_0+\mathcal{K}_m(A,r_0)$ 中選擇 $x_m$，使 $\|b-Ax_m\|_2$ 最小。Arnoldi 正交化建立正交基底 $V_{m+1}$，滿足

$$
AV_m=V_{m+1}\overline H_m,
$$

其中 $\overline H_m$ 為上 Hessenberg 矩陣。令 $\beta=\|r_0\|_2$、$v_1=r_0/\beta$，並寫 $x_m=x_0+V_my$，則

$$
\|b-Ax_m\|_2
=\|\beta e_1-\overline H_m y\|_2.
$$

因此每一步需要解的是小型最小平方問題，而非重新解完整的 $n\times n$ 系統。

### 左、右預條件與真殘差

左預條件求解

$$
P^{-1}Ax=P^{-1}b,
$$

其 GMRES 內部目標是最小化 $\|P^{-1}(b-Ax)\|_2$。右預條件令 $x=P^{-1}y$，求解

$$
AP^{-1}y=b.
$$

右預條件 GMRES 最小化的是原系統殘差 $\|b-AP^{-1}y\|_2$。左預條件的內部殘差即使很小，原系統真殘差仍可能未達容差；因此最終判定應重算 $b-Ax$。

### 平流擴散系統的非對稱來源

考慮一維有因次對流擴散方程

$$
\frac{\partial c}{\partial t}
+u\frac{\partial c}{\partial x}
=D\frac{\partial^2c}{\partial x^2}+s.
$$

其中 $x$ 的單位為公尺、$t$ 為秒、$u$ 為 $\mathrm{m/s}$、$D$ 為 $\mathrm{m^2/s}$。若 $c$ 為 $\mathrm{kg/m^3}$，則 $s$ 為 $\mathrm{kg/(m^3\,s)}$。隱式 Euler 離散可寫為

$$
\left(I+\Delta t\,uD_x-\Delta t\,D L\right)c^{n+1}
=c^n+\Delta t\,s^{n+1},
$$

其中 $D_x$ 是一階差分算子，$L$ 是 Laplacian 離散。符號須依原方程移項與算子定義一致決定；邊界閉合、網格及平流方向也會改變矩陣係數。方向性平流通常使矩陣非對稱，故不能只因矩陣稀疏便假定 CG 適用。

**逐步例題一：辨識對稱性。** 令

$$
A=\begin{bmatrix}
2&-1&0\\
-3&4&-1\\
0&-2&3
\end{bmatrix}.
$$

比較 $A_{12}=-1$ 與 $A_{21}=-3$，可知 $A\ne A^T$。此矩陣不符合 CG 的對稱條件，可考慮 GMRES。對角預條件 $P=\operatorname{diag}(2,4,3)$ 易於套用，但只能調整分量尺度，不能保證消除非對稱耦合的困難。無論採何預條件，最後都應計算原系統真殘差。

**逐步例題二：手算停止判定。** 取

$$
A=\begin{bmatrix}2&1\\0&1\end{bmatrix},
\qquad b=\begin{bmatrix}1\\1\end{bmatrix},
\qquad x_0=\begin{bmatrix}0\\0\end{bmatrix}.
$$

初始殘差 $r_0=[1,1]^T$，故 $\|r_0\|_2=\sqrt{2}$。令候選解 $x=[0.45,1]^T$，則

$$
Ax=\begin{bmatrix}1.9\\1\end{bmatrix},
\qquad b-Ax=\begin{bmatrix}-0.9\\0\end{bmatrix},
\qquad \|b-Ax\|_2=0.9.
$$

若 $\mathrm{atol}=10^{-8}$、$\mathrm{rtol}=10^{-2}$，停止門檻為 $10^{-8}+10^{-2}\sqrt{2}\approx0.0141$，此候選解不合格。精確解為 $x_*=[0,1]^T$。即使其他近似解通過線性殘差門檻，也不能據此證明模型正確。

## 逐步手算例題

取

$$
A=\begin{bmatrix}2&0\\1&1\end{bmatrix},
\qquad b=\begin{bmatrix}1\\0\end{bmatrix},
\qquad x_0=0.
$$

初始殘差 $r_0=[1,0]^T$，故 $\beta=1$、$v_1=[1,0]^T$。計算 $Av_1=[2,1]^T$，投影至 $v_1$ 得 $h_{11}=2$。扣除投影後餘量為 $[0,1]^T$，故 $h_{21}=1$、$v_2=[0,1]^T$。一步 GMRES 的小型最小平方問題為

$$
y_1=\arg\min_y
\left\|
\begin{bmatrix}1\\0\end{bmatrix}
-\begin{bmatrix}2\\1\end{bmatrix}y
\right\|_2.
$$

解得 $y_1=2/5$，所以 $x_1=[0.4,0]^T$。真殘差與其範數為

$$
b-Ax_1=\begin{bmatrix}0.2\\-0.4\end{bmatrix},
\qquad \|b-Ax_1\|_2=\sqrt{0.2}.
$$

第二個有效 Krylov 方向可讓此二維問題精確求解。一般問題仍須依指定容差檢查真殘差，不能單靠步數判定。

## 實作與程式

以下為教學用右預條件、重啟式 GMRES。它使用 modified Gram–Schmidt 正交化與 Givens 旋轉，矩陣採小型稠密格式。重要細節是：Givens 旋轉會把 Hessenberg 矩陣的次對角元素刻意設為零，因此必須在旋轉前保存 Arnoldi 餘量是否為零；若在旋轉後才檢查該元素，就會把每一步都錯判成子空間封閉。

程式也在迴圈前檢查初始真殘差，所以 `maxiter=0` 時仍能判斷初值是否合格；它拒絕錯誤向量形狀、非有限值與非整數迭代設定。遇到零樞軸時不呼叫奇異小矩陣的 `solve`。

```python
import numpy as np


def gmres(A, b, x0=None, restart=10, maxiter=100,
          atol=1e-12, rtol=1e-8, apply_Pinv=None):
    """教學用固定線性右預條件 GMRES；A 為小型稠密方陣。

    apply_Pinv 必須在單次求解期間代表同一個線性映射；本函式不支援
    隨迭代變動或非線性預條件器。此類問題需使用另行推導的 Flexible GMRES。
    """
    A = np.asarray(A, dtype=float)
    b = np.asarray(b, dtype=float)

    if A.ndim != 2 or A.shape[0] != A.shape[1]:
        raise ValueError("A 必須是方陣")
    n = A.shape[0]
    if b.shape != (n,):
        raise ValueError("b 必須是形狀 (n,) 的向量")
    if not np.all(np.isfinite(A)) or not np.all(np.isfinite(b)):
        raise ValueError("A 與 b 必須全部為有限值")

    if (not isinstance(restart, (int, np.integer))
            or isinstance(restart, (bool, np.bool_))
            or restart < 1):
        raise ValueError("restart 必須是正整數")
    if (not isinstance(maxiter, (int, np.integer))
            or isinstance(maxiter, (bool, np.bool_))
            or maxiter < 0):
        raise ValueError("maxiter 必須是非負整數")
    if (not np.isfinite(atol) or not np.isfinite(rtol)
            or atol < 0 or rtol < 0):
        raise ValueError("atol 與 rtol 必須是有限非負值")

    x = np.zeros(n) if x0 is None else np.asarray(x0, dtype=float).copy()
    if x.shape != (n,) or not np.all(np.isfinite(x)):
        raise ValueError("x0 必須是有限值且形狀為 (n,)")
    if apply_Pinv is None:
        apply_Pinv = lambda v: v.copy()

    tol = atol + rtol * np.linalg.norm(b)
    history = []
    r = b - A @ x
    true_norm = np.linalg.norm(r)
    history.append(true_norm)

    if true_norm <= tol:
        return x, history, True
    if maxiter == 0:
        return x, history, False

    iterations = 0
    while iterations < maxiter:
        r = b - A @ x
        beta = np.linalg.norm(r)
        if beta <= tol:
            history.append(beta)
            return x, history, True

        m = min(int(restart), int(maxiter - iterations), n)
        V = np.zeros((n, m + 1))
        Z = np.zeros((n, m))
        H = np.zeros((m + 1, m))
        cs = np.zeros(m)
        sn = np.zeros(m)
        g = np.zeros(m + 1)
        V[:, 0] = r / beta
        g[0] = beta
        used = 0
        trial = x.copy()
        breakdown = False

        for j in range(m):
            z = np.asarray(apply_Pinv(V[:, j]), dtype=float)
            if z.shape != (n,) or not np.all(np.isfinite(z)):
                raise ValueError(
                    "預條件器輸出須為有限值且形狀為 (n,)"
                )
            Z[:, j] = z
            w = A @ z

            # Modified Gram–Schmidt。
            for i in range(j + 1):
                H[i, j] = np.dot(V[:, i], w)
                w -= H[i, j] * V[:, i]
            H[j + 1, j] = np.linalg.norm(w)

            # 必須在 Givens 旋轉清零前保存此判斷。
            arnoldi_closed = (H[j + 1, j] == 0.0)
            if not arnoldi_closed:
                V[:, j + 1] = w / H[j + 1, j]

            # 套用先前建立的 Givens 旋轉。
            for i in range(j):
                a = cs[i] * H[i, j] + sn[i] * H[i + 1, j]
                q = -sn[i] * H[i, j] + cs[i] * H[i + 1, j]
                H[i, j], H[i + 1, j] = a, q

            den = np.hypot(H[j, j], H[j + 1, j])
            if den == 0:
                # 沒有可用樞軸，不能解奇異的小型 Hessenberg 系統。
                breakdown = True
                break

            cs[j] = H[j, j] / den
            sn[j] = H[j + 1, j] / den
            H[j, j] = cs[j] * H[j, j] + sn[j] * H[j + 1, j]
            H[j + 1, j] = 0.0
            g[j + 1] = -sn[j] * g[j]
            g[j] = cs[j] * g[j]

            used = j + 1
            iterations += 1
            y = np.linalg.solve(H[:used, :used], g[:used])
            trial = x + Z[:, :used] @ y

            # 用原系統真殘差判定。
            true_norm = np.linalg.norm(b - A @ trial)
            history.append(true_norm)
            if true_norm <= tol:
                return trial, history, True

            # 使用旋轉前保存的旗標，不讀取已被設成零的 H 次對角元。
            if arnoldi_closed:
                breakdown = True
                break

        if used > 0:
            x = trial
        if breakdown:
            return x, history, np.linalg.norm(b - A @ x) <= tol
        if used == 0:
            return x, history, False

    return x, history, np.linalg.norm(b - A @ x) <= tol


def main():
    A = np.array([[2.0, -1.0, 0.0],
                  [-3.0, 4.0, -1.0],
                  [0.0, -2.0, 3.0]])
    b = np.array([1.0, 2.0, 0.0])

    diagonal = np.diag(A)
    if np.any(diagonal == 0):
        raise ValueError("對角預條件不可用：A 有零對角元素")
    apply_Pinv = lambda v: v / diagonal

    x, history, ok = gmres(
        A, b, restart=3, maxiter=30,
        atol=1e-12, rtol=1e-10,
        apply_Pinv=apply_Pinv
    )
    true_r = b - A @ x
    print("converged:", ok)
    print("x:", x)
    print("true residual norm:", np.linalg.norm(true_r))
    print("direct-solve difference:",
          np.linalg.norm(x - np.linalg.solve(A, b)))
    print("residual history:", history)


if __name__ == "__main__":
    main()
```

每個內迭代重算真殘差便於教學，但對大型問題成本較高。實務求解器可能以遞推量監控，再定期重算真殘差。此程式預期在可解且數值行為良好的小型系統上，若回報成功，原系統真殘差應符合指定門檻；解與直接解的差異受條件數與浮點精度影響。以上是預期行為，並非已執行結果。

## 測試與預期結果

| 類別 | 測試 | 預期診斷 |
|---|---|---|
| 正常 | 使用章內非對稱矩陣，計算 `b - A @ x` | 若回報成功，真殘差應符合 $\mathrm{atol}+\mathrm{rtol}\|b\|_2$。 |
| 多方向正常 | 使用二維手算例，容許兩個 Krylov 方向 | 應能檢查至少兩個方向的候選解；每步後都以真殘差判定，不應第一步就因 Givens 清零而誤報 breakdown。 |
| 邊界 | $b=0$、$x_0=0$、`maxiter=0` | 初始真殘差為零，應立即回報成功，且歷程包含初始殘差。 |
| 邊界 | $b\ne0$、`maxiter=0` | 回報未收斂並保留初始真殘差，不進入迭代。 |
| 故障 | 傳入形狀 `(n,1)` 的 $b$ | 應在矩陣運算前拒絕，不得由 NumPy 廣播產生錯誤形狀殘差。 |
| 故障 | $A=0$、$b\ne0$，用恆等預條件 | 無可用樞軸時應回報未收斂，不得對奇異小矩陣呼叫 `solve`。 |
| 故障 | 傳入 NaN 的矩陣、向量或預條件輸出 | 輸入或輸出檢查應拒絕非有限值。 |
| 故障 | 對角線含零而使用對角預條件 | 呼叫者須拒絕無效預條件，不可忽略非有限結果。 |
| 停滯 | 使用短重啟或不良預條件 | 可能未達門檻；記錄真殘差並回報未收斂，不得只報預條件殘差。 |

尺度測試可把方程某列及相應右端同乘常數，使精確解不變，但殘差範數與迭代行為可能改變。若使用行縮放矩陣 $S$，須分辨求解的是 $SAx=Sb$，並在原系統重新計算 $b-Ax$。

## 除錯與常見陷阱

**把預條件殘差當真殘差。** 左預條件可能最小化 $\|P^{-1}(b-Ax)\|_2$。若 $P^{-1}$ 大幅縮小特定方向，該量小仍可能掩蓋原系統殘差。最終判定應回到 $b-Ax$。

**容差定義不完整。** 應明示絕對容差、相對容差、範數及殘差所屬系統。若 $b$ 很小，單用相對殘差可能不合適；若 $b=0$，程式須以絕對殘差處理。

**把求解器收斂當物理驗證。** GMRES 收斂只表示離散線性系統解至指定精度。平流方向、擴散符號、邊界條件、網格截斷誤差與模型假設仍可能錯。濃度非負性、邊界通量與收支守恆要另外檢查；不能以裁零掩蓋負值。

**Givens 旋轉後錯判 breakdown。** 旋轉會刻意將 Hessenberg 次對角元素設為零。必須在旋轉前記錄 Arnoldi 餘量是否為零，並以原始旗標判斷子空間是否封閉。旋轉後直接檢查該元素，會把每個迭代步驟都誤判為 breakdown。

**重啟造成停滯。** 重啟太短會捨棄有用方向。可比較不同重啟長度，觀察每段末端的真殘差；但較長重啟也會增加基底記憶體與正交化成本。

**預條件器不適用。** 對角預條件遇到零對角元素便失效，不完整分解亦可能因樞軸問題失敗。應檢查預條件的建構成本、套用成本、穩定性與問題適配度，而非只比較迭代數。

## 養殖與相場案例

合成池域的溫度或溶氧傳輸模型，在給定速度場、以隱式時間步處理擴散並採方向性平流離散後，可能形成稀疏非對稱系統。即使 GMRES 將代數殘差降至門檻以下，仍須檢查邊界通量、來源與反應收支、單位、網格敏感度及濃度非負性。溶氧跨越管理閾值不是物理相變。本章不提供現場管理門檻或設備操作建議；唯讀 agent 只能呈現合成設定與求解證據，不自行改模型、投餌、加藥或操作設備。

在無因次 Allen–Cahn 或 Cahn–Hilliard 模型中，非線性時間離散可能於每步產生線性子問題，GMRES 可用於求解該子問題。但線性殘差小不保證相場時間離散能量下降。Cahn–Hilliard 在週期或適當無通量邊界下須檢查質量守恆；亦應分別記錄非線性殘差、線性真殘差、總質量與離散自由能，並註明時間格式與步長條件。不能靠裁零或平滑隱藏不穩定。

## 習題

1. **手算：** 對
   $$
   A=\begin{bmatrix}3&1\\0&2\end{bmatrix},
   \qquad b=\begin{bmatrix}4\\2\end{bmatrix},
   $$
   從 $x_0=0$ 出發，計算初始殘差，並說明為何正對角元素不足以判定 CG 適用。

## 習題解答

1. 因 $x_0=0$，$r_0=b=[4,2]^T$，所以 $\|r_0\|_2=\sqrt{20}$。又 $A_{12}=1$、$A_{21}=0$，故矩陣不對稱。正對角元素不足以保證對稱正定，不能據此認定 CG 適用。

2. 無預條件可令 `apply_Pinv=lambda v: v.copy()`；對角預條件可用 `lambda v: v / np.diag(A)`，但須先確認對角線無零。兩次都使用相同初值、容差、重啟與迭代上限，再計算 `np.linalg.norm(b - A @ x)`。預期若回報成功，真殘差均符合同一門檻；哪一者迭代較少須依實際執行結果判定，不能預先聲稱。

3. 左預條件 GMRES 最小化 $\|P^{-1}(b-Ax)\|_2$，$P^{-1}$ 可能縮小特定方向，使預條件殘差很小而原系統殘差仍大。另一方面，病態矩陣可把小殘差或右端擾動放大成顯著解誤差。應重算真殘差，並考慮條件數與資料誤差。

4. 先檢查 $A,b,x_0$ 的形狀與有限值；接著以原系統重算 $b-Ax$，核對容差定義；再檢查預條件器、左右預條件方式及零對角；然後檢查尺度、條件性、重啟長度與殘差歷程，必要時以直接解作小型參照。這些屬輸入與代數求解診斷。之後檢查平流方向、流入邊界、擴散符號及矩陣組裝，並做網格細化與通量檢查，屬離散驗證。最後檢查速度、擴散係數、反應式及物理假設是否適合合成情境，屬模型檢驗；單純增加迭代次數不能取代以上工作。

## 本章小結

GMRES 適合一般非對稱系統，在 Krylov 子空間中最小化殘差。重啟減少記憶體需求，但可能造成停滯。左、右預條件所最小化的量不同；最終應重算原系統真殘差 $b-Ax$，並明示絕對及相對容差。求解器收斂、離散正確與物理模型可信是不同判斷，須各自診斷。
