    *   分析：
        *   定義 $\partial_n$ 為沿水域的**單位外法向**導數。對於水面，外法向指向上方（空氣）。
        *   熱流密度 $q = -k \nabla T \cdot \mathbf{n} = -k \partial_n T$。
        *   Newton 冷卻定律：熱從水（$T$）流向空氣（$T_{\text{air}}$）。若 $T > T_{\text{air}}$，熱流向外（正）。
        *   方程：$q_{\text{out}} = h(T - T_{\text{air}})$。
        *   代入：$-k_{\text{th}}\partial_n T = h_{\text{th}}(T - T_{\text{air}})$。
        *   文稿寫的是 $h_{\text{th}}(T - T_{\text{air}})$。
        *   文稿文字說明：「水比空氣熱時，右端為正，表示熱向外流」。
        *   若 $T > T_{\text{air}}$，右端 $h(T-T_{\text{air}}) > 0$。左端 $-k \partial_n T$ 為外向熱流。符合。
        *   前稿錯誤：前稿寫的是 $h_{\text{th}}(T_{\text{air}} - T)$，這會導致 $T > T_{\text{air}}$ 時右端為負，與「外向通量取正」矛盾。
        *   本稿修正：改寫為 $T - T_{\text{air}}$。
        *   結論：**本稿邊界條件符號正確**。
    *   溶氧同理：$-D\partial_n c = h_m(c - c_{\text{sat}})$。若 $c < c_{\text{sat}}$（缺水氧），氧從空氣進入水。外向通量應為負（即內向通量為正）。
        *   右端 $h_m(c - c_{\text{sat}})$。若 $c < c_{\text{sat}}$，右端為負。
        *   左端 $-D\partial_n c$ 為外向溶質通量。
        *   負的外向通量 = 正的內向通量。符合物理。
        *   文稿文字：「水中濃度較低時，外向溶質通量為負，表示氧進入水域」。正確。

**2. 問題清單**

1.  **無因次化公式符號錯誤**
    *   定位：數學與物理推導 > 無因次化 > 第二段（當流速趨於零時）。
    *   原因：文稿宣稱取 $T_{ref} = L^2/D$（擴散時間尺度），但寫出的無因次方程中擴散項係數為 1（正確），而平流項係數寫為 $\mathrm{Pe}_c^{-1}$（錯誤，應為 $\mathrm{Pe}_c$ 或 $1$ 取決於速度定義）。
        *   若 $t^* = t D / L^2$，則 $\partial_t = \frac{D}{L^2} \partial_{t^*}$。
        *   原方程：$\partial_t c + \mathbf{u} \cdot \nabla c = D \nabla^2 c + \dots$
        *   代入：$\frac{D}{L^2} \partial_{t^*} c^* + \frac{U}{L} \mathbf{u}^* \cdot \frac{1}{L} \nabla^* c^* = D \frac{1}{L^2} \nabla^{*2} c^* + \dots$ （假設 $\mathbf{u} = U \mathbf{u}^*$）。
        *   整理：$\frac{D}{L^2} [ \partial_{t^*} c^* + \frac{U L}{D} \mathbf{u}^* \cdot \nabla^* c^* - \nabla^{*2} c^* ] = \dots$
        *   即 $\partial_{t^*} c^* + \mathrm{Pe}_c \mathbf{u}^* \cdot \nabla^* c^* = \nabla^{*2} c^* + \dots$
        *   文稿寫的是 $\mathrm{Pe}_c^{-1}$。
    *   最小修法：將公式中的 $\mathrm{Pe}_c^{-1}$ 改為 $\mathrm{Pe}_c$。

2.  **邊界條件文字描述精確度**
    *   定位：數學與物理推導 > 邊界條件。
    *   原因：文稿修正了 Robin 條件符號，現在正確。無問題。

3.  **程式碼 `laplacian_2d` 的邊界精度**
    *   定位：實作與程式。
    *   原因：`np.pad(mode='edge')` 在邊界上給出一階精確的零通量邊界條件（針對 Laplacian 的邊界項而言，整體截斷誤差受邊界影響可能降為一階，若內點為二階）。文稿未聲稱邊界為二階，僅作為數值步進器，可接受。

**3. 結論**

本稿主要錯誤在於無因次化段落中，當時間尺度改為擴散尺度 $L^2/D$ 時，平流項的無因次係數寫錯（寫成 $\mathrm{Pe}^{-1}$ 而非 $\mathrm{Pe}$）。此為可定位的實質錯誤，需修正。
