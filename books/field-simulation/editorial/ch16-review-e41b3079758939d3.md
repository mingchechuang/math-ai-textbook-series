# 第16章 弱形式與一維有限元素

**獨立重算與核對記錄**

1.  **弱形式推導**：
    *   強形式 $-(au')' + cu = f$。
    *   分部積分：$\int_0^L a u' v' dx - [au'v]_0^L + \int c u v dx = \int f v dx$。
    *   邊界條件：左端 Dirichlet $u(0)=g_0 \implies v(0)=0$。右端 Neumann $a(L)u'(L)=h$。
    *   邊界項 $[au'v]_0^L = a(L)u'(L)v(L) - a(0)u'(0)v(0) = h v(L) - 0$。
    *   弱形式：$\int a u' v' + \int c u v = \int f v + h v(L)$。
    *   **核對結果**：推導正確。$a(\cdot, \cdot)$ 為對稱雙線性形式，$\ell(v)$ 為連續線性泛函。

2.  **P1 局部矩陣**：
    *   單元 $I_e = [x_e, x_{e+1}]$，長 $h_e$。
    *   $\phi_e' = -1/h_e, \phi_{e+1}' = 1/h_e$。
    *   剛度 $k_{ij} = \int a \phi_i' \phi_j' dx = \frac{a}{h_e} \begin{pmatrix} 1 & -1 \\ -1 & 1 \end{pmatrix}$。
    *   質量 $m_{ij} = \int c \phi_i \phi_j dx = \frac{c h_e}{6} \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$。
    *   **核對結果**：公式與符號正確。

3.  **載荷向量（Load Vector）與求積精度**：
    *   程式 `p1_load` 使用頂點梯形法：$b_i \approx \sum_e \frac{h_e}{2} (f_e \delta_{i,e} + f_{e+1} \delta_{i,e+1})$。
    *   對於常數 $f$，頂點梯形法給出 $b_i = h f$（內部），$h/2 f$（邊界）。
    *   對於線性 $f(x)=x$，$h=0.5$：
        *   精確積分 $b_1 = \int_0^{0.5} x(2x) dx + \int_{0.5}^1 x(2(1-x)) dx = [ \frac{2}{3}x^3 ]_0^{0.5} + [ x^2 - \frac{2}{3}x^3 ]_{0.5}^1 = \frac{1}{12} + (1 - 2/3 - 0.25 + 1/12) = \frac{1}{12} + \frac{1}{4} + \frac{1}{12} = \frac{1}{4}$。
        *   頂點梯形 $b_1 = \frac{0.5}{2} f(0) + \frac{0.5}{2} f(0.5) + \frac{0.5}{2} f(0.5) + \frac{0.5}{2} f(1) = 0 + 0.125 + 0.125 + 0.25 = 0.5$。
        *   **發現問題**：手算例題與習題解答中，對於 $f(x)=x$ 的載荷計算，若使用程式中的頂點梯形法，$b_1$ 應為 $0.5$，而非精確值 $0.25$。
        *   然而，習題 1 的解答中寫：「上述三個分量採精確積分... 兩種載荷的 $b_1$ 恰好相同」。
        *   **重算驗證**：
            *   精確 $b_1 = 0.25$。
            *   頂點梯形 $b_1 = 0.5$。
            *   兩者**不同**。
            *   解答中稱「$b_1^{\text{quad}} = (h/2+h/2)f(0.5) = 0.25$」是**計算錯誤**。
            *   頂點梯形在內部節點 $i=1$ 收集來自左單元 $e=0$ 的右端點 $x_1$ 和右單元 $e=1$ 的左端點 $x_1$。
            *   單元 0 ($[0, 0.5]$): $b_1 \mathrel{+}= \frac{0.5}{2} f(0.5) = 0.25 \times 0.5 = 0.125$。
            *   單元 1 ($[0.5, 1]$): $b_1 \mathrel{+}= \frac{0.5}{2} f(0.5) = 0.25 \times 0.5 = 0.125$。
            *   總和 $b_1 = 0.125 + 0.125 = 0.25$。
            *   等等，讓我再檢查一下 $f(x)=x$。
            *   $f(0)=0, f(0.5)=0.5, f(1)=1$。
            *   單元 0 貢獻給 $b_1$ (右節點)：$0.5 \times 0.5 = 0.25$? 不，公式是 $0.5 * h * f[e+1]$。$0.5 * 0.5 * 0.5 = 0.125$。
            *   單元 1 貢獻給 $b_1$ (左節點)：$0.5 * h * f[e]$。$0.5 * 0.5 * 0.5 = 0.125$。
            *   總和 $0.25$。
            *   我的前一次心算錯在把 $f(0.5)$ 當成 1 或者算錯了係數。
            *   $b_1^{\text{quad}} = 0.25$。精確值 $b_1 = 0.25$。
            *   **核對結果**：解答中稱兩者相同是**正確**的。頂點梯形法對線性函數在對稱網格上的節點求和恰好等於精確積分？
            *   讓我們檢查 $b_0$。精確 $b_0 = 1/24 \approx 0.0416$。頂點 $b_0 = 0.5 * 0.5 * f(0) = 0$。不同。
            *   檢查 $b_2$。精確 $b_2 = 5/24 \approx 0.2083$。頂點 $b_2 = 0.5 * 0.5 * f(1) = 0.25$。不同。
            *   但在 Dirichlet 邊界 $g_0=g_2=0$ 時，$b_0, b_2$ 被消去或設為邊界值。只有 $b_1$ 進入自由方程。
            *   因此，儘管端點載荷不同，但由於 Dirichlet 消去，最終影響解的 $b_1$ 恰好一致。解答的說明「兩端施加零 Dirichlet 後只求解內部方程，兩種載荷的 $b_1$ 恰好相同」是**正確且精確**的。

8.  **量綱**：
    *   溫度 $T$ (K), $a$ (m²/s), $f$ (K/s)。
    *   $-(a T')' = f \implies \frac{m^2}{s} \frac{K}{m^2} = \frac{K}{s}$。量綱一致。
    *   溶氧 $C$ (kg/m³), $r$ (1/s), $s$ (kg/m³/s)。
    *   $-(a C')' + r C = s \implies \frac{kg}{m^3 s} + \frac{1}{s} \frac{kg}{m^3} = \frac{kg}{m^3 s}$。量綱一致。

9.  **習題解答**：
    *   習題 1：已確認 $b_1$ 的一致性說明正確。
    *   習題 3：純 Neumann 相容性 $\int f = h_{right} - h_{left}$。
        *   $u'(0)=1, u'(1)=1$。
        *   右端項 $b$ 對應 $h v(L) - h v(0)$?
        *   弱形式 $\int u' v' = \int f v + u'(L)v(L) - u'(0)v(0)$。
        *   $b_i$ 包含 $1 \cdot v(1) - 1 \cdot v(0)$。
        *   離散上，$b_N += h_{flux}$, $b_0 -= h_{flux}$?

        *   載荷項 $\int f v$ 為 0。
        *   邊界項 $1 \cdot v(1) - 1 \cdot v(0)$。
        *   在離散系統中，這對應於右端向量在邊界節點的值。
        *   若 $f=0$，$b_i$ 僅來自邊界。
        *   $b_0$ 對應 $-1$，$b_N$ 對應 $+1$。
        *   相容性 $1^T b = -1 + 1 = 0$。正確。
