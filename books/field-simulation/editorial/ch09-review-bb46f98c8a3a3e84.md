## 非阻擋校對建議

1. 「時間收斂觀測階與真殘差判準」段落重複兩次，可刪除後一段；這是編輯問題，不影響正確性。
2. `validate_inputs` 可像其他整數檢查一樣拒絕布林值：
   ```python
   if not isinstance(n_steps, int) or isinstance(n_steps, bool) or n_steps < 1:
       raise ValueError(...)
   ```
3. `rel_res` 目前計算後未回傳；可移除或加入診斷歷史。
4. 小結的「持續振盪」宜改成「長時間反號振盪且衰減緩慢」，以延續正文對有限 $q$ 時 $|R_{\mathrm{CN}}|<1$ 的精確限定。
5. 養殖案例應避免把 BE 的數值平滑直接等同物理可信；較準確的說法是仍須以時間細化與資料誤差模型確認。

以上均不構成拒稿理由。
