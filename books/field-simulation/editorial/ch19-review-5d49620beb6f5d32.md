## 阻擋性問題

1. **程式無法完成一步**

   **原句：**

   ```python
   lap_u_x = (
       self.u[:, 1:self.nx]
       - 2*self.u[:, :self.nx-1]
       + self.u[:, :self.nx-2]
   ) / self.dx**2
   ```

   shape 分別為 `(ny,nx-1)`、`(ny,nx-1)`、`(ny,nx-2)`，不能 broadcasting。

   **最小修法：**刪除此未使用區段及空 `pass` 迴圈，只對 `u[:,:nx]` 計算，再同步重複週期面。

2. **$v$ 分量沒有預測或校正**

   **原句：**

   ```python
   # self.v = self.v + self.dt * self.nu * lap_v
   # self.v = self.v - (self.dt / self.rho) * dp_dy
   ```

   Poisson 右端含 $D_yv$，但校正缺少 $G_yp$，故一般不能使完整散度歸零。

   **最小修法：**完整實作 `lap_v`、$v$ 預測、壓力校正及 `v[ny,:]=v[0,:]`。

3. **動能漏算 $v$**

   **原句：**

   ```python
   E = 0.5 * self.rho * np.sum(uc**2) * self.dx * self.dy
   ```

   應包含 $u_c^2+v_c^2$，並明示為每單位厚度的二維動能。

4. **Taylor–Green 與 Stokes 模型混用**

   **原句：**

   > $p=-\frac14(\cos2x+\cos2y)e^{-4\nu t}$  
   > Stokes 限，忽略平流

   完整 Navier–Stokes 對應

   $$
   p=\frac{\rho}{4}(\cos2x+\cos2y)e^{-4\nu t}+C(t).
   $$

   若忽略平流，則應有 $\nabla p=0$。

   **最小修法：**選定完整 Navier–Stokes 或 Stokes 黏性模態；現有程式只能支持後者。

5. **手算例題的消去式錯誤**

   **原句：**

   > $2p_0-p_2+2p_3=0\Rightarrow p_2=2(p_0+p_3)$

   正確為

   $$
   -p_2+2p_3-p_0=0,\qquad p_2=2p_3-p_0.
   $$

   最終向量雖可代回，中間推導仍須更正。

6. **沒有製造來源測試**

   **原句：**

   > 平流項設為 0 或手動製造

   稿中沒有 $\mathbf f$ 的公式、量綱、程式介面或離散動量殘差。

   **最小修法：**補一組完整 $\mathbf u,p,\mathbf f$，並檢查散度及動量殘差。

7. **習題 1 的週期矩陣及答案錯誤**

   **原句：**

   > $A=[[2,-1],[-1,2]]$，$p=[0,0]$

   對 $N=2,\Delta x=1$，兩個週期鄰居重合，應為

   $$
   A=\begin{bmatrix}2&-2\\-2&2\end{bmatrix}.
   $$

   若 $\rho=\Delta t=1$，零均值解是 $p=[1/2,-1/2]^T$，不是零向量。
