## 問題與直覺

### 為什麼需要迭代法？
Poisson 方程 $-\Delta u = f$ 在 1D 離散後得到線性系統 $A x = b$，其中 $A$ 為三對角 SPD 矩陣。若網格點數 $N$ 很大（例如 $N=10^5$），直接求解（如 LU 分解）需 $O(N^3)$ 時間與 $O(N^2)$ 空間，無法擴展。稀疏矩陣 $A$ 每行僅有 3 個非零元素，稀疏率 $>99\%$，迭代法可僅用 $O(N)$ 空間與每步 $O(N)$ 計算，總迭代步數若為 $O(N)$ 或更少，則總成本 $O(N^2)$，遠優於直接法。

## 數學與物理推導

### SPD 矩陣與能量泛函
設 $A \in \mathbb{R}^{n \times n}$ 對稱正定（SPD），則對任意 $x \ne 0$，有 $x^T A x > 0$。定義二次型：
$$
f(x) = \frac{1}{2} x^T A x - b^T x
$$
$f$ 為凸二次泛函，最小值點滿足 $\nabla f(x) = Ax - b = 0$，即 $Ax = b$。求解 $Ax = b$ 等价於最小化 $f(x)$。

### CG 的共軛梯度推導
CG 基於以下性質：
1. 搜索方向 $p_k$ 彼此 $A$-共軛：$p_i^T A p_j = 0, i \ne j$。
2. 殘差 $r_k = b - Ax_k$ 彼此正交：$r_i^T r_j = 0, i \ne j$。
3. $f(x_k)$ 在 Krylov 空間 $\mathcal{K}_k(A, r_0)$ 中達到最小。

初始化：$x_0 = 0$（或任意），$r_0 = b - Ax_0$，$p_0 = r_0$。

第 $k$ 步：
$$
\alpha_k = \frac{r_k^T r_k}{p_k^T A p_k}
$$
$$
x_{k+1} = x_k + \alpha_k p_k
$$
$$
r_{k+1} = r_k - \alpha_k A p_k
$$
$$
\beta_k = \frac{r_{k+1}^T r_{k+1}}{r_k^T r_k}
$$
$$
p_{k+1} = r_{k+1} + \beta_k p_k
$$

### 殘差與誤差界
- **真殘差**：$r_k = b - Ax_k$。停止條件：$\|r_k\|_2 \le \text{atol} + \text{rtol} \cdot \|b\|_2$。
- **A-範數誤差界**：$\|x_k - x_*\|_A \le 2 \left(\frac{\sqrt{\kappa(A)} - 1}{\sqrt{\kappa(A)} + 1}\right)^k \|x_0 - x_*\|_A$，其中 $\kappa(A) = \lambda_{\max}/\lambda_{\min}$ 為條件數。
- **關鍵**：殘差小不等於解誤差小；必須報告真殘差，並區分收斂與精度。

### Jacobi 與 Gauss–Seidel 預條件
- **Jacobi**：$D x^{(k+1)} = b - (L+U) x^{(k)}$，其中 $A = D + L + U$。
- **Gauss–Seidel**：$(D+L) x^{(k+1)} = b - U x^{(k)}$。
- **PCG**：用 $M^{-1}$ 預條件，$M \approx A$，加速收斂。對 1D Poisson，Jacobi 預條件可使收斂步數從 $O(N^2)$ 降至 $O(N)$。

## 逐步手算例題

### 例 1：1D Poisson 三點系統
問題：$-u''(x) = f(x)$，$x \in [0,1]$，$u(0)=u(1)=0$。網格 $N=2$ 內部點，$h=1/3$，$f(x)=1$。

離散：
$$
\frac{u_{i-1} - 2u_i + u_{i+1}}{h^2} = -f_i
$$
對 $i=1,2$：
$$
\begin{cases}
2u_1 - u_2 = h^2 f_1 \\
-u_1 + 2u_2 = h^2 f_2
\end{cases}
\Rightarrow
A = \begin{bmatrix} 2 & -1 \\ -1 & 2 \end{bmatrix}, \quad
b = \begin{bmatrix} h^2 \\ h^2 \end{bmatrix} = \begin{bmatrix} 1/9 \\ 1/9 \end{bmatrix}
$$

直接解：$u_1 = u_2 = \frac{1}{9} \cdot \frac{2}{3} = \frac{2}{27}$（對稱解）。

CG 迭代（$x_0 = 0$）：
- $r_0 = b = [1/9, 1/9]^T$，$\|r_0\|^2 = 2/81$
- $p_0 = r_0$，$Ap_0 = [2/9 - 1/9, -1/9 + 2/9]^T = [1/9, 1/9]^T = r_0$
- $\alpha_0 = \frac{r_0^T r_0}{p_0^T A p_0} = \frac{2/81}{2/81} = 1$
- $x_1 = x_0 + \alpha_0 p_0 = [1/9, 1/9]^T$
- $r_1 = b - Ax_1 = [1/9, 1/9]^T - [2/9 - 1/9, -1/9 + 2/9]^T = [1/9 - 1/9, 1/9 - 1/9]^T = [0, 0]^T$

1 步收斂（因為 $N=2$，Krylov 空間維數為 2，最多 2 步；此處因對稱性提前收斂）。

### 例 2：非 SPD 反例
設 $A = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}$（對稱但非正定），$b = [1, 0]^T$。

- $A$ 有特徵值 $\pm 1$，非正定。
- CG 要求 $p_k^T A p_k > 0$ 以定義 $\alpha_k$。取 $p_0 = r_0 = b = [1, 0]^T$，則 $p_0^T A p_0 = 0$，$\alpha_0$ 未定義。
- 結論：標準 CG 不能應用於非 SPD 系統，需改用 GMRES、BiCGStab 等。

## 實作與程式

### NumPy 自足 CG 求解器
```python
import numpy as np

def cg_sparse(A, b, x0=None, tol=1e-8, max_iter=1000, M_inv=None):
    """
    共軛梯度求解 Ax = b，A 為 SPD 稀疏矩陣（或可調用的線性算子）。
    A: 可調用函數，輸入 x 返回 A@x（或稀疏矩陣）。
    b: 右端向量和量。
    x0: 初始猜测，預設零向量。
    tol: 相對與絕對容差（真殘差）。
    max_iter: 最大迭代次數。
    M_inv: 可選預條件，輸入 r 返回 M_inv@r。
    返回 (x, n_iter, residual_norm, converged)
    """
    if x0 is None:
        x = np.zeros_like(b, dtype=float)
    else:
        x = x0.copy()
    
    r = b - A(x)
    norm_r0 = np.linalg.norm(r)
    if norm_r0 < tol:
        return x, 0, norm_r0, True
    
    if M_inv is not None:
        z = M_inv(r)
    else:
        z = r.copy()
    
    p = z.copy()
    rz = np.dot(r, z)
    n_iter = 0
    converged = False
    
    for k in range(max_iter):
        n_iter = k + 1
        Ap = A(p)
        pAp = np.dot(p, Ap)
        if abs(pAp) < 1e-15:
            raise ValueError("p^T A p ~ 0，A 可能非 SPD 或 num 不穩定")
        alpha = rz / pAp
        x += alpha * p
        r -= alpha * Ap
        norm_r = np.linalg.norm(r)
        if norm_r < tol * (1 + np.linalg.norm(b)):
            converged = True
            break
        if M_inv is not None:
            z = M_inv(r)
        else:
            z = r.copy()
        rz_new = np.dot(r, z)
        beta = rz_new / rz
        rz = rz_new
        p = z + beta * p
    
    return x, n_iter, norm_r, converged

# 測試：1D Poisson 5 點
N = 5
h = 1.0 / (N + 1)
f = np.ones(N)
b = (h ** 2) * f

def A_mul(x):
    out = np.zeros_like(x)
    out[0] = 2 * x[0] - x[1]
    out[-1] = -x[-2] + 2 * x[-1]
    out[1:-1] = -x[:-2] + 2 * x[1:-1] - x[2:]
    return out

x0 = np.zeros(N)
x_cg, n_it, res, conv = cg_sparse(A_mul, b, x0=x0, tol=1e-10)
x_direct = np.linalg.solve(np.diag(2*np.ones(N) - 1*np.ones(N-1, 1)
                               - 1*np.ones(N-1, -1) + np.zeros((1,1))
                               + np.zeros((1,1))), b)  # 簡化構造
# 更清晰構造 A 矩陣
A_mat = np.zeros((N, N))
for i in range(N):
    A_mat[i, i] = 2.0
    if i > 0: A_mat[i, i-1] = -1.0
    if i < N-1: A_mat[i, i+1] = -1.0
x_direct = np.linalg.solve(A_mat, b)

err = np.linalg.norm(x_cg - x_direct)
print(f"CG 迭代 {n_it} 步，殘差 {res:.2e}，收斂={conv}")
print(f"與直接解差：{err:.2e}")
# 預期：n_it <= N，err < 1e-8，conv=True
```

# info=0 表示收斂

```

### 與直接解比較
- 稀疏性：$A$ 非零元素 $3N$，直接法需 $O(N^2)$ 空間。
- 時間：直接法 $O(N^3)$，CG 每步 $O(N)$，總 $O(N \cdot k)$，$k \le N$。
- 精度：CG 收斂時殘差小，但需驗證 $x$ 是否接近直接解。

## 測試與預期結果

| 測試案例 | 預期結果 | 失敗情形 |
|---|---|---|
| 1D Poisson $N=5$，SPD | CG ≤5 步收斂，$\|r\| < 1e-10$，$\|x-x_*\| < 1e-8$ | 若 $N$ 增大，步數 ~ $O(N)$ |
| 非 SPD 對稱 $A$（特徵值負） | 拋出 $p^T A p \le 0$ 異常 | 若未檢查，$\alpha$ 負或除零 |
| 右端 $b$ 不在 $A$ 列空間（不相容） | 殘差不降，收斂失敗 | 若錯誤歸因於 $A$ 非 SPD |
| 預條件 Jacobi | 步數從 $O(N^2)$ 降至 $O(N)$ | 若 $M^{-1}$ 錯誤，收斂更慢 |
| $b$ 含 NaN/Inf | 立即拒絕 | 若未輸入檢查，結果無意義 |

## 除錯與常見陷阱

1. **殘差小 ≠ 解準**：必須報告 $\|r\|$ 與 $\|x-x_*\|$（若有參考解）。
2. **非 SPD 誤用**：平流項使 $A$ 非對稱，需用 BiCGStab/GMRES。
3. **CSR 索引錯誤**：`indptr`、`indices`、`data` 三陣列必須一致；常見 off-by-one。
4. **預條件不匹配**：$M^{-1}$ 必須近似 $A^{-1}$ 且 SPD；否則可能收斂失敗。
5. **停止條件模糊**：必須使用真殘差 $r = b - Ax$，並明示 atol/rtol。
6. **浮點精度**：大 $N$ 時 $p^T A p$ 可能因舍入為負，需檢查。

## 養殖與相場案例

### 案例：池塘溫度 Poisson 穩態求解
池塘溫度場 $T(x,y)$ 滿足 $-\kappa \nabla^2 T = S$（無源 $S=0$），邊界為環境溫度。離散後得 2D Poisson 系統 $A T = b$，$A$ 為 5-點 Laplacian SPD 稀疏矩陣。

- **問題規模**：$64 \times 64$ 網格，$N=4096$ 未知數。
- **直接法**：需 $O(N^2) \approx 10^8$ 空間，時間 $O(N^3) \approx 10^{12}$，不可行。
- **CG 求解**：每步 $O(N)$，條件數 $\kappa(A) \sim N^2 \approx 2.6 \times 10^5$，預期步數 $O(\sqrt{\kappa}) \approx 500$，總運算 $2 \times 10^9$，可行。
- **養殖應用**：求穩態溫度場以預測溶氧分布；但注意這是穩態近似，動態需時間離散。

### 注意
- 此處 $A$ 為 SPD 是因為純擴散（無平流）。若加入平流項，$A$ 非對稱，需 GMRES。
- 邊界條件必須正確施加（Dirichlet 固定值不進入系統，Neumann 影響邊界行）。

## 習題

1. **手算**：對 3 點 1D Poisson（$N=3$，$h=1/4$，$f=1$），寫出 $A$、$b$，手算 CG 前兩步，驗證 $r_1$ 正交 $r_0$。
2. **程式**：修改 NumPy CG 函數，加入 Jacobi 預條件（$M=D$），比較 $N=32$ 時有/無預條件的迭代步數。
3. **反例**：構造一個 $4 \times 4$ 對稱但非正定矩陣 $A$，示範 CG 在第幾步失敗，並解釋原因。
4. **整合**：將 1D Poisson CG 求解器擴展到 2D（$N_x \times N_y$），使用 CSR 格式（可手動構造或 SciPy），求解 $-\Delta u = 1$，Dirichlet 零邊界，與解析解 $u(x,y) = \frac{1}{2}(x^2 - x + y^2 - y)$ 比較 $L_2$ 誤差，$N_x=N_y=16$。

## 習題解答

### 習題 1
$N=3$，$h=1/4$，$A = \begin{bmatrix} 2 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 2 \end{bmatrix}$，$b = h^2 [1,1,1]^T = [1/16, 1/16, 1/16]^T$。

$r_0 = b$，$p_0 = r_0$。
$Ap_0 = [2/16 - 1/16, -1/16 + 2/16 - 1/16, -1/16 + 2/16]^T = [1/16, 0, 1/16]^T$。
$\alpha_0 = \frac{r_0^T r_0}{p_0^T A p_0} = \frac{3/256}{3/256} = 1$。
$x_1 = [1/16, 1/16, 1/16]^T$。
$r_1 = b - Ax_1 = [1/16, 1/16, 1/16]^T - [2/16-1/16, -1/16+2/16-1/16, -1/16+2/16]^T = [1/16-1/16, 1/16-0, 1/16-1/16]^T = [0, 1/16, 0]^T$。
$r_0^T r_1 = (1/16)(0) + (1/16)(1/16) + (1/16)(0) = 1/256 \ne 0$？檢查：$r_0^T r_1 = \frac{1}{16}\cdot 0 + \frac{1}{16}\cdot \frac{1}{16} + \frac{1}{16}\cdot 0 = \frac{1}{256}$。但理論應正交？重查 $Ax_1$：
$A x_1 = [2(1/16) - 1/16, -1/16 + 2(1/16) - 1/16, -1/16 + 2(1/16)]^T = [1/16, 0, 1/16]^T$。正確。
$r_1 = [1/16 - 1/16, 1/16 - 0, 1/16 - 1/16] = [0, 1/16, 0]^T$。
$r_0^T r_1 = 0 + 1/256 + 0 = 1/256$。但 CG 理論保證 $r_k$ 正交？實際上 CG 保證 $r_k$ 與 $p_j$ 正交，及 $r_k$ 與 $r_j$ 正交（$j<k$）。重驗：$r_0 = [1/16,1/16,1/16]$，$r_1 = [0,1/16,0]$，$r_0^T r_1 = 1/256$。矛盾？問題：$\alpha_0$ 計算。
$p_0^T A p_0 = [1/16,1/16,1/16] \cdot [1/16, 0, 1/16] = 2/256$。
$r_0^T r_0 = 3/256$。
$\alpha_0 = (3/256)/(2/256) = 3/2$，非 1！先前算錯。
修正：$\alpha_0 = 3/2$。
$x_1 = x_0 + (3/2) p_0 = [3/32, 3/32, 3/32]^T$。
$r_1 = b - A x_1 = [1/16,1/16,1/16]^T - A[3/32,3/32,3/32]^T$。
$A x_1 = [2(3/32)-3/32, -3/32+2(3/32)-3/32, -3/32+2(3/32)]^T = [3/32, 0, 3/32]^T$。
$r_1 = [1/16 - 3/32, 1/16 - 0, 1/16 - 3/32] = [2/32-3/32, 2/32, 2/32-3/32] = [-1/32, 2/32, -1/32]^T$。
$r_0^T r_1 = (1/16)(-1/32) + (1/16)(2/32) + (1/16)(-1/32) = (-1+2-1)/512 = 0$。正交驗證成功。

### 習題 2
（程式略，預期：$N=32$ 無預條件步數 ~ $O(N) \approx 30$，有 Jacobi 預條件步數 ~ $O(N) \approx 30$？實際 1D Poisson Jacobi 預條件不改善條件數太多，需更強預條件如 multigrid。但比較程式應能跑通。）

### 習題 3
$A = \begin{bmatrix} 1 & 2 & 0 & 0 \\ 2 & 1 & 0 & 0 \\ 0 & 0 & 1 & 2 \\ 0 & 0 & 2 & 1 \end{bmatrix}$，特徵值：$1\pm2$（重複），即 $3, -1, 3, -1$。非正定。
$b = [1,0,0,0]^T$。$x_0=0$，$r_0=b$，$p_0=r_0$。
$Ap_0 = [1,2,0,0]^T$。
$p_0^T A p_0 = 1\cdot1 + 0\cdot2 + 0 + 0 = 1 > 0$？但第二步可能失敗。
$\alpha_0 = (1)/(1) = 1$。$x_1 = [1,0,0,0]$。
$r_1 = b - A x_1 = [1,0,0,0] - [1,2,0,0] = [0,-2,0,0]$。
$p_1 = r_1 + \beta_0 p_0$，$\beta_0 = (r_1^T r_1)/(r_0^T r_0) = 4/1 = 4$。
$p_1 = [0,-2,0,0] + 4[1,0,0,0] = [4,-2,0,0]$。
$A p_1 = A[4,-2,0,0] = [4\cdot1 + (-2)\cdot2, 4\cdot2 + (-2)\cdot1, 0,0] = [0, 6, 0, 0]$。
$p_1^T A p_1 = 4\cdot0 + (-2)\cdot6 + 0 + 0 = -12 < 0$。$\alpha_1$ 負，迭代發散或無意義。失敗於第 2 步。

## 本章小結

- 稀疏矩陣 CSR 格式高效存儲三對角及更高稀疏系統。
- SPD 矩陣保證 CG 收斂，能量泛函最小化提供理論基礎。
- 真殘差 $r = b - Ax$ 是停止條件基礎；誤差界依賴條件數。
- Jacobi/Gauss–Seidel 預條件可加速，但需正確實現。
- 非 SPD 系統不可用標準 CG，需其他 Krylov 方法。
- 養殖應用中，純擴散穩態 Poisson 可用 CG；含平流需非對稱求解器。
