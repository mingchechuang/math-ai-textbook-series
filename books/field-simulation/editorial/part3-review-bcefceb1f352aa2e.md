## 必須修正事項

### 1. 第16章對集中質量精度的概括不正確，且與後文矛盾

> 「若採集中質量……總質量不變但精度降為一階。」  
> 後文：  
> 「集中質量會引入 $\mathcal O(h^2)$ 相位誤差」

**原因：** P1集中質量不會普遍把整個方法降成一階；精度取決於方程、網格、時間格式、所測範數及規則性。在許多規則網格上的P1拋物問題中，集中質量仍可保有二階空間 $L_2$ 精度。後文又稱其相位誤差為 $\mathcal O(h^2)$，兩者不一致。

**最小修法：** 將前句改為：「集中質量改變離散頻散、耗散及誤差常數；是否降低收斂階須依問題、網格、時間格式與範數分析，不能一概稱為一階。」

### 2. 第14章以一般 `Exception` 包住CSR驗證，可能掩蓋程式缺陷

> ```python
> try:
>     validate_csr(indptr, indices, data, n)
> except Exception as e:
>     return None, 0, np.nan, False, f"invalid_input: {str(e)}"
> ```

**原因：** `validate_csr`的契約錯誤應是 `ValueError`或`TypeError`。捕捉所有 `Exception` 會把索引錯誤、名稱錯誤或其他實作缺陷也偽裝成使用者輸入錯誤，不符合跨卷「不得吞掉一般例外」的診斷原則。

**最小修法：**

```python
except (ValueError, TypeError) as e:
```

其他非預期例外應直接傳出，以便定位程式錯誤。

### 3. 第15章Arnoldi封閉判定使用浮點精確相等

> `arnoldi_closed = (H[j + 1, j] == 0.0)`

**原因：** 數值Arnoldi中，理論上為零的餘量可能只達捨入尺度；反之，極小但非零的餘量會造成除以極小值、放大誤差並產生失真的新基底。以精確等號判定與本章強調的數值診斷不一致。

**最小修法：** 在正交化前保存 $\|A z_j\|_2$ 或其他局部尺度，採明示容差，例如

$$
h_{j+1,j}\le
\epsilon_{\rm arn}\max(1,\|Az_j\|_2).
$$

將 `epsilon_arnoldi` 設為有限非負輸入或明示固定值，並在測試中加入近封閉Krylov子空間案例。這仍是數值判定，不是完整秩證明。

### 4. 第16章核心示範仍預設較新的NumPy API

> `np.trapezoid((uh - ex) ** 2, xs)`  
> 「若本機版本較舊請改用 `np.trapz`」

**原因：** 全卷契約要求核心實驗不能默認最新版API，且小程式應自足。要求讀者手動改函數名稱，會使原樣程式在部分符合Python 3.10但NumPy較舊的環境失敗。

**最小修法：** 像第4章一樣提供自足梯形積分函數，或在程式內明確做相容分支，而不是只在正文要求手動修改。
