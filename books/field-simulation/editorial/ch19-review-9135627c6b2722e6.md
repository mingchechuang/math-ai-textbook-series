## 阻擋性問題

### 1. `compute_laplacian_u()` 會發生 broadcasting shape 錯誤

**可定位原句：**

```python
lap_u_x = (self.u[:, 1:self.nx] - 2*self.u[:, :self.nx-1] + self.u[:, :self.nx-2]) / self.dx**2
```

前兩項 shape 是 `(ny, nx-1)`，最後一項是 `(ny, nx-2)`，不能相加。雖然下文重新建立 `lap_u`，Python 仍會先執行這一行，故程式在進入後續迴圈前即失敗。

**最小修法：**

刪除整段未使用的切片試算，包括 `u_left`、`u_mid`、`u_right`、`lap_u_x`，只保留一致的迴圈版本；或直接在獨立的 `u[:, :nx]` 上以 `np.roll` 計算，再同步最後一面。

### 2. `v` 的黏性更新與壓力校正均未實作

**可定位原句：**

```python
# Similar for v, omitted for brevity, assume v=0 or similar structure
```

```python
# self.v = self.v + self.dt * self.nu * lap_v
```

```python
# self.v = self.v - (self.dt / self.rho) * dp_dy
```

Taylor–Green 初始條件的 `v` 並非零。程式只衰減及校正 `u`，而 `v` 保持初值，故一步後通常不再滿足

$$
D_xu+D_yv=0.
$$

即使壓力 Poisson 解正確，只校正 $u$ 也不能實現使用完整 $DG$ 算子推導的投影。因此「投影後散度小於 $10^{-10}$」及二維動能衰減測試均不成立。

**最小修法：**

完整實作 `compute_laplacian_v()`，並啟用：

```python
self.v += self.dt * self.nu * lap_v
self.v[self.ny, :] = self.v[0, :]
...
self.v -= (self.dt / self.rho) * dp_dy
self.v[self.ny, :] = self.v[0, :]
```

`lap_v` 必須只對 `v[:ny, :]` 的獨立面計算，再同步 `v[ny, :]`。

### 3. 程式的動能診斷漏掉 $v$ 分量

**可定位原句：**

```python
uc = 0.5 * (self.u[:, :self.nx] + self.u[:, 1:self.nx+1])
# vc = ...
E = 0.5 * self.rho * np.sum(uc**2) * self.dx * self.dy
```

Taylor–Green 動能是

$$
E=\frac{\rho}{2}\int_\Omega(u^2+v^2)\,dA.
$$

目前只計算 $u$，不能與全文所稱的 $E(t)/E(0)=e^{-4\nu t}$ 比較。

**最小修法：**

加入：

```python
vc = 0.5 * (self.v[:self.ny, :] + self.v[1:self.ny+1, :])
E = 0.5 * self.rho * np.sum(uc**2 + vc**2) * self.dx * self.dy
```

並明示二維結果是每單位厚度的動能。

### 4. Taylor–Green 壓力符號錯誤，且完整 Navier–Stokes 與 Stokes 測試混寫

**可定位原句：**

> $p(x,y,t) = -\frac{1}{4}(\cos(2x) + \cos(2y)) e^{-4\nu t}$

對稿中

$$
u=\sin x\cos y\,e^{-2\nu t},\qquad
v=-\cos x\sin y\,e^{-2\nu t}
$$

重算平流項可得

$$
(\mathbf u\cdot\nabla)\mathbf u
=
\left(\frac12\sin 2x,\frac12\sin 2y\right)e^{-4\nu t}.
$$

完整 Navier–Stokes 方程要求

$$
\nabla p
=-\rho(\mathbf u\cdot\nabla)\mathbf u,
$$

因此在 $\rho=1$ 時應取

$$
p=\frac14(\cos 2x+\cos 2y)e^{-4\nu t}+C(t),
$$

不是負號。若如後文所說忽略平流而只測 Stokes 擴散，則壓力應為空間常數，不能同時列出上述非定常空間壓力。

**最小修法：**

將例題明確拆成二選一：

- 完整 Taylor–Green：保留平流並把壓力改成正號；
- Stokes 黏性模態：明示刪除平流，令 $p=C(t)$，不要稱其為完整 Taylor–Green 動量解。

現有程式只實作後者。

### 7. 習題 1 的週期矩陣與解答均錯誤

**可定位原句：**

> $A=[[2,-1],[-1,2]]$

> $p=[0,0]$

對 $N=2$ 週期網格，左右鄰居是同一個另一節點，因此負 Laplacian 的兩個鄰接貢獻會合併。若 $\Delta x=1$，正確矩陣是

$$
A=
\begin{bmatrix}
2&-2\\
-2&2
\end{bmatrix},
$$

而不是非奇異的 $\begin{bmatrix}2&-1\\-1&2\end{bmatrix}$。此外，非零右端不可能由 $p=0$ 滿足。

若 $\Delta t$ 與 $\rho$ 未指定，答案也不能得到唯一數值壓力。

**最小修法：**

在題目指定 $\rho=1$、$\Delta t$。例如 $\Delta t=1$ 時，

$$
b=[2,-2]^T,
$$

零均值解為

$$
p=[1/2,-1/2]^T.
$$

再依 face gradient 完成速度校正。另須確認 $N=2$ 時組裝程式會把重合鄰居的兩次貢獻都累加。

### 9. 測試容差與真殘差未定義

**可定位原句：**

> `投影後 ... 應小於 10^-10（機器精度）`

程式使用 `np.linalg.pinv`，但未指定 `rcond`，也未檢查

$$
r=b-Ap.
$$

絕對散度門檻還會受速度、網格尺度與 $\Delta t$ 影響，不能普遍稱 $10^{-10}$ 為機器精度。

**最小修法：**

明示 `atol`、`rtol`，同時檢查：

```python
r = rhs - self.A @ p_flat
```

以及投影後散度，例如以

```python
norm <= atol + rtol * reference_norm
```

判定。並說明小殘差不等同小解誤差。

### 11. 無因次體力尺度沒有定義

**可定位原句：**

> `+ f*`

無因次化列出了 $\mathbf u,\mathbf x,t,p$，卻沒有定義 $\mathbf f^*$。由加速度尺度 $U^2/L$ 可得

$$
\mathbf f=\frac{U^2}{L}\mathbf f^*,
\qquad
\mathbf f^*=\frac{L}{U^2}\mathbf f.
$$

**最小修法：**

補上此尺度；若重力保留，還須說明可能出現的 Froude 數或如何吸收到修正壓力中。不要籠統宣稱解只取決於 $Re$ 與幾何，因為外力及其無因次參數也會影響解。
