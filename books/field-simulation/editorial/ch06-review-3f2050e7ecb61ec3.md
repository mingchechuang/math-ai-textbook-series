## 1. 重算與核對
1. **FTCS 截斷誤差符號**：
   - 原句：「代入並利用 $u_t = D u_{xx}$ 消去零階項，得 ... $\tau_h = \frac{\Delta t}{2} u_{tt} - \frac{D h^2}{12} u_{xxxx} + \dots$」
   - 重算：時間項 $\frac{u^{n+1}-u^n}{\Delta t} = u_t + \frac{\Delta t}{2}u_{tt}$。空間項 $D \frac{u_{i+1}-2u_i+u_{i-1}}{h^2} = D(u_{xx} + \frac{h^2}{12}u_{xxxx})$。
   - LTE 定義 $\tau = L_h u - f_h = (u_t + \frac{\Delta t}{2}u_{tt}) - D(u_{xx} + \frac{h^2}{12}u_{xxxx}) = \frac{\Delta t}{2}u_{tt} - \frac{D h^2}{12}u_{xxxx}$。
   - 原句後續將 $u_{tt}$ 替換為 $D u_{xxxx}$ 後寫成「$\frac{D^2 \Delta t}{2} u_{xxxx} - \frac{D h^2}{12} u_{xxxx}$」。
   - **問題**：此處符號本身沒錯（基於泰勒展開的殘差），但需注意 $u_{tt} = D u_{xxxx}$ 是基於 PDE $u_t = D u_{xx}$ 對時間再求導。若 $D$ 常數，則 $u_{tt} = D u_{xxxx}$。公式邏輯正確。
   - **但是**，原句在「例題 1」中手算：
     - $u_{tt} = 0.02$, $u_{xxxx} = 5$.
     - 時間項：$\frac{\Delta t}{2} u_{tt} = \frac{0.005}{2} \times 0.02 = 5.0 \times 10^{-5}$. 正確。
     - 空間項：$-\frac{D h^2}{12} u_{xxxx} = -\frac{0.1 \times (0.01)^2}{12} \times 5 = -\frac{0.1 \times 10^{-4}}{12} \times 5 = -\frac{5 \times 10^{-5}}{12} \approx -4.17 \times 10^{-6}$.
     - 原句寫：「$-4.17\times 10^{-7}\,\\mathrm{K/s}$」。
     - 重算：$5 \times 10^{-5} / 12 \approx 4.166 \times 10^{-6}$。
     - **錯誤**：原句少了一個數量級（$10^{-7}$ vs $10^{-6}$）。

2. **MMS Poisson 誤差估算**：
   - 原句預期輸出：`errs ≈ [4.0e-4, 1.0e-4, 2.5e-5, 6.3e-6]`。
   - 理論誤差常數：對於 $u^* = \sin(\pi x)$，二階中心差分 Poisson 求解器的 $L_2$ 誤差常數 $C \approx \frac{\pi^4}{12} \frac{1}{\sqrt{3}\pi} \dots$ 或簡單估算。
   - 已知二階精度的 $L_2$ 誤差通常比例於 $h^2$。
   - $N=8, h=0.125$. $N=64, h=0.015625$. 比例 $8^2 = 64$ 倍減少。
   - 若 $N=8$ 時 $E \approx 4e-4$，則 $N=64$ 時 $E \approx 4e-4 / 64 \approx 6.25e-6$。
   - 原句預期值符合二階收斂的數量級關係。此處無誤。

3. **習題 4 (b) 中心格式能量**：
   - 原句：「中心 FTCS 的離散能量 ... 不下降 ... 無條件不穩定」。
   - 對於平流方程，中心差分的放大因子 $|G| > 1$ 當 $\mathrm{CFL} > 0$（除零頻外）。能量確實不下降且增長。描述正確。

## 2. 可定位原句、原因與最小修法

### 錯誤 1：例題 1 空間項手算數量級錯誤
- **原句**：
  ```
  空間項：$-\\dfrac{D h^2}{12} u_{xxxx} = -\\dfrac{0.1 \\times (0.01)^2}{12} \\times 5 = -4.17\\times 10^{-7}\\,\\mathrm{K/s}$。
  ```
- **原因**：
  計算 $\frac{0.1 \times 0.0001}{12} \times 5 = \frac{0.00005}{12} \approx 4.167 \times 10^{-6}$。原句寫成 $10^{-7}$，少了一個零。
- **最小修法**：
  將 `10^{-7}` 改為 `10^{-6}`。

### 錯誤 2：Lax 定理陳述中的範數一致性表述不夠嚴謹（風格/準確性）
- **原句**：
  ```
  **穩定**：必須在與收斂相同的範數下、對所有 $\\Delta t, h$ 一致成立。
  ```
- **原因**：
  Lax 定理的「穩定」通常定義為對初始誤差的有界性（von Neumann 穩定性在 $L_2$ 或 $L_\infty$）。雖然定理確實要求在收斂範數下穩定，但此處表述尚可。
  *然而*，原句前面說「三者也必須在同一個範數下討論」，這在一般教科書中是必要的。此點視為正確，不作為阻擋錯誤。

### 錯誤 3：習題 2 解答中 Neumann 相容性積分錯誤
- **原句**：
  ```
  $\\int_0^1 f\\,dx = -\\pi^2[\\sin(\\pi x)/\\pi]_0^1 = 0$
  ```
- **原因**：
  $f(x) = -\pi^2 \cos(\pi x)$。
  積分 $\int_0^1 -\pi^2 \cos(\pi x) dx = -\pi^2 [\frac{1}{\pi} \sin(\pi x)]_0^1 = -\pi [\sin(\pi) - \sin(0)] = 0$。
  計算結果正確。
  *但是*，原句寫的是 $u^*(x) = \cos(\pi x)$。
  $u^{*'} = -\pi \sin(\pi x)$。
  $u^{*'}(0) = 0$, $u^{*'}(1) = -\pi \sin(\pi) = 0$。Neumann 邊界條件 $u'(0)=u'(1)=0$ 滿足。
  $u^{*''} = -\pi^2 \cos(\pi x)$。
  方程 $u'' = f \implies f = -\pi^2 \cos(\pi x)$。
  相容性 $\int_0^1 f dx = 0$ 滿足。
  此處無誤。

### 錯誤 4：程式碼中 `solve_poisson_1d` 的邊界處理
- **原句（程式碼）**：
  ```python
  u = np.concatenate(([0.0], u_int, [0.0]))
  ```
- **原因**：
  對於 $u'' = f, u(0)=u(1)=0$，內部點方程 $u_{i-1} - 2u_i + u_{i+1} = h^2 f_i$。
  當 $i=1$ 時，$u_0$ 已知為 0，所以 $-2u_1 + u_2 = h^2 f_1$。
  矩陣 $A$ 的構造：
  `k=0` (對應 $i=1$): `A[0,0]=-2.0`. 沒有 `A[0, -1]` 因為 $u_0$ 移到右邊。
  這裡 $b = h^2 f(x_{int})$。
  當 $i=1$, 項 $u_0$ 為 0，所以 $b_0$ 不需調整？
  正確方程：$u_0 - 2u_1 + u_2 = h^2 f_1 \implies -2u_1 + u_2 = h^2 f_1 - u_0$.
  因為 $u_0=0$，所以 $b_0 = h^2 f_1$ 是正確的。
  當 $i=N-1$ (最後一個內部點), $u_N=0$，同理 $b_{N-2} = h^2 f_{N-1}$。
  程式碼邏輯正確。

### 錯誤 5：「故障案例二」的描述邏輯
- **原句**：
  ```
  將 $u_0 = 0$ 換成 $(-3u_0 + 4u_1 - u_2)/(2h) = 0$
  ```
- **原因**：
  這是試圖用二階單邊差分來近似 $u'(0)=0$ (Neumann) 或者是說原本 Dirichlet $u(0)=0$ 被換成了這個？
  如果原問題是 Dirichlet $u(0)=0$，換成這個式子就改變了邊界條件的本質。
  但如果是指「將邊界處的未知數處理方式改動」，這個描述稍微模糊。
  通常測試「邊界殺手」是：內部二階，邊界用一階 ghost 或延遲。
  這裡的具體公式 $(-3u_0 + 4u_1 - u_2)/(2h) = 0$ 是 $u'(0)$ 的二階近似。
  如果這是一個 Neumann 問題，這其實是**二階**正確的邊界處理。
  如果這是一個 Dirichlet 問題 $u(0)=0$，你不能用 $u'(0)=0$ 來替代。
  原句說「將 $u_0 = 0$ 換成 ...」，意味著邊界條件從 $u=0$ 變成了 $u'=0$ 的离散形式？這會徹底改變問題。
  更可能的意圖是：在組裝系統時，錯誤地使用了低階邊界近似導致全域階數下降。
  但這裡給出的公式是二階精度的導數近似。如果用於 Neumann，它不會把階數拉低到 1。
  如果用於 Dirichlet $u(0)=0$，你應該直接設 $u_0=0$。
  這裡的描述容易引起混淆：用二階單邊差分替代 Dirichlet 值，這不僅是階數問題，而是邊界條件錯誤。
  **建議修法**：明確說明是「將二階內部的邊界行改為一階近似（例如 ghost 點 $u_0 = u_1$ 或類似），從而引入 $O(h)$ 誤差」。或者修正案例為：「若邊界處使用一階 ghost cell 策略 $u_{-1}=u_1$ (對應 $u''=0$? 不對，對應 $u'(0)=0$ 的一階?)」。
  通常殺手是：內部二階中心，邊界處用一階前向/後向差分來計算 Laplacian，或者 ghost 值設定不匹配二階精度。
  例如：$u_0$ 用 $u_1 - h u'_0$ (一階) 而非二階。
  原句的具體例子 $(-3u_0 + 4u_1 - u_2)/(2h) = 0$ 是 $u'(0)=0$ 的二階格式。如果原問題是 $u(0)=0$，這根本是錯的邊界。
  **判定**：此處例子選擇不當或描述不清，可能誤導讀者以為這是「階數下降」的標準範例，而實際上這是「邊界條件錯誤」。標準的「階數下降」範例是邊界處理僅有一階精度（如 $u_0 \approx u_1$ 用於 $u'=0$ 是錯誤的，$u_0 = u_1$ 是零階？不，$u'(0)=0$ 若用 $u_1-u_0=0$ 則 $u_0=u_1$，這是 $O(h)$ 精度對 $u'$，對 $u$ 也是 $O(h)$ 相對誤差？不，若 $u$ 平滑，$u_1 = u_0 + h u'_0 + \dots = u_0 + O(h^2)$ 若 $u'_0=0$。所以 $u_0=u_1$ 是 $O(h^2)$ 誤差？
  讓 $u(x) = x^2$. $u(0)=0, u'(0)=0$.
  $u_1 = h^2$.
  Ghost $u_{-1} = u_1 = h^2$.
  中心差分在 $i=0$ (如果計算): $(u_1 - 2u_0 + u_{-1})/h^2 = 2$. True $u''(0)=2$. Error $O(h^2)$.
  所以 $u_{-1}=u_1$ 對 $u'=0$ 是二階相容的。
  那麼什麼是「一階邊界殺手」？
  如果是 Dirichlet $u(0)=A$，內部二階。若你在計算 $u_1$ 的方程時，錯誤地使用了 $u_0$ 的近似值，或者邊界行的係數不對。
  或者，在 Neumann 問題中，使用 $u_{-1} = u_1 - 2h u'_0$ (若 $u'_0 \neq 0$) 這是一階？
  通常，**單邊差分算子本身是一階或二階**。如果邊界處用一階單邊差分來計算導數並強加條件，可能導致降階。
  鑑於此處技術細節容易出錯且原句例子 $(-3u_0+4u_1-u_2)/2h=0$ 是二階公式，用它來產生「一階全域收斂」的說法是**矛盾**的，因為這個公式本身不是一階誤差的來源（對 $u'=0$ 而言）。
  **必須修正**：將案例改為明確的「一階邊界近似」，例如：「將邊界處理改為一階 ghost cell 規則 $u_{-1} = u_1 - 2h u'(0)$ 但 $u'(0)$ 用一階差分估計」，或更簡單的：「在邊界點僅使用一階中心差分（如果可能）或一階單邊差分來處理邊界貢獻」。
  最安全的修法：將該故障案例描述改為「若邊界條件的離散僅具有一階精度（例如使用一階 forward difference 來施加 Neumann 條件 $u'(0)=0 \implies (u_1-u_0)/h = 0 \implies u_0=u_1$，注意：如上分析，對 $u \sim x^2$ 這是 $O(h^2)$？不，若 $u=x$ (非零導數)，$u_0 = u_1 - h$. 若 $u_0=u_1$，誤差 $O(h)$. 所以對 $u' \neq 0$ 的 Neumann，$u_0=u_1$ 是一階誤差。對 $u'=0$，它意外地是二階。
  為了避免這種微積分陷阱，建議改為：「使用一階單邊差分來計算邊界處的 Laplacian 或源項」，或簡單地說「邊界行使用一階精度的格式」。

  **具體修改建議**：
  原句：`將 $u_0 = 0$ 換成 $(-3u_0 + 4u_1 - u_2)/(2h) = 0$`
  此處 $u_0=0$ 是 Dirichlet。換成這個公式是把它變成 Neumann $u'(0)=0$ 的二階實現。這不僅降階，而是**改變了物理邊界條件**。
  如果目的是測試「邊界處理精度影響全域收斂」，應該保持邊界條件不變，只降低其**離散精度**。
  例如：原問題 $u(0)=0$。正確處理是 $u_0=0$。
  錯誤處理：假設我們誤用 $u_0 \approx u_1 - h u'_0$，而 $u'_0$ 用 $(u_1-u_0)/h$ 估計？循環論證。
  或者，對於 $u''=f$，邊界點 $i=0$ 不参与未知數求解。
  最常見的「邊界殺手」是在**非均勻網格**或**複雜邊界**，或者**Neumann 問題**中。
  在純 Dirichlet Poisson 1D 均勻網格中，只要 $u_0, u_N$ 精確給定，內部二階保證全域二階。無法通過「改變 $u_0=0$ 的寫法」來製造階數下降，除非你**不精確**給定 $u_0$。
  例如：$u_0$ 是用外推得到的，且外推僅一階。
  **因此，該測試案例對於 Dirichlet 1D Poisson 來說，設計上是有問題或描述嚴重的錯誤。**

  **建議修法**：將「故障案例二」改為針對 **Neumann 問題** 的一階 ghost cell 錯誤，或說明在 Dirichlet 問題中若邊界值 $u(0)$ 的插值僅一階精度（例如在細化網格中重映射時），會導致全域一階。
  簡化修法：將該案例刪除或修改為「若邊界條件的離散精度低於內部格式精度（例如對 Neumann 問題使用一階 ghost 值 $u_{-1} = u_1 - 2h u'_0$ 其中 $u'_0$ 由一階差分給定），全域收斂將退化為一階。」

## 3. 總結
主要阻擋錯誤為 **例題 1 的數量級計算錯誤** 和 **故障案例二的邏輯/物理不一致**。

**最小修法清單：**
1. 例題 1 中 `-4.17\times 10^{-7}` 改為 `-4.17\times 10^{-6}`。
2. 故障案例二：原描述混淆了邊界條件類型與精度問題。建議改為：「**故障案例二：邊界離散精度不足**。若在 Neumann 問題 $u'(0)=0$ 中，使用一階 ghost cell 規則 $u_{-1} = u_1 - 2h u'(0)$ 但 $u'(0)$ 通過一階差分近似，或使用 $u_{-1}=u_1$ (對 $u \neq$ 常數且 $u'(0) \neq 0$ 時為一階誤差)，則邊界引入 $O(h)$ 誤差，全域觀測階會從 2 降為 1。」（需配合將 MMS 測試對象暫時切換為 Neumann 或說明此為一般性警告）。
   *或者更簡單地*：將該案例改為「若程式碼中錯誤地將二階中心差分用於邊界點（例如使用非對稱的一階單邊差分來計算 $u''$ 在邊界附近的貢獻），會導致收斂階數下降。」

鑑於故障案例二的具體數學公式 $(-3u_0+4u_1-u_2)/2h=0$ 是二階格式，卻聲稱導致一階收斂（在該特定 Neumann 零導數情境下甚至可能維持二階，或若作為 Dirichlet 則是錯題），該處必須修正以符合數值分析事實。
