## 1. 重算與核對

### 1.1 截斷誤差（LTE）符號與量綱
- **原句**：「$\tau_h = \frac{\Delta t}{2} u_{tt} - \frac{D h^2}{12} u_{xxxx} + \dots$」
- **重算**：
  - 時間項：$\frac{u^{n+1}-u^n}{\Delta t} = u_t + \frac{\Delta t}{2}u_{tt} + O(\Delta t^2)$
  - 空間項：$D \frac{u^{n}_{i+1}-2u^n_i+u^n_{i-1}}{h^2} = D(u_{xx} + \frac{h^2}{12}u_{xxxx} + O(h^4))$
  - PDE: $u_t = D u_{xx}$
  - 殘差 $\tau = (u_t + \frac{\Delta t}{2}u_{tt}) - D(u_{xx} + \frac{h^2}{12}u_{xxxx}) = \frac{\Delta t}{2}u_{tt} - \frac{D h^2}{12}u_{xxxx}$
  - 利用 $u_t = D u_{xx} \implies u_{tt} = D u_{xxxx}$ (若 D 為常數)
  - $\tau = \frac{D \Delta t}{2}u_{xxxx} - \frac{D h^2}{12}u_{xxxx}$
- **核對**：原句寫成 $\frac{D^2 \Delta t}{2} u_{xxxx}$。這裡 $u_{tt}$ 的替換有疑問。
  - $u_t = D u_{xx}$
  - $u_{tt} = \partial_t (D u_{xx}) = D \partial_t (u_{xx}) = D (u_{xx})_t = D (u_t)_{xx} = D (D u_{xx})_{xx} = D^2 u_{xxxx}$ (若 D 常數)
  - 所以 $\frac{\Delta t}{2} u_{tt} = \frac{D^2 \Delta t}{2} u_{xxxx}$。
  - **結論**：公式正確。

### 1.2 例題 1 手算
- **參數**：$D=0.1, h=0.01, \Delta t=0.005, u_{tt}=0.02, u_{xxxx}=5$。
- **時間項**：$\frac{0.005}{2} \times 0.02 = 0.0025 \times 0.02 = 5.0 \times 10^{-5}$。正確。
- **空間項**：$-\frac{0.1 \times (0.01)^2}{12} \times 5 = -\frac{0.1 \times 10^{-4}}{12} \times 5 = -\frac{5 \times 10^{-5}}{12} \approx -4.167 \times 10^{-6}$。
- **原句**：「$-4.17\times 10^{-6}$」。正確。
- **量綱**：$u_{tt}$ (K/s^2) * s = K/s。$D$ (m^2/s) * h^2 (m^2) * u_{xxxx} (K/m^4) = K/s。一致。

### 1.3 例題 2 MMS Poisson
- **解**：$u^* = \sin(\pi x)$。$u'' = -\pi^2 \sin(\pi x)$。$f = u''$。
- **離散算子**：$L_h u = \frac{u_{i-1}-2u_i+u_{i+1}}{h^2}$。
- **LTE**：$L_h u^* - f^* = \frac{h^2}{12}u^{*''''} = \frac{h^2}{12}\pi^4 \sin(\pi x)$。
- **計算**：
  - $N=4, h=0.25$。$x=0.5$。
  - $\tau \approx \frac{0.25^2}{12} \pi^4 \times 1 = \frac{0.0625}{12} \times 97.409 \approx 0.507$。正確。
  - $N=8, h=0.125$。
  - $\tau \approx \frac{0.125^2}{12} \pi^4 = \frac{1}{16} \times 0.507 \approx 0.0317$？
  - 原句寫：「$N=8: \tau \approx 0.127$」。
  - 重算：$h$ 減半，$h^2$ 減為 $1/4$。
  - $0.507 / 4 = 0.12675 \approx 0.127$。正確。
  - 比值 $0.507/0.127 \approx 4 = 2^2$。符合二階。

### 1.4 程式碼邏輯
- `solve_poisson_1d`: 標準三對角矩陣求解。邊界 $u_0=u_N=0$ 已消去。
- `b = h^2 f(x_int)`。正確，因為方程是 $(u_{i-1}-2u_i+u_{i+1}) = h^2 f_i$。
- `err = sqrt(h sum(e^2))`。這是 $L_2$ 範數的黎曼和近似。
- **問題**：對於 $N$ 個內部點，$L_2$ 範數定義為 $\sqrt{\int_0^1 e^2 dx} \approx \sqrt{\sum_{i=1}^{N-1} e_i^2 h}$。
- 預期誤差 $O(h^2)$。
- $N=8, h=0.125$。$N=64, h=0.015625$。
- $h$ 比例 $1/8$。$h^2$ 比例 $1/64$。
- 預期 $E_8 \approx 4.0e-4$。$E_{64} \approx 4.0e-4 / 64 \approx 6.25e-6$。
- 原句預期：`[4.0e-4, ..., 6.3e-6]`。符合推導。

### 1.5 習題 3 反例
- **原句**：「$\|x - x^*\| \le \|A^{-1}\| \cdot \|r\| \le \kappa(A) \|x^*\| \frac{\|r\|}{\|b\|}$」
- **核對**：
  - $Ax=b, Ax_h=b+r$ (殘差定義 $r=b-Ax_h$ 或 $r=Ax_h-b$? 通常 $r=b-Ax$).
  - $A(x^*-x_h) = Ax^* - Ax_h = b - (b-r) = r$.
  - $\|x^*-x_h\| = \|A^{-1}r\| \le \|A^{-1}\| \|r\|$.
  - $\|A^{-1}\| = \frac{1}{\sigma_{min}}$. $\kappa(A) = \frac{\sigma_{max}}{\sigma_{min}}$.
  - $\|A^{-1}\| = \kappa(A) \frac{1}{\|A\|}$.
  - 不等式 $\|x^*-x_h\| \le \kappa(A) \frac{\|r\|}{\sigma_{min}}$ 是標準界。
  - 原句寫 $\kappa(A) \|x^*\| \frac{\|r\|}{\|b\|}$。
  - 這依賴於 $\|b\| \approx \|A\| \|x^*\|$ (若 $x^*$ 方向與 $A$ 主特徵向量一致) 且 $\|r\|/\|b\|$ 是相對殘差。
  - 這是一個常用的工程估算，雖然嚴謹的界是 $\|A^{-1}\|\|r\|$，但作為「病態放大」的直覺說明，此不等式在數值分析教材中常見，用於解釋為何相對殘差小但相對誤差大（當 $\kappa$ 大時）。
  - **判定**：可接受。

### 1.6 故障案例二：Dirichlet 邊界精度
- **原句**：「全域誤差會被此 $O(h)$ 邊界項主導... 收斂階被限制為一階... 在粗網格下觀測階可能介於 1 與 2 之間...」
- **分析**：
  - 邊界誤差 $O(h)$ 會在邊界層產生影響。
  - 對於 Poisson 問題，邊界誤差 $e_0 = O(h)$ 會通過差分方程傳播到內部。
  - 全域誤差 $E_h = \max(|e_i|)$ 或 $\|e\|_2$。
  - 若邊界條件錯誤導致 $O(h)$ 誤差，通常全域誤差會退化为 $O(h)$。
  - 觀測階應趨近 1。
  - 原句描述「介於 1 與 2 之間... 逐漸趨近 1」是合理的漸進行為描述，因為在極粗網格下，$O(h^2)$ 項可能還與 $O(h)$ 項相當（若係數不同），但隨著 $h$ 減小，$O(h)$ 主導。
  - **判定**：描述準確，未做絕對斷言，符合數值實驗現象。

### 1.7 習題 4 中心格式能量
- **原句**：「中心 FTCS ... 放大因子 $|g|^2 = 1 + (CFL)^2 \sin^2(k\Delta x) > 1$，無條件不穩定。」
- **核對**：
  - 平流方程 $u_t + a u_x = 0$。
  - 中心差分離散：$u_i^{n+1} = u_i^n - \frac{a \Delta t}{2 \Delta x}(u_{i+1}^n - u_{i-1}^n)$。
  - 離散色散關係：$G = 1 - i \mu \sin \theta$，其中 $\mu = \frac{a \Delta t}{\Delta x}, \theta = k \Delta x$。
  - $|G|^2 = 1 + \mu^2 \sin^2 \theta$。
  - 若 $\mu > 0$ 且 $\sin \theta \neq 0$，則 $|G|^2 > 1$。
  - 能量增長。不穩定。
  - **判定**：正確。

## 2. 可定位原句、原因與最小修法

### 疑慮 1：例題 2 LTE 符號一致性
- **原句**：
  ```
  L_h u^*\big|_{x_i} = u^{*''}(x_i) + \frac{h^2}{12} u^{*''''}(x_i) + \dots = -\pi^2 \sin(\pi x_i) + \frac{h^2}{12} \pi^4 \sin(\pi x_i) + \dots
  所以 LTE $\tau_h(x_i) = \frac{h^2}{12} \pi^4 \sin(\pi x_i) + \dots$
  ```
- **原因**：
  定義 LTE 為 $L_h u^* - f_h$。
  這裡 $f_h$ 是 PDE 右邊項在網格上的值，即 $f(x_i) = u^{*''}(x_i)$。
  所以 $\tau_h = (u^{*''} + \frac{h^2}{12}u^{*''''}) - u^{*''} = \frac{h^2}{12}u^{*''''}$。
  符號正確。
- **判定**：無誤。

### 疑慮 2：程式碼中 $N$ 的定義與 $h$
- **原句**：
  ```python
  h = 1.0 / N
  x = np.linspace(0.0, 1.0, N + 1)
  ...
  A = np.zeros((N - 1, N - 1))
  ```
- **原因**：
  若 $N=8$，網格點數 $9$ ($0..8$)。內部點 $7$ 個。
  $h = 1/8$。
  矩陣大小 $(8-1) \times (8-1) = 7 \times 7$。正確。
- **判定**：無誤。

### 疑慮 3：習題 2 Neumann 相容性
- **原句**：
  ```
  $u^* = \cos(\pi x)$，$u^{*'} = -\pi\sin(\pi x) = 0$ at $x=0,1$
  ```
- **原因**：
  $\sin(0)=0, \sin(\pi)=0$。導數為 0。
  $u^{*''} = -\pi^2 \cos(\pi x)$。
  $\int_0^1 -\pi^2 \cos(\pi x) dx = -\pi^2 [\frac{1}{\pi}\sin(\pi x)]_0^1 = 0$。
  相容性滿足。
- **判定**：無誤。

### 疑慮 4：Lax 定理的適用範圍
- **原句**：「對**線性、適定**的初值問題... 非線性... 不直接適用。」
- **原因**：
  Lax-Richtmyer 定理確切上是針對線性問題。非線性有泛化，但條件更複雜（如單調算子、熵解等）。
  原句已明列限制。
- **判定**：無誤。

### 疑慮 5：故障案例三 範數影響
- **原句**：「若省略 $h$ 權重... 觀測階會變成 1.5 而非 2.0。」
- **分析**：
  $L_2$ 誤差 $E \sim h^2$。
  $\|e\|_2 \sim h^2$。
  $\|e\|_{L_2} = \sqrt{\sum e_i^2 h} \sim \sqrt{N \cdot h^4 \cdot h} = \sqrt{\frac{1}{h} h^5} = h^2$。
  未加權 $L_2$ (即 $l_2$ 範數) $\sqrt{\sum e_i^2} \sim \sqrt{N \cdot h^4} = \sqrt{\frac{1}{h} h^4} = h^{3/2}$。
  所以觀測階從 2 變為 1.5。
- **判定**：計算正確。
