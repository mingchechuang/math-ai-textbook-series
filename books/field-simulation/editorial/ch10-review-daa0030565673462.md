## 審稿結論

**須修正一維程式的擴散更新；目前它與手算例及守恆主張不符。**

1. **一維通量差符號錯誤。**「實作與程式」中：
   ```python
   rate = (dr * dright - dl * dleft) / dx**2
   ```
   其中 `dleft = np.roll(q, 1) - q` 已是「左鄰格減本格」。依稿內四格初值手算，現式在第 0 格給出 $(-1)-(-1)=0$，在第 1 格給出 $0-1=-1$；更新不會得到聲稱的 $(0.8,0.1,0,0.1)$，總量也不守恆。**最小修法：**改為 `rate = (dr * dright + dl * dleft) / dx**2`，並保留現有四格結果與總量測試作為回歸檢查。

2. **手算例混用通量密度與整面通量的單位。**「例一」把 $F_{i+1/2}$ 定義成逐面量，卻將結果標為 $\mathrm{kg/(m^2s)}$；前文已定義 $F=AJ$，故 $F$ 應為 $\mathrm{kg/s}$。例二的 $F_{1/2}$ 也有同樣問題。兩例因面積恰為 $1\,\mathrm{m^2}$，數值不變，但不能省略單位區別。**最小修法：**若沿用符號 $F$，將逐面結果改標 $\mathrm{kg/s}$；或改稱 $J$，並在更新式明寫 $F=AJ$。

上述是可由稿內公式直接重算的問題，無須以執行結果推斷。修正後，一維程式的守恆與非負性敘述才有相應的實作依據。
