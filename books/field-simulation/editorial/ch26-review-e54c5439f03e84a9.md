# 第26章 能量泛函與變分梯度流 審稿意見

## 1. 重算與核對

### 1.1 界面能量 (Interface Energy) 重算
*   **原句**：$\sigma = \frac{2\sqrt{2}}{3} \sqrt{\kappa}$。
*   **重算**：
    *   能量泛函 $F[\phi] = \int_{-\infty}^{\infty} \left[ W(\phi) + \frac{\kappa}{2} (\phi')^2 \right] dx$，其中 $W(\phi) = \frac{(\phi^2-1)^2}{4}$。
    *   穩態方程（Euler-Lagrange）：$\mu = W'(\phi) - \kappa \phi'' = 0$。
    *   $W'(\phi) = \phi^3 - \phi$。
    *   $\phi^3 - \phi - \kappa \phi'' = 0$。
    *   乘以 $\phi'$ 並積分：
        $$ \int (\phi^3 - \phi) \phi' dx - \kappa \int \phi'' \phi' dx = 0 $$
        $$ \frac{\phi^4}{4} - \frac{\phi^2}{2} - \frac{\kappa}{2} (\phi')^2 = C $$
    *   邊界條件 $\phi \to \pm 1, \phi' \to 0$。
        $C = \frac{1}{4} - \frac{1}{2} - 0 = -\frac{1}{4}$。
        或者寫成 $W(\phi) - \frac{\kappa}{2}(\phi')^2 = W(\pm 1) = 0 \implies W(\phi) = \frac{\kappa}{2}(\phi')^2$。
    *   $\frac{\kappa}{2} (\phi')^2 = \frac{(\phi^2-1)^2}{4} \implies \phi' = \pm \frac{1-\phi^2}{\sqrt{2\kappa}}$ (取正支)。
    *   界面能量 $\sigma = \int_{-\infty}^{\infty} \left[ W(\phi) + \frac{\kappa}{2} (\phi')^2 \right] dx = \int_{-\infty}^{\infty} 2 W(\phi) dx$。
    *   換元 $dx = \frac{\sqrt{2\kappa}}{1-\phi^2} d\phi$。
    *   $\sigma = \int_{-1}^{1} 2 \cdot \frac{(1-\phi^2)^2}{4} \cdot \frac{\sqrt{2\kappa}}{1-\phi^2} d\phi = \frac{\sqrt{2\kappa}}{2} \int_{-1}^{1} (1-\phi^2) d\phi$。
    *   $\int_{-1}^{1} (1-\phi^2) d\phi = \left[ \phi - \frac{\phi^3}{3} \right]_{-1}^{1} = \frac{4}{3}$。
    *   $\sigma = \frac{\sqrt{2\kappa}}{2} \cdot \frac{4}{3} = \frac{2\sqrt{2\kappa}}{3} = \frac{2\sqrt{2}}{3} \sqrt{\kappa}$。
*   **結論**：計算正確。

### 1.2 習題 2 解析解與手算驗證
*   **原句**：$\phi_t = \phi - \phi^3$。解析解 $\phi(t) = \frac{\phi_0 e^t}{\sqrt{1 - \phi_0^2 + \phi_0^2 e^{2t}}}$。
*   **重算**：
    *   $\frac{d\phi}{dt} = \phi(1-\phi^2)$。
    *   $\frac{d\phi}{\phi(1-\phi^2)} = dt$。
    *   部分分式：$\frac{1}{\phi(1-\phi^2)} = \frac{1}{\phi} + \frac{1}{2}\left(\frac{1}{1-\phi} - \frac{1}{1+\phi}\right)$。
    *   積分：$\ln|\phi| - \frac{1}{2}\ln|1-\phi| - \frac{1}{2}\ln|1+\phi| = t + C$。
    *   $\ln \left( \frac{\phi}{\sqrt{1-\phi^2}} \right) = t + C$。
    *   $\frac{\phi}{\sqrt{1-\phi^2}} = A e^t$，其中 $A = \frac{\phi_0}{\sqrt{1-\phi_0^2}}$。
    *   $\phi^2 = A^2 e^{2t} (1-\phi^2) \implies \phi^2 (1 + A^2 e^{2t}) = A^2 e^{2t} \implies \phi = \frac{A e^t}{\sqrt{1+A^2 e^{2t}}}$。
    *   代入 $A$：
        $$ \phi(t) = \frac{\frac{\phi_0}{\sqrt{1-\phi_0^2}} e^t}{\sqrt{1 + \frac{\phi_0^2 e^{2t}}{1-\phi_0^2}}} = \frac{\phi_0 e^t}{\sqrt{1-\phi_0^2 + \phi_0^2 e^{2t}}} $$
*   **手算驗證** ($\phi_0=0.5, \Delta t=0.1$)：
    *   $t=0.1$。
    *   $e^{0.1} \approx 1.10517$。
    *   $e^{0.2} \approx 1.22140$。
    *   分母：$\sqrt{0.75 + 0.25(1.22140)} = \sqrt{0.75 + 0.30535} = \sqrt{1.05535} \approx 1.02730$。
    *   分子：$0.5 \times 1.10517 = 0.552585$。
    *   $\phi(0.1) \approx 0.552585 / 1.02730 \approx 0.53790$。
    *   歐拉第一步：$\phi^1 = 0.5 + 0.1(0.5 - 0.125) = 0.5375$。
    *   誤差 $\approx 0.0004$。符合一階收斂。
    *   $t=0.2$。
    *   $e^{0.2} \approx 1.22140$。
    *   $e^{0.4} \approx 1.49182$。
    *   分母：$\sqrt{0.75 + 0.25(1.49182)} = \sqrt{0.75 + 0.372955} = \sqrt{1.122955} \approx 1.059695$。
    *   分子：$0.5 \times 1.22140 = 0.61070$。
    *   $\phi(0.2) \approx 0.61070 / 1.059695 \approx 0.57631$。
    *   歐拉第二步：$\phi^1 = 0.5375$。
    *   $\phi^2 = 0.5375 + 0.1(0.5375 - 0.5375^3) = 0.5375 + 0.1(0.5375 - 0.15556) = 0.5375 + 0.038194 = 0.575694$。
    *   誤差 $|0.57631 - 0.57569| \approx 0.00062$。
    *   原句寫誤差約 $6 \times 10^{-4}$。正確。

### 1.3 Hessian 特徵值與穩定性
*   **原句**：$\lambda_{\max} \approx 18.4$。
*   **重算**：
    *   $\mu = \phi^3 - \phi - \kappa \Delta \phi$。
    *   線性化：$\delta \mu \approx (3\phi^2 - 1) \delta \phi - \kappa \Delta \delta \phi$。
    *   特徵值問題：$\lambda_i \approx W''(\phi_i) - \kappa \lambda_i^{Laplacian}$。
    *   週期網格 Laplacian 最大特徵值（Nyquist）為 $\frac{4}{\Delta x^2}$。
    *   $\Delta x = 1/64 = 2^{-6}$。$\Delta x^2 = 2^{-12} \approx 2.44 \times 10^{-4}$。
    *   $\frac{4}{\Delta x^2} = 4 \times 64^2 = 16384$。
    *   $\kappa = 10^{-3}$。
    *   梯度項貢獻：$\kappa \frac{4}{\Delta x^2} = 10^{-3} \times 16384 = 16.384$。
    *   雙井項貢獻：$W''(\phi) = 3\phi^2 - 1$。最大值在 $\phi=\pm 1$ 為 $2$。
    *   $\lambda_{\max} \approx 2 + 16.384 = 18.384 \approx 18.4$。
    *   穩定條件 $M \Delta t \lambda_{\max} < 2 \implies \Delta t < 2/18.4 \approx 0.108$。
    *   原句估算正確。

### 1.4 程式碼檢查
*   `chem_potential_1d`:
    *   `lap = (np.roll(phi, -1) - 2.0 * phi + np.roll(phi, 1)) / dx ** 2`
    *   `mu = (phi ** 3 - phi) - kappa * lap`
    *   符合 $\mu = \phi^3 - \phi - \kappa \Delta \phi$。
*   `free_energy_1d`:
    *   `W = 0.25 * (phi ** 2 - 1.0) ** 2`
    *   `grad = (np.roll(phi, -1) - phi) / dx`
    *   `return dx * np.sum(W + 0.5 * kappa * grad ** 2)`
    *   符合 $F_h = \sum \Delta x [W + \frac{\kappa}{2} |\nabla \phi|^2]$。
*   `gradient_check_demo`:
    *   `lhs = grad_check(F, phi, v, eps=1e-6)`
    *   `rhs = dx * np.sum(mu * v)`
    *   離散能量梯度 $\nabla F_h$ 的分量為 $\frac{\partial F_h}{\partial \phi_i}$。
    *   對於週期網格，$\frac{\partial F_h}{\partial \phi_i} = \Delta x \mu_i$。
    *   方向導數 $\nabla F_h \cdot \mathbf{v} = \sum \frac{\partial F_h}{\partial \phi_i} v_i = \sum \Delta x \mu_i v_i$。
    *   程式碼 `rhs` 正確對應理論值。

## 2. 可定位原句、原因、最小修法

### 疑慮 1：邊界案例 ($\kappa=0$) 的 $\lambda_{\max}$ 描述
*   **原句**：
    ```
    **邊界案例（$\kappa = 0$）**：... $\lambda_{\max} = \max_i |3\phi_i^2 - 1|$ ...
    ```
*   **原因**：
    當 $\kappa=0$ 時，$\mu_i = \phi_i^3 - \phi_i$。
    顯式歐拉：$\phi^{n+1} = \phi^n - \Delta t (\phi_n^3 - \phi_n)$。
    穩定性取決於 Jacobian $J = 1 - \Delta t W''(\phi_n)$，其中 $W''(\phi) = 3\phi^2 - 1$。
    穩定條件 $|1 - \Delta t W''(\phi)| < 1$。
    若 $W''(\phi) > 0$，需 $\Delta t W''(\phi) < 2$。
    若 $W''(\phi) < 0$（例如 $\phi=0$ 附近，$W''=-1$），$1 - \Delta t(-1) = 1+\Delta t > 1$，顯式歐拉**永遠不穩定**（這是物理上的不穩定性，$\phi=0$ 是鞍點，解會遠離 0 趨向 $\pm 1$）。
    原句寫 $\lambda_{\max} = \max |3\phi^2-1|$。
    在 $\phi \in [-1, 1]$ 範圍內，$|3\phi^2-1|$ 的最大值是 2（在 $\phi=\pm 1$）。
    在 $\phi=0$ 附近，$|3\phi^2-1|=1$。
    原句後續提到「$M \Delta t \lambda_{\max} < 2$ 僅是局部線性化估算... 反例... 能量反而上升」。
    這裡的邏輯是正確的，即顯式歐拉在 $\phi$ 接近 0 時雖然 $|J|>1$（放大），但這是物理預期（趨向 $\pm 1$），而在 $\phi$ 接近 $\pm 1$ 時若步長過大會導致振盪。
    原句的反例 $\phi^n=0.7$ 展示了步長過大導致能量上升。
    雖然 $\lambda_{\max}$ 的定義用絕對值稍微籠統（因為負曲率模態的行為不同），但結合理論解釋和反例，結論是嚴謹的。
    *判定*：無誤。

### 疑慮 2：習題 4 解答中 CH 符號
*   **原句**：
    ```
    演化式必須取 $+\Delta t\,\Delta_h\mu^{n+1}$；在本卷 $L \approx \Delta$ 為負半定 Laplacian 的約定下，負號會反轉耗散方向...
    ```
*   **原因**：
    Cahn-Hilliard: $\phi_t = \nabla \cdot (M \nabla \mu) = M \Delta \mu$ (若 M 常數)。
    離散：$\frac{\phi^{n+1} - \phi^n}{\Delta t} = M \Delta_h \mu^{n+1}$。
    $\phi^{n+1} = \phi^n + \Delta t M \Delta_h \mu^{n+1}$。
    符號是加號。
    如果寫成減號，就是 $\phi_t = - \Delta \mu$，能量 $F$ 會增加（$\frac{dF}{dt} = \int \mu (-\Delta \mu) = \int |\nabla \mu|^2 > 0$），這是錯誤的。
    原句解釋正確。
