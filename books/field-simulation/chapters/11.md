## 問題與直覺

一階迎風格式對標量線性平流穩定且守恆，卻有一個致命弱點：數值擴散過強。方波在數十步內被抹成斜坡，精細結構全數喪失。若把單元值理解為單元平均，那麼每個界面處回推特徵線時若能用更高階的分片多項式近似真解，理論上能壓低截斷誤差。

最簡單的想法是中心差分空間離散 $u_i' \approx (u_{i+1}-u_{i-1})/(2\Delta x)$，此式形式上是二階，卻在陡峭梯度附近產生 Gibbs 型過衝。這種振盪不是穩定性失效，而是缺乏單調性——格式在高波數附近仍有放大誤差的能力。

Godunov 的貢獻在於：把單元平均上的守恆更新視為求解分段常數初值下的 Riemann 問題，並以特徵線上風側的狀態作為界面通量，這天然給出單調格式，但僅有一階。MUSCL 重構則把分段常數升級為分段線性：每個單元透過左右界面外推值向鄰元延伸。若斜率不加限制，二階格式仍會振盪；TVD 限制器就是一個局部開關，在光滑區保留較大斜率、在極值或激波附近把斜率壓到零，使總變差不增。

## 數學與物理推導

**標量守恆律。** 設 $u(x,t)\ge 0$ 為一維標量密度，$a$ 為常數速度，連續方程為

$$\partial_t u + a\,\partial_x u = 0. \qquad (11.1)$$

特徵線 $\mathrm{d}x/\mathrm{d}t = a$，解沿特徵線不變。

**有限體積離散。** 在第 $i$ 個單元 $C_i = [(i-\tfrac12)\Delta x,\, (i+\tfrac12)\Delta x]$ 上定義單元平均

$$\bar u_i(t) = \frac{1}{\Delta x}\int_{C_i} u(x,t)\,\mathrm{d}x.$$

對 (11.1) 在 $C_i$ 上積分並用微積分基本定理：

$$\Delta x\,\frac{\mathrm{d}\bar u_i}{\mathrm{d}t} + \bigl(F_{i+1/2} - F_{i-1/2}\bigr) = 0,\quad F_{i+1/2} \approx a\,u\bigl((i+\tfrac12)\Delta x,\,t\bigr).$$

前向 Euler 時間步得守恆更新

$$\bar u_i^{n+1} = \bar u_i^n - \frac{\Delta t}{\Delta x}\bigl(F_{i+1/2} - F_{i-1/2}\bigr). \qquad (11.2)$$

(11.2) 是守恆的：內部面通量求和時兩兩抵消，週期邊界下 $\sum_i \bar u_i^{n+1} = \sum_i \bar u_i^n$。

**Godunov 通量。** 若把單元值近似為分片常數，$i+1/2$ 面兩側為 $u_i$（左）與 $u_{i+1}$（右），Riemann 解在 $x/t=a$ 處的值即上風狀態：

$$F_{i+1/2}^{\mathrm{God}} = \begin{cases} a\,u_i, & a > 0,\\[2pt] a\,u_{i+1}, & a < 0.\end{cases} \qquad (11.3)$$

此為迎風格式，在 CFL 條件 $|a|\Delta t/\Delta x \le 1$ 下穩定，且 TVD，但空間精度僅為 $\mathcal{O}(\Delta x)$。

**MUSCL 重構。** 在每單元上採用分片線性重構

$$u_i(x) = \bar u_i + s_i\,\frac{x - x_i}{\Delta x},\quad x \in C_i.$$

在 $i+1/2$ 面處向左、右兩側外推得

$$u_{i+1/2}^L = \bar u_i + \tfrac12 s_i,\qquad u_{i+1/2}^R = \bar u_{i+1} - \tfrac12 s_{i+1}.$$

Godunov 通量改以上風側重構值代入：

$$F_{i+1/2} = \begin{cases} a\,u_{i+1/2}^L, & a > 0,\\[2pt] a\,u_{i+1/2}^R, & a < 0.\end{cases} \qquad (11.4)$$

**斜率與限制器。** 定義前後差分

$$\Delta^+ u_i = u_{i+1} - u_i,\qquad \Delta^- u_i = u_i - u_{i-1}.$$

以斜率比 $r_i = \Delta^- u_i / \Delta^+ u_i$ 寫成

$$s_i = \phi(r_i)\,\Delta^- u_i,$$

其中 $\phi$ 為限制器函式。常用選擇：

- **minmod**：$\phi_{\min}(r) = \max(0,\min(1,r))$，等價於

$$s_i^{\min} = \mathrm{minmod}\bigl(\Delta^- u_i,\ \Delta^+ u_i\bigr),\quad
\mathrm{minmod}(p,q) = \begin{cases} \mathrm{sgn}(p)\min(|p|,|q|), & pq > 0,\\[2pt] 0, & pq \le 0.\end{cases}$$

- **superbee**：$\phi_{\mathrm{sb}}(r) = \max\bigl(0,\min(2r,1),\min(r,2)\bigr)$。
- **van Leer**：$\phi_{\mathrm{vL}}(r) = (r+|r|)/(1+|r|)$。

當 $pq \le 0$（含任一端為零）時 minmod 給出 $s_i = 0$，該單元退化為分片常數。這使極值處的外推不會越過鄰元取值範圍。

**TVD 條件。** 定義週期網格上的總變差

$$\mathrm{TV}(u^n) = \sum_i |u_{i+1}^n - u_i^n|,$$

格式稱為 TVD，若每步 $\mathrm{TV}(u^{n+1}) \le \mathrm{TV}(u^n)$。Harten 的經典結論：若 $\phi$ 落在 Sweby 區域

$$0 \le \phi(r) \le \min\{2r,\ 2\},\quad r \ge 0, \qquad (11.5)$$

且 $|a|\Delta t/\Delta x \le 1$，則 (11.4) 配前述斜率 $s_i=\phi(r_i)\Delta^- u_i$ 對標量線性平流是 TVD。minmod 位於 $0\le \phi\le 1$ 的保守區，光滑極值附近降為一階，代價換取無振盪；superbee 貼近上邊界 $2$，更銳利但仍位於區域內。

**穩定性、守恆、TVD 與非負性是四個獨立命題。** 例如 (11.4) 在 CFL 條件下守恆且 TVD，但不自動保證處處非負：若 $u_i > 0$ 但 $\ u_{i+1/2}^L < 0$，一步更新後可能出現負值。若要保證非負，需要更強的正保持限制器（例如對斜率再加 $\pm u_i$ 上界），或對特定問題另行證明。事後裁零會破壞守恆記錄，必須避免。

## 逐步手算例題

**例 11.1（光滑資料上的 minmod 斜率）。** 週期網格 $N = 6$，$\Delta x = 1$，單元值

$$u = [\,1.0,\ 2.0,\ 4.0,\ 7.0,\ 8.0,\ 8.0\,],$$

速度 $a = 1$，$\Delta t = 0.5$，故 CFL $=0.5$。求各單元 minmod 斜率、界面左狀態，並更新單元 $i=3$。

解：逐一計算
- $i=0$：$\Delta^- u_0 = 1-8=-7$，$\Delta^+ u_0 = 1$，符號相反，$s_0 = 0$。
- $i=1$：$\Delta^- u_1 = 1$，$\Delta^+ u_1 = 2$，同號，$s_1 = 1$。
- $i=2$：$\Delta^- u_2 = 2$，$\Delta^+ u_2 = 3$，同號，$s_2 = 2$。
- $i=3$：$\Delta^- u_3 = 3$，$\Delta^+ u_3 = 1$，同號，$s_3 = 1$。
- $i=4$：$\Delta^- u_4 = 1$，$\Delta^+ u_4 = 0$，$s_4 = 0$。
- $i=5$：$\Delta^- u_5 = 0$，$\Delta^+ u_5 = -7$，$s_5 = 0$。

以 $a>0$ 的左狀態公式 $u_{i+1/2}^L = u_i + \tfrac12 s_i$ 得

$$u_{0.5}^L = 1.0,\ u_{1.5}^L = 2.5,\ u_{2.5}^L = 5.0,\ u_{3.5}^L = 7.5,\ u_{4.5}^L = 8.0,\ u_{5.5}^L = 8.0.$$

通量 $F_{i+1/2} = a\,u_{i+1/2}^L$。更新 $i=3$：

$$u_3^{n+1} = 7.0 - \tfrac{0.5}{1}\bigl(7.5 - 5.0\bigr) = 7.0 - 1.25 = 5.75.$$

檢核：初始和 $\sum u_i = 30$；更新後 $F_{3.5} - F_{2.5}$ 的淨通量已從 $i=3$ 转移到 $i=2$，質量仍為 $30$。此例展示 minmod 對光滑區保留二階斜率，因此數值擴散明顯低於迎風格式。

**例 11.2（方波跨步，含中心斜率對照）。** 週期 $N=6$，單元值

$$u = [\,0.5,\ 1.0,\ 1.0,\ 0.5,\ 0.0,\ 0.0\,],$$

$a=1$，$\Delta t = 0.5$，$\Delta x = 1$，CFL $=0.5$。

先算 minmod 斜率：
- $s_0$：$\Delta^- u_0 = 0.5$，$\Delta^+ u_0 = 0.5$，$s_0 = 0.5$。
- $s_1$：$\Delta^- u_1 = 0.5$，$\Delta^+ u_1 = 0$，$s_1 = 0$。
- $s_2$：$\Delta^- u_2 = 0$，$\Delta^+ u_2 = -0.5$，$s_2 = 0$。
- $s_3$：$\Delta^- u_3 = -0.5$，$\Delta^+ u_3 = -0.5$，$s_3 = -0.5$。
- $s_4$：$\Delta^- u_4 = -0.5$，$\Delta^+ u_4 = 0$，$s_4 = 0$。
- $s_5$：$\Delta^- u_5 = 0$，$\Delta^+ u_5 = 0.5$，$s_5 = 0$。

界面左狀態：

$$u_{0.5}^L = 0.75,\ u_{1.5}^L = 1.0,\ u_{2.5}^L = 1.0,\ u_{3.5}^L = 0.25,\ u_{4.5}^L = 0.0,\ u_{5.5}^L = 0.0.$$

通量 $F_{i+1/2} = u_{i+1/2}^L$（$a=1$）。更新：

$$u_0^{n+1} = 0.5 - 0.5(0.75 - 0.0) = 0.125,$$
$$u_1^{n+1} = 1.0 - 0.5(1.00 - 0.75) = 0.875,$$
$$u_2^{n+1} = 1.0 - 0.5(1.00 - 1.00) = 1.000,$$
$$u_3^{n+1} = 0.5 - 0.5(0.25 - 1.00) = 0.875,$$
$$u_4^{n+1} = 0.0 - 0.5(0.00 - 0.25) = 0.125,$$
$$u_5^{n+1} = 0.0 - 0.5(0.00 - 0.00) = 0.000.$$

和 $= 0.125+0.875+1+0.875+0.125+0=3.0$，與首步 $\sum u_i = 3.0$ 相符。TV 檢核：初始 $\mathrm{TV} = 0.5+0+0.5+0.5+0+0.5 = 2.0$；新狀態 $\mathrm{TV} = 0.75+0.125+0.125+0.75+0.125+0.125 = 2.0$，不增；峰值 $1.0$ 保持、最小值不低於 $0$。

**對照：中心斜率。** 若用 $s_i = (u_{i+1} - u_{i-1})/2$，得到 $s = [0.5, 0.25, -0.25, -0.5, -0.25, 0.25]$。相應界面值為

$$u_{0.5}^L = 0.625,\ u_{1.5}^L = 1.125,\ u_{2.5}^L = 0.875,\ u_{3.5}^L = 0.25,\ u_{4.5}^L = -0.125,\ u_{5.5}^L = 0.125.$$

一步之後：

$$u^{n+1} = [\,0.25,\ 0.75,\ 1.125,\ 0.8125,\ 0.1875,\ -0.125\,].$$

總和仍為 $3.0$，但已出現 $1.125 > 1$ 的過衝與 $-0.125 < 0$ 的下衝；TV 為 $0.5 + 0.375 + 0.3125 + 0.625 + 0.3125 + 0.375 = 2.5$，較初始 $2.0$ 增大。此為限制器缺失導致的典型 TVD 違反，同時說明「守恆」並不蘊含「TVD」或「非負」。

## 實作與程式

以下程式為自足 CPU 實作，只用 NumPy，週期邊界。若需 SciPy，請依賴明列章節自行引入。

```python
import numpy as np

def minmod(a, b):
    """逐元素 minmod：同號取絕對值較小者，異號之一或異號取 0。"""
    sa = np.sign(a); sb = np.sign(b)
    return 0.5 * (sa + sb) * np.minimum(np.abs(a), np.abs(b))

def rhs_muscl(u, a, dx):
    """一維線性平流的 -dF/dx，週期邊界，minmod-MUSCL 重構。

    F[i] 儲存 F_{i+1/2}（單元 i 右面）。
    """
    u = np.asarray(u, dtype=float)
    s = minmod(u - np.roll(u, 1), np.roll(u, -1) - u)
    if a > 0.0:
        uL = u + 0.5 * s                # u^L_{i+1/2}
        F = a * uL
        return -(F - np.roll(F, 1)) / dx
    elif a < 0.0:
        uR = np.roll(u, -1) - 0.5 * np.roll(s, -1)  # u^R_{i+1/2}
        F = a * uR
        return -(F - np.roll(F, 1)) / dx
    else:
        return np.zeros_like(u)

def step_muscl(u, a, dx, dt):
    """一次前向 Euler 步，CFL = |a|*dt/dx <= 1。"""
    return np.asarray(u, dtype=float) + dt * rhs_muscl(u, a, dx)

def total_variation_periodic(u):
    u = np.asarray(u, dtype=float)
    return float(np.sum(np.abs(np.roll(u, -1) - u)))

def mass(u, dx):
    return float(np.sum(np.asarray(u, dtype=float)) * dx)
```

用法示範（合成方波，正向速度）：

```python
N = 200
dx = 1.0 / N
x = (np.arange(N) + 0.5) * dx
u0 = np.where((x > 0.25) & (x < 0.50), 1.0, 0.0)   # 週期方波
a, CFL = 1.0, 0.4
dt = CFL * dx / abs(a)
u, m0, tv0 = u0.copy(), mass(u0, dx), total_variation_periodic(u0)
for _ in range(400):
    u = step_muscl(u, a, dx, dt)
m1, tv1 = mass(u, dx), total_variation_periodic(u)
print("mass", m0, m1, abs(m1 - m0) / abs(m0))
print("tv", tv0, tv1)
print("range", float(u.min()), float(u.max()))
```

預期結果（依推導，非本機實測）：質量相對誤差為浮點舍入量級；TV 不增；`u.min() >= -1e-15`、`u.max() <= 1.0 + 1e-15`。若把 `dx`、`CFL` 與迭代數調整，上述結論仍應成立，不應依賴特定參數。

反向速度只需傳入 $a=-1$，實作會走右狀態分支；不需要修改其他程式。

## 測試與預期結果

以下結果為依公式與已知單調性推導所得的預期，不代表本機已執行。

**正常測試 1：光滑正弦波。** 取 $u_0(x)=\sin(2\pi x)$、$N=200$、$a=1$、CFL$=0.4$，跑到 $t=1$（一整週期）。預期：$\sum u_i\Delta x$ 相對誤差為浮點舍入量級；離散 $L^1$ 誤差隨 $N$ 加倍而下降，minmod-MUSCL 由於極值降階，全局觀測階約為 $1.0$ 到 $2.0$ 之間；數值不超出初值振幅。

**正常測試 2：方波。** 同上初值、`CFL=0.4`，跑到 $t=1$。預期：峰值單調下降但不超過 $1$，最小值不低於 $0$；TV 單調不增；輪廓呈「輕微擴散但無過衝」。

**邊界測試：反向速度。** 取 $a = -1$ 於同一方波例。預期：質量與 TV 性質與正向對稱；若把 $a=-1$ 傳給 $a>0$ 分支（例如硬寫重建方向），則會觀測到 TV 增加與極值越界，這是快速診斷重構方向錯誤的測項。

**故障測試 1：CFL 超限。** 取 $|a|\Delta t/\Delta x = 1.2$，方波在十數步後出現明顯振盪，TV 不再單調，最大最小值越出 $[0,1]$。此為明確的 CFL 條件違反，不代表 minmod 失效。

**故障測試 2：把 minmod 換成中心斜率。** 使用 $s_i = (u_{i+1} - u_{i-1})/2$。例 11.2 已給出 TV 由 $2.0$ 增至 $2.5$、出現過衝與下衝的反例。程式中只需替換 `s = minmod(...)` 那一行，即可重現同一現象。

**故障測試 3：非週期資料配週期程式。** 若把 `np.roll` 用於非週期資料，遠端會被人為接上，產生虛假通量；質量看似守恆但物理上不正確。真實非週期實作必須改寫為顯式 ghost cell，或以入流／出流邊界條件閉合。

四個獨立的檢查項：

- **守恆**：每步 $\mathrm{mass}(u^{n+1}) - \mathrm{mass}(u^n)$ 為浮點舍入量級。
- **TVD**：每步 $\mathrm{TV}(u^{n+1}) \le \mathrm{TV}(u^n)$（依所用離散與 CFL 條件）。
- **穩定**：數值不隨步數爆炸，偏差在合理範圍。
- **非負**：對本格式不具備一般性定理；對特定資料可數值檢查，若需要保證須改造限制器或加入正保持修正，**不得事後裁零**。

## 除錯與常見陷阱

1. **誤將「二階形式」理解為「處處二階」。** 限制器在極值與激波附近降階，全局誤差常呈 $1.0$ 到 $1.5$ 階，不是程式錯誤。
2. **下標錯位。** $F_{i+1/2}$ 放在第 $i$ 位還是第 $i+1$ 位必須全程一致；`np.roll(F, 1)` 是取 $F_{i-1/2}$，常被誤認為「向右移動」。
3. **正負速度共用單側重構。** 當 $a$ 隨時間或空間改變時，必須逐面判斷上風方向並選擇 $u^L$ 或 $u^R$；固定用一側會在反向下游取到錯誤資訊。
4. **`np.roll` 當一般邊界。** 它只適用週期。非週期必須顯式 ghost cell。
5. **把限制器塞進時間推進。** 限制器是空間重構步驟；時間高階須另用 SSP-RK 等 TVD 時間積分，本章僅示範前向 Euler。
6. **事後裁零。** `np.maximum(u, 0)` 會悄悄改質量並掩蓋不穩定；診斷應報告質量變化，而非隱藏。
7. **以 CFL 代替限制器，或以限制器代替 CFL。** 兩者是不同機制，都需要成立才有 TVD 結論。
8. **對稱性誤判。** 對 $a<0$ 若沿用正向重構再取負通量，等於在面處取了下游狀態，會破壞一致性並引發振盪。

## 養殖與相場案例

設有一座合成養殖池，水體以已知水平速度 $a$ 沿 $\pm X$ 傳輸，$u$ 為溶氧偏差量的無因次量（相對於供氧設定）。若取 $a>0$ 表示水体自西向東流動，一階迎風格式會把局部耗氧形成的低氧塊在數十步內過度擴散，導致模擬低估缺氧持續時間；minmod-MUSCL 在保留低氧塊輪廓上較真實，但其前提是 $a$ 為常數、一維、無橫向混合，不可外推為三維真實池況。

若把本章格式用於相場方程中的平流子步，必須注意：Cahn–Hilliard 的守恆量 $\int\phi\,\mathrm{d}x$ 與 Allen–Cahn 的非守恆量性質不同，平流步驟對兩者的影響必須分別記錄，不能把質量守恆的 MUSCL 結論直接套到 AC。溶氧跨管理閾值不是相變；數值過衝跨過閾值也不是相變，只是離散誤差。渲染逼真不代表物理驗證。agent 只讀取並回報診斷，不得據此修改模型、投餌或加藥。

## 習題

**習題 11.1（手算）。** 週期網格 $N=5$，$\Delta x=2$，單元值

$$u = [\,0.0,\ 1.0,\ 3.0,\ 3.0,\ 1.0\,],$$

速度 $a=2$，$\Delta t=0.4$。請 (a) 求各單元 minmod 斜率；(b) 給出全部界面左狀態 $u_{i+1/2}^L$；(c) 求一步更新後各單元值；(d) 驗證總質量與 TV 是否分別保持與不增。

**習題 11.2（程式）。** 用 `step_muscl`，取 $N=64$、週期方波、$a=1$、CFL$=0.5$，跑到 $t=2$。記錄 (a) 質量相對誤差；(b) TV 隨時間的軌跡；(c) 過程中最小值與最大值；(d) 把限制器換成中心斜率 $s_i=(u_{i+1}-u_{i-1})/2$，重複 (b)(c) 並比較。

**習題 11.3（反例）。** 在 $a>0$、CFL 穩定條件下，MUSCL 是否一定 TVD？針對下列限制器逐一判定並說明：
- $\phi(r) = r$
- $\phi(r) = 2r$
- $\phi(r) = \max(0, \min(2r, 2))$

**習題 11.4（整合）。** 某合成池一維溫度偏差場的速度時段為 $a=-0.5$ 與 $a=1.0$ 交替。請 (a) 修改 `rhs_muscl` 使其接受分段速度；(b) 解釋為何不能對兩個時段統一使用同一個上風側；(c) 列出應同時檢查的四個性質與各自判據。

## 習題解答

**11.1 解答。**
(a) 週期差分逐一計算：$s_0 = 0$，$s_1 = 1.0$，$s_2 = 0$，$s_3 = 0$，$s_4 = -1.0$。
(b) $a>0$，$u_{i+1/2}^L = u_i + \tfrac12 s_i$：$u_{0.5}^L = 0.0$，$u_{1.5}^L = 1.5$，$u_{2.5}^L = 3.0$，$u_{3.5}^L = 3.0$，$u_{4.5}^L = 0.5$。
(c) 通量 $F_{i+1/2} = 2\,u_{i+1/2}^L$：$F = [0.0, 3.0, 6.0, 6.0, 1.0]$。$\Delta t/\Delta x = 0.2$。
$u^{n+1} = [0.2,\ 0.4,\ 2.4,\ 3.0,\ 2.0]$。
(d) 質量和初始與更新後皆為 $8$。初始 $\mathrm{TV} = 6$；更新後 $\mathrm{TV} = 0.2 + 2.0 + 0.6 + 1.0 + 1.8 = 5.6$，不增。四項性質在本步皆成立。

**11.2 解答思路。**
(a) $\mathrm{mass}$ 相對誤差應為 $10^{-12}$ 以下量級。
(b) $\mathrm{TV}$ 應單調不增；任何上升若顯著超出浮點噪聲需查 CFL 或實作。
(c) 數值應落在 $[0,1]$ 內；唯一例外是浮點噪聲量級。
(d) 中心斜率版本會出現 TV 上升與越界極值。這是缺少限制器的預期後果，與 11.2(b)(c) 形成對照。

**11.3 解答。** Sweby 區域 $0\le\phi(r)\le\min(2r,2)$ 為充分條件。
- $\phi(r)=r$：當 $r>2$ 時 $\phi(r)>2$，逸出區域，一般會振盪。
- $\phi(r)=2r$：當 $r>1$ 時 $\phi(r)>2$，亦逸出區域。
- $\phi(r)=\max(0,\min(2r,2))$：恰在 Sweby 上邊界，充分條件成立，一般 TVD；但仍可能有非負性的細節問題，須另驗。

**11.4 解答思路。**
(a) 把 `a` 改為長度為 $N$ 的陣列（或依面分段），在每個面 $i+1/2$ 處檢查局部速度符號：正取 $u_{i+1/2}^L$、負取 $u_{i+1/2}^R$、為零則通量取零。
(b) 不同時段資訊傳播方向相反，若固定用一側，其中一個時段將以錯誤方向取狀態，違反一致性並破壞 TVD。
(c) 四項判據：
- 守恆：每步 $\mathrm{mass}(u^{n+1}) = \mathrm{mass}(u^n)$ 至浮點舍入。
- 穩定：$\max_i |a_i|\,\Delta t/\Delta x \le 1$ 每步成立。
- TVD：$\mathrm{TV}(u^{n+1}) \le \mathrm{TV}(u^n)$。
- 有界：數值落在初始 $\min$ 與 $\max$ 之間（或明示資料依賴界）。

## 本章小結

一階迎風守恆、TVD 但過度擴散；中心差分形式上二階但會振盪。MUSCL 以分片線性重構與限制器函式 $\phi$ 折衷兩者：光滑區提供高階通量，極值與激波附近把斜率壓到零以維持 TVD。minmod 是最保守的選擇，代價是極值附近局部降為一階；superbee 更銳利但仍位於 Sweby 區域。守恆、TVD、穩定性與非負性是四個獨立性質，須分別驗證與報告。任何「讓數值看起來更好」的後處理（例如裁零）都可能破壞守恆，必須在質量與 TV 日誌中如實記錄。
