- 結論：證明正確。

**蒸餾梯度 (Prop 26.2)**
- 損失 $\mathcal{L} = \text{KL}(p||q) = \sum p \log p - \sum p \log q$。
- 梯度 $\frac{\partial \mathcal{L}}{\partial z_j} = \frac{q_j - p_j}{T}$。
- 推導：$\frac{\partial}{\partial z_j} (-\sum p_k \log q_k) = -\sum p_k \frac{1}{q_k} \frac{\partial q_k}{\partial z_j}$。
- $\frac{\partial q_k}{\partial z_j} = \frac{1}{T} q_k (\delta_{kj} - q_j)$。
- 代入得 $-\frac{1}{T} \sum p_k (\delta_{kj} - q_j) = -\frac{1}{T} (p_j - q_j \sum p_k) = -\frac{1}{T} (p_j - q_j) = \frac{q_j - p_j}{T}$。
- 結論：證明正確。

### 2. 潛在問題檢查

**B1 解答中的 Shape**
- 題目：「把 `quantize_symmetric` 改成逐列（沿 $D_{\mathrm{out}}$ 軸）版本」
- 本卷約定：$W (D_{in}, D_{out})$。
- 「逐列」通常指對每一列（輸出通道）計算一個 scale。
- 沿 $D_{in}$ (axis 0) 取 max。
- Scale shape 應為 $(1, D_{out})$ 或 $(D_{out},)$。
- 解答寫：「回傳尺度形狀 $(D_{\mathrm{in}},1)$」，「`max_abs = np.max(np.abs(W), axis=1...)`」。
- **這裡有錯誤！**
- 如果 `W` 是 $(D_{in}, D_{out})$。
- `axis=1` 是沿著 $D_{out}$ 軸 reduction，結果形狀是 $(D_{in}, 1)$。
- 這意味著對每一**行**（輸入通道）計算一個 scale。這通常稱為 **Per-Row** 或 **Per-Input-Channel** 量化。
- 題目說「逐列（沿 $D_{\mathrm{out}}$ 軸）」，這個描述本身有歧義。
    - 「逐列」通常指 Columns (Output Channels)。
    - 「沿 $D_{out}$ 軸」如果是指 reduction 的軸，那是 axis=1 (Row-wise scale)。
    - 如果是指作用在 $D_{out}$ 維度上（即對每個 $j$ 計算 scale），那是 axis=0 (Column-wise scale)。
- 看主程式中的 `quantize_per_column`：
    - `max_abs = np.max(np.abs(W), axis=0, keepdims=True)` -> Shape $(1, D_{out})$。
    - 這是對每一列（Output Channel）計算 scale。
- 習題 B1 說：「改成逐列（沿 $D_{\mathrm{out}}$ 軸）版本」。
- 如果 B1 是要做 Per-Row (Input Channel)，那麼 Scale shape 是 $(D_{in}, 1)$。
- 解答 B1 給的是 `axis=1`，Shape $(D_{in}, 1)$。
- 但題目文字「逐列（沿 $D_{\mathrm{out}}$ 軸）」如果是指 Per-Output-Channel，則解答錯了。
- 然而，解答 B1 的標題是「逐列版本」，但在深度學習中，Per-Channel 常指 Output Channel。
- 讓我們仔細看 B1 的題目文字：「回傳尺度形狀 $(D_{\mathrm{in}},1)$」。
- 題目已經指定了 shape 是 $(D_{in}, 1)$。這意味著是 Per-Row (Input Channel)。
- 所以解答是符合題目要求的。
- 但題目中的括號「沿 $D_{\mathrm{out}}$ 軸」可能是指 $D_{out}$ 軸是保留的？或者是指對 $D_{out}$ 軸上的元素進行處理？
- 通常「沿某軸」指的是 reduction 的軸。如果沿 $D_{out}$ (axis 1) reduction，則剩餘 $D_{in}$。Shape $(D_{in}, 1)$。
- 所以解答與題目一致。
- 不過，主程式中的 `quantize_per_column` 是 axis=0。
- 這裡的術語「逐列」可能引起混淆，因為在 $W(D_{in}, D_{out})$ 中，Column 是 Output Channel (axis 1)。
- 沿 axis 0 reduction 是 Per-Column (Output Channel)。
- 沿 axis 1 reduction 是 Per-Row (Input Channel)。
- 題目 B1 說「逐列（沿 $D_{out}$ 軸）」，如果「逐列」意指 Per-Column (Output)，那應該是 axis=0。
- 但題目指定 Shape $(D_{in}, 1)$，這是 Per-Row。
- 這顯示題目本身可能存在術語誤用或混淆。

- **最小修法**：將 B1 題目中的「逐列」改為「逐行」，或將括號內的「沿 $D_{\mathrm{out}}$ 軸」改為「沿第 1 軸」以避免與主程式的 `quantize_per_column` (axis 0) 混淆。
