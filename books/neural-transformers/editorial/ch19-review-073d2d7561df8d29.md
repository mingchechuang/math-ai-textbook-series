# 一、重算確認正確的部分

## 1. 注意力手算

給定

\[
Q=
\begin{bmatrix}
1&0\\
0&1\\
1&1
\end{bmatrix},\quad
K=
\begin{bmatrix}
1&0\\
1&1\\
0&1
\end{bmatrix},
\]

可得：

\[
QK^T=
\begin{bmatrix}
1&1&0\\
0&1&1\\
1&2&1
\end{bmatrix}.
\]

除以 \(\sqrt2\) 並施加下三角因果遮罩後，三列注意力權重約為：

\[
(1,0,0),
\]

\[
(0.3302,0.6698,0),
\]

\[
(0.2482,0.5035,0.2482).
\]

因此第三列輸出：

\[
0.2482(1,0)+0.5035(0,1)+0.2482(1,1)
=(0.4964,0.7517).
\]

稿中數值正確。

## 2. FFN 手算

\[
[1,2]W_1=[1,2,1,2],
\]

經 ReLU 後不變，再乘第二層權重：

\[
[1,2,1,2]W_2=[2,5].
\]

中間 shape \((1,4)\) 與輸出 shape \((1,2)\) 正確。

## 3. shape 與 broadcast

實作的主要 shape 為：

- `idx`: \((B,T)\)
- token embedding：\((B,T,D)\)
- position embedding：\((1,T,D)\)
- batch 軸廣播後：\((B,T,D)\)
- Q/K/V reshape：\((B,T,H,d_h)\)
- transpose：\((B,H,T,d_h)\)
- scores：\((B,H,T,T)\)
- mask：\((T,T)\)，向 batch 與 head 軸廣播
- attention output：\((B,H,T,d_h)\)
- merge heads：\((B,T,D)\)
- logits：\((B,T,V)\)

softmax 沿最後 key 軸執行，正確。

## 4. loss reduction

目前程式等價於：

\[
\mathcal L
=
\frac{
\sum_{b,t:Y_{b,t}\ne PAD}
-\log p(Y_{b,t}\mid X_{b,0:t})
}{
\sum_{b,t}\mathbf 1[Y_{b,t}\ne PAD]
}.
\]

`ignore_index=PAD_ID` 排除分子中的 PAD，`valid_count` 提供相同 target mask 的分母，且全 PAD target 在除法前拒絕。正確。

## 5. padding 契約

程式正確限制：

1. input PAD 只能是右側連續後綴；
2. target PAD 只能是右側連續後綴；
3. PAD input 位置必須有 PAD target。

條件只要求：

\[
X_{b,t}=PAD\Longrightarrow Y_{b,t}=PAD,
\]

而沒有錯誤地要求反方向，故合法的：

\[
X=[a,b,c],\quad Y=[b,c,PAD]
\]

仍能通過。新增的正常與故障案例也涵蓋了主要分支。

## 6. 因果性證明

證明已納入：

\[
\widetilde H_{l-1}^{(j)}
=
\operatorname{LN}_1(H_{l-1}^{(j)}),
\]

並正確指出 LayerNorm 與 FFN 不混合 time 軸。對位置 \(i\)，注意力只使用 \(j\le i\) 的 K/V；注意力權重本身也只依賴 \(Q_i\) 和 \(j\le i\) 的 K。殘差只合併同一位置。因此多層歸納結論成立。

# 二、主要阻擋問題：PAD 梯度測試仍是假陽性

## 逐字原句

```python
x_grad = torch.tensor([[1, 2, 0]], dtype=torch.long)
t_grad = torch.tensor([[2, 3, 0]], dtype=torch.long)
```

接著：

```python
pad_grad = model.tok_emb.weight.grad[model.PAD_ID]
assert torch.all(pad_grad == 0)
```

這一次 PAD 確實出現在 embedding lookup 中，但測試仍不能驗證 `padding_idx=0`。

## 原因

位置 2 是 PAD，且 target 位置 2 也是 PAD，所以其 loss 被 `ignore_index` 排除。有效 loss 只有位置 0 和 1。因果模型中：

- 位置 0 只能依賴 input 位置 0；
- 位置 1 只能依賴 input 位置 0、1；
- 位於未來的 input 位置 2 不可能影響位置 0、1。

因此 PAD embedding row 沒有任何通往有效 loss 的梯度路徑。即使 `nn.Embedding` 沒有設定 `padding_idx=0`，此測試中的 PAD row 梯度仍會是零。

換言之，這個測試無法區分：

```python
nn.Embedding(V, D, padding_idx=0)
```

和：

```python
nn.Embedding(V, D)
```

因此仍是假陽性。

## 最小修法

把 `padding_idx` 測試獨立於語言模型 loss。直接對 embedding lookup 建立 probe：

```python
model.zero_grad(set_to_none=True)
probe_ids = torch.tensor([[0, 1]], dtype=torch.long)
probe = model.tok_emb(probe_ids).sum()
probe.backward()

assert torch.all(model.tok_emb.weight.grad[0] == 0)
assert torch.any(model.tok_emb.weight.grad[1] != 0)
```

此時 PAD row 與 token 1 row 都直接參與 probe。如果移除 `padding_idx=0`，PAD row 應得到非零梯度；保留時則為零，測試才具有故障鑑別力。

完成 probe 後必須再次：

```python
model.zero_grad(set_to_none=True)
```

再執行端到端 loss 的梯度流測試，避免 probe 梯度污染後續結果。

# 四、`view` 與 stride 的說明仍錯

## 逐字原句

> 「`.contiguous()` 不可省略，因為 `transpose` 後張量通常非連續，直接 `view` 會失敗或給出錯誤的記憶體映射」

目前程式：

```python
out.transpose(1, 2).contiguous().view(...)
```

是正確寫法。但文字錯在：

1. stride 不相容時，`view` 通常應拋錯，不是靜默給出錯誤映射；
2. 如果改用 `reshape`，框架可以在必要時建立副本，所以 `.contiguous()` 不是所有寫法中都不可省略。

## 最小修法

改成：

> 「本程式在 transpose 後使用 `view`，因此先呼叫 `.contiguous()`；否則 transpose 後的 stride 通常與所求 shape 不相容，使 `view` 拋錯。若改用 `reshape`，框架可在必要時建立副本。」

# 五、因果性測試仍可能把 token 改成 PAD

## 逐字原句

```python
x_mod[:, -1] = (x_mod[:, -1] + 1) % V
```

若原 token 為 \(V-1\)，新值會變成 0，即 PAD。雖然 PAD 位於最右端且不違反 input 契約，但測試同時改變了 token 內容與 padding 身分。

## 最小修法

使用：

```python
x_mod[:, -1] = x_mod[:, -1] % (V - 1) + 1
```

原 token 來自 \(1,\ldots,V-1\)，修改後仍為非 PAD，且一定與原 token 不同。

另外，這個測試只驗證修改最後 token 不影響前面 logits。更一般的程式測試可選一個中間分界 \(c\)，修改 \(c+1,\ldots,T-1\)，再比較 \(0,\ldots,c\)。一般性的證明仍由歸納法提供。

# 七、習題仍掩蓋 transpose

## 逐字原句

> 「給定 \(D=4,H=2\)，輸入 \(X\in\mathbb R^{1\times2\times4}\)」

此處 \(T=H=2\)。reshape 後：

\[
(B,T,H,d_h)=(1,2,2,2),
\]

transpose 後：

\[
(B,H,T,d_h)=(1,2,2,2).
\]

兩個 shape 的數字完全一樣，因此學生即使忘記 transpose，也會寫出相同數字。

## 最小修法

把 \(T\) 改為 3：

- projection：\((1,3,4)\)
- reshape：\((1,3,2,2)\)
- transpose：\((1,2,3,2)\)
- scores：\((1,2,3,3)\)

同步修改答案即可。

## 逐字原句
