# 一、先行重算

## 1. 例題 4.1

三筆正確類別機率為 $0.9,0.9,0.6$，所以

$$
-\ln 0.9=0.1053605,\qquad -\ln 0.6=0.5108256.
$$

總 NLL 為

$$
2(0.1053605)+0.5108256=0.7215466\text{ nats}.
$$

平均為

$$
0.7215466/3=0.2405155\text{ nats}.
$$

由 nats 轉為 bits 應除以 $\ln 2$，等價於乘以 $\log_2 e$：

$$
0.2405155/\ln 2
=0.2405155\log_2 e
\approx0.34699\text{ bits}.
$$

數值答案大致正確，但正文所說「除以 $\log_2(e)$」錯誤，公式卻使用乘法，兩者互相矛盾。

## 2. KL 習題

$$
D_{\mathrm{KL}}(P\parallel Q)
=0.1\log_2(0.5)+0.2\log_2(2/3)+0.7\log_2(1.4).
$$

各項約為

$$
-0.1,\quad -0.116993,\quad 0.339598,
$$

合計

$$
0.122605\text{ bits}.
$$

答案的 $0.1225$ bits 可接受。

## 3. KL 證明中的支撐集計算

令 $S=\{x:P(x)>0\}$。在 $P$ 的期望下，

$$
\mathbb E_P\left[\frac{Q(X)}{P(X)}\right]
=\sum_{x\in S}Q(x),
$$

一般只保證

$$
\sum_{x\in S}Q(x)\leq1,
$$

不一定等於 1。若 $P=[1,0]$、$Q=[1/2,1/2]$，該期望就是 $1/2$。原證明把 $P(x)=0$ 的位置也錯誤地算進期望。

不過結論仍可成立：

$$
D_{\mathrm{KL}}(P\parallel Q)
\geq-\log\sum_{x\in S}Q(x)\geq0.
$$

等號還要求兩個不等式都取等號，因而要求 $Q$ 在 $S$ 外沒有質量，且 $Q/P$ 在 $S$ 上為常數，最後得到 $P=Q$。

## 4. 程式 shape 重算

手算例題若送入 `cross_entropy`，則 `y_pred.shape == (3,2)`。函數先算：

```python
sums = np.sum(y_pred, axis=-1)
```

得到 shape `(3,)`，這一步正確。接著呼叫：

```python
log_q = safe_log_probs(y_pred)
```

但 `safe_log_probs` 內部使用：

```python
np.sum(p)
```

它會把整個 `(3,2)` 矩陣全部相加，結果為 $3$，不是 $1$，因此拋出 `ValueError`。所以目前主程式無法計算正文自己的三樣本例題。

# 二、必修問題

## 1. KL 非負性證明在不同支撐集下有漏項

**原句：**

> `\mathbb{E}\left[\frac{Q(x)}{P(x)}\right] = \sum_{x} P(x) \frac{Q(x)}{P(x)} = \sum_{x} Q(x) = 1`

**問題：**

$Q(x)/P(x)$ 只在 $P(x)>0$ 的位置參與 $P$ 期望。當 $P(x)=0,Q(x)>0$ 時，不能藉由形式消去 $P(x)$ 把該 $Q(x)$ 加回來。定理目前只假設 $P(x)>0\Rightarrow Q(x)>0$，沒有假設 $Q$ 的支撐也包含於 $P$ 的支撐，因此上述等式一般不成立。

**最小修法：**

把該行改為

$$
\mathbb E_P[Q(X)/P(X)]
=\sum_{x:P(x)>0}Q(x)\leq1,
$$

再寫

$$
D_{\mathrm{KL}}(P\parallel Q)
\geq-\log\sum_{x:P(x)>0}Q(x)\geq0.
$$

等號條件另補：第一個 Jensen 等號要求 $Q/P$ 在 $P$ 支撐上為常數；第二個等號要求 $Q$ 在 $P$ 支撐外質量為零。兩者合併才得到 $P=Q$。不要僅寫「$Z$ 為常數」就跳到全域 $P=Q$。

## 2. nats 轉 bits 的文字公式錯誤

**原句：**

> `若需 bits，除以 $\log_2(e) \approx 1.4427$。`

緊接著又寫：

> `0.24052 \times \log_2(e) \approx 0.3469 bits`

**問題：**

兩句互相矛盾。正確轉換為

$$
L_{\rm bits}=\frac{L_{\rm nats}}{\ln2}
=L_{\rm nats}\log_2 e.
$$

若真的除以 $\log_2e$，會得到約 $0.1667$，不是 $0.3469$。

**最小修法：**

將「除以 $\log_2(e)$」改成「除以 $\ln2$，等價於乘以 $\log_2e$」。

## 3. 常見陷阱中的單位轉換再次寫反，且 NumPy API 不存在

**原句：**

> `若業務需求是 bits，必須顯式轉換：value * np.log(2) 或 np.log(value, 2)。`

**問題：**

若 `value` 已是 nats，轉為 bits 應是 `value / np.log(2)`，不是乘法。`np.log(value, 2)` 也不是 NumPy 的「指定底數」呼叫方式；第二個位置參數不是 log base。

**最小修法：**

改為：

```python
bits = nats / np.log(2.0)
```

若從機率直接計算 base-2 對數，使用 `np.log2(prob)`。

## 4. `safe_log_probs` 的歸一化 reduction 軸錯誤

**原句：**

```python
if np.abs(np.sum(p) - 1.0) > 1e-9:
    raise ValueError("Probabilities must sum to 1.")
```

**問題：**

函數接收的實際輸入是 `(N,C)`，卻沿全部軸求和。只要 $N>1$，合法批次的總和就是 $N$，必然被拒絕。這是實際 shape／reduction 錯誤，不是介面偏好。

**最小修法：**

讓函數接收 `axis=-1`，並使用：

```python
sums = np.sum(p, axis=axis)
if np.any(np.abs(sums - 1.0) > 1e-9):
    raise ValueError(...)
```

或者移除 `safe_log_probs` 內重複的歸一化檢查，由外層統一檢查。

## 5. 宣稱精確處理零機率，實際卻 clip 成有限值

**原句：**

> `處理 p=0 的情況，返回 -inf。`

但程式是：

```python
p_clipped = np.clip(p, 1e-15, 1.0)
return np.log(p_clipped)
```

**問題：**

$p=0$ 時返回的是 $\log(10^{-15})$，有限，不是 `-inf`。這也與本章反對「任意加 epsilon 假裝精確」的論述衝突。

**最小修法：**

若本章要實作數學定義，先檢查合法概率，再用明確分支：

```python
out = np.full_like(p, -np.inf, dtype=float)
positive = p > 0
out[positive] = np.log(p[positive])
return out
```

後續 CE 必須只在 $P>0$ 的位置相乘，避免直接形成 `0 * -inf == nan`。

## 6. CE 的零機率回傳 shape 錯誤，且一筆失敗污染整批

**原句：**

```python
if np.any(mask):
    return np.full(y_true.shape, np.inf)
```

**問題：**

若 `y_true` 是 one-hot `(N,C)`，回傳 shape 變成 `(N,C)`，違反 docstring 宣稱的 `(N,)`。此外，只要批次內任何一筆有零機率，所有樣本都被回傳為 `inf`，無法知道是哪一筆失敗。

**最小修法：**

先算每筆是否有支撐違規：

```python
bad = np.any((y_true_onehot > 0) & (y_pred == 0), axis=-1)
ce = ...
ce[bad] = np.inf
```

回傳值固定為 `(N,)`。若要全批拒絕，則應拋出例外，而不是回傳 shape 不一致的陣列。

## 7. 用 $10^{-15}$ 當作數學上的零，改變了 KL 與 CE 定義

**原句：**

```python
mask = (y_true_onehot > 0) & (y_pred < 1e-15)
```

以及：

```python
if np.any((p_true > 1e-15) & (q_model < 1e-15)):
    return np.inf
```

**問題：**

例如 $P=10^{-16},Q=0$ 在數學上仍有 $P>0,Q=0$，KL 應為無限，但程式忽略該項。反過來，$Q=5\times10^{-16}>0$ 時 KL 是很大的有限值，程式卻回傳無限。閾值可以是另行定義的業務拒絕規則，但不能冒充精確 KL。

**最小修法：**

本章教學版使用精確比較 `p > 0`、`q == 0`。若另提供近似容差，必須改名並明示它計算的不是精確 KL。

## 8. 非有限值故障測試與實作不一致

**原句：**

> `輸入包含 NaN：safe_log_probs 應檢測並拋出異常。`

**問題：**

目前沒有 `np.isfinite` 檢查。對 NaN 而言，`p < ...`、`p > ...` 和 `abs(sum(p)-1)>...` 均可能為 False，函數最後回傳 NaN，不會依宣稱拋錯。正負無限也沒有可靠處理。

**最小修法：**

所有公開函數入口先加：

```python
if not np.all(np.isfinite(p)):
    raise ValueError("Probabilities must be finite.")
```

`p_true`、`q_model`、`y_true`、`y_pred` 和 NLL 陣列均需相應檢查。

## 9. `kl_divergence` 沒有驗證輸入是概率分布

**原句：**

> `p_true: (C,) 真實分布`
>
> `q_model: (C,) 模型分布`

**問題：**

函數不檢查 shape、一維性、非負、有限性或總和為 1。`[-1,2]`、`[2,2]` 或不同 shape 都可能產生無意義結果或廣播。

**最小修法：**

加入一個供 CE 與 KL 共用的概率驗證函數，檢查：

1. shape 完全相同；
2. 一維或明確最後類別軸；
3. 全部有限；
4. 每項 $\geq0$；
5. 沿類別軸總和約為 1。

容差只用於驗證浮點歸一化，不用於重新定義正支撐集。

## 10. index 標籤缺少 dtype、shape 與 batch 核對

**原句：**

```python
y_true_onehot[np.arange(y_true.shape[0]), y_true] = 1.0
```

**問題：**

浮點標籤會觸發 NumPy 索引錯誤；負標籤可能從尾端索引而被靜默接受；標籤數與 `y_pred.shape[0]` 不一致時行列索引可能錯配。主函數註解說「one-hot」，卻沒有驗證 one-hot 是否非負、每列總和為 1 或 shape 等於預測。

**最小修法：**

在索引前檢查整數 dtype、`shape == (N,)`、$0\le y<C$；one-hot／soft-label 分支則檢查 `shape == y_pred.shape`、有限、非負及每列總和為 1。

## 11. bits 測試與 nats 程式不相容

**原句：**

> `預期結果：NumPy 計算結果應為 [1.0] (bits) 和 0.0 (KL)`

以及：

> `計算出的 KL 應接近 0.531。`

**問題：**

程式全部使用 `np.log`，輸出 nats。對 $[0.5,0.5]$ 的熵會得到 $\ln2\approx0.6931$ nats，不是 $1$ bit。偏斜分布的 KL 也會是約 $0.3681$ nats，而不是 $0.531$ bits。另外程式沒有獨立的 entropy 函數，測試 1 所稱的 $H(P)$ 無法直接由所附 API 計算。

**最小修法：**

要麼所有程式測試改為 nats；要麼函數增加明確的 `base` 參數並除以 `np.log(base)`。測試必須給出實際函數呼叫與 `assert`，不能只列自然語言預期。

## 12. 困惑度函數沒有落實有效 token 契約

**原句：**

```python
def perplexity_from_nll(nll_per_token, total_tokens):
    ...
    avg_nll = np.sum(nll_per_token) / total_tokens
```

**問題：**

调用者可以傳入長度為 2 的 NLL，卻宣稱 `total_tokens=100`，函數仍接受。也沒有處理 PAD mask、負 token 數、NaN、`inf` 或 overflow。全書規約要求依有效 token 總 NLL／有效 token 數計算，而不是接受與陣列脫鉤的任意分母。

**最小修法：**

介面改為接收 `valid_mask`，驗證 shape 相同，計算 `count = valid_mask.sum()` 並拒絕零有效 token；或至少驗證一維輸入時 `total_tokens == nll_per_token.size`。若 NLL 已是有效 token 的壓平列表，根本不需要外傳 `total_tokens`。

## 13. 標籤平滑公式沒有歸一化

**原句：**

> `將 one-hot 1.0 改為 1-\epsilon，其他類改為 \epsilon/C`

**問題：**

總和為

$$
1-\epsilon+(C-1)\frac{\epsilon}{C}
=1-\frac{\epsilon}{C}\ne1.
$$

**最小修法：**

選定一種約定並寫清楚：

- 與均勻分布混合：目標類為 $1-\epsilon+\epsilon/C$，其他類為 $\epsilon/C$；
- 只把質量分給非目標類：目標類為 $1-\epsilon$，其他類為 $\epsilon/(C-1)$。

## 14. 「低 NLL 意味著校準正確」過強

**原句：**

> `低 NLL 不僅意味著準確性高，也意味著模型對其自信度有正確的估計。`

**問題：**

NLL 是 proper scoring rule，期望 NLL 在真條件分布處最優，但有限資料上的較低 NLL 不足以推出準確率高或已校準。少數高信心錯誤可主導 NLL；兩個模型也可能有相同 NLL 而校準曲線不同。

**最小修法：**

改成「NLL 同時評分正確類別機率與過度自信錯誤；在真分布期望及模型可表達等條件下，其最優解是真條件分布，但有限測試集上的低 NLL 不單獨證明校準良好。」

## 15. 資訊幾何段落混淆 KL、Fisher 距離與 $L_1/L_2$

**原句：**

> `KL 散度 ... 對應於 Fisher 計量下的 geodesic 距離的近似（局部二階）。`

以及：

> `使得 ... Q_\theta 在 L_1 或 L_2 意義上（取決於損失函數形式）最接近經驗分布`

**問題：**

KL 不是對稱距離，也不直接等於 Fisher geodesic 距離。正確的局部敘述是在正則參數化下，鄰近參數的 KL 二階項由 Fisher 資訊矩陣給出，通常含 $1/2$。而 NLL／交叉熵最小化對應經驗分布到模型分布的前向 KL（差一個與模型無關的經驗熵），不是未指定的 $L_1$ 或 $L_2$ 最接近。

**最小修法：**

刪除 $L_1/L_2$ 句。局部敘述限縮為

$$
D_{\mathrm{KL}}(p_\theta\parallel p_{\theta+\delta})
=\frac12\delta^\top I(\theta)\delta+o(\|\delta\|^2),
$$

並明列正則性條件或來源；若本章不準備支持該進階結論，直接移至延伸閱讀即可。

## 16. 高斯案例與「支撐集不包含 30 度」互相衝突

**原句：**

> `假設正常水溫分布為 P \sim \mathcal{N}(25,2^2)`

後文又說：

> `若模型完全未見過 30 度（支撐集不包含），NLL 將趨近於無限大`

**問題：**

非退化高斯分布的支撐集是整條實數線，30 度仍有正密度，不會因「未見過」而變成支撐集外。連續分布使用的是密度 NLL，密度也不是離散事件機率。本章前面還宣稱「所有計算均基於離散分類問題」，此處突然切換到連續高斯而未定義。

此外，高 NLL 不自動是可靠 OOD 訊號，不能用一次高 NLL 直接證明分布外。

**最小修法：**

要保持離散範圍，就明確把溫度分箱並使用有限類別分布；若保留高斯，則改成「30 度密度較低，因此 NLL 較大但有限」，並說明高 NLL 只能作待驗證的異常分數，門檻必須在獨立驗證資料上制定。不得暗示真實養殖安全閾值。

# 三、重要但可局部修補的問題

## 1. 懲罰「指數級增加」不準確

**原句：**

> `錯誤的「懲罰」應當隨著機率遠離 1 而指數級增加。`

**原因：**

損失是 $-\log p$。當 $p\to0^+$ 時無界增加，但相對於 $p$ 並不是「指數級增加」；反而是由 loss 反解機率時 $p=e^{-\ell}$。

**最小修法：**

改成「當賦給真實類別的機率趨近 0 時，$-\log p$ 無界增大」。

## 2. NLL 的總和與平均定義混用

**原句：**

> `負對數似然（NLL）定義為：-\frac1N\sum...`

後面的例題卻稱：

> `總 NLL (Sum)`

**原因：**

文獻中 NLL 可指總和或平均，但章內必須固定名稱，否則 `exp(NLL)` 的困惑度會含混。

**最小修法：**

定義 `total NLL` 與 `mean NLL`；困惑度只能取每個有效 token 的平均 NLL 再指數化。

## 3. 困惑度的「候選詞數量」只是一種特殊情況直覺

**原句：**

> `若 PP=100，表示模型平均每步在 100 個詞之間感到同等程度的困惑。`

**原因：**

一般模型並不等同於每一步都在 100 個候選上均勻分布；PP 是平均對數損失的指數。只有均勻分布於 $K$ 個候選的特殊情況才有 $PP=K$ 的精確解釋。

**最小修法：**

加入「等效」與「特殊均勻情況」限制，不要按字面聲稱每一步都有 100 個同等候選。

## 4. `cross_entropy_indices` 仍不是完整解答

**原句：**

```python
probs = y_pred[np.arange(y_pred.shape[0]), y_true_idx]
```

**原因：**

未檢查 `len(y_true_idx) == y_pred.shape[0]`、整數 dtype、`y_pred` 二維、概率非負／有限／逐列歸一化。它也依賴外部 `np`，雖然章首已有 import，但作為解答最好明示沿用前述 import。

**最小修法：**

補齊 shape、dtype、範圍和概率驗證；零機率逐筆回傳 `inf` 即可，不需要先 `np.any(probs <= 0)` 分支。

## 5. 習題類型不完全符合本卷規約

本卷要求「手算／程式／反例／整合」四類。現有第二題是證明題，沒有明確的反例題。證明本身當然有價值，但不能替代指定的反例類別。

**最小修法：**

# 四、測試與自足性

目前只有測試敘述，沒有可直接放在程式後執行的測試碼。自足程式至少應補上不依賴外部框架的 `assert` 或小型測試函數，覆蓋：

1. 正常多批次 `(N,C)` CE，確認回傳 `(N,)`；
2. one-hot 與 index 標籤結果一致；
3. 單一樣本 $Q_y=0$ 只使該樣本 CE 為 `inf`；
4. $P=0,Q=0$ 的 KL 項不造成 NaN；
5. $P>0,Q=0$ 回傳 `inf`；
6. $Q>0$ 但極小時回傳大的有限值，而非因閾值變成 `inf`；
7. NaN、正負無限、負概率、未歸一化概率均拒絕；
8. 錯誤 label dtype、負 label、越界 label、batch 長度不符均拒絕；
9. 空有效 token 拒絕；
10. 不同 token 數批次先合併總 NLL 再算 perplexity；
11. bits 與 nats 轉換一致；
12. 手算例題數值與程式輸出一致。

我沒有執行程式，因此上述只能稱為必要的預期測試，不能寫成「已通過」。
