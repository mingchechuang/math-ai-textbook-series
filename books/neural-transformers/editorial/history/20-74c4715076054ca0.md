# 第20章 下一詞元訓練與合成日誌資料

## 學習目標與先備知識

本章把已定義的張量、分類損失與 decoder-only 模型，接到一個完整而可檢查的訓練流程：從合成文件生成、資料切分、詞彙表，到錯一位的輸入與目標、遮罩平均、CPU 訓練及保留資料評估。

完成本章後，你應能：

- 說明下一詞元目標如何由同一序列錯位一格而來。
- 區分文件、窗口、詞元與有效監督位置。
- 在建立詞彙表或切窗前，先按文件分割資料，避免重疊內容洩漏。
- 明確寫出logits、targets、loss與遮罩的shape及reduction軸。
- 以有效詞元總數計算平均交叉熵與困惑度。
- 撰寫自足的合成資料生成器及小型CPU訓練loop，並將未執行的結果標示為預期。

先備知識為矩陣乘法、softmax交叉熵、embedding與因果遮罩。這一章不載入前章模組、不下載語料或權重，也不把示範程式宣稱為已訓練模型。

## 問題與直覺

語言模型不直接回答「這篇文件是什麼意思」，而是對每個前綴給出下一詞元的條件分布。若詞元序列為

$$
(x_0,x_1,\ldots,x_{L-1}),
$$

訓練輸入是$(x_0,\ldots,x_{L-2})$，目標是$(x_1,\ldots,x_{L-1})$。模型在位置$t$看見不晚於$t$的輸入，並預測$x_{t+1}$。最後一個輸入位置沒有本序列內的下一詞元，不應憑空多算一個目標。

這個錯位看似簡單，實際上有四個容易混淆的邊界：

1. **文件邊界**：不應把一份文件末尾接到另一份文件開頭，再當成自然的下一詞元關係。
2. **窗口邊界**：長文件切成上下文窗口後，相鄰窗口可能有重疊；相同文件的窗口必須留在同一資料分割。
3. **填充邊界**：批次中的PAD只為對齊長度，不是語言模型要預測的詞元。
4. **統計邊界**：平均損失應依有效目標詞元數計算，而不是把不同長度批次的平均值再等權平均。

因此，資料流的順序是：先生成或取得文件及其分組標記；再按文件分成訓練、驗證、測試；只用訓練資料建立詞彙表；最後各自切窗與批次化。若先切窗再隨機拆分，重疊窗口可把同一段內容放進訓練與測試兩邊，測試分數便不再代表未見文件上的表現。

本章的日誌只含人工設計的合成欄位與有限模板，例如日期、槽別、觀察狀態及文字標記。它們不是現場測量、操作建議或安全閾值。合成資料能檢查管線是否運作，不能證明模型理解真實養殖，也不能作為設備控制依據。

## 定義、定理與推導

### 下一詞元的因子分解

自回歸模型將一份長度為$L$的文件機率分解為：

$$
p(x_0,\ldots,x_{L-1})
=\prod_{t=0}^{L-1}p(x_t\mid x_0,\ldots,x_{t-1}).
$$

在條件中沒有前文的$t=0$位置，可用BOS（序列起始）表示前綴，或在訓練時不納入該位置的損失。本章程式不額外插入BOS；每個長文件只使用相鄰詞元對，故每份文件長度$L$產生$L-1$個監督位置。

模型輸出logits，非正規化分數。若詞彙大小為$V$、批次大小為$B$、輸入長度為$T$，則logits形狀為$(B,T,V)$，目標及有效遮罩形狀均為$(B,T)$。詞彙軸是最後一軸，交叉熵沿$V$計算；之後對有效的$B,T$位置求和，再除以有效目標詞元總數。

令$z_{b,t,v}$為logit，正確目標為$y_{b,t}$，單一位置的負對數似然為：

$$
\ell_{b,t}
=\log\sum_{v=0}^{V-1}\exp(z_{b,t,v})-z_{b,t,y_{b,t}}.
$$

為避免直接計算大指數，令$m=\max_v z_v$，改寫為：

$$
\ell=\log\sum_v\exp(z_v-m)+m-z_y.
$$

有效詞元遮罩為$a_{b,t}\in\{0,1\}$，總損失定義為：

$$
\mathcal L
=\frac{\sum_{b=0}^{B-1}\sum_{t=0}^{T-1}a_{b,t}\ell_{b,t}}
{\sum_{b=0}^{B-1}\sum_{t=0}^{T-1}a_{b,t}}.
$$

若分母為零，平均沒有定義；實作應拒絕該批次，不能回傳零或NaN假裝訓練正常。此處$B,T$上的加總與平均各有明確意義；不能先對每個序列平均，再把短序列與長序列當作同等權重，除非目標明確定為序列加權而非詞元加權。

### PAD與詞彙表

PAD是批次補齊的記號，不是自動消失的訊號。模型若在padding位置輸出logits，而目標仍被納入loss，便會被訓練去預測PAD。正確做法是以目標是否有效建立遮罩，讓padding目標對分子及分母都沒有貢獻。

詞彙表只從訓練文件建立，並固定保留PAD與UNK兩個特殊項目。UNK用於表示不在訓練詞彙表中的詞元。本章的示範資料全部由訓練模板產生，因此常見情況不會出現UNK；測試仍須涵蓋未見詞元，以檢查映射規則。若為了讓測試文本「看起來更完整」而用測試資料增加詞彙表，便把測試分布的資訊帶進訓練流程。雖然這不一定洩漏標籤，仍違反「詞彙表由訓練資料擬合」的評估契約。

### 小命題：錯位一格恰好形成相鄰預測對

**命題。** 對一份詞元序列$(x_0,\ldots,x_{L-1})$，令輸入為$(x_0,\ldots,x_{L-2})$、目標為$(x_1,\ldots,x_{L-1})$。位置$t$的輸入前綴為$(x_0,\ldots,x_t)$，其目標正是序列中的下一個詞元$x_{t+1}$；所有相鄰的一步預測對在此構造中恰好各出現一次。

**證明。** 輸入位置$t$取自原序列的$x_t$，而錯位後同一位置的目標取自$x_{t+1}$，所以它們構成相鄰對$(x_t,x_{t+1})$。由於$t$依序遍歷$0,1,\ldots,L-2$，取得的對依序是$(x_0,x_1),\ldots,(x_{L-2},x_{L-1})$。任一相鄰對的左側索引唯一決定$t$，因此不會重複；任一原序列內的一步相鄰對，其左側索引必介於$0$與$L-2$，因此不會遺漏。證畢。

這個命題只說明標籤構造，不保證模型學到語義或能泛化。資料可能高度規律，模型也可能只記住模板。

### 困惑度與token計數

令測試集合有效詞元的總負對數似然為$S$，有效詞元數為$N>0$，則平均每詞元NLL是$S/N$，困惑度為：

$$
\mathrm{PPL}=\exp(S/N).
$$

這裡使用自然對數，NLL單位為nats。計數必須是有效目標詞元的總數；不能先算每批困惑度再作不加權平均。若$N=0$，PPL未定義，評估程序應拒絕回報數值。困惑度衡量指定tokenization與測試分布下的預測不確定性，不是流暢度、安全性或事實正確性的替代指標。

## 逐步手算例題

### 例一：錯位、窗口與目標數

一份已詞元化文件是：

$$
[\text{BOS},\ \text{槽A},\ \text{狀態平穩},\ \text{EOS}].
$$

移除最後一項作輸入、移除第一項作目標，得到：

| 位置$t$ | 輸入 | 目標 |
|---:|---|---|
| 0 | BOS | 槽A |
| 1 | 槽A | 狀態平穩 |
| 2 | 狀態平穩 | EOS |

逐步核對：

1. 原長度$L=4$。
2. 輸入長度為$L-1=3$。
3. 目標長度同樣為$3$。
4. 有效監督位置數為$3$，而不是$4$。
5. 若此文件超過窗口長度，需要在同一文件內切窗；不可把最後一詞元接到下一份文件的首詞元，製造額外相鄰對。

### 例二：PAD遮罩下的詞元平均

某批次有三個目標位置，兩個有效、最後一個是PAD。假設對前兩個有效位置，模型給正確類別的機率分別為$1/2$與$1/4$；PAD位置的loss即使算得很大，也必須遮掉。

逐步計算：

1. 第一個有效位置NLL為$-\ln(1/2)=\ln2$。
2. 第二個有效位置NLL為$-\ln(1/4)=\ln4=2\ln2$。
3. 乘有效遮罩後，分子為$\ln2+2\ln2=3\ln2$。
4. 有效目標數為$2$，平均NLL為$3\ln2/2$ nats。
5. 困惑度為$\exp(3\ln2/2)=2^{3/2}$。

若錯把PAD計入分母，就會得到$3$；若對兩筆有效位置的loss各自取不同批次平均再平均，也可能因批次長度不同而得到另一個結果。以上計算只在假設的模型機率下成立，不代表任何程式實測值。

## 實作與程式

以下程式以標準庫與NumPy建立合成文件，先以文件為單位分割，再用訓練文件建立詞彙表，最後於各分割內切窗。模型是供CPU示範的單層自回歸循環語言模型，而非Transformer；本章焦點是下一詞元目標、邊界與loss平均。程式沒有下載模型或語料，未在本章執行，輸出及測試結果僅為預期。

每個訓練樣本包含一個窗口的輸入、錯一位的目標與布林有效遮罩。批次尾端以PAD補齊；整個窗口沒有跨文件。簡單循環模型在每個位置讀取目前token embedding與前一隱狀態，對詞彙表輸出logits，並明確因果地只依賴目前及以前的位置。

```python
from collections import Counter
import numpy as np


PAD = "<PAD>"
UNK = "<UNK>"
EOS = "<EOS>"


def make_documents(n_groups=18, per_group=6, seed=17):
    """只生成示範文字；每份文件附群組與時間索引。"""
    rng = np.random.default_rng(seed)
    documents = []
    for group in range(n_groups):
        for time in range(per_group):
            slot = f"槽{group % 3}"
            trend = ("平穩", "觀察")[int(rng.integers(0, 2))]
            tokens = [
                "日誌", f"群{group}", f"時段{time}",
                slot, trend, "記錄", EOS
            ]
            documents.append({
                "group": group,
                "time": time,
                "tokens": tokens,
            })
    return documents


def split_documents(documents):
    """依完整群組切分，不拆散同群文件。"""
    train, valid, test = [], [], []
    for doc in documents:
        g = doc["group"]
        if g < 12:
            train.append(doc)
        elif g < 15:
            valid.append(doc)
        else:
            test.append(doc)
    return train, valid, test


def build_vocab(train_docs):
    words = sorted({
        token
        for doc in train_docs
        for token in doc["tokens"]
        if token not in (PAD, UNK)
    })
    vocab = {PAD: 0, UNK: 1}
    vocab.update({word: i + 2 for i, word in enumerate(words)})
    return vocab


def encode_windows(docs, vocab, window=8):
    """先逐文件編碼，再於文件內建立錯位窗口。"""
    if window < 1:
        raise ValueError("window 必須至少為 1")
    examples = []
    for doc in docs:
        ids = [vocab.get(token, vocab[UNK]) for token in doc["tokens"]]
        if len(ids) < 2:
            continue
        # 一次最多預測 window 個目標；相鄰片段不跨文件。
        for start in range(0, len(ids) - 1, window):
            chunk = ids[start:start + window + 1]
            if len(chunk) >= 2:
                examples.append((chunk[:-1], chunk[1:]))
    return examples


def make_batch(examples, indices, pad_id=0):
    chosen = [examples[i] for i in indices]
    width = max(len(x) for x, _ in chosen)
    x = np.full((len(chosen), width), pad_id, dtype=np.int64)
    y = np.full((len(chosen), width), pad_id, dtype=np.int64)
    valid = np.zeros((len(chosen), width), dtype=bool)
    for b, (xb, yb) in enumerate(chosen):
        n = len(xb)
        x[b, :n] = xb
        y[b, :n] = yb
        valid[b, :n] = True
    return x, y, valid


class TinyRNN:
    """供CPU示範的單層循環語言模型；不含外部預訓練權重。"""

    def __init__(self, vocab_size, emb=12, hidden=20, seed=23):
        rng = np.random.default_rng(seed)
        self.E = rng.normal(0, 0.08, (vocab_size, emb))
        self.Wx = rng.normal(0, 1 / np.sqrt(emb), (emb, hidden))
        self.Wh = rng.normal(0, 1 / np.sqrt(hidden), (hidden, hidden))
        self.bh = np.zeros(hidden)
        self.Wo = rng.normal(0, 1 / np.sqrt(hidden), (hidden, vocab_size))
        self.bo = np.zeros(vocab_size)
        self.params = [self.E, self.Wx, self.Wh, self.bh, self.Wo, self.bo]

    def loss_and_grads(self, x, y, valid):
        B, T = x.shape
        V = self.bo.shape[0]
        H = self.bh.shape[0]
        if valid.shape != (B, T) or y.shape != (B, T):
            raise ValueError("x、y、valid 的批次與時間shape必須一致")
        count = int(valid.sum())
        if count == 0:
            raise ValueError("批次沒有有效目標詞元")

        hs = np.zeros((B, T + 1, H))
        probs = np.zeros((B, T, V))
        loss_sum = 0.0
        for t in range(T):
            xt = self.E[x[:, t]]
            hs[:, t + 1] = np.tanh(
                xt @ self.Wx + hs[:, t] @ self.Wh + self.bh
            )
            z = hs[:, t + 1] @ self.Wo + self.bo
            z = z - z.max(axis=1, keepdims=True)
            p = np.exp(z)
            p /= p.sum(axis=1, keepdims=True)
            probs[:, t] = p
            rows = np.arange(B)
            loss_sum += -np.log(p[rows[valid[:, t]], y[valid[:, t], t]]).sum()

        grads = [np.zeros_like(p) for p in self.params]
        gE, gWx, gWh, gbh, gWo, gbo = grads
        dh_next = np.zeros((B, H))

        for t in range(T - 1, -1, -1):
            zgrad = probs[:, t].copy()
            rows = np.arange(B)
            zgrad[rows[valid[:, t]], y[valid[:, t], t]] -= 1.0
            zgrad *= valid[:, t, None] / count

            gWo += hs[:, t + 1].T @ zgrad
            gbo += zgrad.sum(axis=0)
            dh = zgrad @ self.Wo.T + dh_next
            da = dh * (1.0 - hs[:, t + 1] ** 2)
            gWx += self.E[x[:, t]].T @ da
            gWh += hs[:, t].T @ da
            gbh += da.sum(axis=0)
            np.add.at(gE, x[:, t], da @ self.Wx.T)
            dh_next = da @ self.Wh.T

        return loss_sum / count, grads

    def step(self, grads, lr):
        for p, g in zip(self.params, grads):
            p -= lr * g


def iterate_batches(examples, batch_size, rng, shuffle):
    order = np.arange(len(examples))
    if shuffle:
        rng.shuffle(order)
    for start in range(0, len(order), batch_size):
        yield make_batch(examples, order[start:start + batch_size])


def evaluate(model, examples, batch_size=8):
    """回傳token加權NLL及有效token數；空資料集拒絕評估。"""
    if not examples:
        raise ValueError("評估集合沒有樣本")
    total_nll = 0.0
    total_tokens = 0
    rng = np.random.default_rng(0)
    for x, y, valid in iterate_batches(examples, batch_size, rng, False):
        loss, _ = model.loss_and_grads(x, y, valid)
        n = int(valid.sum())
        total_nll += loss * n
        total_tokens += n
    if total_tokens == 0:
        raise ValueError("評估集合沒有有效目標詞元")
    return total_nll / total_tokens, total_tokens


def run_demo():
    docs = make_documents()
    train_docs, valid_docs, test_docs = split_documents(docs)

    # 詞彙表只用訓練文件；每個split另行切窗。
    vocab = build_vocab(train_docs)
    train_ex = encode_windows(train_docs, vocab)
    valid_ex = encode_windows(valid_docs, vocab)
    test_ex = encode_windows(test_docs, vocab)

    model = TinyRNN(len(vocab))
    rng = np.random.default_rng(41)
    history = []
    for epoch in range(8):
        for x, y, valid in iterate_batches(train_ex, 8, rng, True):
            loss, grads = model.loss_and_grads(x, y, valid)
            model.step(grads, lr=0.03)
        valid_nll, valid_tokens = evaluate(model, valid_ex)
        history.append((epoch + 1, valid_nll, valid_tokens))

    test_nll, test_tokens = evaluate(model, test_ex)
    return {
        "vocab_size": len(vocab),
        "train_windows": len(train_ex),
        "valid_windows": len(valid_ex),
        "test_windows": len(test_ex),
        "history": history,
        "test_nll": test_nll,
        "test_tokens": test_tokens,
        "test_perplexity": float(np.exp(test_nll)),
    }


if __name__ == "__main__":
    print(run_demo())
```

程式中的每個批次loss都是批次內有效目標詞元的平均，梯度也除以同一個有效詞元數。不同批次使用SGD更新，故一個epoch並不等同「先把全訓練集梯度加總再更新一次」；若要比較不同微批的梯度累積，必須以有效詞元數加權，不能直接平均微批平均值。模型的驗證NLL用「批次平均乘有效數」還原總NLL，再除以驗證集總詞元數。

此教學模型以PAD補齊，但仍更新PAD embedding列的可能性要小心：padding位置被loss遮掉，模型輸出的梯度在該位置為零；然而若padding位置位於前段，它仍可能影響後段隱狀態。當一筆序列的有效內容結束後，後續PAD不會產生loss，但不應再接有效目標，因此不會讓PAD狀態服務於任何有效監督。更一般的架構仍應明確處理padding key、position與狀態傳遞，不能把loss遮罩當成所有padding問題的解答。

## 測試與預期結果

以下測試是建議加入的檢查；本章沒有執行它們，故結果均為預期，不是通過紀錄。

### 正常測試

1. **位移長度**：對長度為$L$的token序列，確認每個文件的輸入、目標長度均為$L-1$，且第$t$個目標等於原序列第$t+1$項。
2. **切分互斥**：以文件識別碼檢查train、valid、test沒有交集；檢查同一group沒有跨集合。
3. **窗口不跨文件**：為兩份短文件使用不同的標記，確認任何窗口的詞元都只來自其中一份文件。
4. **PAD遮罩**：將有效token計數與原始文件的相鄰詞元數比較；批次補齊增加的PAD位置不得增加計數。
5. **重複索引梯度**：讓兩個batch位置輸入同一token，檢查embedding梯度採累加而非覆寫。程式以`np.add.at`實作此累加。
6. **平均一致性**：把相同有效token分成不同大小批次，累加各批次平均乘該批有效數，除以總有效數；應與一次整批token加權NLL一致到浮點容差內。

預期`run_demo()`會回傳詞彙大小、各分割窗口數、驗證歷史與測試NLL。程式未執行，不能聲稱loss下降、模型收斂或測試分數具有特定數值。

### 邊界測試

- **空有效批次**：`valid`全為False時，預期拋出`ValueError`，避免除以零。
- **極短文件**：只有一個token的文件沒有相鄰目標，預期不產生訓練窗口；空文件亦不應產生窗口。
- **窗口長度非法**：`window=0`或負值預期拒絕。
- **未知詞元**：只在valid或test出現的詞元預期映射為訓練詞彙表中的UNK，不能改寫詞彙表。
- **批次大小一**：批次維度仍是$B=1$，`x`、`y`及`valid`仍有shape$(1,T)$；不得因squeeze而失去batch軸。
- **空評估集合**：預期拒絕計算平均NLL或PPL。

### 故障測試

- **目標未錯位**：若誤把`y=x`，測試應指出目標不是輸入的下一詞元；即使訓練loss降低，也不代表目標正確。
- **先切窗再拆分**：故意將同一長文件的不同窗口放進train與test，分組互斥檢查應失敗。
- **PAD未遮罩**：把padding列加入loss後，有效token計數測試應失敗；訓練可能因此學到預測PAD。
- **跨文件串接**：串接兩份文件而未插入邊界，人工檢查會找到「前一份文件末token到下一份文件首token」的虛假目標對。
- **測試集擬合詞彙表**：把test獨有詞加入vocab的故障版本，應違反訓練詞彙表契約。
- **非有限輸入**：若logits含NaN或無限值，softmax可能污染loss與梯度。正式訓練應在模型輸出及梯度上加有限值斷言；不能以加epsilon或直接忽略來掩蓋故障。
- **詞元平均重複除數**：若每步梯度已除以有效token數，累積後又除一次總數，梯度會被錯誤縮小。反之，對總loss求和卻完全不除，也會令更新尺度隨批次有效token數改變。

## 反例與常見陷阱

**把低訓練loss當成能力。** 重複模板可能讓模型記住群組標記與固定詞序。訓練loss低只描述訓練目標；是否能泛化要看事先保留、未參與詞彙表擬合及模型選擇的集合。即使測試表現良好，也只支持對該合成分布的有限結論。

**在拆分前切重疊窗口。** 假設窗口長度為8，相鄰窗口共享大量詞元；將窗口隨機分入不同集合，可令測試樣本幾乎是訓練樣本的副本。應先按文件、群組或時間切分，再在各分割內切窗；若部署情境要預測未來，還應保留時間先後，不能只以隨機切分取代時間測試。

**把EOS或PAD混為一談。** EOS是文件內容的一部分，可作為模型預測目標；PAD只是補齊記號。將兩者用同一ID會讓模型無法分辨「文件結束」與「批次填充」。忽略EOS則可能令模型訓練資料缺乏明確文件終止訊號。

**目標錯一位或因果遮罩錯位。** 若輸入與目標同位置，模型可能只複製當前詞元。若注意力允許讀到未來目標，loss可降低但訓練任務已作弊。單看分數不足以查明，應以改動未來詞元不影響過去輸出、遮罩索引與人工小例子共同驗證。

**混用loss平均。** `sum`、`mean`與mask必須寫清楚。對詞元加權任務，跨批次總NLL除以總有效詞元數才是整體平均；不同批次的平均loss不能無權重地等權平均。梯度累積也必須保留相同權重。

**把合成規律誤作真實知識。** 模型可能輸出看似可信的日期、槽別或狀態，但那只是合成模板的延伸，不是對現場的觀測。不存在於輸入中的資料不得靠生成補齊；任何現場判斷須由可靠量測、來源與專業程序支持。

## AI、幾何與養殖案例

本章中的合成日誌可包含群組、時間、槽別與有限狀態詞元。例如「群4、時段2、槽1、觀察」只表示生成器按其規則構造了一行文字，不代表真的量測到某個池槽狀態。這些文字適合測試資料管線，不能直接代表感測器精度、魚體狀況或操作閾值。

從幾何角度看，詞元經embedding查表變成向量；模型把前綴映射成hidden state，再對詞彙表做線性投影得到logits。交叉熵的梯度會調整這些向量與權重，使目標詞元相對競爭類別取得較高分數。但向量距離不是自動存在的因果關係；模型在表示空間中學到的相近，也不等於某項養殖因素造成另一項變化。

資料切分應對應要回答的問題：

- **新文件評估**：以完整文件分組，不讓同一文件的窗口跨集合。
- **新群組評估**：以槽別或群組分割，測試模型是否只記住群組標記。
- **未來時間評估**：用較早時間訓練、較晚時間驗證與測試，檢查時間分布改變。
- **模板偏移評估**：保留不同模板或未見詞元，檢查UNK與分布外輸入處理。

這些評估回答的是不同問題，不應混成單一分數。若某種槽別只出現在測試集，詞彙表將其映射到UNK是管線行為，不是模型已理解新槽別。若要使用真實日誌，還需另行處理資料權限、匿名化、量測品質與專業審核；本章沒有提供這些資料或流程。

生成模型可能產生錯誤或不存在的記錄。任何下游系統應將模型輸出視為待查內容，而不是資料庫事實或操作命令。本章不控制泵浦、曝氣、投餌、加藥、財務或任何外部設備。

## 習題

### 一、手算題

1. 詞元序列為`[A, B, C, D, E]`，寫出輸入、目標及有效目標數。若窗口最多容納3個目標詞元，寫出符合本章「相鄰窗口不漏掉目標對」的窗口內容；說明是否可以跨下一份文件補足。
2. 某批次三個位置的目標機率依序為$1/2$、$1/8$、最後一格是PAD；有效遮罩為$(1,1,0)$。求有效token平均NLL及PPL，並說明PAD的機率是否應進計算。

### 二、程式題

3. 修改資料生成器，使文件含四個文字欄位，並為每份文件保留明確的group及time。實作文件級切分、只用訓練文件建立詞彙表、UNK映射和切窗；以斷言驗證同一文件的窗口不跨split。
4. 為程式加入資料與梯度有限值檢查，並寫一個loss測試：同一組有效token先作單批次，再分為兩個不同長度微批，還原總NLL與總token數，比較詞元平均。

### 三、反例題

5. 某人先將每份長文件切成大量重疊窗口，再把所有窗口隨機切成train與test，並以test loss作模型優劣比較。構造一個明確的資料洩漏情境，說明為何測試結果會過度樂觀；給出符合本章契約的最小修正。
6. 某實作者說：「我在PAD位置也計算交叉熵，因為模型看得到PAD，所以loss平均更穩定。」指出這個說法至少兩個問題，並寫出有效token平均的分子與分母。

### 四、整合題

7. 設計一個合成日誌評估計畫，分別回答「對新文件泛化」與「對較晚時間泛化」；寫出切分單位、詞彙表擬合資料、窗口建立次序、loss與PPL分母，以及不可由合成結果推論的事項。
8. 有兩個微批，第一批有效目標2個、平均loss為$L_1$，第二批有效目標6個、平均loss為$L_2$。寫出合併後詞元平均loss，並說明為何$(L_1+L_2)/2$一般錯誤。若以微批梯度累積，說明如何按有效數加權。

## 習題解答

### 一、手算題解答

1. 輸入為`[A, B, C, D]`，目標為`[B, C, D, E]`，有效目標數為4。分成最多3個目標的連續窗口，可取輸入`[A,B,C]`、目標`[B,C,D]`，再取輸入`[D]`、目標`[E]`；第二窗口的輸入包含前一窗口最後一個目標，才能保留邊界相鄰對$(D,E)$。兩窗口都來自原文件，不能拿下一份文件的詞元補足。如果資料管線刻意採不重疊區塊，則須另行定義上下文重置及邊界目標策略，不能默默省略或跨文件接續。
2. 第一個NLL為$\ln2$，第二個為$\ln8=3\ln2$。PAD遮罩為0，不計入分子或分母。有效平均為$(\ln2+3\ln2)/2=2\ln2$ nats，PPL為$\exp(2\ln2)=4$。

### 二、程式題解答

3. 文件生成器應讓每份文件保有不重複文件ID，以及group、time等欄位。以整份文件為最小切分單位，先建立train、valid、test，再從train文件收集詞元建立詞彙表；valid或test的未知詞映射為UNK。對每個split獨立逐文件切窗，並為每個窗口保留來源文件ID。斷言每個文件ID只能出現在一個split，即可抓出同文件窗口跨集合。若以時間為目標，先依時間指定整段區間，不可先隨機打散。
4. 對所有參數、logits、loss與梯度檢查`np.isfinite(...).all()`。先用同一批有效位置計算總NLL$S$與計數$N$；再分成有效數分別為$n_1,n_2$的微批，其平均為$L_1,L_2$。比較$(S/N)$與$(n_1L_1+n_2L_2)/(n_1+n_2)$，容許浮點誤差。這是數值等價檢查，不是模型泛化測試。若要比較梯度，同樣對微批平均梯度乘各自有效數後加總，再除以總有效數。

### 三、反例題解答

5. 一份長文件含有高度重疊的窗口$w_1,w_2$，它們共享多數詞元。若$w_1$進train、$w_2$進test，模型訓練時已看過測試窗口大部分內容，test loss不能代表未見文件。最小修正是先依完整文件（或指定group／時間）分割，再在各split內獨立切窗，並用train建立詞彙表。
6. 第一，PAD不是監督目標；它的loss會改變模型預測分布，讓模型學會輸出填充符號。第二，把PAD加入分母會讓平均值依批次補齊長度而變，樣本相同但batch排列不同可能得到不同loss。正確分子是$\sum_{b,t}a_{b,t}\ell_{b,t}$，分母是$\sum_{b,t}a_{b,t}$，且分母必須大於0；全無效時拒絕計算。

### 四、整合題解答

7. 對新文件泛化，以文件ID或文件所屬group作互斥分割；對較晚時間泛化，按時間先後分出早期train、較晚valid及最晚test。兩項評估最好分開回報，不把不同目的的測試集合混為一談。先切文件，再僅用train文件建立詞彙表，最後在每個split內逐文件切窗。以有效目標詞元總NLL除以有效目標數計算平均NLL，PPL為其指數；分母為有效目標詞元總數。合成結果不能證明真實量測有效、具現場因果解釋、可作安全決策或能跨資料分布泛化。
8. 合併平均為$(2L_1+6L_2)/8$。$(L_1+L_2)/2$把只有2個有效詞元的微批與有6個的微批等權，除非兩批有效數相同，否則不等於詞元平均。若梯度$g_1,g_2$各已按微批有效數取平均，累積的詞元平均梯度為$(2g_1+6g_2)/8$；若先累積未平均的梯度總和，最後除一次總有效數8，亦可得到同一加權方式。

## 本章小結

下一詞元訓練將輸入與目標錯位一格，使每個位置預測原序列中的下一個詞元。要讓這個目標有效，資料切分必須先於窗口建立：先按文件、群組或時間界定資料集合，再只用訓練資料擬合詞彙表，之後於每份文件內切窗。

對形狀$(B,T,V)$的logits，交叉熵沿最後的詞彙軸計算；有效目標遮罩形狀是$(B,T)$。PAD不參與loss，平均分母是有效目標詞元總數；困惑度則是有效token平均NLL的指數。空有效批次沒有定義良好的平均，必須明確拒絕。

合成CPU程式可以檢查資料管線、梯度及評估公式，卻不等於已訓練，也不能證明模型理解真實日誌。驗收時應分別檢查錯位、切分互斥、文件邊界、PAD遮罩、token加權與非有限值；任何實驗結論都須附上資料分割和計數定義。
