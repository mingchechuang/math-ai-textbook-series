# 第30章 整合專題：合成養殖日誌Transformer與Agent

## 學習目標與先備知識

本章將矩陣、機率、反向傳播、注意力、自回歸訓練與唯讀Agent整合成一個可稽核的小型專題：模型讀取**合成養殖日誌**，預測下一個字元；生成後，Agent只可查詢預先核准的合成紀錄，並須提供可定位的來源，否則拒答。

完成本章後，讀者應能：

1. 說明模型、資料、目標函數、評估指標與泛化能力是不同概念。
2. 依文件群組切分資料，再建立詞表與訓練視窗，避免重疊視窗造成洩漏。
3. 追蹤decoder-only模型的張量形狀、因果遮罩、有效token loss與生成位置。
4. 設計未來資訊洩漏、快取等價性與分布外測試，並把未執行的結果明確標示為預期。
5. 將生成文字與工具授權分開：模型可以提出查詢，但只能由程式驗證並呼叫唯讀mock工具。

先備知識為矩陣乘法、softmax與交叉熵、梯度下降、Python及NumPy基本語法。完整模型部分使用PyTorch CPU；程式明列依賴，不下載權重、語料或tokenizer，也不執行shell、網路或設備操作。本文沒有實際執行程式，因此所有測試結果均為**預期**，不表示程式已通過或模型已訓練。

## 問題與直覺

假設日誌由以下合成規則產生：

```text
槽位=南槽;天數=12;天氣=晴;狀態=穩定
```

模型收到前綴`槽位=南`，輸出下一字元的機率分布。若要生成完整紀錄，就從起始符號`^`開始，反覆預測下一字元，直到輸出結束符號`$`或達到長度上限。

須分清楚五件事：

- **資料契約**：每筆資料是合成文件，含生成seed、文件群組、時間欄與生成規則版本。
- **模型**：把token前綴映射成下一token logits的參數化函數。
- **目標函數**：只對有效的下一token標籤計算負對數似然。
- **評估**：在預先保留的群組或時間區間上計算token加權NLL與perplexity。
- **能力主張**：測試結果只支持指定合成分布上的觀察，不能推出真實養殖操作能力、因果知識或安全性。

本專題採文件群組切分：先依`group`將來源文件分到train、validation與test，再只用train建立詞表與估計任何資料統計量，最後才為各集合建立視窗。來自同一文件的重疊視窗不可分落不同集合。程式使用固定群組清單與固定seed作為教學示例；正式實驗還應保存逐文件manifest，逐列記錄來源識別、時間、seed、生成規則版本與所屬集合。

本章也採用一個簡單基線：只以train資料估計下一token的整體頻率分布，對每個有效目標都預測該分布。它不利用上下文，不能代表所有合理基線；其作用是提供可重算的最低限度比較。訓練詞表、基線統計與模型參數都不得使用test資料。

## 定義、定理與推導

### 張量與機率域

令批次大小為$B$、序列長度為$T$、模型維度為$D$、注意力頭數為$H$。模型輸入token id形狀為$(B,T)$；embedding後為$(B,T,D)$；語言模型輸出logits為$(B,T,V)$，其中$V$為詞表大小。目標token形狀為$(B,T)$。

對第$b$筆、第$t$個有效標籤，令logits為$z_{b,t,:}$，正確類別為$y_{b,t}$。穩定的單點交叉熵為：

$$
\ell_{b,t}=\log\sum_{j=1}^{V}\exp(z_{b,t,j})-z_{b,t,y_{b,t}}
$$

計算log-sum-exp時先減去該列最大值。令有效標籤遮罩$m_{b,t}\in\{0,1\}$，有效token總數為$N=\sum_{b,t}m_{b,t}$。若$N>0$，批次平均損失為：

$$
L=\frac{\sum_{b,t}m_{b,t}\ell_{b,t}}{N}
$$

若$N=0$，評估或訓練應明確報錯，不可除以零，也不可悄悄回傳零損失。這裡的mean是**所有有效token的整體平均**，不是先求每列平均再平均各列；後者會讓長短不同的文件得到不同權重。總有效token NLL為$S=\sum m_{b,t}\ell_{b,t}$，token加權perplexity為$\exp(S/N)$。perplexity的指數輸入使用nats/token；不可對不同token數批次的perplexity做不加權平均。

### 小命題：下一token遮罩不可讀取未來token

**命題。** 若位置$i$的計算僅依賴位置不大於$i$的輸入token，且所有注意力層只允許查詢位置$i$讀取絕對位置$j\le i$的key，則位置$i$的輸出不依賴任何位置$k>i$的輸入token。

**證明。** 先考慮單層自注意力。位置$i$的query只與允許的key做內積，遮罩將所有$j>i$的位置排除；因此其注意力加權值只由位置$i$或更早的value組成。逐位置的正規化、前饋層與殘差連接只組合同一位置的表示，不會引入其他位置的新資訊。故此層位置$i$表示只依賴不晚於$i$的輸入。對多層模型以層數歸納：若上一層每個位置$i$只依賴不晚於$i$的輸入，下一層位置$i$只讀取上一層$j\le i$的表示；每個該表示又只依賴不晚於$j\le i$的輸入。因此任意層的$i$位置輸出均不依賴$k>i$。證畢。

這項結論依賴實作確實採用同一因果遮罩、位置索引正確，而且沒有額外的跨位置洩漏路徑。它不是「模型理解因果」的證明。

### 自回歸對齊與資料切分

若token序列為$(x_0,x_1,\ldots,x_T)$，訓練輸入是$(x_0,\ldots,x_{T-1})$，標籤是$(x_1,\ldots,x_T)$。兩者shape均為$(B,T)$，但每個輸入位置的目標向前移一格。因果遮罩讓位置$t$不能看見輸入中位置大於$t$的token；而輸入位置$t$對應的標籤正是原序列$x_{t+1}$。

PAD若用於補齊，必須在loss中忽略其標籤，也不能讓有效query讀取PAD key。本章資料批次採右側補齊：`x.ne(pad_id)`作為key有效遮罩，targets中的`-100`作為loss忽略標記。兩者各自處理：key遮罩限制注意力可讀位置；loss遮罩決定哪些標籤計入目標。

切分先於詞表擬合與視窗建立，理由是：同一文件的相鄰重疊視窗高度相關；若一部分進train、一部分進test，測試就不再是獨立文件上的評估。詞表若由全部集合建立，也會把測試文件是否出現某字元的資訊帶入訓練流程。本章採訓練集合建詞表，驗證／測試出現未見字元時，以訓練詞表中的`<UNK>`表示。

### 證據契約

每次訓練至少記錄：生成規則版本、資料seed、文件group與切分、詞表、模型設定、初始化seed、訓練步數、optimizer狀態、訓練與驗證token數、最佳checkpoint選擇規則，以及每項測試的預期與實際結果欄位。程式中的manifest先以記憶體資料結構建立並列印；除非明確另存檔案，不稱為「已保存到磁碟」。未執行的結果欄位標記「未執行」，不能填入推測數字。

test只在模型與選擇規則固定後使用；不得根據test分數挑超參數或checkpoint。基線和模型須使用相同的詞表、有效標籤與token加權指標，才能進行有意義的比較。

## 逐步手算例題

### 例一：有效token平均與perplexity

假設兩個有效標籤的正確類別機率分別為$1/2$與$1/4$，第三格為PAD且不計入loss。

1. 第一步，把正確類別機率取負對數：第一格為$-\log(1/2)=\log2$，第二格為$-\log(1/4)=\log4=2\log2$。
2. 第二步，將有效格相加：$S=3\log2$。PAD格遮罩為零，不加進總和。
3. 第三步，有效token數為$N=2$，所以平均NLL為$S/N=1.5\log2$。
4. 第四步，perplexity為$\exp(1.5\log2)=2^{1.5}$，約為$2.828$。

若錯把三格都放進分母，就會因PAD而低估NLL；若先計算兩個批次的perplexity再不加權平均，也不一定得到以總NLL除以總token數的結果。

### 例二：因果遮罩與一個query

令query/key維度$D=1$，query為$1$，兩個key為$0$與$\log3$。未遮罩的點積分數是$0$與$\log3$，softmax權重為$1/4$與$3/4$。若value為$2$與$10$，輸出是：

$$
\frac14\cdot2+\frac34\cdot10=8
$$

現在假設這是序列位置0的query，key 1屬於未來位置，因此因果遮罩只允許key 0。允許列的softmax只含一項，權重為1，輸出變成2。未來value由10改成任意其他有限數，位置0的輸出都仍為2。這是遮罩語義的手算檢查，不取代多層模型的程式測試。

### 例三：文件切分與滑動視窗

有四份合成文件，group依序為G1、G2、G3、G4。先指定G1、G2為train，G3為validation，G4為test；完成切分後才在每份文件內以長度4建立視窗。例如train文件序列長度7，可能得到索引0–3、1–4、2–5、3–6的視窗。所有視窗的來源仍標記為同一train文件。不可將第一個視窗放train、第二個放test；它們共享大部分字元，會洩漏局部內容。若驗證文件含訓練詞表沒有的字元，映射為`<UNK>`，而不是事後把它加進詞表。

## 實作與程式

以下為單檔CPU PyTorch專題程式，涵蓋合成文件、group切分、manifest、訓練詞表、視窗、簡單頻率基線、decoder-only模型、loss、optimizer、訓練loop、生成、未來洩漏測試、增量KV cache等價性檢查、合成OOD評估與唯讀mock Agent。程式沒有下載模型或資料，也不控制真實設備。教材程式尚未執行；程式輸出及測試結果都不能視為已訓練或已通過。

依賴為Python標準庫與PyTorch；版本、CPU型號、dtype均未知。正式實驗應將manifest、版本資訊、訓練紀錄與checkpoint另行序列化保存。以下checkpoint只在記憶體建立示例物件，不代表已寫入磁碟；不載入不可信pickle或checkpoint。

```python
import math
import random
from dataclasses import dataclass

import torch
import torch.nn as nn
import torch.nn.functional as F


PAD, BOS, EOS, UNK = "<PAD>", "^", "$", "<UNK>"
RULE_VERSION = "synthetic-log-v1"


@dataclass
class Doc:
    doc_id: str
    group: str
    time: int
    text: str
    seed: int
    rule_version: str


def make_documents(seed=17, per_group=4):
    """完全合成；欄位只是教學字串，不是操作閾值或實務建議。"""
    rng = random.Random(seed)
    groups = ["G0", "G1", "G2", "G3", "G4"]
    weather = ["晴", "雲", "雨"]
    state = ["穩定", "觀察", "待查"]
    docs = []
    for gi, group in enumerate(groups):
        for j in range(per_group):
            time = gi * 10 + j
            text = (
                f"槽位={['北槽','南槽','西槽'][gi % 3]};"
                f"天數={time};天氣={rng.choice(weather)};"
                f"狀態={rng.choice(state)}"
            )
            docs.append(Doc(
                doc_id=f"SYN-{group}-{j}", group=group, time=time,
                text=text, seed=seed, rule_version=RULE_VERSION
            ))
    return docs


def split_documents(docs):
    train_groups, val_groups, test_groups = {"G0", "G1"}, {"G2"}, {"G3", "G4"}
    out = {
        "train": [d for d in docs if d.group in train_groups],
        "val": [d for d in docs if d.group in val_groups],
        "test": [d for d in docs if d.group in test_groups],
    }
    names = ("train", "val", "test")
    group_sets = [{d.group for d in out[name]} for name in names]
    assert group_sets[0].isdisjoint(group_sets[1])
    assert group_sets[0].isdisjoint(group_sets[2])
    assert group_sets[1].isdisjoint(group_sets[2])
    return out


def build_manifest(split):
    rows = []
    for split_name in ("train", "val", "test"):
        for doc in split[split_name]:
            rows.append({
                "doc_id": doc.doc_id,
                "group": doc.group,
                "time": doc.time,
                "seed": doc.seed,
                "rule_version": doc.rule_version,
                "split": split_name,
            })
    return rows


def build_vocab(train_docs):
    chars = sorted({ch for d in train_docs for ch in d.text})
    tokens = [PAD, BOS, EOS, UNK] + chars
    return {tok: i for i, tok in enumerate(tokens)}


def encode_document(doc, vocab):
    return [vocab[BOS]] + [
        vocab.get(ch, vocab[UNK]) for ch in doc.text
    ] + [vocab[EOS]]


def make_windows(docs, vocab, context):
    pairs = []
    for doc in docs:
        ids = encode_document(doc, vocab)
        for start in range(0, len(ids) - 1, context):
            x = ids[start:start + context]
            y = ids[start + 1:start + context + 1]
            if x:
                pairs.append((x, y, doc.doc_id))
    return pairs


def collate(pairs, pad_id):
    if not pairs:
        raise ValueError("空資料批次")
    t = max(len(x) for x, _, _ in pairs)
    x = torch.full((len(pairs), t), pad_id, dtype=torch.long)
    y = torch.full((len(pairs), t), -100, dtype=torch.long)
    for i, (xi, yi, _) in enumerate(pairs):
        x[i, :len(xi)] = torch.tensor(xi, dtype=torch.long)
        y[i, :len(yi)] = torch.tensor(yi, dtype=torch.long)
    return x, y


def train_frequency_baseline(train_pairs, vocab_size):
    counts = torch.zeros(vocab_size, dtype=torch.float64)
    for _, targets, _ in train_pairs:
        for token_id in targets:
            counts[token_id] += 1
    if counts.sum() == 0:
        raise ValueError("基線訓練資料沒有目標token")
    # 加一平滑，避免基線對某類給出零機率。
    probs = (counts + 1.0) / (counts.sum() + vocab_size)
    return probs


def evaluate_frequency_baseline(probs, pairs):
    total_nll = 0.0
    total_tokens = 0
    for _, targets, _ in pairs:
        for token_id in targets:
            total_nll -= math.log(float(probs[token_id]))
            total_tokens += 1
    if total_tokens == 0:
        raise ValueError("評估集沒有有效token")
    mean_nll = total_nll / total_tokens
    return {
        "nll_per_token": mean_nll,
        "perplexity": math.exp(mean_nll),
        "tokens": total_tokens,
    }


class CausalBlock(nn.Module):
    def __init__(self, d_model, n_head, d_ff, dropout=0.0):
        super().__init__()
        if d_model % n_head:
            raise ValueError("d_model必須可被n_head整除")
        self.d_model = d_model
        self.n_head = n_head
        self.dh = d_model // n_head
        self.qkv = nn.Linear(d_model, 3 * d_model)
        self.out = nn.Linear(d_model, d_model)
        self.ff1 = nn.Linear(d_model, d_ff)
        self.ff2 = nn.Linear(d_ff, d_model)
        self.n1 = nn.LayerNorm(d_model)
        self.n2 = nn.LayerNorm(d_model)
        self.drop = nn.Dropout(dropout)

    def _project_qkv(self, x):
        b, t, d = x.shape
        qkv = self.qkv(x).view(b, t, 3, self.n_head, self.dh)
        q, k, v = qkv.permute(2, 0, 3, 1, 4).unbind(0)
        return q, k, v

    def forward(self, x, key_valid=None, position_offset=0):
        b, t, d = x.shape
        q, k, v = self._project_qkv(x)
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.dh)

        q_pos = torch.arange(position_offset, position_offset + t,
                             device=x.device)[:, None]
        k_pos = torch.arange(position_offset, position_offset + t,
                             device=x.device)[None, :]
        allowed = (k_pos <= q_pos)[None, None, :, :]

        if key_valid is not None:
            if key_valid.shape != (b, t):
                raise ValueError("key_valid必須為(B,T)")
            allowed = allowed & key_valid[:, None, None, :]

        if not bool(allowed.any(dim=-1).all()):
            raise ValueError("遇到全遮罩query列")

        scores = scores.masked_fill(~allowed, float("-inf"))
        attn = self.drop(torch.softmax(scores, dim=-1))
        z = (attn @ v).transpose(1, 2).contiguous().view(b, t, d)
        x = self.n1(x + self.drop(self.out(z)))
        f = self.ff2(self.drop(F.gelu(self.ff1(x))))
        return self.n2(x + self.drop(f))

    def incremental(self, x_new, cache):
        """單token增量前向；cache每層保存已投影的K、V。"""
        b, t, d = x_new.shape
        if t != 1:
            raise ValueError("incremental每次只接受一個token")
        position = cache["length"]
        q, k_new, v_new = self._project_qkv(x_new)
        old = cache["layers"][cache["layer_index"]]
        if old is None:
            k_all, v_all = k_new, v_new
        else:
            k_all = torch.cat([old[0], k_new], dim=2)
            v_all = torch.cat([old[1], v_new], dim=2)

        scores = q @ k_all.transpose(-2, -1) / math.sqrt(self.dh)
        # 單一新query位於最後位置；所有已快取key與本步key均不晚於它。
        allowed = torch.ones(
            (b, self.n_head, 1, k_all.shape[2]),
            dtype=torch.bool, device=x_new.device
        )
        if not bool(allowed.any(dim=-1).all()):
            raise ValueError("遇到全遮罩query列")
        attn = self.drop(torch.softmax(
            scores.masked_fill(~allowed, float("-inf")), dim=-1
        ))
        z = (attn @ v_all).transpose(1, 2).contiguous().view(b, 1, d)
        x = self.n1(x_new + self.drop(self.out(z)))
        f = self.ff2(self.drop(F.gelu(self.ff1(x))))
        out = self.n2(x + self.drop(f))

        cache["layers"][cache["layer_index"]] = (k_all, v_all)
        cache["layer_index"] += 1
        return out


class TinyLogTransformer(nn.Module):
    def __init__(self, vocab_size, d_model=32, n_head=4, d_ff=64,
                 n_layer=2, max_len=96, dropout=0.0):
        super().__init__()
        if d_model % n_head:
            raise ValueError("d_model必須可被n_head整除")
        self.max_len = max_len
        self.n_layer = n_layer
        self.token = nn.Embedding(vocab_size, d_model)
        self.pos = nn.Embedding(max_len, d_model)
        self.blocks = nn.ModuleList([
            CausalBlock(d_model, n_head, d_ff, dropout)
            for _ in range(n_layer)
        ])
        self.final_norm = nn.LayerNorm(d_model)
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
        self.lm_head.weight = self.token.weight

    def forward(self, ids, key_valid=None):
        if ids.ndim != 2:
            raise ValueError("ids必須為(B,T)")
        b, t = ids.shape
        if t < 1 or t > self.max_len:
            raise ValueError("序列長度超出範圍")
        if key_valid is not None and key_valid.shape != (b, t):
            raise ValueError("key_valid必須為(B,T)")
        pos = torch.arange(t, device=ids.device)
        x = self.token(ids) + self.pos(pos)[None, :, :]
        for block in self.blocks:
            x = block(x, key_valid)
        return self.lm_head(self.final_norm(x))

    def init_cache(self):
        return {"length": 0, "layers": [None] * self.n_layer,
                "layer_index": 0}

    def step(self, token_ids, cache):
        if token_ids.ndim != 2 or token_ids.shape[1] != 1:
            raise ValueError("token_ids必須為(B,1)")
        position = cache["length"]
        if position >= self.max_len:
            raise ValueError("cache已達max_len")
        pos = torch.tensor([position], device=token_ids.device)
        x = self.token(token_ids) + self.pos(pos)[None, :, :]
        cache["layer_index"] = 0
        for block in self.blocks:
            x = block.incremental(x, cache)
        cache["length"] += 1
        return self.lm_head(self.final_norm(x))


def masked_token_loss(logits, targets):
    if logits.shape[:2] != targets.shape:
        raise ValueError("logits與targets的B,T軸不一致")
    valid = targets.ne(-100)
    n = int(valid.sum())
    if n == 0:
        raise ValueError("批次沒有有效標籤")
    total = F.cross_entropy(
        logits.reshape(-1, logits.shape[-1]),
        targets.reshape(-1),
        ignore_index=-100,
        reduction="sum",
    )
    return total / n, total.detach(), n


@torch.no_grad()
def evaluate(model, pairs, pad_id, batch_size=32):
    model.eval()
    total_nll = 0.0
    total_tokens = 0
    for start in range(0, len(pairs), batch_size):
        batch = pairs[start:start + batch_size]
        x, y = collate(batch, pad_id)
        key_valid = x.ne(pad_id)
        logits = model(x, key_valid=key_valid)
        _, nll, n = masked_token_loss(logits, y)
        total_nll += float(nll)
        total_tokens += n
    if total_tokens == 0:
        raise ValueError("評估集沒有有效token")
    mean_nll = total_nll / total_tokens
    return {"nll_per_token": mean_nll,
            "perplexity": math.exp(mean_nll),
            "tokens": total_tokens}


def train(model, pairs, pad_id, steps=20, batch_size=16, seed=29):
    if not pairs:
        raise ValueError("訓練資料為空")
    rng = random.Random(seed)
    optimizer = torch.optim.AdamW(
        model.parameters(), lr=1e-3, weight_decay=1e-2
    )
    model.train()
    for _ in range(steps):
        chosen = [pairs[rng.randrange(len(pairs))]
                  for _ in range(min(batch_size, len(pairs)))]
        x, y = collate(chosen, pad_id)
        key_valid = x.ne(pad_id)
        optimizer.zero_grad(set_to_none=True)
        logits = model(x, key_valid=key_valid)
        loss, _, _ = masked_token_loss(logits, y)
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        optimizer.step()
    return optimizer


@torch.no_grad()
def generate(model, vocab, prompt="^", max_new=80, temperature=0.0):
    if temperature < 0:
        raise ValueError("temperature不可為負")
    inv = {i: tok for tok, i in vocab.items()}
    ids = [vocab.get(ch, vocab[UNK]) for ch in prompt]
    model.eval()
    for _ in range(max_new):
        context = ids[-model.max_len:]
        x = torch.tensor([context], dtype=torch.long)
        logits = model(x)[0, -1]
        if temperature == 0:
            nxt = int(torch.argmax(logits))
        else:
            probs = torch.softmax(logits / temperature, dim=-1)
            nxt = int(torch.multinomial(probs, 1))
        ids.append(nxt)
        if inv[nxt] == EOS:
            break
    return "".join(inv[i] for i in ids)


@torch.no_grad()
def check_future_invariance(model, ids, t, change_token):
    """只改t後的輸入；檢查至t位置的logits是否不變。"""
    model.eval()
    if ids.ndim != 2 or ids.shape[0] != 1:
        raise ValueError("測試只接受shape為(1,T)的ids")
    if not 0 <= t < ids.shape[1] - 1:
        raise ValueError("t必須留有至少一個未來位置")
    a = ids.clone()
    b = ids.clone()
    b[:, t + 1:] = change_token
    la = model(a)
    lb = model(b)
    return torch.allclose(la[:, :t + 1], lb[:, :t + 1],
                          atol=1e-6, rtol=1e-5)


@torch.no_grad()
def check_cache_equivalence(model, ids, atol=1e-6, rtol=1e-5):
    """逐位置比較完整前向與單tokenKV cache前向。"""
    model.eval()
    if ids.ndim != 2 or ids.shape[0] != 1:
        raise ValueError("測試只接受shape為(1,T)的ids")
    full = model(ids)
    cache = model.init_cache()
    pieces = []
    for i in range(ids.shape[1]):
        pieces.append(model.step(ids[:, i:i + 1], cache))
    inc = torch.cat(pieces, dim=1)
    return torch.allclose(full, inc, atol=atol, rtol=rtol)
```

### 快取路徑的對照條件

`check_cache_equivalence`比較同一序列的完整前向與逐token增量前向。要把這項比較解讀為有效測試，需固定同一模型權重、eval模式、dropout關閉、相同輸入與位置編碼，並確保cache在測試開始時為空。程式的增量路徑以cache長度作絕對位置，逐層保存key與value；每次新token讀取已快取key及當前key。每個新query只面對過去與當前位置，因此本例可使用全True的key列。若擴充到多tokenprefill、批次中不同長度序列或滑動視窗，必須重新推導矩形遮罩與位置偏移，不能直接套方陣`tril`。

跨樣本污染應以兩個獨立cache測試：先用樣本A填充cache，再建立新cache處理樣本B，並與從空cache直接處理B比較。不能重用A的cache處理B。逐位一致不是跨CPU、PyTorch版本或dtype的保證；測試須指定絕對與相對容差，並記錄執行環境。

### Agent工具契約

`call_read_tool`要求請求只有`action`、`mode`、`query`三欄；只允許`action="lookup"`與`mode="read"`。拒絕其他欄位或動作時，在呼叫工具前就中止。成功呼叫會建立事件紀錄；即使之後因沒有引用而拒答，也保留已發生的查詢事件。工具回傳的span可定位，但只證明該合成字串出現在指定文件中，不證明其內容符合現實。

### Manifest與基線的限制

程式中的manifest包含文件識別、group、time、seed、規則版本與split，並印出供檢視；若要聲稱已保存，必須另行明確寫入持久媒介並驗證內容。本章不執行檔案寫入。頻率基線只由train目標token計數，加一平滑後對validation、test與OOD使用同一機率向量；它能提供可重現的比較點，但忽略上下文，不應誤稱為強基線。

## 測試與預期結果

以下均為**未執行的測試設計與預期**。程式列印的`future_invariance_expected`與`cache_equivalence_expected`只是待驗證輸出；不能據此宣稱已通過。實際執行時應另存環境版本、seed、例外訊息與結果。

### 正常測試

1. **切分與manifest**：呼叫`split_documents`後，預期train、val、test的group互不相交。`build_manifest`對每份來源文件產生一列，欄位應含文件id、group、time、seed、生成規則版本及split。
2. **形狀檢查**：輸入`ids:(B,T)`，預期embedding為$(B,T,D)$，每頭$Q,K,V$為$(B,H,T,d_h)$，scores為$(B,H,T,T)$，logits為$(B,T,V)$。當$B=1$時批次軸仍保留。
3. **loss檢查**：logits為$(B,T,V)$、targets為$(B,T)$；有有效標籤時預期loss有限，忽略標籤不貢獻分子或分母。
4. **基線檢查**：基線機率只由train目標估計，總和預期為1；validation與test分別按有效token總NLL除以token數計算，不能平均各批次perplexity。
5. **訓練與生成**：短訓練後預期模型可以生成有限長度字串，參數仍有限；不保證loss下降或文字符合日誌欄位。
6. **Agent來源**：唯讀查詢命中指定文件時，預期回傳可定位span及事件紀錄；沒有引用或引用文件不存在時，預期拒答並保留已發生的查詢事件。
7. **快取對照**：在eval模式、固定權重與同一序列下，增量logits預期與完整前向在指定容差內相符。這僅是待執行假設，不是目前的實測結果。

### 邊界測試

1. **未知字元**：validation、test或OOD文件出現train詞表外字元時，預期映射至`<UNK>`，不改變詞表。
2. **零有效標籤**：targets全為`-100`時，`masked_token_loss`預期明確丟出`ValueError`。
3. **空資料**：空訓練批次或空評估集合預期拒絕，不得回傳零loss或未定義perplexity。
4. **序列長度**：模型收到長度0或大於`max_len`的序列時預期拒絕；cache到達長度上限時預期報錯。
5. **非整除頭維度**：`d_model`不能被`n_head`整除時，預期建構模型即拒絕。
6. **全遮罩列**：若key有效遮罩令query沒有任何允許key，預期明確報錯。
7. **錯誤工具schema**：缺欄位、多欄位或`action="shell"`、`mode="write"`等請求，預期在工具呼叫前拒絕。

### 故障與洩漏測試

1. **未來token不變性**：固定模型與前綴，只改位置$t$之後的token，位置0至$t$的logits預期在容差內不變。此測試由`check_future_invariance`提供；實際執行結果未知。
2. **文件重疊**：故意把同文件視窗分到不同集合時，應由manifest驗證拒絕。現有split函式依group切分；正式manifest驗證器還應檢查`doc_id`不可跨split。
3. **cache reset**：用樣本A填cache後，不得將該cache用於樣本B。應建立空cache處理B，並與獨立cache的結果比較；若重用cache使結果不同，預期測試失敗。
4. **cache位置錯位**：故意將位置偏移一格，完整前向與增量前向預期不再符合；測試應能察覺，而非只比較生成字串。
5. **padding遮罩**：建立含右側PAD的批次，預期`key_valid=x.ne(pad_id)`的shape為$(B,T)$，且loss只計有效targets。若改用左側padding或內部缺口，須另外定義位置策略，不能沿用此例假設。
6. **非有限logits**：含NaN或無窮值時應在訓練前明確檢查並中止；本程式未加入自訂有限值檢查，正式實驗需另加檢查與錯誤紀錄。
7. **OOD偏移**：欄位順序或值域不同的合成文件應以訓練詞表映射後單獨評估；不得用OOD結果調參，再把同一集合當成獨立測試。
8. **不存在引用**：工具沒有回傳指定文件或span時，預期Agent拒答。生成內容再流暢，也不能替代來源核驗。

## 反例與常見陷阱

- **低訓練誤差不等於泛化。** 訓練集含高度重疊視窗時，模型可能只擬合局部字串。必須看group切分後的validation與test，並檢查manifest。
- **Test不是調參集。** 看到test perplexity後再改詞表、epoch或生成策略，test就成了模型選擇資料；最終分數不再是未見選擇的評估。
- **平均方式會改變答案。** 有效token總NLL除以有效token總數，與先計算每列或每批次平均再平均通常不同；梯度累積也須按有效token數加權。
- **遮罩方向不可想當然。** 本章手寫遮罩採True=允許。其他API可能用相反語義；接API時應核對具體文件與shape。遮罩必須在softmax前施加。
- **key遮罩不是loss遮罩。** PAD不應成為有效query可讀取的key；PAD標籤也不應計入NLL，兩件事必須各自處理。
- **無來源的生成不是證據。** 「狀態穩定」即使合乎日誌格式，也不代表任何真實槽位當下穩定。Agent應回傳來源，否則拒答。
- **合成資料只驗證指定生成器下的程式路徑。** 它不能提供真實感測噪音、事件因果、專業閾值或現場安全保證。
- **快取錯位不一定報錯。** cache長度、位置編碼、樣本邊界任一錯誤都可能產生看似合理的輸出；應以完整前向logits逐位置比對。
- **數值結果不是因果解釋。** 注意力權重、loss下降與生成流暢度各自有限，不能單獨解讀成模型知道原因、支持操作或安全。

## AI、幾何與養殖案例

把一份合成日誌視為字元空間中的點序列，embedding把離散字元映射到$D$維向量；位置編碼則讓模型區分「先出現」與「後出現」。注意力依query與key相似度形成一組加權組合，但這種幾何關係不自動等於資料中的因果關係。若訓練文件只包含固定欄位順序，模型可能學到格式上的連續性，而非欄位間可靠的實務關聯。

在本章案例中，group可代表合成槽位來源，time可代表合成時間標記。按group切分可檢驗模型遇到不同合成群組時是否仍能預測字元；若group同時編碼固定模板，測試結果仍只代表這個資料生成器下的偏移。可另外製作OOD測試：在固定切分後，改用訓練未出現的欄位順序、字串組合或合成生成規則，並報告有效token數、NLL、perplexity及錯誤類型。少量OOD例子不是普遍可靠性的證據。

工具層應比生成層更保守。模型可以提出「查詢某份紀錄」，程式則驗證動作是否在allowlist、欄位型別是否正確、目標文件是否存在，然後只讀取合成記憶體資料。檢索片段必須保留來源識別與字元起訖位置；若來源找不到，回覆只能說無法核實。任何包含指令的檢索文本都視為不可信資料，不得覆蓋工具契約或系統政策。

真實養殖的感測、巡檢與操作決策涉及校正、現場情境與專業責任。本專題沒有真實資料、操作閾值或現場驗證；不得用生成結果控制泵浦、曝氣、投餌、加藥或其他設備，也不可把Agent當成現場專業人員的替代品。

7. 某Agent生成「已查證南槽紀錄」但工具沒有回傳來源span。為何這不能算引用？提供兩項可機器檢查的拒答條件。

### D. 整合設計題

8. 規劃不下載外部資料的合成OOD評估：描述生成規則、群組／時間切分、詞表處理、指標、拒答測試與manifest。不得用test調參。
9. 為增量KV cache列出至少四項必要條件，並說明逐tokenlogits對照能檢查什麼、不能保證什麼。

## 習題解答

### A. 手算題解答

1. 各token NLL分別是$\log2$、$2\log2$、$3\log2$，所以總NLL為$6\log2$ nats；有效token數是3，平均NLL為$2\log2$ nats/token；perplexity為$\exp(2\log2)=4$。兩個PAD不參與分子或分母。
2. 未遮罩輸出是$(1/3)\cdot0+(2/3)\cdot6=4$。若第二個key被遮罩，唯一可用key權重為1，輸出為0；假設該query仍有至少一個允許key。

### B. 程式題解答

3. 建立有限的`logits:(1,3,V)`與`targets:(1,3)`，其中一格設為`-100`。用`masked_token_loss`計算，再手算兩個有效位置的交叉熵總和除以2，兩者應相等。將所有target改成`-100`，預期`ValueError`。這是測試預期，不是已執行結果。
4. `TinyLogTransformer(vocab_size=..., d_model=10, n_head=3)`預期建構時拒絕；合法模型輸入形狀$(1,T)$時，輸出應為$(1,T,V)$。固定權重並切換eval，只改位置$k>t$的token，比較位置0至$t$ logits；因果遮罩成立時預期相等，實際測試需設定浮點容差。
5. 對A與B分別建立空cache。以A逐token填滿第一個cache後，丟棄該cache；對B使用另一個空cache計算增量輸出，再與模型對B完整前向逐位置logits比較。另可在錯誤實驗中把A的cache拿來接B，確認該操作不屬於允許流程；測試目的不是讓跨樣本cache輸出符合，而是證明介面會要求reset或建立新cache。

### C. 反例題解答

6. 第一，重疊視窗共享大量token，造成來源洩漏。第二，隨機視窗切分不代表新槽位或新時間群組。第三，test被用來支持超出資料分布的主張。最小修正是先按文件group或預先指定的時間區間切分來源，再各自建窗；詞表只用train建立，validation用於選擇，test在設定固定後評估，並報告切分與有效token數。
7. 「已查證」只是一段生成文字，不包含可核實的文件與span；沒有工具回傳就無法定位支持內容。可檢查：(i)citation的doc_id必須在工具結果中；(ii)start與end必須落在文件範圍內，且span確實對應回傳文字。任一條不符就拒答。

### D. 整合設計題解答

8. 固定合成生成器版本與seed，讓每份文件帶唯一group、時間索引及生成規則標籤；先把整個group或預先指定的後段時間區間分配為test，再切train與validation，並建立逐文件manifest。只用train建字符詞表，未知字元映射至`<UNK>`。報告總有效token NLL、token加權perplexity及分group結果；加入欄位順序改變、未知值與缺失欄位的合成OOD集合，明確記錄其生成規則。測試不存在引用時拒答、片段範圍正確及工具只讀。所有超參數由train／validation決定，不能看test後再修改。
9. 至少固定：同一模型權重；eval模式與關閉dropout；相同token序列與絕對位置編碼；cache長度和query/key位置一致；每個新樣本建立空cache；以明確容差逐位置比較logits。對照可抓出常見的cache位置錯位與前向計算差異，但不保證跨硬體、框架版本、dtype逐位一致，也不證明生成語義或模型品質。

## 本章小結

本章以合成文件展示來源切分、訓練詞表、視窗、頻率基線、decoder-only模型、有效token NLL、生成、增量cache與唯讀來源查詢。資料必須先切分，再建立詞表與視窗；每個loss與perplexity都按有效token計數；因果遮罩的key位置按絕對位置判斷；test只在選擇固定後使用。完整前向與增量cache應以同權重、相同模式、正確位置逐token對照；未執行的測試只能報預期，不能冒充實驗結果。

模型生成、來源證據與工具授權是不同層次：文字像日誌不代表真實，檢索片段可定位才提供有限證據，只有程式允許的唯讀mock動作才可執行。本章沒有真實養殖資料、操作閾值或設備驗證，亦未訓練模型；任何現場判斷與操作仍須由具資格的人員依實際資料與流程負責。
