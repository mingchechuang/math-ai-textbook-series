# 第12章 訓練流程、資料洩漏與除錯

## 學習目標與先備知識

完成本章後，讀者應能：

1. 區分訓練集、驗證集與測試集的角色。
2. 說明為何資料切分必須早於標準化、詞表建立、缺值填補與窗口建立。
3. 以群組或時間為單位切分資料，避免同一來源的近似樣本跨集合。
4. 只用訓練資料擬合預處理參數，並把相同轉換套用到驗證集與測試集。
5. 實作早停、模型選擇與可恢復的 checkpoint。
6. 分辨資料洩漏、過擬合、最佳化失敗及程式錯誤。
7. 明確記錄張量形狀、loss 平均軸、隨機種子及資料切分。
8. 在所有超參數確定後，才使用測試集一次估計最終表現。

本章使用 NumPy 與基本分類模型。設每筆樣本橫向儲存：

- 特徵矩陣 $X\in\mathbb{R}^{B\times D}$；
- 權重 $W\in\mathbb{R}^{D\times C}$；
- 偏置 $b\in\mathbb{R}^{C}$；
- logits 為 $Z=XW+b\in\mathbb{R}^{B\times C}$；
- 標籤 $y\in\{0,\ldots,C-1\}^{B}$。

其中 $B$ 是批次大小，$D$ 是特徵維度，$C$ 是類別數。偏置由 $(C,)$ 廣播至 $(B,C)$，其反向梯度必須沿 batch 軸求和回原 shape。

## 問題與直覺

一個常見但錯誤的流程如下：

1. 將全部資料標準化。
2. 從同一長序列建立大量重疊窗口。
3. 隨機把窗口分成訓練、驗證與測試集。
4. 反覆觀察測試結果並調整模型。
5. 報告其中最好的一次測試分數。

這個流程可能得到漂亮數字，卻無法回答「模型對未見來源是否有效」。問題至少有三層。

第一，若標準化均值與標準差來自全部資料，測試集已影響模型看到的輸入座標系。即使沒有使用測試標籤，仍是資訊洩漏。

第二，若長序列先切成重疊窗口再隨機切分，相鄰窗口可能共享幾乎全部觀測。例如長度為四的窗口 $[x_1,x_2,x_3,x_4]$ 與 $[x_2,x_3,x_4,x_5]$ 共享三個元素。前者進入訓練集、後者進入測試集時，測試樣本不再代表真正未見資料。

第三，測試集若參與超參數選擇，便實際扮演驗證集。多次嘗試後挑出最高測試分數，本身就是對測試集過擬合。

較可靠的證據鏈是：

> 定義預測時點與可用資訊 → 以來源、群組或時間切分 → 只在訓練集擬合預處理 → 用驗證集選模型與早停 → 鎖定全部決策 → 最後評估測試集。

低訓練誤差只表示模型能擬合已見資料，不等於泛化能力、因果能力、部署安全性或跨時間穩定性。

## 定義、定理與推導

### 1. 三種資料集合

設完整資料單位集合為 $\mathcal D$，切分為互不重疊的：

$$
\mathcal D_{\mathrm{train}},\quad
\mathcal D_{\mathrm{val}},\quad
\mathcal D_{\mathrm{test}}.
$$

它們的角色是：

- **訓練集**：估計模型參數，也擬合標準化、詞表、缺值填補值等預處理狀態。
- **驗證集**：選擇學習率、正規化強度、模型寬度、早停輪次及決策閾值。
- **測試集**：在上述選擇完成後，估計最終程序對未見資料的表現。

「資料單位」不一定是一列。對同一魚池、裝置、病患、文件或連續日誌，正確單位往往是整個群組或整段時間，而不是切割後的小窗口。

### 2. 經驗風險與 loss 平均

對分類樣本 $i$，穩定的負對數似然為

$$
\ell_i=-z_{i,y_i}+\log\sum_{c=1}^{C}\exp(z_{i,c}).
$$

實作時先令 $m_i=\max_c z_{i,c}$：

$$
\log\sum_c e^{z_{i,c}}
=m_i+\log\sum_c e^{z_{i,c}-m_i}.
$$

batch loss 明確定義為沿樣本軸取平均：

$$
L=\frac{1}{B}\sum_{i=1}^{B}\ell_i.
$$

梯度為

$$
\frac{\partial L}{\partial Z_{i,c}}
=\frac{p_{i,c}-\mathbf 1[c=y_i]}{B},
$$

其中 $p_{i,c}$ 是 softmax 機率，對每個 $i$ 均位於機率單純形：

$$
p_{i,c}\ge 0,\qquad \sum_c p_{i,c}=1.
$$

平均因子 $1/B$ 只能除一次。若 `dZ` 已除以 $B$，更新 $dW=X^\mathsf{T}dZ$ 時不可再除。

### 3. 預處理也是模型的一部分

對第 $j$ 個特徵，訓練統計為

$$
\mu_j=\frac{1}{N_{\mathrm{train}}}\sum_{i\in\mathrm{train}}X_{ij},
$$

$$
\sigma_j=
\sqrt{
\frac{1}{N_{\mathrm{train}}}
\sum_{i\in\mathrm{train}}(X_{ij}-\mu_j)^2
}.
$$

本章使用母體式分母 $N_{\mathrm{train}}$，即 NumPy `std(..., ddof=0)`。轉換為

$$
\widetilde X_{ij}=\frac{X_{ij}-\mu_j}{\sigma_j}.
$$

驗證集與測試集必須沿用訓練集的 $\mu_j,\sigma_j$，不可各自重新擬合。若某訓練特徵滿足 $\sigma_j=0$，本章核心實作直接拒絕；這比靜默加入任意常數更容易發現資料契約錯誤。另一種合法策略是刪除常數特徵，但必須記錄於模型狀態。

### 4. 小命題：訓練標準化後的均值與方差

**命題。** 對固定特徵 $j$，若訓練樣本數 $N>0$ 且以 `ddof=0` 計算的 $\sigma_j>0$，則訓練集轉換值 $\widetilde X_{ij}$ 沿樣本軸的均值為 $0$、方差為 $1$。

**證明。**

由定義，

$$
\frac{1}{N}\sum_{i=1}^{N}\widetilde X_{ij}
=
\frac{1}{N}\sum_i\frac{X_{ij}-\mu_j}{\sigma_j}
=
\frac{\sum_iX_{ij}-N\mu_j}{N\sigma_j}
=0.
$$

再計算使用分母 $N$ 的方差。因轉換後均值為零，

$$
\frac{1}{N}\sum_i\widetilde X_{ij}^2
=
\frac{1}{N}\sum_i
\frac{(X_{ij}-\mu_j)^2}{\sigma_j^2}
=
\frac{\sigma_j^2}{\sigma_j^2}
=1.
$$

因此結論成立。證畢。

這個命題只適用於用來擬合 $\mu_j,\sigma_j$ 的訓練資料。驗證集均值不必為零，方差也不必為一；那種差異可能正是部署時需要觀察的分布偏移。

### 5. 群組切分與時間切分

**群組切分**要求同一來源群組只屬於一個集合：

$$
g_i=g_k\Longrightarrow s_i=s_k,
$$

其中 $g_i$ 是群組識別碼，$s_i$ 是 train、val 或 test 指派。

**時間切分**則要求評估資料晚於訓練資料。例如：

$$
t_{\mathrm{train}}<t_{\mathrm{val}}<t_{\mathrm{test}}.
$$

若任務同時具有群組與時間結構，應依部署問題選擇：

- 預測既有群組的未來：每群組內按時間切。
- 預測全新群組：按群組切。
- 同時要求新群組與未來時段：保留晚期且未見過的群組作最嚴格測試。

不能只為追求較高分數而選擇較容易的切法。

### 6. 早停與模型選擇

令第 $e$ 輪的驗證 loss 為 $V_e$。若

$$
V_e<V_{\mathrm{best}}-\delta,
$$

便保存該輪模型；否則累計未改善次數。達到耐心值 `patience` 後停止，最後恢復最佳驗證輪次，而非最後一輪。

早停本身是模型選擇，因此會消耗驗證資訊。若大量比較架構，單一驗證集也可能被過度使用；可採巢狀交叉驗證或另設最終確認集。測試集仍不得補位成日常監看儀表板。

### 7. 可重現性的範圍

完整 checkpoint 至少應保存：

- 模型參數；
- 優化器狀態；
- 當前 epoch 或 step；
- 最佳驗證指標及最佳參數；
- 預處理統計；
- 切分所用群組或索引；
- 隨機數產生器狀態；
- 資料生成規則、seed、dtype 與重要超參數。

固定 seed 只固定特定偽隨機流程，不保證跨 NumPy 版本、硬體、執行緒設定或不同演算法逐位一致。本章程式未實際執行，因此下文只能列出預期行為。

## 逐步手算例題

### 例題一：只用訓練資料標準化

訓練特徵只有一欄：

$$
X_{\mathrm{train}}=
\begin{bmatrix}
2\\
4\\
6
\end{bmatrix},
\qquad
X_{\mathrm{test}}=
\begin{bmatrix}
100
\end{bmatrix}.
$$

第一步，訓練均值：

$$
\mu=\frac{2+4+6}{3}=4.
$$

第二步，訓練方差：

$$
\sigma^2=
\frac{(2-4)^2+(4-4)^2+(6-4)^2}{3}
=\frac{8}{3}.
$$

故

$$
\sigma=\sqrt{\frac83}\approx1.633.
$$

第三步，轉換訓練集：

$$
\widetilde X_{\mathrm{train}}
\approx
\begin{bmatrix}
-1.225\\
0\\
1.225
\end{bmatrix}.
$$

第四步，使用相同統計轉換測試值：

$$
\widetilde X_{\mathrm{test}}
=\frac{100-4}{1.633}
\approx58.79.
$$

巨大的標準化值不是程式錯誤，而是測試分布偏移的訊號。

若錯誤地使用全部四筆資料，均值變成

$$
\mu_{\mathrm{all}}=\frac{2+4+6+100}{4}=28.
$$

此時訓練資料的座標系已被測試值 100 改變。即使沒有讀取測試標籤，仍發生測試特徵洩漏。

### 例題二：重疊窗口造成來源洩漏

某群組的序列為

$$
[10,11,12,13,14,15].
$$

以窗口長度 $T=3$、步長一建立輸入：

$$
w_1=[10,11,12],\quad
w_2=[11,12,13],
$$

$$
w_3=[12,13,14],\quad
w_4=[13,14,15].
$$

若 $w_1,w_3$ 分到訓練集，而 $w_2,w_4$ 分到測試集：

- $w_1$ 與 $w_2$ 共享 $11,12$；
- $w_3$ 與 $w_2$ 共享 $12,13$；
- $w_3$ 與 $w_4$ 共享 $13,14$。

測試集幾乎是訓練片段的平移副本。正確流程是先把整個群組或完整時間區間指派給某一集合，再於各集合內建立窗口。窗口不得跨越切分邊界。

### 例題三：驗證選模不能改看測試答案

有兩個候選模型：

| 模型 | 驗證 loss | 測試 loss |
|---|---:|---:|
| A | 0.40 | 0.52 |
| B | 0.45 | 0.41 |

依事先契約，應由驗證 loss 選 A，再報告 A 的測試 loss 0.52。不能看見 B 的測試結果較好後改選 B，否則測試集已進入選模流程。

測試分數較差並不推翻規則；它提醒我們驗證集有抽樣不確定性。正確改善方式是重新設計資料收集或驗證程序，而不是反覆偷看測試集。

## 實作與程式

以下程式只依賴 Python 標準庫與 NumPy，在 CPU 上建立合成群組時間資料、按群組切分、只以訓練資料標準化、訓練 softmax 分類器、早停並保存可恢復 checkpoint。程式不下載資料、不使用 GPU，也未在本章寫作過程中執行。

```python
import copy
import pickle
from dataclasses import dataclass
from pathlib import Path

import numpy as np


@dataclass
class Config:
    seed: int = 7
    groups: int = 12
    times: int = 20
    features: int = 3
    classes: int = 2
    epochs: int = 200
    batch_size: int = 16
    lr: float = 0.08
    patience: int = 20
    min_delta: float = 1e-6


def make_data(cfg):
    """回傳 X(N,D), y(N,), group(N,), time(N,)；全部為合成資料。"""
    if cfg.groups < 6 or cfg.times < 2:
        raise ValueError("至少需要6個群組及每群組2個時點")
    rng = np.random.default_rng(cfg.seed)
    rows, labels, group_ids, times = [], [], [], []

    for g in range(cfg.groups):
        group_offset = rng.normal(0.0, 0.7)
        for t in range(cfg.times):
            seasonal = np.sin(t / 3.0)
            x = np.array([
                group_offset + 0.05 * t,
                seasonal + rng.normal(0.0, 0.15),
                rng.normal(0.0, 1.0),
            ], dtype=np.float64)
            score = 1.2 * x[0] - 0.8 * x[1] + 0.3 * x[2]
            score += rng.normal(0.0, 0.25)
            y = int(score > 0.0)
            rows.append(x)
            labels.append(y)
            group_ids.append(g)
            times.append(t)

    return (
        np.stack(rows),                         # (N,D)
        np.asarray(labels, dtype=np.int64),    # (N,)
        np.asarray(group_ids, dtype=np.int64), # (N,)
        np.asarray(times, dtype=np.int64),     # (N,)
    )


def split_by_group(X, y, group, time):
    """群組0..7訓練、8..9驗證、10..11測試。"""
    train_mask = group < 8
    val_mask = (group >= 8) & (group < 10)
    test_mask = group >= 10

    if np.any(train_mask & val_mask) or np.any(train_mask & test_mask):
        raise AssertionError("切分遮罩重疊")
    if np.any(val_mask & test_mask):
        raise AssertionError("切分遮罩重疊")
    if not np.all(train_mask | val_mask | test_mask):
        raise AssertionError("存在未指派樣本")

    out = {}
    for name, mask in [
        ("train", train_mask), ("val", val_mask), ("test", test_mask)
    ]:
        out[name] = {
            "X": X[mask],
            "y": y[mask],
            "group": group[mask],
            "time": time[mask],
        }
    return out


def assert_disjoint_groups(parts):
    names = ["train", "val", "test"]
    sets = {n: set(parts[n]["group"].tolist()) for n in names}
    for i, a in enumerate(names):
        for b in names[i + 1:]:
            if sets[a] & sets[b]:
                raise AssertionError(f"{a}與{b}共享群組")


def fit_standardizer(X):
    if X.ndim != 2 or X.shape[0] == 0:
        raise ValueError("X必須是非空(N,D)矩陣")
    mean = X.mean(axis=0)       # (D,)
    std = X.std(axis=0, ddof=0) # (D,)
    if not np.all(np.isfinite(mean)) or not np.all(np.isfinite(std)):
        raise ValueError("預處理統計含非有限值")
    if np.any(std == 0.0):
        raise ValueError("訓練資料含零方差特徵")
    return mean, std


def transform(X, mean, std):
    if X.ndim != 2 or mean.shape != (X.shape[1],):
        raise ValueError("X或mean形狀錯誤")
    if std.shape != mean.shape or np.any(std <= 0):
        raise ValueError("std形狀錯誤或非正")
    Z = (X - mean) / std
    if not np.all(np.isfinite(Z)):
        raise ValueError("標準化結果含非有限值")
    return Z


def loss_and_grad(X, y, W, b):
    """平均交叉熵；X(B,D), W(D,C), b(C,), y(B,)。"""
    B, D = X.shape
    if B == 0:
        raise ValueError("空批次沒有已定義的平均loss")
    if W.shape[0] != D or b.shape != (W.shape[1],):
        raise ValueError("參數shape不相容")
    if y.shape != (B,) or np.any(y < 0) or np.any(y >= W.shape[1]):
        raise ValueError("標籤shape或範圍錯誤")

    logits = X @ W + b                   # (B,C)
    if not np.all(np.isfinite(logits)):
        raise ValueError("logits含非有限值")
    shifted = logits - logits.max(axis=1, keepdims=True)
    exp_shifted = np.exp(shifted)
    probs = exp_shifted / exp_shifted.sum(axis=1, keepdims=True)

    nll = -shifted[np.arange(B), y] + np.log(
        exp_shifted.sum(axis=1)
    )
    loss = nll.mean(axis=0)              # 沿batch軸平均一次

    dlogits = probs.copy()
    dlogits[np.arange(B), y] -= 1.0
    dlogits /= B
    dW = X.T @ dlogits                   # (D,C)
    db = dlogits.sum(axis=0)             # (C,)
    return float(loss), dW, db


def evaluate(X, y, W, b):
    loss, _, _ = loss_and_grad(X, y, W, b)
    pred = np.argmax(X @ W + b, axis=1)
    accuracy = np.mean(pred == y)
    return {"loss": float(loss), "accuracy": float(accuracy)}


def save_checkpoint(path, state):
    """僅保存本程式自己建立的檔案；不得載入不可信pickle。"""
    path = Path(path)
    with path.open("wb") as f:
        pickle.dump(state, f)


def load_checkpoint(path):
    """pickle可執行任意反序列化行為，只可讀取可信本機檔案。"""
    with Path(path).open("rb") as f:
        return pickle.load(f)


def train(cfg, checkpoint_path="chapter12_checkpoint.pkl"):
    X, y, group, time = make_data(cfg)
    parts = split_by_group(X, y, group, time)
    assert_disjoint_groups(parts)

    mean, std = fit_standardizer(parts["train"]["X"])
    for name in parts:
        parts[name]["Xz"] = transform(parts[name]["X"], mean, std)

    rng = np.random.default_rng(cfg.seed + 1)
    D, C = cfg.features, cfg.classes
    W = rng.normal(0.0, 0.05, size=(D, C))
    b = np.zeros(C, dtype=np.float64)

    best_val = np.inf
    best_params = None
    stale = 0

    Xtr, ytr = parts["train"]["Xz"], parts["train"]["y"]
    for epoch in range(cfg.epochs):
        order = rng.permutation(len(ytr))
        for start in range(0, len(ytr), cfg.batch_size):
            idx = order[start:start + cfg.batch_size]
            _, dW, db = loss_and_grad(Xtr[idx], ytr[idx], W, b)
            W -= cfg.lr * dW
            b -= cfg.lr * db

        val = evaluate(
            parts["val"]["Xz"], parts["val"]["y"], W, b
        )
        if val["loss"] < best_val - cfg.min_delta:
            best_val = val["loss"]
            best_params = (W.copy(), b.copy())
            stale = 0
        else:
            stale += 1

        state = {
            "epoch": epoch,
            "W": W.copy(),
            "b": b.copy(),
            "best_val": best_val,
            "best_params": copy.deepcopy(best_params),
            "mean": mean.copy(),
            "std": std.copy(),
            "rng_state": copy.deepcopy(rng.bit_generator.state),
            "groups": {
                name: np.unique(parts[name]["group"])
                for name in parts
            },
            "config": copy.deepcopy(cfg),
        }
        save_checkpoint(checkpoint_path, state)

        if stale >= cfg.patience:
            break

    if best_params is None:
        raise RuntimeError("沒有取得有效驗證模型")
    W, b = best_params

    # 只有模型與超參數均已鎖定後才評估測試集。
    train_metrics = evaluate(parts["train"]["Xz"], parts["train"]["y"], W, b)
    val_metrics = evaluate(parts["val"]["Xz"], parts["val"]["y"], W, b)
    test_metrics = evaluate(parts["test"]["Xz"], parts["test"]["y"], W, b)

    return {
        "train": train_metrics,
        "val": val_metrics,
        "test": test_metrics,
        "W": W,
        "b": b,
        "mean": mean,
        "std": std,
    }


if __name__ == "__main__":
    result = train(Config())
    print({k: result[k] for k in ("train", "val", "test")})
```

這個範例以群組為切分單位，保留每筆時間欄位供稽核。若任務改為預測同一群組的未來，應改成每個群組內以前段訓練、中段驗證、後段測試，而且必須在時間切分後才建立窗口。

checkpoint 中保存的 `W,b` 是當前輪次狀態，而 `best_params` 是最佳驗證狀態。若要精確續訓，還應恢復 `rng_state`、epoch、早停計數與資料游標；本例每輪結束才存檔，因此恢復點位於 epoch 邊界。載入 pickle 僅限可信的本機自建檔案。

## 測試與預期結果

### 正常測試

```python
cfg = Config()
X, y, g, t = make_data(cfg)
parts = split_by_group(X, y, g, t)
assert_disjoint_groups(parts)

mu, sd = fit_standardizer(parts["train"]["X"])

```

預期：shape 斷言成立；訓練標準化後，各特徵均值近零、母體標準差近一。驗證與測試資料不應被要求具有此性質。

### 邊界測試：最後一個小批次

訓練樣本數為 $8\times20=160$，batch 大小若改為 31，最後一批只有 5 筆。`loss_and_grad` 使用實際的 `B=X.shape[0]` 平均，因此最後一批仍有正確尺度。

```python
cfg = Config(batch_size=31)
result = train(cfg, "boundary_checkpoint.pkl")
```

預期：不因最後批次較小而發生 shape 錯誤。數值指標依 seed 與環境而異，不預先捏造。

### 邊界測試：單筆批次保留 batch 軸

X1 = np.array([[0.2, -0.1, 0.7]])  # (1,3)，不是(3,)
y1 = np.array([1])
W = np.zeros((3, 2))

assert db.shape == b.shape
```

預期：`X1` 保持 $(1,3)$，不因 $B=1$ 移除 batch 軸。

parts["test"]["group"][0] = parts["train"]["group"][0]

```

預期：拋出 `AssertionError`，指出訓練與測試共享群組。

## 反例與常見陷阱

### 1. 先標準化再切分

錯誤理由不是「測試標籤被讀取」，而是測試特徵已參與估計 $\mu,\sigma$。預處理參數也是學習到的狀態。

### 2. 各集合各自標準化

這會讓部署樣本取得自身分布統計，通常不符合單筆推論情境。驗證集與測試集應套用訓練統計，而非被強制轉換成均值零、方差一。

### 3. 先切窗口再隨機切分

相鄰窗口高度重疊，同一事件甚至同一標籤可跨集合。必須先切文件、群組、槽位或時間，再於集合內建窗。

### 4. 每輪都報告測試結果

只要研究者根據測試曲線改變任何決策，測試集就已成為驗證集。最後報告的數字會帶有選擇偏差。

### 5. 用訓練 loss 選 checkpoint

訓練 loss 常隨容量與輪次下降。若目標是泛化，應依事先指定的驗證指標選模型，而不是挑最低訓練 loss。

### 6. 混淆最佳化失敗與過擬合

- 訓練 loss 不降：先查梯度、學習率、標籤與 shape。
- 訓練 loss 降而驗證 loss 上升：可能過擬合或分布偏移。
- 訓練與驗證都異常好：可能有洩漏。
- 訓練、驗證正常但測試很差：可能是選模偏差、切分差異或部署偏移。

### 7. 只固定 seed 就宣稱可重現

seed 不包含套件版本、資料排序、dtype、執行緒、硬體與演算法差異。可重現性是一份完整契約，不是一個整數。

### 8. 將準確率當唯一證據

類別不平衡時，全猜多數類別也可能有高準確率。應同時保存類別比例、混淆矩陣、NLL，以及與簡單基線的比較。任何評估指標都必須先固定計算單位與平均方式。

## AI、幾何與養殖案例

考慮完全合成的養殖感測資料。每個 `group` 代表一個虛構池槽，每個時間點含三個合成特徵：

$$
x_{g,t}\in\mathbb{R}^{3}.
$$

模型的每筆輸入是特徵空間中的一個點。以訓練均值平移、再以訓練標準差逐軸縮放，相當於建立由訓練資料決定的座標系。測試點落在遠離訓練雲的位置時，標準化數值可能很大；幾何上表示外插，而不是應被偷偷重新置中的錯誤。

若目標是預測「全新池槽」，應按池槽群組切分。若目標是預測「已知池槽下一週」，則應按時間切分，且任一輸入窗口只能使用預測時點之前的資料。未來測量、未來維護紀錄或由結果事後填寫的欄位都不可成為輸入。

例如要由時刻 $t-3,t-2,t-1,t$ 預測 $t+1$，合法窗口為

$$
X^{(i)}\in\mathbb{R}^{T\times D}
=\mathbb{R}^{4\times3}.
$$

組成 batch 後 shape 為 $(B,T,D)$。若再攤平成線性分類器輸入，才可明確 reshape 為 $(B,TD)=(B,12)$；reshape 不會交換軸，若原始資料是 $(B,D,T)$，必須先 transpose 再 reshape。

所有池槽、閾值及結果均為合成示範，不能轉為真實投餌、曝氣、加藥或設備控制建議。模型表現也不能取代現場量測與專業判斷。

## 習題

### 一、手算題

訓練特徵為 $[1,3,5,7]^\mathsf{T}$，驗證特徵為 $[9]^\mathsf{T}$。

1. 用 `ddof=0` 計算訓練均值與標準差。
2. 標準化四筆訓練資料及驗證資料。
3. 說明為何不應加入驗證值重新計算統計量。

### 二、程式題

修改本章程式，使切分方式改為每個群組內：

- $t<12$ 為訓練；
- $12\le t<16$ 為驗證；
- $t\ge16$ 為測試。

要求檢查同一筆 `(group, time)` 不會重複，並保持只以訓練資料擬合標準化。

### 三、反例題

某研究者建立長度 10、步長 1 的時間窗口，再隨機以 80/10/10 切分。他聲稱「每個窗口只出現一次，所以沒有洩漏」。指出論證錯誤，並構造兩個跨集合但共享九個元素的窗口。

### 四、整合題

設有三個候選學習率 $0.1,0.01,0.001$，每個各訓練五個 seed。請設計不使用測試集調參的流程，明確回答：

1. 預處理統計從哪裡取得？
2. 如何用驗證集選學習率及 checkpoint？
3. 多 seed 結果如何報告？
4. 測試集何時使用？
5. checkpoint 至少保存哪些狀態？

## 習題解答

### 一、手算題解答

訓練均值為

$$
\mu=\frac{1+3+5+7}{4}=4.
$$

方差為

$$
\sigma^2=
\frac{(1-4)^2+(3-4)^2+(5-4)^2+(7-4)^2}{4}
=\frac{9+1+1+9}{4}=5.
$$

所以 $\sigma=\sqrt5$。

訓練轉換值為

$$
\left[
-\frac3{\sqrt5},
-\frac1{\sqrt5},
\frac1{\sqrt5},
\frac3{\sqrt5}
\right]^\mathsf{T}.
$$

驗證值使用相同統計：

$$
\widetilde x_{\mathrm{val}}
=\frac{9-4}{\sqrt5}
=\sqrt5.
$$

若加入驗證值重新計算，驗證資料便影響輸入座標系，也使訓練階段使用了部署時原本不可得的資訊。故應保留 $\mu=4,\sigma=\sqrt5$。

### 二、程式題解答

可將切分函式改為：

```python
def split_by_time(X, y, group, time):
    train_mask = time < 12
    val_mask = (time >= 12) & (time < 16)
    test_mask = time >= 16

    masks = {
        "train": train_mask,
        "val": val_mask,
        "test": test_mask,
    }
    parts = {}
    seen = set()

    for name, mask in masks.items():
        pairs = list(zip(group[mask].tolist(), time[mask].tolist()))
        if len(pairs) != len(set(pairs)):
            raise AssertionError(f"{name}內有重複(group,time)")
        if seen & set(pairs):
            raise AssertionError("集合間有重複(group,time)")
        seen |= set(pairs)
        parts[name] = {
            "X": X[mask],
            "y": y[mask],
            "group": group[mask],
            "time": time[mask],
        }

    if len(seen) != len(y):
        raise AssertionError("存在遺漏或重複樣本")
    return parts
```

之後仍必須：

```python
mean, std = fit_standardizer(parts["train"]["X"])
for name in parts:
    parts[name]["Xz"] = transform(parts[name]["X"], mean, std)
```

此切法評估的是「已見群組的未來」，不是「全新群組」。兩種問題不可混為一談。

### 三、反例題解答

「每個窗口只出現一次」只排除完全相同的窗口重複，沒有排除內容高度重疊。

設原序列為 $[x_1,x_2,\ldots,x_{11}]$，兩個長度 10 的窗口為

$$
w_1=[x_1,x_2,\ldots,x_{10}],
$$

$$
w_2=[x_2,x_3,\ldots,x_{11}].
$$

它們不相同，卻共享 $x_2,\ldots,x_{10}$ 共九個元素。若 $w_1$ 在訓練集、$w_2$ 在測試集，測試並非獨立的新時間片段。修正方式是先按完整序列或時間區間切分，再於每個集合內建立窗口，且禁止窗口跨界。

### 四、整合題解答

1. 對每一個資料切分，只由訓練集擬合均值、標準差、詞表或缺值填補值。所有候選模型共用同一套已固定的訓練預處理狀態。
2. 每個學習率與 seed 都依驗證 loss 保存最佳 checkpoint。可事先規定以五個 seed 的平均驗證 NLL 選學習率；若相同，再用較小模型或較低變異作固定 tie-break。
3. 報告各 seed 的驗證結果，以及平均值與離散程度；五個 seed 很少，不能宣稱具有普遍統計顯著性。不可只挑最好 seed。
4. 學習率、早停規則、模型架構及報告方式全部鎖定後，才對測試集評估。若根據測試結果再改模型，就需要新的未使用測試集才能得到乾淨的最終估計。
5. 至少保存模型參數、優化器狀態、epoch/step、最佳驗證值、最佳參數、RNG 狀態、資料游標、切分識別碼、預處理統計、設定值、dtype 與資料生成版本。

## 本章小結

可靠訓練不是單一最佳化迴圈，而是一套證據契約。訓練集用來估計參數與預處理狀態；驗證集用來早停及選模；測試集只在全部決策完成後使用。若資料具有群組、文件或時間結構，必須先按真正的部署單位切分，再標準化及建立窗口。

除錯時應先檢查 shape、切分交集、非有限值、標籤範圍、loss 平均與梯度尺度，再討論模型容量。checkpoint 也不只是權重檔案；它應包含優化器、RNG、資料位置、預處理與切分契約。固定 seed 可以改善可追蹤性，但不保證所有環境逐位重現。

最重要的原則是：測試集不是可反覆查詢的答案伺服器。若測試資料參與了座標建立、窗口混合、超參數選擇或人工決策，報告的數字便不再是獨立泛化證據。
