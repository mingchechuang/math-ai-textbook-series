# 一、數值重新核對

## 1. 例題 4.1

三筆正確類別機率為 $0.9,0.9,0.6$：

$$
-\ln0.9\approx0.1053605,
\qquad
-\ln0.6\approx0.5108256.
$$

所以：

$$
\text{Total NLL}
=0.1053605+0.1053605+0.5108256
\approx0.7215466,
$$

$$
\text{Mean NLL}
=0.7215466/3
\approx0.2405155\text{ nats}.
$$

轉換成 bits：

$$
\frac{0.2405155}{\ln2}
\approx0.34699\text{ bits}.
$$

稿中 $0.72155$、$0.24052$、$0.3470$ 均正確。

## 2. KL 習題

$$
\begin{aligned}
D_{\mathrm{KL}}(P\parallel Q)
&=0.1\log_2(0.5)
 +0.2\log_2(2/3)
 +0.7\log_2(1.4)\\
&\approx-0.1-0.116993+0.339799\\
&\approx0.122806\text{ bits}.
\end{aligned}
$$

稿中 $0.12281$ bits 正確。

## 3. PAD 困惑度例題

有效 NLL 是 $2.0,0.5,0.5$：

$$
\text{Total valid NLL}=3,
\qquad
N_{\mathrm{valid}}=3,
$$

$$
\text{Mean NLL}=1,
\qquad
PP=e\approx2.71828.
$$

錯誤的 batch perplexity 算術平均為：

$$
\frac{e^2+e^{0.5}}2
\approx4.51889.
$$

稿中數值及「不能平均不同有效 token 數 batch 的 perplexity」之結論正確。

## 4. 整合題

$$
\text{Total valid NLL}=1.0+0.5+2.0=3.5,
$$

$$
N_{\mathrm{valid}}=3,
\qquad
\text{Mean NLL}=3.5/3\approx1.16667\text{ nats},
$$

$$
\text{Mean NLL}_{\mathrm{bits}}
=1.16667/\ln2
\approx1.68315,
$$

$$
PP=e^{1.16667}\approx3.21127.
$$

答案正確。

# 二、定義與概率條件

## 1. 似然分解

**原句：**

> `若 $x_1,\dots,x_N$ 在給定參數 $\theta$ 下為獨立同分布（i.i.d.）……則聯合似然函數為……`

i.i.d. 樣本的乘積似然條件已明列。

**原句：**

> `此分解來自機率鏈式法則，不要求各 token 無條件獨立，也不額外假設固定階數的馬可夫性`

自回歸序列的乘積是條件概率鏈式分解，不是無條件獨立假設。此處正確。

分類條件似然使用 $p_\theta(y_i\mid x_i)$，沒有把輸入 $x_i$ 的邊際分布錯誤納入判別模型的訓練目標。

## 2. Total NLL 與 Mean NLL

稿件正確限定：

- 有效集合預先固定；
- $N_{\mathrm{valid}}>0$；
- 分母不依賴 $\theta$。

只有在這些條件下，Total NLL 與 Mean NLL 才只差固定正比例常數並有相同最優參數。稿件也正確提醒，若模型自行決定拒答或遮罩而使分母依賴參數，等價性不再自動成立。

## 3. 熵、CE、KL 與 NLL 的值域

**原句：**

> `最終值允許取擴展非負實數 $[0,+\infty]$`

正確。$\ln0=-\infty$ 是中間對數值，合法的熵、CE、KL、NLL 最終不取負值。

**原句：**

> `零權重項約定為 $0\ln a=0$，包括 $a=0$。`

正確處理 $0\ln0$。

**原句：**

> `若存在 $x$ 使 $P(x)>0$ 且 $Q(x)=0$，則該交叉熵項為 $+\infty$，故 $H(P,Q)=+\infty$，且 $D_{KL}(P\|Q)=+\infty$。`

正確。沒有以 epsilon 或 clip 竄改精確零概率的數學定義。

**原句：**

> `若 $H(P)=+\infty$，則 $H(P,Q)-H(P)$ 可能涉及 $\infty-\infty$；此時以 KL 的逐項定義為準`

正確避免不合法的擴展實數減法。

## 4. one-hot CE 與 NLL

由：

$$
H(y_i,q_i)
=-\sum_{c=1}^Cy_{ic}\ln q_{ic}
$$

及 one-hot 性質得：

$$
H(y_i,q_i)=-\ln q_{i,y_i}.
$$

推導正確；若 $q_{i,y_i}=0$，結果為 $+\infty$。

# 三、KL 非負性證明

令 $S=\{x:P(x)>0\}$，稿件得到：

$$
D_{\mathrm{KL}}(P\parallel Q)
=-\sum_{x\in S}P(x)\ln\frac{Q(x)}{P(x)}.
$$

由 Jensen：

$$
D_{\mathrm{KL}}(P\parallel Q)
\geq
-\ln\left(\sum_{x\in S}Q(x)\right).
$$

又因：

$$
\sum_{x\in S}Q(x)\leq1,
$$

所以：

$$
D_{\mathrm{KL}}(P\parallel Q)\geq0.
$$

等號條件分析也正確：

1. $Q(x)/P(x)$ 在 $S$ 上為常數；
2. $Q$ 在 $S$ 外沒有概率質量；
3. 歸一化迫使常數為 1；
4. 因而全域 $P=Q$。

此前曾出現把 $\sum_{x\in S}Q(x)$ 無條件寫成 1 的風險，目前已正確使用「小於等於 1」，不能再以舊問題拒稿。

正文允許可數空間；更完整的出版表述可補一句可數情形使用允許左側為 $+\infty$ 的擴展期望版 Jensen。不過命題結論正確，有限分類主體亦不受影響。

# 四、程式 shape、broadcast 與 reduction

## 1. `cross_entropy`

輸入契約：

- `y_pred`：`(N,C)`；
- index labels：`(N,)`；
- one-hot／soft labels：`(N,C)`。

輸出為 `(N,)`。

類別 reduction 明確為：

```python
np.sum(ce_terms, axis=-1)
```

沒有跨 batch 聚合，也沒有多除一次。

index labels 必須是整數 dtype，且逐項落在 $[0,C)$；Python 整數 list 經 `np.asarray` 後可正常形成整數陣列。soft labels 需非負、有限、每列和為 1。

零概率處理：

```python
mask = y_onehot > 0
ce_terms[mask] = y_onehot[mask] * log_q[mask]
```

因此 $P=0$ 的位置不會執行 $0\cdot(-\infty)$。若存在 $P>0,Q=0$：

```python
sample_bad = np.any(bad_mask, axis=-1)
ce_per_sample[sample_bad] = np.inf
```

只有相應樣本被設為 `inf`。正確。

## 2. 一維 KL

主函數先檢查：

```python
if np.any(p_support & (q_model == 0)):
    return np.inf
```

再計算正支撐上的比值，故不會在支撐集違規位置先除以零。

## 3. 批次 KL

習題答案使用：

```python
bad = np.any(p_support & (q == 0), axis=-1)
safe = p_support & (q > 0)
terms[safe] = p[safe] * (np.log(p[safe]) - np.log(q[safe]))
out = np.sum(terms, axis=-1)
out[bad] = np.inf
```

這符合全部要求：

- 輸入 `(N,C)`；
- 沿最後類別軸 reduction；
- 輸出 `(N,)`；
- 不跨 batch 聚合；
- $P=0$ 項保持 0；
- $P>0,Q=0$ 不進入對數計算；
- 違規只影響該列；
- `N=0` 或 `C=0` 被拒絕。

# 五、Perplexity 與非有限值

## 1. mask 與 token 計數

`nll_values` 與 `valid_mask` 都必須是一維且 shape 相同。mask 必須為布林 dtype。有效 token 數：

```python
count = np.sum(valid_mask)
```

空有效集合被明確拒絕。NLL 只從：

```python
valid_nll = nll_values[valid_mask]
```

取得，所以被 mask 排除位置的值不參與計算。

聚合順序是：

```python
sum_nll = np.sum(valid_nll)
mean_nll = sum_nll / count
np.exp(mean_nll)
```

符合「先累加全局有效 token NLL，再除以總有效 token 數一次」。

## 2. NaN、正無限與負無限

目前順序：

```python
if np.any(valid_nll < 0):
    raise ValueError(...)
if np.any(np.isnan(valid_nll)):
    raise ValueError(...)
if np.any(np.isinf(valid_nll)):
    return np.inf
```

靜態結果是：

- 有限負 NLL：拒絕；
- `-inf`：因為小於零而拒絕；
- NaN：拒絕；
- `+inf`：回傳 `inf`；
- 同時含 NaN 與 `+inf`：NaN 優先拒絕。

策略明確且不讓 NaN 靜默流入。

## 3. overflow

使用：

```python
np.log(np.finfo(np.float64).max)
```

而非任意硬編碼 700。這與函數入口轉成 `float64` 的契約一致。

# 八、Fisher 局部結果

稿件現在限定：

- 有限樣本空間；
- 鄰域內各類別概率嚴格為正；
- 二次連續可微；
- Fisher 資訊存在；
- $\delta\to0$。

並給出：

$$
D_{\mathrm{KL}}(p_\theta\parallel p_{\theta+\delta})
=
\frac12\delta^TI(\theta)\delta
+o(\|\delta\|^2).
$$

有限空間使逐項微分合法。由歸一化條件可得 score 期望為零，對數概率 Hessian 的負期望等於 Fisher 資訊，再將 $\ln p_{\theta+\delta}$ 作二階 Taylor 展開即可得到該式。條件及推導方向足以支持本段，不再是無條件進階定理宣稱。

可選排版修正是把 `\delta^T`、向量的 `^T` 改成 `\delta^\top`，但不影響正確性。
