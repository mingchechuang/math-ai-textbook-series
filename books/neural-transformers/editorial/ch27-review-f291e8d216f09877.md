1. **時間池化的超參數檢查未拒絕非有限值。**  
   原句：「`if sigma <= 0 or window < 0:`」  
   原因：`NaN` 不滿足 `<= 0` 或 `< 0`，因此會通過檢查；`sigma=inf` 也會通過。此後可能產生 NaN 權重，或把無效尺度當成合法輸入。章稿雖聲稱拒絕非法參數，程式沒有涵蓋這些情形。  
   最小修法：在計算前確認 `sigma` 與 `window` 都是有限純量，且分別滿足正值、非負；為 NaN 與正無限參數加故障測試。

2. **對比損失的溫度也缺少有限性檢查。**  
   原句：「`if temperature <= 0:`」  
   原因：`temperature=NaN` 會略過此檢查，之後才可能由 logits 的非有限檢查報錯；`temperature=inf` 則不會被拒絕。這與明確拒絕非法溫度的契約不一致。  
   最小修法：要求 temperature 為有限且大於零，並測試 NaN、正無限與非正值。
