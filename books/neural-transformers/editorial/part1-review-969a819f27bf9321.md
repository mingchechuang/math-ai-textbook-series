### 一、與前兩輪相同、本輪未見修改的實質問題

**（1a）第 1 章命題 1.4 定義句錯誤。** 逐字原句：「設 $\mathcal{H}=\{f_1,\dots,f_M\}$ 是**有限**假設類，$|M|=\mathcal{H}$ 為其基數。」$M$ 是純量記號，$|M|$ 無定義，且右邊 $\mathcal{H}$ 亦錯位；同節下文又用 $M$ 作基數（$2M\exp(-2n\varepsilon^2)$、$\ln M$、$\ln(2M/\delta)$），前後自相矛盾。最小修法：改為「設 $\mathcal{H}=\{f_1,\dots,f_M\}$ 是**有限**假設類，其基數為 $M$」。

**（1b）第 6 章邊界測試 2 單位／數值錯誤。** 逐字原句：「若把 $z$ 改成三個相等巨大值，例如 $(10^{300},10^{300},10^{300})$，數學上 loss 應為 $\log 3$，但 float64 在 $10^{300}+0.477$ 時可能把 $0.477$ 捨入掉，得到 0。」本章命題 6.1、例 6.1 與習題 1／2 皆採自然對數，故數學 loss 應為 $\ln 3\approx 1.0986$，$0.477$ 是 $\log_{10}3$，與本章單位不符；被捨入的加項應為 $1.0986$。最小修法：把「$\log 3$」改為「$\ln 3\approx 1.099$」，把「$10^{300}+0.477$ 時可能把 $0.477$」改為「$10^{300}+1.099$ 時可能把 $1.099$」。浮點消去結論不變。

**（1c）第 4 章與第 6 章 CE 分支契約不一致且未互標。** 第 4 章 `cross_entropy` 對 $y_{\text{true}}>0$ 且 $y_{\text{pred}}=0$ 回傳 `np.inf`；第 6 章 `cross_entropy_loss_and_grad` 要求 `logits` 全有限，故不會由有限 logits 產生 `inf`。兩章各自自洽，但對讀者構成兩個不同「CE 在極端情況如何回應」的介面。最小修法：在第 4 章邊界測試新增一行說明「純機率域可直接觀察到 $+\infty$；由有限 logits 出發的 CE 於本卷核心實作拒絕非有限」（或等效語句），使兩章契約互相指路。

### 二、本輪新增的實質問題

**（2a）第 4 章 `perplexity` 中 `nan` 與 `inf` 的處理不一致，`nan` 被 `inf` 掩蓋。**

逐字原句（函式內）：

```
if np.any(~np.isfinite(valid_nll)):
    if np.any(valid_nll == np.inf):
        return np.inf
    raise ValueError("Non-finite NLL in valid tokens.")
```

若 `valid_nll` 同時含 `inf` 與 `nan`（例如遮罩選到 `[float("inf"), float("nan")]`），第一個條件為 True，內層對 `inf` 的偵測也為 True，於是函式直接回傳 `inf`，任何存在的 `nan` 都被靜默吞掉。這與同函式上方的契約「`NLL for valid tokens must be non-negative`」與同節文字「NaN、正無限與負無限不屬於有限機率值，核心介面應拒絕」互相矛盾——同節把 `nan` 列為應拒絕的輸入，但實作在混入 `inf` 時卻不拒絕。

最小修法：把順序分開，先拒 `nan`、再處理 `+inf`。可改為

```
if np.any(np.isnan(valid_nll)):
    raise ValueError("NaN NLL in valid tokens.")
if np.any(np.isinf(valid_nll)):
    return np.inf
```

並在「測試與預期結果」補一條邊界測試：「有效位置同時含 `inf` 與 `nan` 時預期拋出 `ValueError`，不靜默回傳 `inf`」。此改動不影響既有「含 `+inf` 則 PP 為 `+inf`」的合法路徑。
