# 第03章 向量範數、距離與算子範數

## 學習目標與先備知識

學完本章，讀者應能依定義檢查範數、由範數建立距離，手算向量的 $1$、$2$、無窮範數，以及矩陣的誘導範數；能用算子範數寫出誤差傳播界，並分辨有限維範數等價與「各維度使用同一常數」是不同主張。讀者亦應能辨認：條件數描述的是指定範數及指定問題下的最壞相對敏感度界，不是每筆資料的實際誤差。

先備知識是實數絕對值、有限和、矩陣乘法與可逆矩陣。以下向量一律視為直向量，即列向量（column vector）；矩陣的橫列是 row，縱行是 column。若分量帶有不同物理單位，須先選尺度轉成無因次座標，才可對其歐氏長度賦予明確的比較意義。

## 問題與直覺

設輸入 $x$ 經線性模型 $y=Ax$ 轉為輸出，測量擾動 $\delta x$ 造成 $\delta y=A\delta x$。只說「擾動很小」並不足夠：小是用哪一種長度衡量？輸出的最大可能放大倍數是多少？若由 $y$ 反求 $x$，又會不會把微小的輸出誤差放大？

範數回答第一個問題；誘導算子範數回答第二個問題；可逆矩陣的條件數協助回答第三個問題。這些量依賴座標及尺度。例如同一個幾何向量以兩支幾乎平行的基底表示時，座標係數可能很大且彼此抵銷。因此「座標的歐氏長度大」不能不經檢查就說成「物理位移大」。分析中的誤差敘述須同時交代所量度的對象、採用的範數及映射的方向。

## 定義、定理與推導

**定義：向量範數。** 實向量空間上的函數 $\|\cdot\|$ 若對所有向量 $u,v$ 及實數 $a$ 滿足

$$
\|v\|\geq0,\quad \|v\|=0\Longleftrightarrow v=0;\qquad
\|av\|=|a|\|v\|;\qquad
\|u+v\|\leq\|u\|+\|v\|,
$$

便稱為範數。最後一項是三角不等式。範數誘導距離 $d(u,v)=\|u-v\|$。距離必須對稱、非負、只在兩點相同時為零，並滿足三角不等式。

在 $\mathbb R^n$ 上，三個常用選擇為

$$
\|x\|_1=\sum_{i=1}^n|x_i|,\qquad
\|x\|_2=\left(\sum_{i=1}^n x_i^2\right)^{1/2},\qquad
\|x\|_\infty=\max_i|x_i|.
$$

下標不是向量的分量編號。以 $1$ 範數為例，逐項使用 $|u_i+v_i|\leq|u_i|+|v_i|$ 再相加，便得到三角不等式；無窮範數則先對每個分量給出相同上界，再取最大值。對 $2$ 範數，Cauchy–Schwarz 不等式給出 $u^Tv\leq\|u\|_2\|v\|_2$，因此

$$
\|u+v\|_2^2
=\|u\|_2^2+2u^Tv+\|v\|_2^2
\leq(\|u\|_2+\|v\|_2)^2.
$$

兩邊均非負，取平方根便得三角不等式。這說明三個公式確實符合關鍵公理，而不只是三種看似合理的計算規則。

**小命題與證明：範數確實誘導距離。** 設 $\|\cdot\|$ 是任意實向量空間上的範數，定義 $d(u,v)=\|u-v\|$。非負性及「為零當且僅當 $u=v$」直接來自第一條公理。由齊次性，
$d(u,v)=\|-(v-u)\|=|-1|\|v-u\|=d(v,u)$。又因 $u-w=(u-v)+(v-w)$，三角不等式給出
$d(u,w)\leq d(u,v)+d(v,w)$。四項距離公理均成立，證畢。這是對所有向量的證明，而非抽取幾組座標所做的檢查。

**定義：誘導矩陣範數。** 若輸入 $\mathbb R^n$ 與輸出 $\mathbb R^m$ 已各自選好向量範數，對 $A\in\mathbb R^{m\times n}$ 定義

$$
\|A\|_{\mathrm{in}\to\mathrm{out}}
=\sup_{x\ne0}\frac{\|Ax\|_{\mathrm{out}}}{\|x\|_{\mathrm{in}}}.
$$

這個比值測量指定輸入方向的放大率；上確界則涵蓋所有非零方向。由定義立即有 $\|Ax\|_{\mathrm{out}}\leq
\|A\|_{\mathrm{in}\to\mathrm{out}}\|x\|_{\mathrm{in}}$。有限矩陣的此上確界為有限值。若兩端都用相同的 $p$ 範數，簡寫為 $\|A\|_p$。對有限矩陣，

$$
\|A\|_1=\max_j\sum_i|a_{ij}|,\qquad
\|A\|_\infty=\max_i\sum_j|a_{ij}|.
$$

前者是最大**縱行**絕對值和，後者是最大**橫列**絕對值和。兩式不只是方便記憶的算法，也可從定義推得。對 $1$ 範數，先逐一估計輸出分量並交換有限求和順序：

$$
\|Ax\|_1
\leq\sum_j\left(\sum_i|a_{ij}|\right)|x_j|
\leq\left(\max_j\sum_i|a_{ij}|\right)\|x\|_1.
$$

選擇縱行絕對值和最大的編號 $j_*$，令 $x$ 為該編號的座標基向量；此時 $\|x\|_1=1$，而 $\|Ax\|_1$ 正是該縱行之和，故上界可取到。對無窮範數，固定橫列 $i$，以 $\|x\|_\infty$ 界住每個 $|x_j|$，即可取得最大橫列和的上界。再選取和最大的橫列 $i_*$，令 $x_j$ 與 $a_{i_*j}$ 同號，零元素所對應的 $x_j$ 可任選正負一；於是 $\|x\|_\infty=1$，第 $i_*$ 個輸出分量的絕對值等於該橫列和。這證成下界與上界相等。

$\|A\|_2$ 是最大奇異值；此處引用有限維矩陣的奇異值結果，不把最大元素絕對值、最大特徵值或 Frobenius 範數直接當成它。

**有限維範數等價的具體版本。** 對每個 $x\in\mathbb R^n$，

$$
\|x\|_\infty\leq\|x\|_2\leq\|x\|_1
\leq\sqrt n\,\|x\|_2\leq n\|x\|_\infty.
$$

其中 $\|x\|_1\leq\sqrt n\|x\|_2$ 由 Cauchy–Schwarz 不等式得到；末項還使用 $\|x\|_2\leq\sqrt n\|x\|_\infty$。這證明在**固定有限維度**，三種範數具有相同的收斂向量列：若其中一種範數下與極限之差趨零，固定的比較常數便使另外兩種範數下的差也趨零。但 $\sqrt n$ 和 $n$ 隨維度增長，不能省略「固定」二字。對 $\mathbb R^n$ 上任意兩個範數亦存在正的比較常數，這是有限維範數等價定理；其一般證明可利用歐氏單位球的緊緻性，本章引用此結果，不把它推廣到未指定條件的無限維空間。

矩陣範數還滿足相容的乘法界。若 $A:\mathbb R^n\to\mathbb R^m$、$B:\mathbb R^k\to\mathbb R^n$，並在共同空間使用同一個中間範數，則

$$
\|AB\|_{\mathrm{in}\to\mathrm{out}}
\leq\|A\|_{\mathrm{mid}\to\mathrm{out}}
\|B\|_{\mathrm{in}\to\mathrm{mid}}.
$$

理由是對每個非零 $x$ 先界住 $A(Bx)$，再界住 $Bx$，最後取上確界。這裡的範數下標不能任意混接：若第一步用歐氏長度量 $Bx$，第二步卻只給出它的無窮長度，便還需要額外的範數比較常數。

若 $A\in\mathbb R^{n\times n}$ 可逆，在同一向量範數下定義
$\kappa(A)=\|A\|\|A^{-1}\|$。對 $y=Ax\ne0$ 及擾動 $\delta y$，令 $\delta x=A^{-1}\delta y$。算子界分別給出 $\|\delta x\|\leq\|A^{-1}\|\|\delta y\|$ 及 $\|y\|\leq\|A\|\|x\|$。由於 $x,y$ 均非零，後一式除以正數 $\|x\|\|y\|$，得到 $1/\|x\|\leq\|A\|/\|y\|$；再乘上前一式，便得

$$
\frac{\|\delta x\|}{\|x\|}
\leq\kappa(A)\frac{\|\delta y\|}{\|y\|}.
$$

這是最壞情況的相對誤差上界，不是說每個擾動都達到右端，也不是說 $\kappa(A)$ 單獨提供了誤差的絕對單位。條件數至少為一：由 $I=A^{-1}A$ 的乘法界可得 $1=\|I\|\leq\|A^{-1}\|\|A\|$。奇異矩陣沒有 $A^{-1}$，不得套用上述逆算公式。

## 逐步手算例題

**例一：三種長度與誤差傳播。** 取無因次向量 $x=(3,-4)^T$，則 $\|x\|_1=7$、$\|x\|_2=5$、$\|x\|_\infty=4$。令

$$
A=\begin{pmatrix}2&-1\\0&3\end{pmatrix},
\qquad
\delta x=\begin{pmatrix}0.01\\-0.02\end{pmatrix}.
$$

手算得 $\delta y=A\delta x=(0.04,-0.06)^T$，所以
$\|\delta y\|_\infty=0.06$。由最大橫列和，
$\|A\|_\infty=\max(3,3)=3$；而
$\|\delta x\|_\infty=0.02$，界為 $3(0.02)=0.06$，此例恰好取到等號。最大縱行和給出 $\|A\|_1=\max(2,4)=4$，因此另有
$\|\delta y\|_1=0.10\leq4(0.03)=0.12$。同一擾動在兩種範數下得到不同數字，必須把輸入與輸出的下標一併寫出；不能因第一個界取等號，就推斷第二個也取等號。

**例二：病態逆算與非正交座標。** 考慮

$$
B=\begin{pmatrix}1&1\\0&0.01\end{pmatrix},
\qquad
B^{-1}=\begin{pmatrix}1&-100\\0&100\end{pmatrix}.
$$

$\|B\|_\infty=2$、$\|B^{-1}\|_\infty=101$，故 $\kappa_\infty(B)=202$。若真實座標 $c=(0,1)^T$，物理平面中的向量為 $Bc=(1,0.01)^T$。兩個基底向量 $(1,0)^T$、$(1,0.01)^T$ 幾乎平行。給輸出加入 $\delta y=(0,0.001)^T$，逆算座標誤差為
$B^{-1}\delta y=(-0.1,0.1)^T$：輸出無窮範數僅變動 $0.001$，座標無窮範數卻變動 $0.1$。本例相對誤差分別是 $0.001$ 與 $0.1$；條件數界給的是 $0.1\leq202(0.001)$，並未宣稱實際誤差等於 $0.202$。改選正交座標或為輸入、輸出建立合理尺度，會改變所報告的座標條件數；幾何向量本身並未因此改變。

## 實作與程式

下列程式只需 Python 標準庫，在一般 CPU 上即可使用。`vector_norm` 接收非空數值序列及範數種類，回傳非負長度；`shape` 回傳矩陣的橫列數與縱行數，並拒絕空矩陣和長短不齊的橫列；`matvec` 只接受與矩陣縱行數相同長度的輸入。兩個 `induced` 函式直接按已證公式計算，不聲稱透過取樣求出了上確界。

`finite_sign_check_inf` 是獨立的小矩陣核對：對無窮單位球中的任意 $x$，每個輸出分量是各 $x_j$ 的線性組合，其絕對值不超過對應橫列和；而指定橫列的符號選擇落在頂點集合內並可取到該和。因此只比較分量皆為正負一的頂點便足夠，並非因為一般連續區域都可以靠有限取樣證明。頂點數隨輸入維度指數增長，故此核對函式設有尺寸限制。程式不求逆，也不以浮點檢查充當範數公理的證明。

```python
from itertools import product
from math import sqrt

def vector_norm(x, kind):
    if not x:
        raise ValueError("向量不得為空")
    if kind == 1:
        return sum(abs(v) for v in x)
    if kind == 2:
        return sqrt(sum(v * v for v in x))
    if kind == "inf":
        return max(abs(v) for v in x)
    raise ValueError("範數種類須為 1、2 或 'inf'")

def shape(A):
    if not A or not A[0]:
        raise ValueError("矩陣不得為空")
    width = len(A[0])
    if any(len(row) != width for row in A):
        raise ValueError("矩陣橫列長度不一致")
    return len(A), width

def matvec(A, x):
    _, n = shape(A)
    if len(x) != n:
        raise ValueError("輸入維度不符")
    return [sum(a * v for a, v in zip(row, x)) for row in A]

def induced_one(A):
    m, n = shape(A)
    return max(sum(abs(A[i][j]) for i in range(m))
               for j in range(n))

def induced_inf(A):
    shape(A)
    return max(sum(abs(a) for a in row) for row in A)

def finite_sign_check_inf(A):
    # 小矩陣核對：無窮單位球的符號頂點可取到最大橫列和。
    _, n = shape(A)
    if n > 12:
        raise ValueError("此核對函式只接受至多 12 個輸入分量")
    return max(vector_norm(matvec(A, list(s)), "inf")
               for s in product((-1.0, 1.0), repeat=n))

def close(a, b, tol=1e-12):
    return abs(a - b) <= tol * max(1.0, abs(a), abs(b))

def expect_value_error(function, *args):
    try:
        function(*args)
    except ValueError:
        return
    raise AssertionError("預期 ValueError")

def run_checks():
    A = [[2.0, -1.0], [0.0, 3.0]]
    dx = [0.01, -0.02]
    assert close(vector_norm([3.0, -4.0], 1), 7.0)
    assert close(vector_norm([3.0, -4.0], 2), 5.0)
    assert close(vector_norm([3.0, -4.0], "inf"), 4.0)
    assert close(induced_one(A), 4.0)
    assert close(induced_inf(A), 3.0)
    assert close(finite_sign_check_inf(A), induced_inf(A))
    assert vector_norm(matvec(A, dx), "inf") <= (
        induced_inf(A) * vector_norm(dx, "inf") + 1e-12
    )
    assert close(vector_norm([0.0, 0.0], 2), 0.0)
    expect_value_error(shape, [])
    expect_value_error(shape, [[1.0, 2.0], [3.0]])
    expect_value_error(matvec, A, [1.0])
    expect_value_error(vector_norm, [], 2)

if __name__ == "__main__":
    run_checks()
    print("所有檢查通過")
```

## 測試與預期結果

以上程式**未在此執行**。正常測試預期得到例一的三種向量範數、兩種矩陣範數，以及滿足誤差界的輸出；小矩陣的符號核對預期為 $3$。若執行且斷言均通過，末行預期印出「所有檢查通過」，這是預期輸出而非已取得的執行紀錄。

邊界測試中的零向量預期長度為零；這不表示可將零向量代入算子範數定義中的比值，因該比值明確要求輸入非零。故障測試中的空矩陣、不規則矩陣、矩陣乘向量時維度不符，以及空向量，預期各自拋出 `ValueError`，並由測試輔助函式核對。符號核對若超過十二個輸入分量，也預期拋出 `ValueError`，其限制出於窮舉成本，而非數學公式失效。

有限次運算可以核對實作與特定輸入，不能證明所有矩陣都滿足公式。浮點運算亦可能需要容差；容差通過表示此組輸入的數值結果相容，不表示無限精度的數學等式已由程式證立。

## 反例與常見陷阱

第一，$\|x\|_1$ 與 $\|x\|_\infty$ 雖在固定維度等價，卻不能宣稱存在與維度無關的常數 $C$，使所有 $n$ 的向量均滿足 $\|x\|_1\leq C\|x\|_\infty$。取 $x=(1,\ldots,1)^T\in\mathbb R^n$，左右兩邊分別為 $n$ 與 $C$；令 $n>C$ 即得反例。

第二，把 $\|A\|_\infty$ 誤算為最大縱行和，會讓誤差界用錯常數。例一中兩種值是 $3$ 與 $4$，即使錯誤常數碰巧給出較鬆的界，也不能證明計算方法正確。第三，特徵值小不保證算子範數小：矩陣
$\begin{pmatrix}0&100\\0&0\end{pmatrix}$ 的特徵值全為零，但它作用於 $(0,1)^T$ 的輸出 $2$ 範數是 $100$。特徵值描述特定代數性質，算子範數則檢查所有單位輸入的最大輸出，兩者不能無條件互換。

第四，非正交座標下的巨大係數可能源於抵銷。應先問誤差量的是幾何向量、原始讀值，還是反求的座標。第五，帶單位的不同分量不得直接相加後把所得「長度」當作天然物理量；尺度與權重是模型的一部分，須公開記錄。最後，算子範數界是充分的上界，不是由觀察到一次較小輸出就能反推出矩陣範數也小；最壞方向可能尚未被觀察到。

## AI、幾何與養殖案例

考慮一組**合成**感測讀值：溫度變化 $\delta T$ 以攝氏度的差值記錄，溶氧變化 $\delta C$ 以 $\mathrm{mg/L}$ 記錄。兩者不能直接組成有物理唯一性的 $\sqrt{(\delta T)^2+(\delta C)^2}$。若為演示而選定尺度 $s_T=1\,^\circ\mathrm C$、$s_C=2\,\mathrm{mg/L}$，可定義無因次輸入
$z=(\delta T/s_T,\delta C/s_C)^T$。假設另一個合成的無因次雙輸出模型為
$w=Az$，其中 $A$ 採例一的矩陣，則
$\|\delta w\|_\infty\leq3\|\delta z\|_\infty$。例如輸入無因次擾動的兩個分量絕對值皆不超過百分之一，模型便給出輸出無因次無窮範數不超過百分之三；這仍只是一項依模型與尺度成立的界，不是對現場儀器精度的宣告。

要返回原單位，必須再以各輸出預先聲明的尺度乘回；若模型直接寫於有因次座標，其矩陣元素的單位便是「輸出單位／輸入單位」。改變尺度會改變矩陣數值與所報告的無權重條件數，所以報告必須連同尺度一起保存。在幾何或 AI 的局部線性近似中，矩陣亦可描述輸入擾動如何傳播。但本章的結論只針對所指定的線性映射或已另行論證的近似有效範圍；不能只見到一次算子範數計算，就保證非線性系統在所有狀態的行為。合成養殖資料既非現場校準，也非操作安全證據；自動化代理可唯讀整理尺度、假設和誤差界，不應據此改動設備、投餌或加藥。

   $A=\begin{pmatrix}1&-2\\3&0\end{pmatrix}$ 求 $\|A\|_1$、$\|A\|_\infty$，並以無窮範數界住 $A(0.1,-0.1)^T$。
2. **程式。** 使用本章函式計算 $A=\begin{pmatrix}1&2\\-1&1\end{pmatrix}$ 的兩種誘導範數及 `finite_sign_check_inf(A)`。寫出預期值，並說明為何窮舉檢查不能代替一般證明。
3. **反例。** 有人聲稱「所有維度皆有 $\|x\|_1\leq10\|x\|_\infty$」。給出明確反例；再指出這是否否定固定有限維的範數等價。
4. **整合。** 令
   $B=\begin{pmatrix}1&1\\0&0.01\end{pmatrix}$、
   $c=(0,1)^T$，輸出擾動為 $\delta y=(0,0.001)^T$。求 $\|\delta y\|_\infty/\|Bc\|_\infty$、逆算後的相對座標誤差與 $\kappa_\infty(B)$。說明條件數界與實際結果的關係，並指出一項解讀非正交座標時必要的警告。

## 習題解答

1. $\|x\|_1=5$，$\|x\|_2=\sqrt{4+1+4}=3$，$\|x\|_\infty=2$。矩陣兩個縱行的絕對值和為 $4,2$，故 $\|A\|_1=4$；兩個橫列和為 $3,3$，故 $\|A\|_\infty=3$。擾動無窮範數為 $0.1$，故輸出上界為 $0.3$。直接乘得輸出 $(0.3,0.3)^T$，確實達界。
2. 兩個縱行的絕對值和分別為 $2,3$，故 $\|A\|_1=3$；兩個橫列和分別為 $3,2$，故 $\|A\|_\infty=3$，符號核對預期亦回傳 $3$。程式只檢查這個有限矩陣的有限組頂點；一般公式另須依定義與三角不等式推導。
3. 取 $\mathbb R^{11}$ 中全為 $1$ 的向量，即有 $\|x\|_1=11>10\|x\|_\infty=10$。這只否定「常數 $10$ 適用所有維度」；固定維度 $n$ 仍有 $\|x\|_1\leq n\|x\|_\infty$。
4. $Bc=(1,0.01)^T$，故輸出的相對擾動為 $0.001/1=0.001$。由例二的逆矩陣，$\delta c=(-0.1,0.1)^T$，而 $\|c\|_\infty=1$，相對座標誤差為 $0.1$。$\kappa_\infty(B)=2(101)=202$，其界為 $0.1\leq0.202$，不是實際誤差的等式。基底幾乎平行，座標誤差與幾何位移的長度必須分開陳述。

## 本章小結

範數先規定「大小」，距離再由向量差取得；誘導算子範數則把輸入大小與線性輸出大小連接起來。有限維範數等價保證固定維度下的收斂觀念一致，卻不消除比較常數的維度依賴。條件數提供可逆線性問題的最壞相對誤差界，解讀時必須保留所用範數、座標、尺度與問題方向。
