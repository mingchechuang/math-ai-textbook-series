2.  **Picard–Lindelöf 定理 (Thm 26.4)**
    *   定義 $X$ 為閉球上的連續函數空間，配 $\|\cdot\|_\infty$ 度量。完備性成立。
    *   $T$ 映射 $X \to X$：$\|Ty - y_0\| \le M \alpha \le b$。需 $\alpha \le b/M$。
    *   $T$ 壓縮：$\|Ty - Tz\| \le L \alpha \|y-z\|$。需 $L \alpha < 1$。
    *   $\alpha$ 定義：$\min(a, b/M, 1/(2L))$。確保 $\alpha \le b/M$ 且 $\alpha \le 1/(2L) < 1/L$。邏輯正確。
    *   邊界情況 $M=0, L=0$ 處理在 cases 中，邏輯自洽。
    *   **修正點**：局部唯一性證明中明確限制比較解 $\tilde{y}$ 落於閉球 $\overline{B(y_0,b)}$，這修正了先前可能遺漏的域限制，確保 $\tilde{y} \in X$。

5.  **習題 26.2 (程式)**
    *   **修正點**：重新計算 $y_1, \dots, y_{10}$ 的 Picard 迭代。
    *   真解 $y(t) = \frac{1}{2}(\sin t - \cos t) + \frac{1}{2}e^t$。
    *   $y_0 = 0$。
    *   $y_1 = \int_0^t \cos s ds = \sin t$。
    *   $y_2 = \int_0^t (\cos s + \sin s) ds = \sin t + (1 - \cos t) = \sin t + 1 - \cos t$。
    *   $y_3 = \int_0^t (\cos s + \sin s + 1 - \cos s) ds = \int_0^t (\sin s + 1) ds = (1 - \cos t) + t = t + 1 - \cos t$。
        *   原稿 $y_3 = t + 1 - \cos t$ 正確。先前審稿誤以為 $\sin t$ 會抵消，實為 $\int \cos = \sin$ 與 $\int \sin = -\cos$ 的疊代累積。
    *   $y_4 = \int_0^t (\cos s + t + 1 - \cos s) ds$ ... 等等，這裡要注意積分變數。
        *   $y_3(s) = s + 1 - \cos s$。
        *   $y_4 = \int_0^t (\cos s + s + 1 - \cos s) ds = \int_0^t (s + 1) ds = \frac{t^2}{2} + t$。
        *   原稿 $y_4 = t + \frac{t^2}{2}$ 正確。
    *   $y_5 = \int_0^t (\cos s + \frac{s^2}{2} + s) ds = \sin t + \frac{t^3}{6} + \frac{t^2}{2}$。
        *   解答中給出 $y_5 = \sin t + \frac{t^2}{2} + \frac{t^3}{6}$。正確。
    *   誤差計算：$e_n = y - y_n$。
        *   $y(1) \approx 1.5097$。
        *   $y_3(1) = 1 + 1 - \cos 1 \approx 2 - 0.5403 = 1.4597$。
        *   誤差 $\approx 1.5097 - 1.4597 = 0.05$。
        *   解答中給出 $0.05002756$，吻合。
    *   程式碼使用 `fractions.Fraction` 進行符號積分，避免浮點誤差，邏輯嚴謹。
    *   指出在 $[0,1]$ 上 $q=L\alpha=1$ 非嚴格壓縮，但利用階乘界證明收斂。此點數學上正確且深刻。
