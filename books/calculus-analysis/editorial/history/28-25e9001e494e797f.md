# 第28章 有界算子與有限／無限維的差別

## 學習目標與先備知識

讀完本章，應能指定線性算子的定義域、值域與範數，判斷「有界」究竟指哪一個不等式；證明線性算子有界等價於連續；並說明為何有限維中的熟悉結論不能直接搬到函數空間。讀者需要範數、線性映射、數列收斂與有限維緊緻性的基本知識。本章只建立進入泛函分析所需的幾條界線，**不等於已教完泛函分析**。

## 問題與直覺

矩陣把有限維列向量映成列向量。固定一個矩陣後，輸入足夠小，輸出也會小；矩陣的誘導範數能量化這種控制。可是「把函數微分」也是線性運算，卻可能把振幅極小、振盪極快的函數變成振幅不小的導函數。兩者並不矛盾：它們的定義域、範數及維度不同。

因此，閱讀「微分算子無界」時，第一個問題不是如何計算，而是：**以甚麼範數衡量輸入和輸出？** 「無界」也不表示每個輸入都產生無限大的輸出；它表示不存在一個對所有容許輸入通用的有限放大倍數。

## 定義、定理與推導

設 $X,Y$ 是實數賦範線性空間，$T:X\to Y$ 為**定義在整個 $X$ 上**的線性映射。稱 $T$ 為有界線性算子，是指存在有限常數 $C\geq0$，使每個 $x\in X$ 都滿足

$$
\|Tx\|_Y\leq C\|x\|_X.
$$

其算子範數定義為

$$
\|T\|_{X\to Y}
=\sup_{\|x\|_X\leq1}\|Tx\|_Y
=\sup_{x\ne0}\frac{\|Tx\|_Y}{\|x\|_X}.
$$

上確界容許為 $+\infty$；只有有限時，$T$ 才有界。這裏「有界」不是說集合 $\{Tx:x\in X\}$ 有界：例如恆等算子有界，但它在非零線性空間上的整體像通常無界。若算子只定義在某個線性子空間 $D\subset X$，應寫 $T:D\to Y$，並用 $D$ 所採用的範數計算上確界；不能暗中把定義域改成整個 $X$。

**小命題：** 對上述任意實數賦範線性空間 $X,Y$ 及線性映射 $T:X\to Y$，下列條件等價：① $T$ 有界；② $T$ 在零點連續；③ $T$ 在每一點連續。不要求 $X,Y$ 完備。

**證明。** 若①成立，對任意 $a,x\in X$，線性給出
$\|Tx-Ta\|_Y=\|T(x-a)\|_Y\leq C\|x-a\|_X$。因此 $T$ 在每一點連續，③成立；③顯然推出②。反過來，若 $T$ 在零點連續，取輸出容差 $1$，存在 $\delta>0$，使 $\|z\|_X<\delta$ 時 $\|Tz\|_Y<1$。對 $x\ne0$，令 $z=\delta x/(2\|x\|_X)$，則 $\|z\|_X=\delta/2<\delta$。由線性及範數齊次性，

$$
\|Tx\|_Y=\frac{2\|x\|_X}{\delta}\|Tz\|_Y
<\frac{2}{\delta}\|x\|_X.
$$

$x=0$ 時不等式也成立，故①成立。證畢。這是定理證明，而非從有限筆數值觀察作出的推測。

在 $\mathbb R^n$、$\mathbb R^m$ 各選一個範數後，每個線性映射 $A:\mathbb R^n\to\mathbb R^m$ 都有界。理由之一是有限維範數等價，再配合矩陣逐項估計；等價常數通常依賴維度與所選範數。以 Euclidean 範數為例，若 $A=(a_{ij})$，Cauchy–Schwarz 不等式給出

$$
\|Ax\|_2\leq
\left(\sum_{i=1}^{m}\sum_{j=1}^{n}a_{ij}^{\,2}\right)^{1/2}\|x\|_2.
$$

右方是可用的上界，未必等於真正的算子範數。固定大小矩陣有有限範數，並**不**保證大小不斷增加的一串矩陣具有共同上界。

範數的選擇在函數空間尤其關鍵。對區間 $[0,2\pi]$ 上的函數，記
$\|f\|_\infty=\sup_{x\in[0,2\pi]}|f(x)|$。考慮微分

$$
D:C^1([0,2\pi])\longrightarrow C([0,2\pi]),
\qquad Df=f'.
$$

若定義域採用由 $C([0,2\pi])$ 繼承的 $\|\cdot\|_\infty$，值域也採用 $\|\cdot\|_\infty$，則 $D$ 無界。這不妨礙它在每個個別 $C^1$ 函數上有定義。若改在定義域採用
$\|f\|_{C^1}=\|f\|_\infty+\|f'\|_\infty$，同一規則便滿足
$\|Df\|_\infty\leq\|f\|_{C^1}$，因而有界。兩種說法的算子規則相同，但賦範空間不同。前一種定義域在該範數下不完備，也不是無界結論成立的障礙；上面的小命題本來就沒有完備性假設。

有限維還有另一個容易誤用的性質：閉且有界的集合是緊緻的。無限維賦範空間一般不能照搬此結論。例如在 $C([0,2\pi])$ 的一致範數下，函數列 $f_n(x)=\sin(nx)$ 全部位於閉單位球，卻沒有一致收斂的子列。若某子列一致收斂，其極限必連續，且由 $\sin(nx)$ 在區間上的均方正交性可知，不同正整數 $m,n$ 滿足

$$
\int_0^{2\pi}|\sin(nx)-\sin(mx)|^2\,dx=2\pi.
$$

又因 $\int|u|^2\leq2\pi\|u\|_\infty^2$，兩項的一致範數距離至少為 $1$，故連一致 Cauchy 子列也不存在。這裏使用的是明確的一串函數，而不是「維度無限」四字本身當作證明。

## 逐步手算例題

**例一：固定矩陣的放大倍數。** 令
$A=\begin{pmatrix}2&0\\0&-3\end{pmatrix}$，輸入及輸出都使用 Euclidean 範數。對 $x=(x_1,x_2)^T$，

$$
\|Ax\|_2^2=4x_1^2+9x_2^2
\leq9(x_1^2+x_2^2)=9\|x\|_2^2.
$$

故 $\|A\|_{2\to2}\leq3$。代入 $e_2=(0,1)^T$，比值正好為 $3$，所以 $\|A\|_{2\to2}=3$。這既有上界，也有達到上界的輸入，不是僅試幾個向量所得的猜測。

**例二：高頻函數。** 令 $u_n(x)=\sin(nx)/n$，其中 $n$ 為正整數。在一致範數下，$\|u_n\|_\infty=1/n$，而 $Du_n(x)=\cos(nx)$、$\|Du_n\|_\infty=1$。因此

$$
\frac{\|Du_n\|_\infty}{\|u_n\|_\infty}=n.
$$

若存在通用有限常數 $C$ 使 $\|Df\|_\infty\leq C\|f\|_\infty$，便須對每個 $n$ 有 $n\leq C$，矛盾。注意 $u_n\to0$ 是一致收斂，但 $Du_n$ 不一致收斂至零；微分不能在此範數下任意穿過極限。

再用一個有限截斷看差別。令
$V_N=\operatorname{span}\{1,\sin x,\cos x,\ldots,\sin Nx,\cos Nx\}$。
微分把 $V_N$ 映回 $V_N$；每個固定 $N$ 都得到有限矩陣。若用係數的 Euclidean 範數，把 $\sin(kx),\cos(kx)$ 的係數排成一對，微分在該對上的區塊是
$\begin{pmatrix}0&k\\-k&0\end{pmatrix}$（排列不同只改符號位置），其範數為 $k$。整個截斷矩陣的算子範數便是 $N$。**每個 $N$ 有限**和**這些範數沒有共同有限上界**，是兩個不同命題；此處的係數範數亦不可不加說明地當作一致範數。

## 實作與程式

以下是自足的 NumPy CPU 範例。它建立上述係數空間的微分矩陣，另在網格上量測函數及導函數的一致範數近似。網格最大值只是數值證據；高頻無界性已由手算證明。程式不安裝套件、不使用 GPU；此處未執行，輸出均屬預期。

```python
import numpy as np


def derivative_matrix(N):
    """Basis: 1, sin(x), cos(x), ..., sin(Nx), cos(Nx)."""
    if not isinstance(N, int) or N < 0:
        raise ValueError("N must be a nonnegative integer")
    A = np.zeros((2 * N + 1, 2 * N + 1), dtype=float)
    for k in range(1, N + 1):
        s, c = 2 * k - 1, 2 * k
        A[c, s] = k       # (sin kx)' = k cos kx
        A[s, c] = -k      # (cos kx)' = -k sin kx
    return A


def sampled_amplitudes(n, points=4096):
    if not isinstance(n, int) or n < 1:
        raise ValueError("n must be a positive integer")
    if not isinstance(points, int) or points < 2:
        raise ValueError("points must be an integer at least 2")
    x = np.linspace(0.0, 2.0 * np.pi, points, endpoint=False)
    u = np.sin(n * x) / n
    du = np.cos(n * x)
    return float(np.max(np.abs(u))), float(np.max(np.abs(du)))


for N in (0, 1, 2, 8):
    A = derivative_matrix(N)
    print("N =", N, "shape =", A.shape,
          "coefficient operator norm =", np.linalg.norm(A, 2))

for n in (1, 2, 8):
    amp, derivative_amp = sampled_amplitudes(n)
    print("n =", n, "sampled amplitudes =", amp, derivative_amp)

try:
    derivative_matrix(-1)
except ValueError as exc:
    print("expected invalid-input error:", exc)
```

矩陣的形狀是 $(2N+1,2N+1)$；其橫列代表輸出係數，縱行代表輸入係數。程式中的一維陣列只儲存取樣值，不拿一維 `.T` 冒充列向量與橫列向量之間的轉置。

## 測試與預期結果

**正常測試（預期）：** $N=1,2,8$ 的係數算子範數依次為 $1,2,8$，容許浮點誤差。對 $n=1,2,8$，導函數在 $x=0$ 的取樣值絕對值恰為 $1$；函數振幅的網格估計不超過 $1/n$，可能因網格未命中峰值而略小。

**邊界測試（預期）：** $N=0$ 時只有常數基底，矩陣形狀為 $(1,1)$，唯一元素及算子範數都是零。這不表示完整函數空間的微分算子為零。

**故障測試（預期）：** `derivative_matrix(-1)` 明確拋出 `ValueError`，由示範程式捕捉。若網格點太少，取樣最大值也可能嚴重低估真實峰值；輸入檢查只處理格式，並不能把有限取樣提升成數學證明。

## 反例與常見陷阱

「線性」不是無條件的「連續」：有界等價於連續，但在無限維賦範空間，必須核對有界條件。對本章的 $D$，輸入 $u_n$ 一致趨零而輸出不一致趨零，直接顯示它在零點不連續。

「換個範數不影響結論」也只能在適當條件下說。固定有限維空間中的兩個範數等價；無限維函數空間的 $\|\cdot\|_\infty$ 與 $\|\cdot\|_{C^1}$ 並不等價。甚至使用同一個符號 $D$，一旦定義域範數變了，有界性就可能改變。

「閉且有界所以有最大值」缺少維度與緊緻性條件。有限維閉球緊緻，無限維閉單位球一般不緊緻；不能只憑閉、有界便引用極值定理。反過來，本章並未斷言無限維中一切集合都不緊緻，更未討論各種不同的緊算子概念。

## AI、幾何與養殖案例

在幾何計算或 AI 模型中，把一個連續訊號表示成前 $N$ 個頻率的係數列向量，是常見的有限化步驟。本章的截斷矩陣指出：即使每一版模型都能計算，求導步驟對係數誤差的最壞放大倍數仍會隨 $N$ 增長。若係數誤差的 Euclidean 範數最多是 $\varepsilon$，則固定 $N$ 時，導數係數誤差最多是 $N\varepsilon$；沒有對所有 $N$ 通用的這種上界。這是依模型與範數成立的推論，不是任意實際訊號的誤差保證。

以合成養殖感測序列為例，可把時間 $t$（單位秒）的水溫擾動寫作 $u_n(t)=a\sin(2\pi n t/T)/n$，其中 $a$ 的單位是攝氏度、$T$ 的單位是秒。擾動的最大幅度為 $a/n$ 攝氏度，但變化率的最大幅度是 $2\pi a/T$ 攝氏度每秒。小振幅不必然代表小變化率；求導前應交代時間尺度、量測誤差與所選函數範數。這只是合成模型，不是現場感測器的驗證，也不授權 agent 改動設備或操作設定。

## 習題

1. **手算。** 對 $B=\operatorname{diag}(1,-4,2)$，求 Euclidean 誘導算子範數，並給出達到它的單位列向量。
2. **程式。** 修改本章程式中的測試清單，加入 $N=3$ 與 $N=0$；寫出預期的矩陣形狀與係數算子範數，說明為何執行結果不能證明所有 $N$ 的公式。
3. **反例。** 有人聲稱：「若 $f_n\to0$ 一致收斂且每個 $f_n$ 可微，則 $f_n'\to0$ 一致收斂。」在 $[0,2\pi]$ 上構造反例，列出兩個一致範數。
4. **整合。** 考慮 $D:C^1([0,2\pi])\to C([0,2\pi])$。分別為定義域選用 $\|\cdot\|_\infty$ 及 $\|\cdot\|_{C^1}$，判斷有界性；再解釋為何 $V_5$ 上的微分矩陣有界並不推翻第一項判斷。

## 習題解答

1. 對任意 $x$，$\|Bx\|_2^2=x_1^2+16x_2^2+4x_3^2\leq16\|x\|_2^2$。取單位列向量 $e_2=(0,1,0)^T$，有 $\|Be_2\|_2=4$，故範數為 $4$。
2. $N=3$ 的預期形狀為 $(7,7)$、範數為 $3$；$N=0$ 的預期形狀為 $(1,1)$、範數為 $0$。有限次執行只覆蓋所試的輸入。對一般 $N$ 的結論須利用各個互不混合的二維區塊：第 $k$ 塊把係數 Euclidean 長度乘以 $k$，所以總長度至多乘以 $N$，而只在最高頻塊取非零係數即可達到 $N$；$N=0$ 另行處理。
3. 取 $f_n(x)=\sin(nx)/n$。每項可微，且 $\|f_n\|_\infty=1/n\to0$；但 $f_n'(x)=\cos(nx)$，$\|f_n'\|_\infty=1$，故導函數不一致收斂至零。
4. 採一致範數時，第三題的函數使輸出範數與輸入範數之比為 $n$，故無界。採 $C^1$ 範數時，對每個輸入都有 $\|Df\|_\infty\leq\|f\|_{C^1}$，故有界。$V_5$ 只含截至頻率 $5$ 的有限維函數，使用題定係數 Euclidean 範數時，矩陣範數為 $5$；它沒有控制任意高頻輸入，也不是在原來整個定義域上取得通用常數。

## 本章小結

有界性是「指定定義域範數、值域範數後，存在通用線性誤差界」的性質；對線性算子，它恰好等價於連續。固定有限維矩陣必有界，但有限截斷的一串範數可以不一致有界。微分的高頻例子與閉單位球的非緊緻例子，指出從有限維走向函數空間時，必須重新查驗範數、極限與緊緻性假設。
